## 1. 实现与拒绝边界

现有参考在相机运动与稠密运动间逐像素选择供体；空间接缝和供体切换可能造成时序不稳定。本轮在已经准入的观测供体之间增加固定空间/时间代价，仍要求不同真实帧的支持、可见上下文、遮挡排除及完整双线性采样足迹。前帧修复结果只能影响代价，不能变成新观测。

v1 的羽化输出先验在双表面及床面退步。v2 换成实际供体颜色历史、活动矩形和可见预测拒绝检查；双表面总分改善，但上表面退步。v3 再增加可见运动残差分组和组内检查；分组无法证明隐藏物体的真实几何，最终仍退步。[契约与固定参数](../specs/空间与时序一致参考选择研究契约_v0.1_2026-10-18.md)、[最终内核](../../research/temporal-background/coherent_reference.py)、[直接检查](../../research/temporal-background/test_coherent_reference.py)。

源码的 `crossvalidation` 表示可见上下文内的拒绝启发式；拟合、代价和检查共享观测，不能解释为独立交叉验证或不可见区域误差上界。ROI 棋盘奇偶、隐藏 RGB 扰动、实际供体历史、不同帧计数、极小双线性角点、组间隔离、预算先拒绝及取消均有直接检查。

所有七组均精确保留选区外 RGBA 和全帧 alpha。该边界也意味着：若对象腿部、反射或阴影不在选区中，算法不能替操作者修正该选区。局部参考选择与完整对象选择必须分别验收。

## 4. 测量后独立运动补偿诊断

[独立复核器](../../scripts/audit_coherent_reference.py)没有调用主实验的评分函数；重新从 NPZ 计算所有预定指标、不变量、改变像素及质量门槛，并在五组合成输入上增加已知真值运动的误差诊断。平移、双表面/切镜使用生成器的解析坐标；非刚性使用 8 次 Newton 反解，残差小于 1e-4。检查相邻选区的完整四角足迹，切镜跳过；用 OpenCV INTER_LINEAR 采样前帧重建误差。

## 6. 独立研究 CLI 与复现

运行需要显式提供已有的本地 Windows Python/NumPy/OpenCV，不自动安装包或下载。以下从项目根目录运行；`$researchPython` 替换为本机已有解释器，不表示发行环境自带这些库。输出目录必须尚不存在。

```powershell
$researchPython = 'D:/dev/comfyui/ComfyUI_windows_portable_nvidia_0_30_0/ComfyUI_windows_portable/python_embeded/python.exe'
& $researchPython -I -B -X utf8 scripts/run_coherent_reference_fixture.py `
  --input docs/assets/coherent-reference-20261018/elastic_exposure.npz `
  --output product/.runtime/coherent-reproduce --min-donors 2

& $researchPython -I -B -X utf8 scripts/run_coherent_reference_fixture.py `
  --input docs/assets/coherent-reference-20261018/two_motion_cut.npz `
  --output product/.runtime/coherent-cut-reproduce --min-donors 2 --scene-cut-frame 6
```

CLI 只读取 `source/forbidden/selected/fallback`，不读取 NPZ 内真值。两次成功执行（本地新输入及正式公开 NPZ）均与最终配对实验的 RGBA/贡献 mask 相同；一次预置取消返回退出码 2、`RESEARCH_CANCELLED`，没有生成结果文件。[实际命令/退出码](evidence/coherent-reference-20261018/cli-invocations.json)、[公开输入执行记录](evidence/coherent-reference-20261018/cli-public.json)、[取消记录](evidence/coherent-reference-20261018/cli-cancelled.json)。这是独立研究脚本，不是新增正式产品命令或模型适配器。

输入只支持有界本地 NPZ，拒绝远程 URI/UNC、pickle、错误 dtype/shape、压缩展开预算及非法参数；输出限定本工作区 `.runtime` 新目录。取消和超时在检查点生效，不是原生调用硬实时终止。当前自有数组估算 `WH×(256N+2048)`，实测上限 1536 MiB；最终进程峰值工作集 985128960 字节，Windows PeakPagefileUsage 1374101504 字节，均只覆盖诊断 Python 进程，不是系统总内存或所有子进程。默认页文件计数不表示实际磁盘写入量。

完整实验需要前序本地自然 NPZ；公开用户可复现 M01–M03 研究输入及候选。不能把仅可本地访问的自然输入称为可公开完整复现数据集。
