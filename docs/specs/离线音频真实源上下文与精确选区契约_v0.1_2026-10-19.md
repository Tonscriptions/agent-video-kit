# 离线音频真实源上下文与精确选区契约 v0.1

状态：V64 已接入主产品；9 项专项和开发版/离线安装版真实 CLI 音画对照通过，完整回归 1410/1410、2079.167 秒、0 跳过、196 输入冻结一致。V63 的 VACE 实测使用当时冻结的 V62 产品输入；本契约不改变该次模型运行。

目标：允许本地 R3 对短片段使用实际存在的相邻源音频作为分析上下文，再输出原作者选区。原有 `together/apart` 声道模式和默认无上下文行为保持明确；不以音高通过验收自然声音、相位或听感。

## 编号规则

| 编号 | 输入或行为 | 约束与证据要求 |
|---|---|---|
| AC64-01 | `settings.audio_stretch.source_context_ms` | 可选整数 0..1000，默认 0；布尔、小数、字符串、负数和超界拒绝；仍要求现有本地 R3、DLL、许可摘要 |
| AC64-02 | 源句柄 | 在 48 kHz 源采样坐标中，分别向前后扩展请求的长度，并夹到已探测的源时长；只使用真实采样，不循环、重复或补零。未登记有限时长时拒绝使用上下文 |
| AC64-03 | 时间图 | 作者原始 source/target 采样数不变。用首尾映射区间的有理斜率延长上下文，输出长度作最邻近整数采样取整；保留全部原内部锚点。新增上下文若不能表达为正输出采样则拒绝 |
| AC64-04 | 资源 | 扩展后的每份输入/输出 float32 PCM 仍须 ≤512 MiB、1..8 声道；不以原始短选区大小掩盖真实扩展成本。该门限不代表总进程 RAM、所有临时文件和任意长度性能通过 |
| AC64-05 | native 执行 | 对完整上下文执行一次 R3；原曲线整体平移，必要时传入严格递增时间图。无上下文仍保留既有 native 参数行为；上下文整体为精确恒比时可只使用该比率 |
| AC64-06 | 输出选区 | 从实际引擎输出的 `output_head_frames` 开始提取原 `target_frames`，仅复制 float32 PCM 字节并规范化 WAV。反向在裁好选区之后执行；片段起点、时长和其它时间线内容不变 |
| AC64-07 | 独立记录 | 保留请求毫秒数、实际源/输出前后句柄、decode 窗口、作者与扩展时间图、实际输入/原引擎输出/最终裁切 PCM 统计及摘要；缓存键包含上下文和实现版本 |
| AC64-08 | 严格失败 | 实际解码短于计划、引擎采样数/声道不符、非有限 PCM、取消、输入或依赖篡改和缓存冲突均保留原错误，不靠裁空、补零或覆盖旧缓存通过 |
| AC64-09 | 明确取舍 | 相邻源可能包含作者选区外的瞬态和声音；上下文只用于显式选择后的分析处理。`apart` 保独立频谱但可破坏反相相消；`together` 保相消也可能留下短窗频率偏差 |
| AC64-10 | 验收层次 | 产品命令/时间图、实际采样保留、受控 ±5 Hz 音高、反相相消、自然素材及听审分别验收；开发参数探针和隔离候选不得记为正式产品测试或剪映完整等价 |

原问题和原失败继续见 [R3 实测](../validation/离线音频伸缩与真实采样实测_2026-10-17.md)及[声道取舍](../validation/R3声道策略与立体声权衡实测_2026-10-17.md)。本轮真实 CLI 显示：64 ms 上下文配合 apart 可改善选定 4 ms→250 ms 双音与脉冲的频率；125 ms→250 ms 反相最大 `abs(L+R)` 仍为 0.00246022013，未达相消门槛。独立原生探针增加 together 上下文至 256/512 ms 也未修复右声道频率偏差。实际成片、完整回归与发行收据见[本轮实测](../validation/离线音频真实源上下文与短窗音高实测_2026-10-19.md)，开发探针和正式测试不叠加计数，不更改原来的质量门槛。
