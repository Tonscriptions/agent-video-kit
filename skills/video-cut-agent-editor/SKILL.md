# Video Cut Agent Editor

Use this skill when the requested edit should be represented as a reproducible local Agent Project rather than a GUI project. The implementation lives in `product/` in this project.

## Runtime boundary

- Use native Windows Python and the installed `ffmpeg.exe`/`ffprobe.exe` only.
- Set `PYTHONPATH` to the absolute `product/src` directory and invoke `python -m ai_ad_editor`; the repository wrapper also pins TEMP/TMP and Python/model caches to `product/.runtime/` on E drive.
- Keep the default network policy disabled. Do not call GUI automation, HTTP services, or any other closed/online provider.
- Do not start Docker, WSL, containers, or virtual machines. The `doctor` command only reports whether those executables are on PATH.
- Every publishable asset needs a Rights Ledger record with an allowed target use and evidence. Never use a template or `--yes` to bypass this gate.

## Workflow

1. Run `doctor` and fail clearly if FFmpeg/FFprobe is unavailable. Then read `capabilities` and choose only features whose status and limits fit the requested plan; `degraded` and `local_adapter_only` entries must remain visible in the response.
2. Create or inspect a project with `project init`/`project inspect`. For a known legacy Agent Project (`0.0.0`), run `project migrate` first; it hashes/probes only local assets, creates a `before-migrate` snapshot, validates the candidate, and writes a migration report. Unknown or higher schema versions must go through an explicit converter.
3. Ingest local files with `media ingest`; retain the returned asset ID and never invent a media hash. Use `media track --asset-id <id> --roi x,y,w,h` for explainable local template tracking; inspect confidence and drift warnings, and pass `--clip-id` only when the Agent wants a `before-track-apply` snapshot plus position keyframes written back.
4. Use `media understand` for local scene/silence/beat candidates. Add `--transcribe --model-path <existing-local-transformers-model>` only when an offline model has been registered; the command never downloads a model. Add `--srt <project-relative-path>` only when timed segments are returned. Use `media prepare` to make local proxies, thumbnails, and waveforms, and `media highlights` to write a hash-linked deterministic candidate report. Use `ad plan --input <brief.json>` to turn a local advertising brief into timed Hook/Problem/Benefit/Proof/Offer/CTA phases and marker operations before selecting assets. Use `subtitle validate`/`subtitle normalize` for SRT, VTT, ASS, and SSA before publishing captions. Use `tts synthesize --project <path> --text <ASCII/English text> --output <project WAV>` for the local FFmpeg flite voice baseline; inspect `doctor.data.checks.local_features.flite_tts` first and surface the `TTS_LOCALE_UNSUPPORTED` response for non-ASCII text instead of retrying through a network provider. Before writing an effect into a plan, call `effects list` or `effects inspect --name <id-or-alias>`; use the returned backend, parameter limits, and `keyframable` flag. The current catalog has 41 local FFmpeg effects; new native filters are static-only and must keep any keyframe approximation warning visible. For reusable color looks, run `lut register/list/inspect` to copy a local `.cube/.3dl/.csp/.dat` into the project, record SHA-256 and Rights Ledger evidence, then reference it as `{"type":"lut3d","parameters":{"lut_id":"lut_warm"}}`; a changed registered file is rejected by validation. Add `"intensity": 0.5` for a static partial-strength `.cube` look; the renderer writes a source-hash keyed identity-mixed LUT under the project `cache/luts/` directory, while `intensity=0` skips the LUT exactly. `.3dl/.csp/.dat` partial strength and intensity keyframes remain explicit degraded cases. Use `timeline compose` for explicit clip/track/marker changes and reusable motion presets, including split/ripple/slip/slide/speed/reverse/freeze operations; clip transforms accept normalized `transform.anchor.x/y` (or `anchor_x/anchor_y`, default `0.5`) and matching keyframes so an Agent can place a chosen layer corner or edge on a motion path; video-layer rotation compensates the expanded FFmpeg bounds to keep the anchor; independent text canvases still rotate around their canvas center, and nested parent pivots remain an explicit approximation warning; speed curves, nested sequences, static path/polygon masks, basic-shape mask.* keyframes, and normalized alpha feather are available with their reported approximation limits; clip changes may include validated rectangle/circle/ellipse `mask` objects and local FFmpeg `blend` modes. Adjacent clips may use `auto_handle: true` on a complex transition to invoke local xfade without manual overlap handles; the renderer preserves the authored duration with a visible tail-padding approximation warning. Use `template apply` or `template batch` only with a versioned local template and variable snapshot. Use `library index --root <local-dir> --output <catalog.json>` to build the v0.3.0 deterministic catalog, optionally pass `--previous <catalog.json> --incremental` to reuse stat-unchanged records and `--visual-hash` to add local FFmpeg `ahash-v1` samples; then use `library search --catalog <catalog.json>` for filename/relative-path/CJK-token/same-stem subtitle discovery and duration/dimensions/audio-stream filters, `library duplicates --catalog <catalog.json>` for exact SHA-256 duplicate groups, and `library similar --catalog <catalog.json>` for review-only visual candidates. The catalog declares `semantic.source=deterministic-local` and `vector_index=false`: do not describe this as VLM, OCR, embedding, person or object understanding, and never use visual candidates as a rights or publish decision. Feed selected records through Rights Ledger before publishing. Run `policy audit --project <path>` before a publish plan. For project-bound writes, pass a stable `--idempotency-key` when the caller may retry.
5. Run `validate`; the project validator includes the local Agent Project JSON Schema executor when `jsonschema` is installed and reports its engine. For a release or ad publish also run `rights check`, render with `--publish`, and finish with `quality check --require-audio` (add `--expensive` for black-frame/loudness scans). Use `quality scopes --project <path> --input <project-media> --at-seconds <seconds>` when an Agent or reviewer needs local waveform/vectorscope/histogram PNG evidence; read the [scope contract](../../docs/specs/本地色彩Scope审查契约_v0.1_2026-10-14.md) and treat these images as review artifacts rather than automatic color grading. Render may declare `--container mp4|webm|mkv`, local video/audio codecs, CRF or bitrates; preserve the resulting encoder settings in the manifest. For multiple output variants, write a project-local queue JSON and use `queue enqueue`, `queue list/inspect`, then `queue run`; the queue is a sequential local FFmpeg runner, failed/cancelled jobs require explicit `--job-id` retry, and `queue cancel` uses a project-local marker. Read the [queue contract](../../docs/specs/本地渲染队列与任务状态契约_v0.1_2026-10-14.md) before relying on state transitions.
6. Use `convert import/export` only through its conversion report. Export can target `agent-json`, `otio`, or `kdenlive-xml`; treat `Approximate`, `Baked`, `Unsupported`, and `Failed` as visible outcomes that require a decision.
7. Inspect the render manifest and probe the output before reporting success. If the renderer warns that keyframes, effects, transitions, or transforms are preserved but not executed, report that limitation. If a render is cancelled or fails, retain the returned `operation_id`; retry with `render --resume <operation_id>` only after the CLI accepts the unchanged project and asset fingerprints. This is a validated rebuild from the recorded plan, not a partial-frame checkpoint.

Agent calls should consume the JSON envelope and exit code. Keep a project-relative change set in a file so the operation is reviewable and repeatable.
