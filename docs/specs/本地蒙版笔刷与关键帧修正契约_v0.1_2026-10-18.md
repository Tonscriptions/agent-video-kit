# 本地蒙版笔刷与关键帧修正契约 v0.1

状态：正式实现，专项/实测与 1005 项完整回归已通过；针对已编码选区的可编辑修正，不构成自然修复或完整剪映验收。

`media mask-edit --project PATH --asset-id MASK --edits LOCAL.json --derived-asset-id NEW` 对已登记的图像/视频蒙版作显式本地修正。使用 Python 标准库和已有 FFmpeg；不加载模型、安装依赖、下载或启动浏览器/虚拟化。原素材与原分割结果不变，派生结果可以作为已有 `media inpaint --mask-asset-id NEW` 的输入。

编辑文件绑定实际输入 `asset_id/sha256/channel/width/height/fps/frames`。帧号使用零起点 CFR 显示时钟；不能把别的蒙版、缩放、范围或帧率的操作静默套入。视频默认使用源平均帧率，也可显式 `--fps` 重采样；显示旋转/SAR 与既有 `quality mask` 保持一致。图像只含一帧、编辑时钟为 1 fps；视频输出精确 CFR。所有操作范围为 `[start_frame,end_frame)`，关键帧必须从操作起点开始。

文件结构为 `version:1.0.0`、`coordinate_space:normalized-output`、`mask`、`scene_cut_frames`、`operations`，可选 `samples_per_axis:1|2|4`（默认 1）。`mask` 的 fps 为可精确表示的有理数字符串，约分后的分子/分母须能由原生编码器有符号 32 位整数表示；宽、高、帧数为整数，channel 为 alpha/luma。位置/羽化/透明度允许有限小数，不接受 bool 冒充数字。最多 512 KiB、64 操作、总计 1024 关键帧与 16384 个控制点；重复 JSON 键、NaN/Infinity、未知字段、重复操作 ID、越界帧或非法形状拒绝。

每项操作含 `id/mode/type/start_frame/end_frame/interpolation/keyframes`；可选 `feather_pixels`（0..64，默认 0）和 `opacity`（0..1，默认 1）。mode 为 add/subtract/intersect/replace；type 为 rectangle/ellipse/polygon/brush。框关键帧使用 `frame,box:[left,top,right,bottom]`；polygon 使用 `frame,points:[[x,y],...]`，至少三点；brush 使用 `frame,points,radius_pixels`，至少一点，半径为输出像素。所有位置在 0..1；宽高正值，笔刷在画布边缘裁切。

关键帧采用 linear 或 hold。linear 对对应顶点、框边界及笔刷半径插值，须固定点数；hold 允许不同点数。末关键帧之后保持至操作结束。操作跨越显式切点时必须在切点有新关键帧；切点前保持上一段，不向下一场景插值。组号/形状不是对象身份，未执行光流或自动跟踪。

采样默认在像素中心；2×2/4×4 为固定格子覆盖平均。polygon 使用 even-odd 填充，brush 为线段胶囊并集。羽化只向形状内部衰减：矩形/多边形/笔刷按边界距离，椭圆按归一化半径乘短轴的近似距离；不宣称椭圆精确欧氏距离。coverage 乘 opacity 后以四舍五入量化到 0..255。

操作按数组顺序执行模糊集合：add=max(base,coverage)，subtract=min(base,255−coverage)，intersect=min(base,coverage)，replace=coverage。add/subtract 不改变形状零覆盖处；intersect/replace 可改变全画布，必须显式选择。结果 RGB 固定为白色，alpha 为编辑覆盖；不是源 RGB 保真工具。未涉及帧的 alpha 保留原解码值；输入图像/视频的原 RGB 与音频不进入蒙版输出。

执行预估临时原始存储 `5×W×H×N`、自有像素缓冲 `12×W×H` 和形状/采样工作量；默认分别为 512 MiB、256 MiB 和 2 亿估算单元，支持显式有界提高。预算不包括 FFmpeg、Python 对象/解释器、编码文件和系统总 RAM。逐帧、栅格行和原生进程检查取消/超时；解码/编码失败或输入摘要变化时不提交派生资产。输出为图像 PNG 或视频 QTRLE/ARGB MOV；MOV 的视频 time scale 显式设为帧率分子，使分数帧率逐帧精确且声明完整末帧区间，便于已有修复入口消费。NUT 的 format.duration 只到末帧 PTS，不能直接当该区间的覆盖时长。必须核对全部编码 RGBA 哈希、帧数、PTS、几何和无音频。

完整编辑计划嵌入派生资产的 source 元数据，并进入报告、快照和工程包；可用 `--edits-from-asset EDITED` 替代 `--edits FILE` 重建同一绑定源的新版本，两者严格互斥。复用时检查引擎、规范化计划摘要与权利依赖；更改形状须提供新计划，不能覆盖已登记版本。派生权利依赖原蒙版，复用计划另依赖原编辑资产，不能提升许可状态。项目写锁、元数据事务、幂等、失败清理与原生发布无覆盖语义沿用现有产品。项目锁沿用退出码 6，取消/超时退出码 8；参数/预算错误退出码 2。命令不自动入轨或生成修复视频；用户可以显式把新蒙版交给修复/跟踪入口。

验收需包含独立几何参考和实际编码像素：正负布尔顺序、软覆盖/透明度、brush 单点/胶囊、polygon/框/椭圆、变点数 hold、线性关键帧、切镜、边缘裁切、不涉及帧保真、alpha/luma、分数帧率/原始显示时钟、预算/取消/篡改/回滚/幂等/权利依赖、工程包重建。公开原输入/成片/GIF 必须原创或已有发布授权。自然漏选的明确检查点可以证明指定像素修正，不能证明完整对象或修复纹理/时序达到剪映。
