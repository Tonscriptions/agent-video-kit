## 输入与时钟

`subtitle segment --project <目录> --input <本地文件> --output <新的项目内 JSON>`
接受 SRT/VTT/ASS/SSA/TTML、已有 ASR `segments` 或 `transcription.segments` 报告、
以及 `format=agent-subtitle-source-v1` 的 JSON。后一种结构包含项目一致的
`ticks_per_second` 和有序 `lines`；每行包含唯一 `id`、`text`、`start_tick`、
`end_tick`，可选 `translation` 和 `marks=[{index,start_tick}]`。

所有公开字符索引均为 Unicode 码点，不是 UTF-16 单元或 UTF-8 字节。标记是原文中
字符的起始时间，必须按字符和时间严格递增、位于行内。没有标记时按上游权重分配
行时长，明确报告 estimated；有标记时仍只证明给定起点，词内部时间仍由算法估算，
不得称为逐字强制对齐。绝对 tick 使用 Python 整数；Node 只计算行内相对毫秒。

原句、标点、字符范围和标记保留在报告中。显示时才按上游字幕惯例裁去部分 CJK
尾部标点；不得修改原始逐字稿、伪造 ASR 或静默删除内容。原句时钟不得重叠。
分段量化不能产生正时长时必须拒绝，不能向原句之外延长。

## 本地算法

固定复用 OpenFilm `b138595d4c2d1fa5262b4a8a8c7cd98187c4b077` 的
`subtitle-segments.mjs` 原始字节，随包保留 MIT 原文。使用本机 Node >=22.2，
通过固定 JSON stdin/stdout worker 调用；没有 npm/npx、依赖安装、GUI、浏览器、
服务商或网络请求。执行前核验算法摘要，移除继承的 Node 注入选项，禁止 shell
wrapper。缺少 Node、算法变化、预算/超时、非法结果应明确失败。

规则沿用上游 camelCase 名称，允许有界覆盖宽度、阅读时长、停顿、权重和分段代价。
按句、分句、暂停和最小代价切分；保护英语词、缩写、数字单位、括号和混排术语。
不可拆的长词可能超宽，短原句可能小于最短阅读时间，必须报告而不是拆坏或扩时。
Intl/ICU 版本记录在输出；跨 ICU 版本不承诺相同中文词边界。

## 翻译与纠正

翻译必须由输入明确提供，不进行模型翻译或远程调用。算法按原文的分段时钟切分
给定译文；不适合切开的译文可跨数段共享，报告共享字符范围。这是启发式文本对齐，
不是翻译质量或语义准确性的证明。`--mode original|translation|bilingual` 决定输出；
后两者要求每行提供非空译文，翻译模式合并相邻共享译文，避免重复闪现。

`--corrections <JSON>` 格式为 `{expected_input_sha256, edits:[{line_id,part,text,target}]}`；
`target` 默认为 text，也可为 translation。摘要绑定本次输入原始字节；part 始终指向
本次纠正前的分段。相同/重叠范围拒绝；多段改动按原范围从右向左应用，再重新分段。
正文中未改动的标记保留绝对时间，改动范围内部的标记合并为一个起点，不能冒充重新
识别。删除片段的空白和尾部标点按上游 replacePiece 约定处理，记录前后原句。

## 应用、权利与事务

`--apply --track-id <subtitle轨道>` 生成独立文字片段；可使用 `--sequence-id`、
`--timeline-start-tick`、`--font-asset-id` 和显式 `--replace-track`。默认拒绝覆盖既有
片段和锁定轨道；格式、范围、字体、项目或权利依赖不合法时不能部分写入。
`--source-asset-id` 可重复声明本地来源权利依赖，执行时核验源文件与台账摘要。

正式执行登记报告 generated 资产和 SRT subtitle 资产，片段依赖生成字幕的权利记录。
新增文本/译文默认未核验，仅内部使用；来源已核验不自动证明新文字的版权。
复核后由现有 Rights Ledger 流程修改。应用创建 before 快照、操作与 provenance，
使用项目原生写锁、跨文件事务和幂等键。失败清理本轮新文件，任何已有文件不覆盖。
dry-run 可运行纯规划但不写报告、字幕、资产、操作或项目。

## 验收

需要原始上游测试及固定数据对照、Unicode/大 tick/规则/错误/预算专项、真实 CLI
dry-run 与应用、双语/局部回写、幂等/锁定/冲突/回滚/权利门禁、完整产品回归和离线
wheel 打包。真实中文本地 ASR 与人工给定标记分别标明来源，提供可公开原片和
字幕成片/GIF；未获公开权利的 ASR 音频保留在本地。记录连续播放、听审、抽帧和
自动核验的实际范围。该模块不关闭说话人分离、强制对齐或完整剪映等价的需求。

## 参数与格式示例

| 参数 | 约定 |
|---|---|
| `--input` | 已有本地字幕、ASR JSON、源 JSON 或本命令已有报告；绑定原始文件 SHA |
| `--output` / `--srt` | 新的项目 `assets/` 内 JSON / SRT；SRT 默认与 JSON 同名，均不得覆盖 |
| `--rules` | 本地 JSON；沿用上游 camelCase，摘要进入幂等指纹 |
| `--corrections` | 本地纠正 JSON；摘要进入幂等指纹，`part` 从 0 起 |
| `--expected-input-sha256` | 可选；显式绑定预览时的源文件原字节 |
| `--mode` | original（默认）、translation、bilingual |
| `--source-asset-id` | 可重复；继承来源资产的权利依赖，不授予新文字公开许可 |
| `--apply` / `--track-id` | 显式写入 subtitle 轨道；未 apply 仍登记 JSON/SRT 资产 |
| `--sequence-id` / `--font-asset-id` | 选定序列和已登记的本地字体；仅 apply 可用 |
| `--timeline-start-tick` | 非负项目 tick 偏移；只偏移显示 cue/SRT/片段，不改变报告原始行时钟；仅 apply 可用 |
| `--replace-track` | 显式清空目标字幕轨道再写入；仅 apply 可用，不解除轨道锁定 |
| `--dry-run` / `--idempotency-key` | 沿用通用 CLI；预览不落盘，重放绑定输入/规则/纠正字节 |

```json
{
  "format": "agent-subtitle-source-v1",
  "ticks_per_second": 90000,
  "lines": [{
    "id": "line_1", "text": "本地剪輯，免費開源，字幕清楚。",
    "start_tick": 45000, "end_tick": 495000,
    "translation": "Local editing. Free and open source. Clear captions.",
    "marks": [{"index": 0, "start_tick": 45000}, {"index": 5, "start_tick": 180000}, {"index": 10, "start_tick": 337500}]
  }]
}
```

纠正示例中 `expected_input_sha256` 必须替换为完整 `sha256:<64hex>`。

```json
{
  "expected_input_sha256": "sha256:<本次输入原字节摘要>",
  "edits": [{"line_id": "line_1", "part": 0, "text": "本地字幕，", "target": "text"}]
}
```

源行 ID 为 1..128 位 ASCII 字母、数字、点、下划线或横线，必须唯一。绝对 tick
限制在非负有符号 64 位整数；每行最长 24 小时，原句必须严格有序且不重叠。输入或
配置最多 8 MiB，1..10,000 行，单行原文/译文各最多 2,000 码点，总量 100,000 码点。
保守工作量 `Σ(text_len² + text_len × translation_len²)` 上限 25,000,000；纠正文字
也在启动 worker 前预算。超限必须由调用方显式分批，不能静默截断。

输出格式为 `agent-subtitle-segments-v1`，包括 `source`、纠正时的 `original_source`、
`rules`、`pieces`、`corrections`、算法提交/摘要/Node/ICU/Unicode 版本，以及明确的
`timing_basis`、警告和显示 cue。`pieces` 使用源行绝对 tick；`display_cues` 包含显式
入轨偏移。上游权重可能缩短显示尾部，源原句的完整结束时间仍保留，不能把两者混为一谈。

## 能力与发行边界

ASS/SSA/TTML 输入在本命令中提取纯文字及时间，原样式、动画、外部字体回退和排版
不会迁移。ASR 的非空 words/marks 结构必须先显式转换为上述码点/tick 源格式，本命令
拒绝静默丢弃逐字证据。共享译文是启发式对齐，双语模式仍可能在相邻原文段显示同一译文。

worker 的 30 秒时限和 128 MiB V8 旧生代堆上限不是操作系统总 RSS 的限制或性能承诺。
算法保持原字节，Python 负责整数时钟、输入读取锁、资源预算和结果验证；不会启动浏览器。
当前 wheel 使用已有本地 Node/FFmpeg，不捆绑模型或其他运行依赖；完整项目 Schema
尚未随 wheel 分发，仓库外使用已声明的内置语义校验回退，此发行缺口单独保留。
