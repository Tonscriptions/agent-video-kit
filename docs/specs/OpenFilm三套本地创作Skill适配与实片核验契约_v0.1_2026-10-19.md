# OpenFilm 三套本地创作 Skill 适配与实片核验契约

V61 Agent 工作流适配增量，依据 [15 步映射](../OpenFilm创作流程本地适配设计_2026-10-19.md)及固定 OpenFilm `7a64d1f`。目标是让 Agent 使用现有本地编辑内核完成三类创作任务，减少重复组织素材、作者时钟和审片流程。不是增加第二套时间线、GUI、云生成路由或用说明文件替代未实现的 AI 内核。

| 编号 | 要求与核验 |
|---|---|
| G61-01 | 三个规范入口分别命名 `video-cut-reference-remake`、`video-cut-long-to-short`、`video-cut-screen-demo`，按请求选取；规范文件位于 E 盘仓库 `skills/`，本地发现入口使用同名 junction。移植上游创作要求时保留固定来源和 MIT notice，不分发封面或在线 provider |
| G61-02 | 所有生产输入必须是本地素材及已登记资源；既有 CLI 承担 ingest、compose/edit、字幕、运镜、render、权利和质量门禁。使用已有原生 Windows Python/FFmpeg；不启动 Docker/WSL、虚拟环境或其它用户服务，不下载运行时或权重 |
| G61-03 | 参考片重建先记录复刻目标、源/目标画布和整数 tick 锚点；原参考留在参考区，不直接加入正式素材图。Agent 依据画面组织独立生产素材/字卡/关键帧。同时间点分别检查切点、构图、动作和实际像素；内容替换时不把像素不相等认作风格失败，不保证未经实测的精确复刻 |
| G61-04 | 长转短保留原文否定、条件、问答和指代关系。保存每条成片的源区间、原文、首句、选择理由和未确认词。先有转写/明确原文与源时钟，再决定片段；镜头/静音/能量高光仅作候选。已有 ASR/字词定位失败不得通过重新命名 Skill 宣称解决 |
| G61-05 | 录屏演示使用真实发生的操作和结果；区分用户提供锚点、跟踪观测与 Agent 推测。将明确锚点编排为可编辑缩放/平移及标注，等待删减和加速要说明。不得把重新绘制的界面称为真实录屏，也不把通用目标跟踪称为 UI OCR/点击识别 |
| G61-06 | 每套实际运行至少一组原生 CLI 编辑链，保存原输入、计划、命令/输出、实际成片、可编辑工程和失败。录屏核验若使用原创受控网页，应由真实页面动作产生状态并捕获画面，明确它是测试应用，不冒充视频编辑器 GUI 或自然商业录屏 |
| G61-07 | 验证作者源区间/切点和逐帧 PTS；独立解码检查变换锚点或原帧身份；音频按各自源区间的 PCM 参考核对。文字字形、重复用例及采用同一渲染器的参考另列，不用同一实现的回放冒充独立图像质量基准 |
| G61-08 | 同步保留 dry-run 与实际应用，拒绝案例检查工程摘要未变。复刻的参考不得隐含成为交付资产；长转短不能无提示拼接被切掉的限定语；演示中的等待/变速不能作为真实产品耗时。技能文案和执行报告均应揭示这些限制 |
| G61-09 | 公开素材须有实际来源/许可范围。原创画面、文本、测试页面及可授权资源可发布；未完成输出许可核对的语音留在本机并保留商业门禁拒绝，不将其登记成已验证 CC0。可发布无音 GIF 展示技术画面，同时明确它不证明听感或完整原视频交付 |
| G61-10 | 每个 Skill 按 skill-creator 校验描述、名称和未完成占位符，核对本地文档引用及真实加载目录。入口要支持 Agent 创作判断，引用既有内核限制；不机械固定镜头数，不硬编码本机验收目录为生产路径，不默认扩大联网或外部写入权限 |
| G61-11 | 本轮如不修改产品/测试/Schema/离线包代码，则 188 个 V60 冻结输入前后相等，并明确沿用已完成的 1374/1374 回归，不为 Skill 文档重复跑完整套件或把新命令调用加为单元测试数。若修改产品则另立当前完整回归和发行核验 |
| G61-12 | 若使用原生浏览器捕获受控测试页，禁止远程请求，结束必须关闭自建页面、浏览器和子进程；保留生命周期证据，不触碰其它用户窗口。README、进度、Skill 清单、安装清单与实测报告同步更新，普通提交/推送 main |
| G61-13 | 第二版技术检查后的静帧复核发现长句默认字号出框、持续放大裁掉结果状态；保留第二版原始技术通过收据及观察。后续复测以显式安全字幕字号/位置修正，并在每个动作后回到完整源画面展示结果；逐帧字幕边缘、每次回全景 RGB 与再次静帧复核通过后再登记 Skill。此项为观察后补充，不能回写成首轮已满足 |

三套工作流的技术串联通过不能证明自动语义选择、逐词声学精度、任意参考片重建、讲话人识别、UI OCR/点击恢复、隐私全发现、自然审美/听感、长片性能或完整剪映功能和效果等价。这些仍属于完整产品目标，分别保留未完成项与质量门槛。
