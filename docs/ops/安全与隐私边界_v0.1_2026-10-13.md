| 项目 | 内容 |
|---|---|

| 状态 | 评审中 |

| 目标 | 保护本地素材、项目、许可证证据和 Agent 执行环境 |

视频素材可能包含人脸、声音、地址、屏幕内容、未发布产品和客户数据。系统默认按敏感本地数据处理，不因为“只是剪辑文件”而降低权限要求。

## 1. 信任边界

| 区域 | 默认信任 | 访问规则 |
|---|---|---|
| 项目规范文件、锁文件、操作日志 | 项目写入器 | 原子写入，保留快照和哈希 |
| 用户素材 | 不可信输入 | 只读探测，限制路径、大小、格式和解码资源 |
| 模板/效果包/插件 | 未验证输入 | 验证来源、哈希、许可证和 manifest 后加载 |
| AI 模型与权重 | 受供应链约束 | 锁定 revision/哈希，不允许模型脚本任意写盘或联网 |
| 外部项目与元数据 | 不可信结构化输入 | 解析隔离、字段限长、拒绝未知危险协议 |
| Agent 指令/brief | 可能含提示注入 | 把媒体元数据与系统指令分层，不允许素材文本改变权限策略 |

## 2. 必须防护的风险

- 路径穿越、符号链接逃逸、命令注入、恶意文件名和未校验环境变量；
- 解码器漏洞、压缩炸弹、超长/超高分辨率文件、无限循环项目和递归嵌套；
- 未授权网络访问、模型/素材下载投毒、哈希不一致和许可证证据篡改；
- 日志泄露本地路径、令牌、客户文本、原始音频或人脸信息；
- 资产元数据、字幕或 OCR 内容包含提示注入，诱导 Agent 执行删除、联网或越权操作；
- 模板/插件偷偷覆盖项目、安装程序或调用 GUI/剪映客户端。

## 3. 默认策略

1. 默认 `--no-network`；网络操作必须显式配置、记录 URL、证书/响应摘要和文件哈希。
2. 子进程使用参数数组和受限环境，不通过 shell 拼接命令；输入路径只能位于项目根目录或用户明确授权目录。
3. 媒体分析设置最大文件大小、最大分辨率、最大时长、最大递归深度和超时；超过限制返回结构化错误。
4. 令牌、Cookie、客户素材和人脸/声音样本不得写入普通日志；日志只记录引用 ID 和摘要哈希。
5. 默认最小权限运行，不修改系统目录、不自动安装驱动、不关闭安全软件、不执行 Docker/WSL/容器或虚拟化环境。
6. 权利证据和发布门禁不能被 `--yes`、模板变量或 Agent 文本跳过。

## 4. 审计事件

以下事件必须进入操作审计：读取/写入项目、下载、模型加载、插件加载、网络访问、Rights Ledger 状态变化、转换丢失、渲染发布、取消、失败重试和人工批准。每条事件含时间、操作 ID、主体、资产/项目 ID、动作、结果和证据引用。

## 5. 安全验收

P0 交付前至少验证：路径越权被拒绝、恶意/损坏媒体超时退出、无网络模式无外连、未验证资产被发布阻断、插件哈希不符被拒绝、日志不包含秘密、取消任务清理子进程、迁移失败不覆盖原项目。每个失败都要保留退出码和复现输入。
