# 命名音频总线、发送/返回与侧链实测

V55 产品验证，2026-10-18。**本轮增加原生本地音频路由内核，未接受完整剪映等价。** 代码与运行均在 E 盘，没有 Docker/WSL、虚拟环境、模型调用或生产联网。OpenFilm R04/V54 的源码研究与 73 项 HTML 定向继续另计。

## 实际功能与边界

作者字段为 `sequence.audio_routing`，由现有 `timeline compose` 事务写入。命名 bus 支持多级输出、共享效果返回、pre/post-fader 发送、轨道/bus/master 音量与声像自动化、发送增益自动化，以及指定轨道或 bus 的侧链。节点以 48 kHz 双声道浮点求和，不按输入数归一化，不自动限制峰值。

效果在前，pre_fader 在本节点音量/声像之前，post_fader 在其后；这是显式开启新字段后的处理顺序，会改变旧链音量位于效果前的行为，迁移须听审。mute 同时关闭 pre/post 与检测信号；solo 隔离选中通路，必要时用第二套完整检测上下文维持侧链状态。循环（包括 gain=0）、缺失引用、非法字段/自动化及工作配额在写入前拒绝。详见[先行契约](../specs/命名音频总线发送返回与侧链契约_v0.1_2026-10-18.md)。

路由子序列先完成全部声音处理，再由父容器裁切、反向、曲速、定格及输出窗口，多实例保留各自状态和时间；同一 FFmpeg graph 不产生作者伪资产或有损中间文件。片段组选择自动扩展到路由序列全部片段，跨项目重映射 track_id；原生 package 保留完整图，OTIO/MLT/明文草稿明确报告 Unsupported。碰撞换轨可复制线性路由，拒绝拆分命名检测源、轨道侧链或非线性音色状态。缩短序列须同时处理越界自动化点，不静默改写其时间。

## 真实失败保留

1. [首轮 25 项](evidence/audio-routing-20261018-v55/targeted-first.json)有 3 失败：重复行在数组长度门禁提前归错；两份未约束包长的侧链参考尾部截断。[原源码](evidence/audio-routing-20261018-v55/first-failure-source.zip)、[9 次本机分包探针](evidence/audio-routing-20261018-v55/sidechain-packet-probe-first.json)保留。无约束的同长输入输出 81,920..94,208 帧；两支均 `asetnsamples=1024:p=0` 后均为 96,000 帧，产品同步采用，未通过补零掩盖差异。
2. [第二轮 34 项](evidence/audio-routing-20261018-v55/targeted-second.json)有 1 失败/2 错误：背景超出缩短的序列、片段组响应路径取错、重排后的时长放不下夹具点。修正夹具布局/字段及有效时间范围；随后 [34 项](evidence/audio-routing-20261018-v55/targeted-third.json)、[35 项](evidence/audio-routing-20261018-v55/targeted-final.json)通过。当前 37 项另含策略与命名检测轨道候选回归。
3. 原演示[首轮](../assets/audio-routing-20261018-v55/failure.json)的 ID 重名被正确拒绝；[第二轮](../assets/audio-routing-20261018-v55-final/failure.json)遗漏容器起点，按 append 语义加到背景末尾，AR05 实际 4 秒，触发样本数检查。计划/调用/部分输出未覆盖。
4. [第一轮安装](evidence/audio-routing-native-install-20261018-v55/failure.json)错误使用渲染前摘要，漏计合法交付记录；修正取样位置。[第二轮安装](evidence/audio-routing-native-install-final-20261018-v55/failure.json)检出 `track:…/bus:…` 清单节点被识别成远程 URI。改为 `track/…/bus/…`，**没有放宽策略或增加 URI 豁免**，增加渲染后策略回归并中断旧全量重新冻结。
5. 历史[初始合集](../assets/audio-routing-real-20261018-v55/audio-routing-showcase.mp4)再拼接六份 AAC，多 29.333 ms；[复制 H264 的部分修复](../assets/audio-routing-real-20261018-v55/audio-routing-showcase-exact.mp4)留下 20.996 ms 视频起点，[失败记录](evidence/audio-routing-20261018-v55/media-finalize-first-failure.json)保留。最终用六份实际浮点母版一次编码音轨、视频 setpts 重置，精确核对 0..13 秒，没有调宽门槛。
6. 代码复核发现自动碰撞候选若是另一条命名检测轨道，会改变该检测信号；排除这类候选并增加独立回归，第二次主动[中断全量](evidence/audio-routing-20261018-v55/full-final-interruption.json)。后续 37 项、演示、发行与全量均使用新冻结，不将中断算通过。
