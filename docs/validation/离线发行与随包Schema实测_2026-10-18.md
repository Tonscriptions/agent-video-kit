[已测试发行 ZIP](../assets/offline-release-final-20261018/agent-video-kit-cp313-win_amd64.zip)为 **1,029,334 字节**，摘要 `sha256:4aa6ff1bfdc204a4d3e21a69edcf32a61fe042b5b8f974cd3bef08f020efc4e4`。它就是本轮实测的构建物，未另行构建一份替换。另存[发行清单](../assets/offline-release-final-20261018/release-manifest.json)和[安装回执](../assets/offline-release-final-20261018/install-receipt.json)；清单摘要为 `sha256:214e3c45ccd7409f9b3b79d0afde77a24fb90720d77af6821ccc7ebd4c55ac19`。摘要不是作者签名。

将 ZIP 解压到一个新的 E 盘目录。使用显式已有的原生 Windows CPython 3.13 x64 及其 pip；下面的解包位置和全新安装目标可以按本地目录修改，目标已存在则拒绝：

```powershell
C:\Python313\python.exe -I -B -X utf8 E:\dev\sandbox\avk-release\install.py --target E:\dev\sandbox\avk-installed --manifest-sha256 sha256:214e3c45ccd7409f9b3b79d0afde77a24fb90720d77af6821ccc7ebd4c55ac19 --dry-run
C:\Python313\python.exe -I -B -X utf8 E:\dev\sandbox\avk-release\install.py --target E:\dev\sandbox\avk-installed --manifest-sha256 sha256:214e3c45ccd7409f9b3b79d0afde77a24fb90720d77af6821ccc7ebd4c55ac19

C:\Python313\python.exe -I -S -B -X utf8 E:\dev\sandbox\avk-installed\run.py schema export --output E:\dev\sandbox\agent-project.schema.json
```

`run.py`/生成的 PowerShell 入口将核心依赖限定在安装目录并默认将缓存放在其 `runtime/`。FFmpeg/FFprobe 必须是明确已有的原生工具；可选的模型和 Node/Chromium 仍另行本地登记。所有生成输出和安装缓存均在 E，本轮没有全局 pip install 或对 C 盘安装依赖。依赖许可、源获取和 Python 3 日期适配见[第三方说明](../third-party/离线Python依赖与日期检查器许可说明_2026-10-18.md)。

## 开发失败和验收边界

首次日期负例在顶层写入了额外的 `created_at`，而正式位置在 `project.created_at`。原 [baseline](evidence/schema-release-baseline-20261018.json)保留，顶层调用不能证明日期格式覆盖；独立旧 wheel 的执行器/Schema 降级观察仍然有效。第一次 Schema 专项为 16 项中的 **5 失败、2 错误**，原[日志](evidence/offline-release-tests-20261018/offline-schema-targeted-dev1-20261018.log)保留；修正夹具层级、语义问题用例和既有 doctor 退出码预期后，16/16 通过。没有放宽日期判断或改 Schema 来通过。

首个 [dev1 安装样例](evidence/offline-release-real-dev1-20261018/verification.json)的文件/安装/画面检查通过，但沿用了每秒重复音频，前后 PCM 相同，不能区分一秒 source slip。本轮增强为非周期原创双声道源，再做完整正式样例；正式前后 PCM 摘要分别为 `da2a50bbac0c6c3ac25f14570d7c81d2a193f9ca4741bab0dbd85c50425029be`、`c15803d0128f327926c1c3285e1cf20161d0743d734539b6a551e087b0aa97d2`。两轮不累计为 180 帧验收。

随包合同及本机不同目录的独立安装已核验；另一台干净机器、其他 Python/ABI、升级覆盖和全部平台未验收。OpenFilm 当前复用结论另见[编号决策表](../OpenFilm当前复用决策_2026-10-18.md)，本轮研究没有新的上游源码变化。自然 AI/声音质量、复杂 HTML/字体、长片/HDR/资源、内容库和完整剪映功能/效果仍独立验收，不能由发行通过推断完成。

安装路径收尾复核发现原入口在拒绝 UNC 之前会进入 `Path.exists`；[阻断探测的原记录](evidence/offline-release-tests-20261018/pre-path-boundary.json)保留，未实际执行 SMB/DNS。现已在文件探测前统一拒绝 UNC、设备路径、URI 和映射网络盘，同时覆盖 bundle、安装目标、取消标记、构建输出和 wheel 库；两项新增测试包含入口拒绝和原生盘类型检查。首轮完整 **1081/1081，1707.75 秒、160 文件冻结**的[旧终态](evidence/offline-release-tests-20261018/pre-path-full.json)与[原日志](evidence/offline-release-tests-20261018/pre-path-full.log)保留，它早于该修正，不替代当前源码的完整回归。

目录联接检查随后改为从根到叶逐级 `stat(follow_symlinks=False)`，不在检查前调用会跟随链接的 `exists()`，并增加在进入后代前拒绝联接的测试。中途[复验记录](evidence/offline-release-tests-20261018/interrupted-pathguard-full.json)、[日志](evidence/offline-release-tests-20261018/interrupted-pathguard-full.log)及[仅终止所属运行树的原因](evidence/offline-release-tests-20261018/interrupted-pathguard-reason.json)保留；它没有完整终态，不计作通过。最终发行安装器与最终完整回归按同一冻结版本核对。
