当前是独立库层实验，使用已有 Float32 作者宿主和原生音频引擎，将高精度帧与作者音轨流式写入 FFV1/PCM MKV。默认 CLI `render`、preview、queue 和缓存尚未接入；完整剪映功能及效果等价仍未完成。

| 编号 | 约束 | 当前实现或验收边界 |
|---|---|---|
| FS-01 | 工程与入口 | 接收经过 Schema 验证的 Agent Project 和明确的 `FloatTimeline`；原作者工程不改写。当前没有新增公开 CLI 命令 |
| FS-02 | 浮点颜色 | 工作表面连续、straight RGBA Float32；D65 相对 RGB。交付须显式选择 BT.709 基色的 linear、sRGB 或 BT.709 camera OETF |
| FS-03 | 唯一整数边界 | 最后交付时 Float64 缩放、nearest-even 量化至16位。GBR(A) planar 顺序明确；alpha 独立，无隐式8位中间链 |
| FS-04 | 越界策略 | RGB 允许在工作表面为有限负值或大于1。整数交付默认拒绝；显式 `clip` 记录裁剪分量数。alpha 必须在0..1 |
| FS-05 | 写入背压 | 4个独立 bytes 分块、每块最多65,536字节；写线程不通过切片保留整帧。FFmpeg输入队列2帧；没有整片帧列表或全片 raw 临时视频 |
| FS-06 | 预算含义 | 表面尺寸沿用宿主预算；4分块仅是传输队列预算，不是总RSS或FFmpeg内部滤镜内存保证。超时范围0..3600秒 |
| FS-07 | 作者终点 | 视频使用 ceil(duration×fps) 帧；音频使用 ceil(duration×48000) 样本。两者终点分开记录，不用 `-shortest` 丢弃作者音频末尾 |
| FS-08 | 音频复用 | 使用现有原生音频时钟/混音器；保留音频叶子及嵌套容器、裁切、倒放、冻结、窗口和总线字段；不另建音频引擎 |
| FS-09 | 画面剥离 | 在深拷贝编译工程中剥离真实视觉叶子；嵌套视频轨转为同ID音频编译容器，保留order、mute及routing。消费内部合成黑视频，不解码这些视觉源 |
| FS-10 | 自动化 | 保留 `audio.*` 和现有合法别名 `volume`/`pan`；现有音量接口为线性幅值，不能把 `audio.volume_db` 当成既有受支持字段 |
| FS-11 | 音画绑定 | 音频计划绑定完整作者JSON SHA、序列ID及本地根目录；不允许把其它工程的音频计划与当前视频合成 |
| FS-12 | 输入稳定 | 编码前后验证已登记源、派生音频缓存、作者IR、FFmpeg和执行实现SHA。源变化不得替换最终输出 |
| FS-13 | 输出事务 | 仅支持已有目录下 `.mkv`。同目录独占 UUID 临时文件，验证后原子改名；覆盖须显式选择。失败只删除自有临时文件 |
| FS-14 | 进程生命周期 | 仅拥有自身创建的编码器和两个线程。取消/超时终止其子进程、等待写线程和stderr线程、清空队列；不停止其他任务的进程 |
| FS-15 | 有界诊断 | stderr最多保留2×65,536字节；结构化失败记录原生命令、PID、退出码、线程关闭及临时输出清理状态 |
| FS-16 | 实际精度 | 无损回读65,536码值及独立alpha；结合真实作者PCM测试倒放/冻结、分数终点。演示逐个检查全部编码帧和立体声样本，不用编码器成功代替效果核验 |
| FS-17 | 对照来源 | 剪辑演示像素使用上轮已独立校验且SHA固定的20帧参考；原片另用独立 source-over。明确区分复用历史参考与新算法对照 |
| FS-18 | 离线复现 | 从固定8-wheel本地源重新构建安装；比对全部产品资源和931份NumPy文件/许可，用 `-I -S` 重新运行媒体与专项；不复制宿主site-packages、不下载运行依赖 |
| FS-19 | 明确未连接 | 文件型本地音频stretch Job、源转场计划拒绝；宿主其它未接入效果沿用显式拒绝。H.264/10-bit最终编码器选择、完整render manifest/rights/queue/resume等仍需统一接入 |
| FS-20 | 发布与目标 | 完整回归、安装、README编号证据、17 Skills及索引字节通过后才普通推送；专项不累计成全量。自然素材、连续播放/试听、HDR/ICC/PQ/HLG、4K长片RSS和完整剪映效果仍须独立验收 |

当前实测、失败与复现见[核验报告](../validation/浮点视频流与作者音轨合成独立实测_2026-10-22.md)。本轮没有新增 OpenFilm 原码或云服务；既有 MIT 归属保留。
