## 2. 原输入、实际视频和 GIF

源 RGBA 是本轮脚本生成的 256×64、10 fps、12 帧 FFV1/BGRA，每行含全部 0–255 Alpha；每帧/行移动覆盖率并改变颜色。音频为本轮原创 48 kHz 双声道 float32。源帧 0–4 后插入四帧第 4 帧，再恢复源帧 5–11，形成 16 帧复合定格。算法真值仅使用原像素/样本和此帧列表，不调用产品时间映射函数。

## 4. 音画 gate 的正负控制

检查用作者整数 tick 及有理帧率推导预期视频/音频结束；记录原始时长差、开始差、末端差及扣除可解释量化后的剩余误差。只要真实开始/末端偏移任意一项超过原上限，就拒绝。共同整体偏移也不能隐藏在相同开始时间里。Matroska DURATION 标签表示流末端，必须减去流开始得到时长；未知或损坏标签保持未核验警告，不伪造为容器总时长。

| 编号 | 素材 / 条件 | 当前剩余误差 | 当前 CLI / V51 对照 |
|---|---|---|---|
| N01 | DP09，明确绑定 root D=4.01s | 接近 0；原始 90 ms 仍保留 | render /quality check /golden capture /verify 均通过；V51 render 退出 6 |
| N02 | DP09，省略 `--sequence-id`，作者 D 未知 | 90 ms，不猜量化豁免 | 退出 2；保持原严格行为 |
| N03 | [音频延后 120 ms](../assets/delivery-precision-20261018/negative-delayed.mp4) | 119.333 ms | 退出 2；同一文件 V51 **错误通过**，原时长差仅 68.667 ms |
| N04 | [音频提前 120 ms](../assets/delivery-precision-20261018/negative-advanced.mp4) | 120 ms | 退出 2 |
| N05 | [音频只到 3.8 秒](../assets/delivery-precision-20261018/negative-short.mp4) | 210 ms | 退出 2 |
| N06 | [音频长到 4.3 秒](../assets/delivery-precision-20261018/negative-long.mp4) | 290 ms | 退出 2，同时触发整体时长不符 |
| N07 | [两流共同延后 120 ms](../assets/delivery-precision-20261018/negative-both-shifted.mp4) | 120.02 ms | 退出 2；同一文件 V51 **错误通过** |

这些是流时钟控制，不能检测时长/PTS 正确但内容口型错位的音轨。黑帧、响度、true peak 与实际声音听审仍分别执行，不因结构通过而自动获得结论。

## 5. Agent 的实际调用方式

```powershell
python -X utf8 -m ai_ad_editor render --project <工程> --output <工程>/renders/alpha.webm --container webm --video-codec libvpx-vp9 --audio-codec libopus --pixel-format yuva420p --crf 0 --publish
python -X utf8 -m ai_ad_editor quality check --project <工程> --input <工程>/renders/output.mp4 --sequence-id <序列ID> --require-audio
```

VP9 `CRF=0` 且没有显式视频码率覆盖才启用 `-lossless 1`；RGB→YUV 4:2:0 仍有色彩/色度损失，manifest 明确 `rgba_lossless=false`。默认 CRF=18、其它非零 CRF、VP8 或显式码率均不能承诺 Alpha 无损。解码 WebM 的 Alpha 应在 `-i` 前显式 `-c:v libvpx-vp9` / `libvpx`；素材有 `alpha_mode=1` 时产品渲染器自动选择对应本地解码器，随后固定为 straight RGBA 再进行合成。

独立 quality CLI 通过 `--sequence-id` 才知道作者 D；不擅自更改既有默认。golden verify 可以沿用 capture 保存的序列。输出报告中的原始差值不会消失；使用者可核对 `expected_quantization_delta_seconds`、`av_sync_residual_seconds`、`av_sync_residuals` 和 `stream_timing`。

## 7. 失败保留与视觉边界

第一次专项使用旧产品执行了 20 项，保留 [before 日志](evidence/delivery-precision-tests-20261018/before.log)、[冻结输入](evidence/delivery-precision-tests-20261018/before.json) 和 [当时测试源码](evidence/delivery-precision-tests-20261018/before-test.py)。初始测试曾误用不支持的 canvas background 字段，之后改为真正的背景图片轨；不把该夹具错误称为产品缺陷。
