## 1. 输入与环境

输入为本机 skimage 随附的 astronaut 人像图片，生成确定性平移的 3 秒、512×512、12 fps 视频，附带 48 kHz 单声道 440 Hz 正弦音频。原始图像、夹具视频及本地开发证据均保存 SHA-256；本例是自然人像静态图片加受控画面运动，未包含自然人体运动，也没有独立人工真值 alpha。素材许可仍为 unverified。

模型为官方 RVM v1.0.0 `rvm_mobilenetv3_fp32.onnx`，14,975,696 bytes，SHA-256 为 `88d4531297118f595bf2fd60f6f566aec2e559393802d1f436c380f0cbbd2828`。开发验证阶段显式从[官方 release](https://github.com/PeterL1n/RobustVideoMatting/releases/tag/v1.0.0)获取，模型位于 E 盘忽略目录；产品和 smoke 脚本只接受已存在的本地文件，不包含下载器。代码、权重、源素材与生成结果的许可分别核验；本次未证明模型商业使用许可。

运行环境为原生 Windows、Python 3.13.14、numpy 2.4.6、onnx 1.22.0、ONNX Runtime 1.28.0，固定 `CPUExecutionProvider`、4 个推理线程。本次未使用 Azure provider、CUDA 回退、剪映、闭源服务、Docker、WSL 或浏览器。

所有输入须事先存在，输出根目录须为新路径。脚本通过公开 CLI 执行摄取、登记 dry-run/正式/inspect、抠像 dry-run/正式、透明视频及音频入轨、两种背景渲染、去背景透明输出、quality/validate/policy 和预期权利阻断。渲染使用独立的 straight-alpha 混合结果作像素比较参考；该参考使用模型 alpha，证明合成链路，不证明模型 alpha 本身正确。

## 4. 已观察到的质量缺口

目视复核了开头、中间和末尾三组图。主体脸部及主要身体区域能够从背景中分离，两种背景和软边缘合成可见；首帧右侧身体/边缘有明显缺失，之后随循环状态趋稳。人物手持头盔被部分或整体排除，并非完整人物与道具联合抠像。两次真模型管道的原始 RGBA 摘要相同，但这不证明所有输入均具确定性或达到剪映质量。

因此本轮只验收了原生模型的功能接入、透明素材/成片和工程门禁。发丝精度、自然运动、快速运动、遮挡、镜头切换重置、人物携带产品、多人物和真实广告素材的质量仍未验收。必须保留 `MATTING_MODEL_REVIEW_REQUIRED`，不能用管道测试或受控指标代替这些缺口。

## 5. 回归与约束

新增 24 项专项回归位于 `product/tests/test_local_matting.py`，专项结果为 24/24，通过耗时 48.285 秒。覆盖软 alpha 与已有 alpha、分段管道读取、循环状态/非有限值、登记/证据/参数/源篡改、错误角色、前后完整性、音频起点、实际旋转/SAR、分数帧率、范围/片尾、透明字节往返、取消/超时及进程清理、输出竞争保护、幂等、元数据回滚、快照/项目包和权利闭包。

完整回归为 257/257，通过耗时 490.389 秒；14 个 Skill 审计、compileall、doctor 和 capabilities 均通过。源码与日志摘要、文档审计由本轮机器证据及[回归总记录](./回归验证记录_2026-10-13.md)给出；专项中协议测试使用受控 mock worker，真权重推理由本记录另行证明。使用方式、预算、SDR/CFR 语义和结构化拒绝见[RVM 契约](../specs/本地RVM人物视频抠像与透明素材契约_v0.1_2026-10-16.md)。完整剪映功能和效果对标仍未完成。
