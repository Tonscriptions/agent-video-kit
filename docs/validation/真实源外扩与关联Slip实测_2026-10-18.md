## 参照方法与九组范围

输入复用自制 CC0 计数器/原声音。S01/S02/S03/S04/S05 为关联视频/音轨，S06/S09 为嵌套序列，S07/S08 使用完整关联剪口对/三元组。

| 编号 | 真实动作 | 固定 V39 的独立手工作者输入 |
|---|---|---|
| S01 | 关联 slip +1 秒 | 保持 timeline/时长，video/audio 源 [2,6)→[3,7) |
| S02 | 两侧各扩 1 秒 | timeline [1,5)→[0,6)，源 [2,6)→[1,7) |
| S03 | 倒放 2×，两侧各扩 0.5 秒 | 源 [2,6)→[1,7)，timeline [1,3)→[0.5,3.5) |
| S04 | 定格 1 秒、亮度效果动画，两侧各扩 0.5 秒 | 源 [2,6)→[1.5,6.5)，定格/效果关键帧加 0.5 秒，输出时长 6 秒 |
| S05 | 倒放 Bezier 曲线，两侧扩 0.5/1 秒 | 源尾扩至 6.75 秒，保留原曲线控制点，新增边界 hold，声明作者时长 4.5 秒 |
| S06 | 含原子序列音频音量的容器，两侧各扩 1 秒 | 同一完整子序列，父源 [2,6)→[1,7)，父 timeline [0,6) |
| S07 | 关联 roll +0.5 秒，显式 source | 左侧真实源尾增长，右侧恢复选择完整作者的后 1.5 秒 |
| S08 | 关联 slide −0.5 秒，显式 source | 中间倒放主体整体移位，左侧裁短，右侧真实源头增长 0.5 秒 |
| S09 | 嵌套曲线 duration 归一化，尾扩 1 秒 | 子源 [2,6)→[2,8)，父 duration 4→5 秒；明确再归一化警告 |

参照不是调用新 planner 生成，而是生成器中的独立手工工程；渲染使用固定旧源码。完整作者窗口包装仍是相同产品模型，RGB/PCM 相同只能证明规划与兼容性，不能独立证明其全部渲染/曲线/音质正确。S01、S02 另用直接解码的源帧 RGB 网格作最近身份匹配，核对明确帧号，方法不读取 planner 或参照 timeline。

媒体生成器使用两个原生 Python worker 分别导入当前/固定 CLI 的真实 `main`，每次传入完整 argv 并保存原始 stdout/stderr 和返回码；记录的“CLI 调用数”指入口调用，**不是每条都重新启动 shell/进程**。worker 最后退出并记录状态。发行核验另外从隔离 wheel 运行独立进程的 CLI，不使用该媒体 worker。

## 门禁、回滚与开发记录

包括真实源不足、头部负时间、旧版本入口不支持、过期项目摘要、同幂等 key 重试和批次第二步失败后的原项目字节核对。专项还检查锁定关联成员、有理数源尾、整数源头、填充作者、过界定格、嵌套源界、跟踪源/目标、真实转场额外句柄和旧 compose 入口。

首次开发 37 项中 36 通过、1 个测试夹具错误：audio 源 [5,100) 实际包含足够处理长度，却期望填充作者错误。随后分别用 [5,80) 和 [5,85) 表达填充与真实头不足，40 项修正/扩展专项通过。再补旧 compose 入口与能力清单后，以最终冻结全套为权威；开发记录不替代最终版本测试。早期 V39 范围 53 项通过，但期间文件变化，`frozen_equal=false`，只记开发观察。最初逐进程媒体预跑因后续统一旧入口与能力清单而主动中断，原调用与文件保留，不能计为完成的媒体实测。发布开发档案时，ZIP 在 writer 尚未关闭前的 CRC 检查曾误报；关闭后 135 个原文件逐字节一致，已改为关闭后读回，原发布器与检查记录一并保留，不计为产品测试失败。

## 限制

这是短合成内容，未做自然广告/人物语义验收、连续播放或听审。曲线/定格音频沿用已有处理；默认 atempo、R3 极短音高/apart 相位问题仍开放。真实外扩会重新求值淡入淡出、效果和 native retiming；S09 保留显式归一化警告，不能称旧主体时钟不变，归一化嵌套曲线与定格的组合也未单独验收。跟踪观察失效时拒绝，部分真实源转场端点 resize 继续拒绝，完整磁吸未完成。可视图/GIF 为兼容性对照，不是完整剪映效果验收。
