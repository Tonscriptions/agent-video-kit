# 本地模型管道诊断与有界留证契约 v0.1

**状态：V67 已实现并完成本轮限定验收；范围见[实测记录](../validation/本地模型管道诊断与回收前留证实测_2026-10-20.md)。** 本文是先行设计和实现约束，不增加 V66 历史产品通过数。来源、固定模块 SHA、原生失败证据及已有有界读取见[复用待办](../OpenFilm诊断模块复用与原生模型故障后续项_2026-10-20.md)。继续使用原生 Windows、现有 Python/FFmpeg 管道和项目错误协议。

目标是让 Agent 区分解码、模型、编码与取消，并在临时区回收后定位本次失败；不把管道 Broken pipe 当作根因。当前 `matte_native` 已有 response 2,500 字节和三份 stderr 各 1,500 字节的尾部摘要，优先抽取这些有限读取规则。上游 `tail` 的全文件读取不移植。诊断不负责修复底层 Torch 访问冲突，也不证明自然画质。

## 接口和归因

| 编号 | 约束 |
|---|---|
| DIA-01 | 保留现有错误码、CLI 退出码、operation ID、事务、取消和权利语义。新增诊断是可选结构化附件引用；没有附件或附件失败时，原始错误仍可机器读取。正式增加错误字段前同步 Agent CLI 契约及消费者兼容检查 |
| DIA-02 | 为本次实际启动的 decoder、worker、encoder 分别记录 role、PID、启动时刻、首次观察到的退出值和清理后的最终退出值。未启动/启动失败、仍运行、已结束及主动终止分开；不以数组位置或 stderr 最后一句推断故障进程 |
| DIA-03 | 原样保留 Python/subprocess 返回值；Windows 另输出 `returncode & 0xffffffff` 的无符号整数及八位十六进制。主动清理造成的退出值不得冒充自然异常；其它平台不把普通负信号号解释为 Windows 状态 |
| DIA-04 | 记录首先观察到的失败集合和观测时刻，不承诺观测顺序就是因果顺序。模型异常可导致解码器/编码器连带失败；有多个已失败进程时全部保留，根因字段允许 unknown。没有转储栈或独立证据，不宣布 Torch、CUDA、几何或模型本身的根因 |
| DIA-05 | 进度只读取当前请求对应的有界 JSON，验证帧数与已知阶段；无进度、坏 JSON、未知阶段和进度落后分别说明。最后阶段是定位线索，不是崩溃位置证明 |
| DIA-06 | 显式取消、超时和资源准入拒绝分别报告，保留是谁触发清理及发生时刻。快照/输出冲突、无效响应、像素回读失败和诊断失败不能互相覆盖；重试不自动降低采样、画幅、帧数或原质量门槛 |

## 留证边界与默认预算

以下预算在实现前声明，实际执行范围以实测记录为准。预算按实际读取/写入字节核对；读取大日志不能只在完整读取后裁字符串。进度原文件最多读取 32 KiB，保存的进度字段、请求和响应摘要合计最多 32 KiB；worker JSON 错误另外限为这份摘要内不超过 2,000 UTF-8 字节，并经过脱敏。

| 编号 | 对象 | 上限和规则 |
|---|---|---|
| DIA-07 | stderr | decoder/worker/encoder 各最多读取尾部 64 KiB；seek 后 read 有显式大小。记录原文件大小、读取偏移、实际读取数、是否截断和保留字节 SHA；UTF-8 解码替代及整行裁切另外注明 |
| DIA-08 | 结构化附件 | response 最多 128 KiB；进度/已脱敏请求摘要合计最多 32 KiB；manifest 最多 64 KiB。超预算/无效内容只记录拒绝原因及实际已读数，不尝试整份加载 |
| DIA-09 | 单次诊断 | 固定白名单、不超过 8 个文件；附件原始总字节最多 512 KiB。默认不打 ZIP；如后续增加显式导出，ZIP 最多 768 KiB，超出即拒绝导出并保留已有本地记录 |
| DIA-10 | 目录和路径 | 只处理当前任务自行创建的临时目录、固定文件名及本项目诊断目录；拒绝目录联接、符号链接、越界和被替换边界。文件读取前后核对身份/范围，失败时说明附件不可得。拒绝用户提供任意待收集目录或路径列表 |
| DIA-11 | 不收集的内容 | worker stdout 为 RGBA 二进制，decoder stdout 也是帧管道；不复制原媒体、帧缓冲、权重、整份提示词/环境变量、命令行秘密、其它工程、全局 Codex SQLite、聊天/会话或浏览器资料。只保留必要字节计数、角色和摘要 |
| DIA-12 | 内容最小化 | 采用上游脱敏思路并覆盖本项目 Windows/混合路径、鉴权字符串和常见 token 字段；只发布白名单字段。源码/adapter/模型摘要、参数身份和错误阶段保留。脱敏不是完整秘密识别证明；附件默认仅本地，不自动上传或发送消息 |
| DIA-13 | 保存顺序 | 先保留自然退出观测，按现有规则停止并 wait 自建子进程，关闭日志句柄，再做有界快照；在 `_pipeline_workspace` 回收前写入项目专属诊断目录。不得等目录删除后才尝试复制，不停止其它任务 |
| DIA-14 | 写入与清理失败 | manifest/附件使用临时文件加原子发布；部分附件失败仍写出有限的拒绝摘要和次级警告。保留原业务错误；失败留证不能使半成品资产登记成功。诊断目录清理失败不触发递归诊断 |
| DIA-15 | 历史保留 | 仅管理新建的项目诊断目录：默认最多 32 次、总计 64 MiB、最长 14 天；先删除已结束且超龄/最旧记录，不碰活动任务。明确标注被清理或缺失的引用，不删除 `docs/` 实测证据和原视频 |

记录须绑定本次源、实现闭包、adapter、模型清单、原生 Python 和有效采样配置的 SHA；“声明版本”和实际 worker/探测所得版本分开，不能在失败路径为取版本而额外加载 Torch 或再次启动模型。只记录必要设备身份；不自动扫描其它任务或全局 Windows 事件。已保存的 Windows 事件可作为独立外部证据引用，不能由退出码单独冒充事件已核对。

## 预先定义的验收

| 编号 | 验收 | 证据边界 |
|---|---|---|
| DIA-T01 | 受控 decoder/worker/encoder 各自失败、启动失败和同时失败 | 实际原生子进程；验证首次观测与清理后退出值不混淆、没有残留、原输出/项目不变。伪造退出码不算真实 Torch 崩溃 |
| DIA-T02 | 取消、超时、资源拒绝、坏报告、诊断写入失败 | 保留原错误码/退出码与次级警告；不运行新的重试或降低质量，未登记候选资产 |
| DIA-T03 | 大日志与字节预算 | 用稀疏/大日志和带读取计数的文件对象验证实际读取总量受限；非 ASCII 截断、无换行长行、空文件及超大 response 另验。仅检查输出文件小不算通过 |
| DIA-T04 | 路径与内容边界 | 联接/符号链接、越界、身份替换、并发任务、秘密字段及 RGBA 二进制不被收集；只含本次白名单和相符 SHA |
| DIA-T05 | 留证与历史 | 清理后仍能核验附件/manifest；注入局部写入失败，确认原错误仍在；验证 32 次/64 MiB/14 天和活动任务保护，不触碰文档证据 |
| DIA-T06 | 实际历史失败映射 | 用 V66 已保存的 PID/Windows 事件核对诊断字段设计；如没有新真实崩溃，只标为历史对照，不能声称已经现场捕获下一轮 Torch 访问冲突 |
| DIA-T07 | 新实现与发行 | 重新登记 adapter、冻结修改后的源码、运行相关与完整回归，离线安装核对；开发日志、模拟/真实异常、模型推理、质量与性能分计。新增诊断不关闭原生崩溃长期稳定性或剪映等价缺口 |

实施顺序：先扩展进程观测与有界辅助函数，再接回收前留证和错误引用，最后做历史保留及可选显式导出。优先复用现有 seek/限长、原子写入、Windows Job、事务和错误码基础设施；OpenFilm 只提供摘要/脱敏/有限历史的参考约定。R07 的 1–2 人日估计仅覆盖纯本地辅助逻辑，未覆盖这里新增的原生进程归因、攻击边界和压力验收，不当作本契约总工期。
