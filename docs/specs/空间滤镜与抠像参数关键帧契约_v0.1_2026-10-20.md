颜色对比目录以前把 red/green/blue 默认值写成 1，渲染器实际默认 0；本轮把目录改正为 0，静态渲染默认行为保持一致。对比系数与权重需要配合；零权重时修改系数可能没有像素效果。模糊允许半径 0 并显式设置两轴；静态输出统一六位小数。静态 similarity 的零值以前会被原生后端拒绝，现在钳到后端实际下限 0.00001；动态值越界则明确拒绝。

## 2. 编辑接口

沿用 `timeline compose` 的 `update_clip.patch.effects`。例如 tps=90000、完整作者长度 180000 的画面先模糊再恢复：

```json
{
  "operations": [{
    "op": "update_clip",
    "clip_id": "picture",
    "patch": {"effects": [{
      "type": "blur",
      "parameters": {"radius": 0},
      "keyframes": [{"property": "radius", "keyframes": [
        {"at_tick": 0, "value": 0, "interpolation": "linear"},
        {"at_tick": 90000, "value": 12, "interpolation": "linear"},
        {"at_tick": 180000, "value": 0, "interpolation": "linear"}
      ]}]
    }]}
  }]
}
```

效果顶层 `keyframes` 优先于 `parameters.keyframes`；属性可以带 `effect.`、`parameters.` 或效果名的前缀。同一通道的重复别名拒绝。参数 `color`、planes、采样枚举、填充 token 不在动态白名单中；把它们写成关键帧不会静默退回静态。

## 3. 时间与执行

六种插值为 hold、linear、ease_in、ease_out、ease_in_out、bezier。Bezier 沿用既有 33 点／32 段、20 步逆函数和八位小数段序列化近似，不宣称等于解析曲线。作者点严格按整数 tick 递增，必须位于完整作者区间；值为有限数字，拒绝布尔、字符串、NaN、无穷和超大整数。Bezier 控制点也执行结构化有限数检查；修复此前超大整数触发 OverflowError 的问题。

沿用实际 CFR 栅格取样、两个样本之间发命令、首状态显式设置、六位小数、Bezier 超界钳位计数、完整作者时钟和 `_nested_clock`。正常片段、文字、复合片段和区间调节层共用现有入口。trim/split 保留相位；相对 retime 保存完整作者子图；直接嵌套时按既有时间映射语义解释参数，不把连续作者取样与已栅格子图反转混为一谈。

每个实例有根图唯一 target。后端可执行文件摘要、实际 T 命令探测、派生命令摘要和参数清单进入 manifest。`native-color-command-cfr-v1` 是保留的协议名称，本轮扩展至空间／抠像通道，不通过换名建立第二个编译器。

根图共享：2,000,000 状态样本、200,000 命令、16 MiB 文本、1,024 动态实例。静态与动态抠像另外共用最多 1,024 个覆盖合成节点，各有根图唯一标识；计数与上限通过 key_alpha_compositors 元数据公开。缺少本地运行时命令、超预算或缓存被改动时明确拒绝。包、JSON 与片段组保留作者参数，目标项目重建缓存，不携带旧 cache 路径作为依赖。

## 4. Alpha 与质量边界

gblur 处理 RGB 与 Alpha 平面，几何变换会改变覆盖范围；这些效果不能统一用“原 Alpha 不变”判断。颜色对比应保留输入覆盖。原生 colorkey 会覆盖输入 Alpha，因此本项目在静态与动态路径均显式分离该抠像阶段的输入 Alpha 与原生 RGB 距离覆盖，再计算 round(input_alpha × native_key_coverage / 255)，以 8 位精度合并，RGB 保持来自抠像分支。此前阶段已经改变的 Alpha 以实际进入抠像时的覆盖为准，不回溯到素材最初的 Alpha。透明输入不能被重新变成可见。

每个抠像节点记录 colorkey-alpha-coverage、计算公式、8 位精度和 input_coverage_preserved。动态命令仍寻址独立的原生 colorkey 实例；覆盖合成标签跨递归根图唯一。单独调用静态滤镜构造器时用确定性内容标识，实际产品图始终使用根图分配器。本轮独立逐帧静态参照包含上述 Alpha 乘积；有背景的成片另用独立 source-over 算术核验。

镜头畸变仍采用本地滤镜默认采样／填充，未加入标定反求、主体语义或无损几何重建。抠像未包含去溢色、头发专用模型或自然绿幕质量承诺。模糊仍为原有编码域平面滤镜，未实现线性光／HDR 模糊或完整剪映空间特效。

验收应分别记录作者模型、命令是否真正执行、全帧像素、编码 PTS、完整 PCM、原始素材与权利、自然视觉质量和人工连续审片。MP4/GIF 是有损预览；精确数值使用 FFV1 RGBA／PCM。本轮结果见 [实测与失败记录](../validation/空间滤镜与抠像关键帧实测_2026-10-20.md)。
