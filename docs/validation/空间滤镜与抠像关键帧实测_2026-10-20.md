本轮 V75 给 blur、color_contrast、lens_correction、chroma_key 增加 14 个实际执行的关键帧数值通道。完整产品目标仍是开源、本地、面向 Agent 的剪辑内核；本轮不把四类技术样例判作剪映全部功能与效果等价。

## 保留的失败和修正

首次隔离检出遇到 Windows 长路径错误，停止已观测的本轮两个 Git 检出进程，恢复全新隔离副本索引，改用启用长路径的稀疏检出；没有重置 main 或清理用户文件。此前进程观测见本轮 evidence 中的 setup-owned-checkout.json。

首轮 [专项 targeted-r1](evidence/spatial-automation-20261020-v75/targeted-r1.json) 实际执行 24 个方法，失败日志中有 5 条失败、4 条子测试错误，保留 [原始日志](evidence/spatial-automation-20261020-v75/targeted-r1.log)。超大整数在 `math.isfinite` 触发 OverflowError 是真实产品错误，已修复为结构化拒绝，控制点同步覆盖。其余失败来自测试参照：颜色对比初始权重全零，四个被检查通道没有像素变化；改为有实际权重的输入。Bezier 参照原先误用解析三次曲线，修正为既有 32 段合同的独立数值参照。没有放宽像素误差或 Alpha 判定。

第一次修正的 [专项 targeted-r2](evidence/spatial-automation-20261020-v75/targeted-r2.json) 执行 25 个方法，历史开发 native-r1 和安装 installed-r1 当时也通过。但这些参照沿用了原生 colorkey 覆盖输入 Alpha 的行为，不能据此认定抠像语义正确。后续静态目检发现透明输入的蓝色条带重新显现，因此在改动前主动停止本轮独占的 full-r1 工作进程，保留 [停止观测](evidence/spatial-automation-20261020-v75/full-r1-stop.json)、失败收据与完整日志。full-r1 没有终态方法计数，不进入通过统计。

新增修复前回归 [targeted-r3-alpha-before-fix](evidence/spatial-automation-20261020-v75/targeted-r3-alpha-before-fix.json) 实际 27 方法、2 项失败，分别证明动态和静态抠像丢失原覆盖。修复后改为抠像阶段输入 Alpha 与原生键控覆盖相乘，保留 RGB，增加独立根图节点预算和元数据。随后 [targeted-r4](evidence/spatial-automation-20261020-v75/targeted-r4.json) 实际 29 方法、9 条子测试失败，原因是别名测试仍断言只有一条元数据，而现在另有覆盖保护记录；将断言改为分别完整检查控制与覆盖记录，未删减像素判定或放宽容差。

最终 [专项 targeted-r5](evidence/spatial-automation-20261020-v75/targeted-r5.json) 为 **29/29、16.696 秒、0 跳过**。14 通道均真实改变像素并匹配各帧静态原生参照；静态与动态抠像、多实例标签和额外预算另有针对性核验。同一份 223 输入的受影响回归：原有调色 [28 项](evidence/spatial-automation-20261020-v75/color-regression-r2.json)、LUT [30 项](evidence/spatial-automation-20261020-v75/lut-regression-r2.json)、混合变速 [23 项](evidence/spatial-automation-20261020-v75/blend-regression-r2.json)。这些是全量子集，不重复加总。

当前真实媒体使用 native-r3 与 installed-r2，各 24 CLI／36 检查；独立参照明确包含键控覆盖与输入 Alpha 的乘积，并验证原本透明的像素始终等于背景。中间 native-r2 虽然媒体通过，仍保留为中间记录，不代表最终同源验收。五个公共素材目录均保留，各自绑定自己的生成收据；历史输出不能替代最终输出。

## 复现

只使用现有 Windows 原生 Python、FFmpeg、七个现有 wheels 和完整回归明确登记的本地 HTML／Rubber Band 运行时。没有 Docker、WSL、容器、虚拟环境、在线素材、云模型或新增模型前向。浏览器仅可能由原有 HTML 回归托管并负责关闭，本轮空间效果和安装样例不启动浏览器。

从仓库根目录执行，所有输出选择新的空位置：

```powershell
C:/Python313/python.exe -E -B -X utf8 scripts/run_frozen_regression.py --pattern test_spatial_automation.py --output docs/validation/evidence/spatial-automation-20261020-v75/reproduction/targeted.json
C:/Python313/python.exe -E -B -X utf8 scripts/smoke_spatial_automation.py --work product/.runtime/spatial-reproduction --evidence docs/validation/evidence/spatial-automation-20261020-v75/reproduction/native --assets docs/assets/spatial-automation-20261020-v75-reproduction
```

离线安装复现使用 `scripts/verify_spatial_automation_install.py`，明确传入已有 wheelhouse 和上述开发样例的 verification.json；不在运行时下载依赖。完整回归使用 `scripts/run_with_regression_fixtures.py`，先以 `scripts/materialize_regression_fixtures.py` 绑定同一提交的八份既有媒体／字体夹具。
