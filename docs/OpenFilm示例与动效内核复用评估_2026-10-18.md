# OpenFilm 配套示例与动效内核复用评估

结论：**配套示例中还有可拆的特效代码，值得单独验证，但当前不能直接放入产品运行。** 主仓库的示例入口指向独立的 [openfilm/examples](https://github.com/openfilm/examples)。本轮进一步审读其两个示例说明、版权声明、时间线，以及八份动效内核文本；没有下载示例媒体、运行示例或接入新渲染后端。

## 1. 实际查到的内容

主仓库仍为 `eefd6a8d`，702 个文件。按本次明确扩展名分类，其中 18 份图像资源为 12 JPG、3 PNG、2 SVG、1 WebP；包含 Skill 封面、海报及界面/品牌图形。没有把这些图形当作广告视频/音乐内容库。

配套仓库固定为 `2e8f47866bc2d32305cd5d97adcffd7480df2297`，与主仓库 `examples-index/SOURCE` 一致；API 快照为 **10 stars / 0 forks**。递归树有 402 个 blob，按同一分类有 222 份媒体/字体条目，GitHub 树声明大小合计 **224,900,384 字节**：104 JPG、37 PNG、8 SVG、25 MP4、36 MP3、9 TTF、3 WOFF2。这里只读取目录元数据和选定文本，**没有下载这些媒体、检查其内容摘要或证明它们都适合再分发**。

两部示例分别是 `one-prompt` 歌词动效与 `openfilm-intro` 中文产品介绍。主仓库自带的 `examples.json` 只有两条索引和海报路径，不能把索引当成已经落地的本地模板库。

[仓库/目录/九份文本原证据](validation/evidence/openfilm-examples-review-final-20261018/verification.json)与[八份内核文本证据](validation/evidence/openfilm-examples-review-final-20261018/px/verification.json)分别记录固定提交、API 时间、blob 标识和本地文本 SHA-256。第一次 raw 文本请求被远端重置，保留[失败记录](validation/evidence/openfilm-examples-review-20261018/failure.json)；后改用同一固定提交的 Git blob API 获取文本，没有取消 TLS 校验。

## 2. 可拆内容、实际收益与接入门槛

| 编号 | 上游内容 | 可降低的开发工作 | 当前兼容性 / 尚未完成 | 优先级 |
|---|---|---|---|---|
| EX01 | `one-prompt/src/px/post.js`、`gl.js` | Bloom、halation、色差、颗粒、暗角、闪白/淡出，以及线性浮点中间纹理的现成 shader 和合成规则 | 依赖 three.js/WebGL2；产品当前 HTML worker 明确拒绝 WebGL。需独立后端、固定本地依赖、显存/超时/取消和多设备一致性验证；不能为运行一个示例直接解除现有边界 | 中，先做有界技术验证 |
| EX02 | `stroke.js` | Hershey 单线字体转折线、按长度逐笔绘制、按字时刻计算绘制长度；可用于白板/标题描线 | Canvas2D 绘制部分可尝试独立提取；仍依赖 SVG 字体加载、曲线工具和字体许可。现有样例不证明支持汉字笔顺，不能当作中文手写内核 | 高，先验证独立模块 |

| EX05 | `engine.js`、`section.js` | 场景切换、任意时间求帧、带状态场景预滚、多子帧运动模糊的实现参考 | 读取了实现，未执行。`section.js` 每帧重置 seek 状态；完整引擎仍依赖场景、音频、字体和 three.js。应与现有帧时钟对照，不整体替换事务和精确编码链 | 中 |

与[十份官方 Skill 映射](OpenFilm官方Skill本地能力映射_2026-10-18.md)结合，先做 `replicate` / `screen-demo` / `long-to-short` 的流程适配，再按明确模板需求验证 EX02/EX06。EX01/EX05 属于新增渲染能力，需要独立原型；不能沿用“现有能力上单流程 1–2 人日”的适配估算。当前没有这些模块的实测接入工时，不估算总节省百分比。

## 3. 本地化和权利处理

配套仓库 README 声明代码为 MIT，媒体按各 `CREDITS.md` 区分；两份声明把贡献者制作的相应媒体列为 MIT，字体列出 SIL OFL、Hershey 等不同要求。这是上游声明的核对，**不是逐文件来源复核或已经完成的本地权利登记**。品牌标识另有商标说明，不能换用自己的产品名称后继续沿用这些品牌画面。见固定提交的[总说明](https://github.com/openfilm/examples/blob/2e8f47866bc2d32305cd5d97adcffd7480df2297/README.md)、[歌词示例声明](https://github.com/openfilm/examples/blob/2e8f47866bc2d32305cd5d97adcffd7480df2297/one-prompt/CREDITS.md)、[中文示例声明](https://github.com/openfilm/examples/blob/2e8f47866bc2d32305cd5d97adcffd7480df2297/openfilm-intro/CREDITS.md)。

`src/px` 还保留 Giacomo Magnanini 的 MIT 原文，拆取时需同时保留该归属及 OpenFilm 的相关声明。样例中的 three.js 从 CDN 加载；若采用，应固定为已审查的本地版本及摘要。配音/歌曲的历史来源包含线上生成服务，不运行其生成脚本；后续更换为已登记本地声音/音乐，重新生成时间对齐证据。中文介绍的部分字体依赖 macOS 系统字体，Windows 下必须明确替换并重新验收文字布局。

建议下一次接入限定为一个独立描线标题或一个中文产品信息卡：登记代码/字体/媒体，固定输入与时间参数，检查乱序取帧、全帧可重建、文字/音画落点及资源清理；提供原输入、真实编码、GIF 和失败记录。完成后才计作新产品能力。本轮新增的是源码/目录研究，**0 示例成片、0 新模型推理、0 新 Skill 安装**；不能据此宣称已具备完整剪映特效、HDR 输出或版权素材商城。
