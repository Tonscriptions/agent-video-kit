## 1. 它实际提供了什么

OpenFilm 的核心模型是 `film.html`：section 表示轨道，iframe/video/img/audio 表示片段；动效页面提供 `window.film.frame(t)`。Node/Playwright 控制本地 Chromium 按时间取画面，FFmpeg 编码并混音。React Studio 和 Electron 桌面应用是编辑界面；`get` 命令另外连接媒体服务商。其[格式草案](https://github.com/openfilm/openfilm/blob/b138595d4c2d1fa5262b4a8a8c7cd98187c4b077/packages/openfilm/SPEC.md)与[包导出入口](https://github.com/openfilm/openfilm/blob/b138595d4c2d1fa5262b4a8a8c7cd98187c4b077/packages/openfilm/package.json)能支持单独使用部分库。

它适合 Agent 写网页动效、广告标题卡、图表、图文解释片及组合媒体。任意时刻重绘的约定、页面检查和独立小模块比“AI 视频 Agent”的宣传定位更有实际复用价值。它没有因此成为完整剪映 NLE：film 顶层 CSS 是静态的，动态动画放在页面脚本里；素材修复、抠像和语音等主要通过服务商或外部生成文件取得。

固定快照共 **619 个文件**，其中扫描到 531 个 JS/TS 源文件、115,795 行，含 157 个测试文件、16,601 行测试。115 个代码文件含 React 运行时导入。此数只描述扫描范围，含界面、脚本及测试，不是可直接移植的核心规模或质量评分。

## 4. 直接删除 GUI 之前的关键发现

1. `timeline-edit.ts` 和 `transitions.ts` 位于 ui/lib，但主体是数据规划。批量删 `studio/ui` 会把它们一起删掉。它们间接导入 timecode.ts，而该文件把纯数学与 React Hook 混在一起。本轮唯一 Hook 分离后原 65 测试通过，建议正式复用时分成 core/time 与 UI adapter。
2. `src/render.mjs` 可以与 React/Electron 分离，但仍依赖 Chromium、Playwright、临时 HTTP 文件服务和 FFmpeg；“没有 GUI”不能解释成“没有浏览器运行时”或“没有内存开销”。默认 worker 根据 CPU/总内存估算，最多 8 个浏览器，不是本项目已验收的资源预算。
3. 原 CLI 的 look/render 会确保项目显示在 Studio；无参数手册入口还会检查 npm 更新。原 Skill 也引导 npx latest。应调用/抽取库入口，不能把这些 CLI/Skill 原封不动放进默认离线路径。
4. `FilmPage.open` 具备 `offline` 和 origin allow-list；但是固定版本 render 的 probe 与 worker 创建没有传入离线参数。**存在 offline 代码不等于默认 render 已严格离线。** 正式引入需覆盖所有页面/探测/worker，并检查实际请求、字体、CDN、WS、Service Worker 与退出回收。当前只是静态定位，未宣称通过网络隔离实测。
5. 非透明输出默认使用 JPEG95 截帧再编码，透明输出用 PNG；motion blur 为多个快门样本经 FFmpeg tmix 平均。它不自动等于线性光、HDR、无损纹理或剪映运动模糊算法，需单独的像素/Alpha/颜色基准。
6. xmeml/草稿导出会对网页动效、无法表达的旋转/速度等进行烘焙。画面能显示与参数继续可编辑是两件事；不能靠导出成功关闭全部工程互转差异。

## 5. 与当前产品主链的合并方式

保持 Agent Project JSON、90k ticks、素材哈希、Rights Ledger、质量门禁、Python 事务/队列和 FFmpeg 最终合成为权威。第一批通过本地 Node JSON worker 调用白名单纯算法，或逐项移植并用同样输入/预期双跑；不新增 Studio HTTP API 依赖。Node worker 只产出建议/compose 操作，回到本项目原验证路径保存。

需显式处理：上游毫秒量化、TOUCH_MS=1、MIN_BLOCK_MS=100、全局当前帧率默认值，与本项目亚帧 tick/非整帧片段的差异；对不兼容输入返回明确限制或实现 ticks 原生等价。不能让取整、过短片段删除或轨道重排静默改变作者工程。操作 planner 不自动赋予素材发布权利，也不能绕开项目锁、事务和能力损失报告。

第二批 HTML 动效输出为本地 PNG/RGBA 帧序列或已验证透明中间资产，再登记源 HTML、字体/脚本闭包与版权；由现有轨道/画布/音频链负责最终结果。iframe 页不是可直接等价替换当前嵌套序列或曲线速度的模型。

|---|---|---|
