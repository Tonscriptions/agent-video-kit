face_landmarks.py adapts tracker.py's RGB normalization, 224/56 face heatmap,
integer crop convention and 66-point heatmap/offset decoding. Modified for
explicit local artifacts, CPU-only ONNX sessions, finite shape checks, zero
network calls, sequential processing and source-pixel (x,y) coordinates.
The webcam, UDP, avatar, RetinaFace, gaze, 3D head fitting and automatic model
lookup code are not used. Models are supplied separately by the caller.
The upstream README explicitly licenses code and models under BSD-2-Clause.
Its training data and topology limitations remain part of the evidence.
