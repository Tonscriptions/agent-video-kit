## 1. 实际修正与验收范围

新 `presentation_window` 保留完整作者源时钟、速度曲线、关键帧、倒放、定格、片段效果和音频处理，然后在输出轴选区。`split_clip` 不再按平均源比例拆点；`ripple_delete` 真正保留中段删除后的左右内容，交叉右边界不再错用整段删除长度。插入可自动拆片段，新增非破坏 `trim_clip`。跨工程片段组继续保留窗口作者信息。

这属于原生编辑能力，不是移植 OpenFilm GUI 或接入新的生成模型。它继续处理 [OpenFilm O02 研究](../OpenFilm_v0.2增量复用与接入建议_2026-10-18.md)指出的源边缘/内部编辑缺口；源范围外扩、完整磁吸、插入覆盖、roll、专业 slide 等仍未完成。

## 3. 反事实对照方法

固定旧版本为 `23ca3cbcd030c7a41e4618cdcfdf0b7cf3bcbb98`（V37）。从 Git archive 提取原产品源文件与 Schema，在独立目录运行真实原生 CLI，生成没有窗口字段的完整原片。新版本运行 compose 后生成实际输出。预期数组只对旧原片作独立明确的帧/采样区间选择，或插入零值黑场/静音；不消费新 planner 的源点计算来生成预期。

这是**固定同一产品旧渲染器的反事实选择对照**，不是独立媒体/时钟算法；它可证实裁后保留了该完整作者结果，不能独立证明原曲线、音高、模型效果或自然广告质量正确。独立重解码脚本重新读取已发布文件，检查结果、帧率/帧数、PCM、文件和原始 CLI 的 SHA-256。

| 编号 | 真实操作 | 预期选择与检查 |
|---|---|---|
| C01 | 倒放、非线性位移动画、音频淡入淡出后分别拆分音画 | 原 40 帧、192,000 立体声采样帧不变 |
| C02 | ease_in_out 源速度曲线+倒放+动画+声音包络，删除 1–2 秒 | 原帧 `[0,10)+[20,40)`，原 PCM `[0,48000)+[96000,192000)` |
| C03 | 在 1–2 秒定格/静音区间内开始裁切，取 1.5–3.5 秒并放在 0 秒 | 原帧 `[15,35)`、PCM `[72000,168000)` |
| C04 | 独立文件字幕在 2 秒处拆分 | 原 cue、完整字幕/声音结果不变；文件字幕动画仍沿既有明确近似边界 |
| C05 | 在含倒放与轨道音频处理的子序列中删中段 | 根结果与旧原片对应片段相同，原子级音频总线处理保留 |
| C06 | 裁切带父级声音淡入淡出的嵌套容器，取 1–3 秒 | 先完成原容器处理，再取 20 帧/96,000 采样帧 |
| C07 | 在片段内部插入 1 秒空隙 | 保留原两侧，插入 10 黑帧与 48,000 立体声零值采样帧 |
| C08 | 保存 C02 已裁窗口组，再跨工程可编辑插入 | 结果与 C02 固定旧原片选区相同；原库的执行上下文/权利约束继续适用 |
| C09 | 上层画面 crop.fit=fit 产生黑边，下层另有视频，拆分上层 | 原 40 帧不变，黑边不能变为透明并透出下层 |

每组保留原工程、操作请求、实际工程、成片、渲染清单与校验摘要；C08 使用片段组请求路径。未承诺这些短小计数器代表自然广告、多语言文本、透明抠像软边、HDR、VFR、长片性能或所有复杂总线。

## 6. 当前边界与下一步

窗口选区不能外扩到完整作者时长以外。部分选区的速度/曲线、倒放、定格高层命令，以及窗口上的智能口播、重构图、跟踪绑定仍明确拒绝；完整作者处理后再裁切可行。转场端点需要先移除受影响声明，同轨旧式复杂转场不静默丢弃。已处理窗口子级再次经文件型 R3 伸缩仍拒绝，FFmpeg 内联声音可继续走既有路径。

轨道/全局效果和闪避在新时间线上执行，不保证等于裁前完整根序列的固定切片；本轮只对明示案例作相应承诺。完整作者图可能重复执行，64 直接窗口/16 层以及栅格预算是规划限额，不能替代长片 RSS/吞吐验收。下一步继续源范围外扩、完整主轨联动、insert/overwrite/roll、自然音画与性能；**完整剪映功能和效果目标仍有效，尚未验收**。
