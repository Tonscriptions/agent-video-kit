## 1. 动画和颜色必须共同执行

`subtitle.animation` 或既有 `subtitle.style.animation` 沿用原有字段。动画先更新位置或整体 alpha，再执行共享的段落排版与普通/激活色选择。`word_timing` 不得提前返回而跳过动画。固定栅格支持淡入、淡出、四方向滑动、pop、bounce、typewriter/typing；独立文字层还支持既有 rotate 姿态。普通和激活文字必须保持相同原生几何、相同位置与前缀，只替换选区颜色；动画 alpha 在颜色/组件合并之后应用一次。旋转内嵌文字继续返回已有近似提示。

使用既有参数，无新增顶层 CLI 开关：

```json
{
  "text": "LOCAL VIDEO",
  "style": {"font_asset_id": "local_font", "fontsize": 48,
    "fontcolor": "white", "active_color": "yellow", "box": false,
    "expansion": "none"},
  "animation": {"type": "typewriter", "delay": 0.12, "duration": 2.3},
  "word_timing": [
    {"text": "LOCAL", "start": 0.15, "end": 1.4},
    {"text": "VIDEO", "start": 1.4, "end": 2.8}
  ]
}
```

## 2. 打字机保持完整段落锚点

布局在完整文字上计算一次。默认居中、text_w/text_h、显式对齐、fix_bounds 和框尺寸以完整段落为准，首字不会先居中、后续字再向两侧扩张。各行有固定原生基线；当前前缀通过本行完整基线减去当前 drawtext 的 `top_a` 定位，避免组合重音、大小写或下伸字母使基线跳动。换行不画额外字形，不消耗一步；源文字中的空格/制表仍消耗一步，自动换行跳过的空格也不缩短作者节奏。

第 `j` 个受支持字素在 `作者片段开始 + delay + j*duration/N` 显示。首字在 delay 时刻出现，最后一字在 delay+duration 之前一步出现，保留既有 API 时序。字素是项目现有的有界组合符/ZWJ 分组，不能宣称完整 Unicode 分词、双向塑形或所有 emoji 支持。

每行绘制一个完整原生前缀，交由本地 FFmpeg/字体引擎处理该前缀的字距与塑形；不再逐字素独立画字并用 Pillow 累加偏移。新增字母可能改变前缀内部的原生连字，这是“完整前缀”语义，不保证完整句子中每个字形永不变化。整段背景框只画一次，尺寸不随前缀增长，在首步启用；每行的边框和阴影随对应前缀更新。

## 3. CFR 与原作者时钟

调度使用已编译祖先映射，包含已支持的裁切、输出起点、速度曲线、Bezier 和倒放边界偏移。逐个最终 CFR 样点决定应显示的前缀，变更命令放在相邻样点中间，规避滤镜输入 timebase 的舍入边界。独立文字源从最终 0 时刻取样；固定内嵌源从展开后的片段起点取样。倒放可以缩短前缀，不假定字数单调增加。

原生 `sendcmd` 必须位于整张文字图分支之前，每个覆盖率组件有独立且足够短的实例名，普通/激活、字面/描边/阴影均逐一更新；不能假定同名命令会广播。文字参数只经过一层 sendcmd token 编码，单引号、反斜杠、逗号、分号、百分号不得变成额外命令。首始前缀用本地 UTF-8 textfile；运行时使用 drawtext 的 `text` 命令。实际本地 FFmpeg 必须声明该运行时能力；本轮实测为 FFmpeg 8.1，不能由 n8.0 源码或 help 声明推断其他构建执行正常。

`cache/text-typing/` 的身份绑定源文字、字体/FFmpeg 原始 SHA-256、样式、原生排版、完整祖先映射、CFR、起点和作者时序。每个命令文件再以完整命令内容的 SHA-256 命名；相同段落随后从高亮切换成普通文字时，不能覆盖已有 plan/manifest 引用的命令流。缓存不是素材或权利登记；渲染不改写作者 assets/settings/sequences 或原始 Rights Ledger。

## 4. 可审计 manifest 和资源边界

`subtitle_time_mapping.text_layout.typing` 记录 `drawtext-native-prefix-cfr-v1`、`native-prefix-runtime-text`、字体/执行器摘要、字素/行/paint/实际组件目标/命令数量、fps、起点、初始前缀长度、各变更的帧号/显示时间/作者时间/字数，以及命令文件相对路径和 SHA-256。相关组件映射记录在 `text_paint.paints[].command_targets`。该证据证明实际编译内容，仍需解码像素验收；不能仅凭 FFmpeg 退出 0 判定命令更新成功。

| 条件 | 行为 |
|---|---|
| 超 512 字素、16384 源字符、128 行、16384 命令或 4 MiB 命令文件 | `SUBTITLE_TYPEWRITER_BUDGET`，退出 2 |
| 控制字符（LF/tab 外） | `SUBTITLE_TYPEWRITER_CONTROL_UNSUPPORTED`，退出 2 |
| RTL/双向控制文字 | `SUBTITLE_TYPEWRITER_BIDI_UNSUPPORTED`，退出 2 |
| 随机/状态存储、x/y 互相引用的位置 | `SUBTITLE_TYPEWRITER_POSITION_UNSUPPORTED`，退出 2 |
| 百分号且 expansion 不为 none | `SUBTITLE_TYPEWRITER_EXPANSION_UNSUPPORTED`，退出 2 |
| 没有可用本地字体 | `SUBTITLE_TYPEWRITER_FONT_REQUIRED`，退出 2 |
| 显式框小于完整段落 | `SUBTITLE_TYPEWRITER_BOX_CLIP_UNSUPPORTED`，退出 2 |
| 原生构建没有运行时 text 能力 | `SUBTITLE_TYPEWRITER_NATIVE_COMMAND_UNAVAILABLE`，退出 6 |
| 动态尺寸内嵌打字机 | 沿用旧路径，`subtitle_typewriter_dynamic_raster` 明确近似 |
| 动态尺寸内嵌打字机+高亮 | 不执行该组合，保留整句及 `subtitle_word_animation`、动态高亮限制；改用独立层 |

拒绝在渲染规划中发生，不输出成功成片、不修改作者时间线/权利；可能已建立诊断缓存。一般多行/高亮仍遵守原契约的范围、字簇、测量和位置门限。

## 5. 验收与保留边界

受控专项须含实际像素：普通动画对照的 R/G 同形、独立原生前缀字距、固定完整段落/多行/自动换行、空格节奏、组合重音及命令分隔符、完整框和半透明组件、内嵌/独立层、旧版失败。公开素材应同时给原视频、固定旧版本真实输出、新输出、控制、来源/字体许可、媒体探测、原始日志和原字节摘要，见[本轮实测](../validation/文字动画高亮组合与原生打字机实测_2026-10-17.md)。

本契约只推进已验的 CFR/8-bit 子项。动态尺寸内嵌、外部 ASS/SRT 动画、通用双向/复杂字簇/字体回退、定格、VFR、完整群组坐标、HDR/线性光、长片/4K 性能、自然素材广泛质量和完整剪映功能/效果等价仍未验收。R/G 同形不等于任意普通/激活颜色与所有混合模式均已精确验收。历史 V21/V22/V23 的当轮失败与边界保持原状。

## 6. 本轮真实交付的新边界

公开裁切+非零起点+Bezier 倒放样例的文字子项通过，但末尾 2 帧背景消失，整组交付未通过；非整帧 3 秒/29.97 fps 被既有时长发布门禁拒绝。最终分数帧率只验明确 90 帧/3.003 秒。见上述实测，不能由文字子项通过推断组合视频完整交付通过。
