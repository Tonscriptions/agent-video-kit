Normalized Gaussian recurrence reference

float_gaussian.py independently implements normalized convex forward/backward
recurrences in NumPy. Its numerical comparison reference is FFmpeg gblur,
libavfilter/vf_gblur.c and vf_gblur_init.h, n8.1:
https://github.com/FFmpeg/FFmpeg/tree/n8.1/libavfilter
The original C implementation is not included in this module. Original
attribution and its permissive notice are retained below.
