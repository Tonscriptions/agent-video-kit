## 目标与边界

把已有的本地 ASR 接口推进为可登记、可复核、可实际生成并应用中文时码字幕的原生 Windows 能力。仅使用显式提供的完整 Whisper Transformers safetensors 目录与本地 Python，不下载模型、不安装包、不调用剪映或远程服务，也不启动 Docker/WSL。CPU 与 CUDA 必须显式选择，不静默切换设备。该能力仍需真实广告语料、人工复核、说话人和逐字对齐专项验收。

## 模型登记

`asr adapter register/list/inspect` 将登记保存到 `project.extensions.local_asr.adapters`，随项目快照与恢复；登记生成独立 Rights Ledger 记录。登记要求模型路径、本地 Python、证据文件，设备为 `cpu` 或 `cuda`，CPU 线程数有界。注册支持 dry-run、幂等和事务；list/inspect 不变更元数据。

仅接受 `model_type=whisper`、无自定义远程代码的配置和完整 safetensors 权重。记录模型配置、分词器、权重分片、Python 与证据文件的大小和 SHA-256；模型文件不能越过登记根目录。执行前和独立 worker 内再次核验。许可证默认未核验，代码许可不自动赋予模型、输入或输出的商业权利。

快照恢复登记元数据，不回滚外部权重或 Python；可移植项目包也不自动打包这些外部运行环境。迁至另一设备需要显式重新登记或重链接并再次核验，不能把仅复制项目 JSON 视为模型已随包交付。

## 转写与应用

`subtitle transcribe` 在 `--model-path` 和 `--adapter-id` 之间二选一；`media understand --transcribe` 也可选择登记模型。原有 Transformers 与 FFmpeg Whisper 入口继续保留，不能把登记路径的完整性/进程隔离证据套用到旧入口。

登记路径通过原生 Python `-I -B -X utf8` 独立 worker 执行，运行缓存与中间 PCM 位于项目 E 盘目录。只从本地加载处理器和模型，禁用远程代码、训练和采样，CPU 使用 float32，CUDA 使用 float16。Python audit hook 拒绝网络调用；这不是操作系统级安全沙箱。推理显式保留超过 30 秒的输入及 attention mask，并验证返回时码、文本、模型/输入哈希和协议。未知协议、空文本片段、非有限时间、越界或重叠时码不能作为成功字幕发布；不能用全文填补无依据的片段时间。

输出必须为项目内新的 SRT，支持相对项目路径。正式应用继承源素材及登记模型的权利依赖；生成字幕资产、独立字幕片段、快照、操作与验收报告。候选台账在项目验证前可见，任何失败恢复原项目/台账并移除本轮新 SRT。既有文件一律保留。`--apply` 必须提供已登记的源资产和字幕轨道；检查重叠、字体和非有限时间线偏移。转写结果保留人工复核要求。

配套字体可通过 `media ingest` 导入 `.ttf/.otf/.ttc`，使用本地 Pillow/FreeType 验证字体及首个 face 的名称，作为独立 font 资产和权利记录保存，再通过 `--font-asset-id` 用于字幕。不能把字体交给 ffprobe 或把系统字体的可读取性视为开放许可证明；集合字体暂只选择 face 0，完整字形覆盖和可变字体专项验收待补。

## 文本质量报告

`subtitle evaluate --input <UTF8-text-or-caption> --reference <UTF8-text-or-caption>` 生成 CER 报告，可使用 `--max-cer` 门禁。`raw` 逐字符比较；默认 `nfkc-text` 明确执行 NFKC、casefold、移除标点与空白，仅保留字母、组合符和数字。默认不转换繁简，不删除重复词，不使用目标逐字稿影响识别。报告包含两端原文哈希、归一化文本、编辑距离、替换/删除/插入数和参考字符数。空参考或超出计算预算拒绝；阈值失败保留报告并返回质量失败。此指标不能替代人工听感、说话人、情绪或字幕边界验收。

## 验证要求

回归须覆盖登记只读/完整性/缺失分片/远程或自定义代码拒绝、严格 worker 结果、真实 PCM 及字幕渲染、入轨时码/权利闭包/幂等、验证与落盘失败回滚、已有输出保留、CER 编辑计数与阈值。另以本机已有真实 Whisper 权重，对已留存原样逐字稿的中文音频执行端到端转写，并保留模型/输入/输出哈希、识别原文、CER、时码、设备/内存/耗时与发布门禁结果。不得把单段通过描述为广泛中文识别质量已验收。
