## 失败、修复与参考边界

1. 首轮 36 方法为 5 失败、21 错误：测试夹具未带画布，CLI 计划缺 `short_tick`，工程包参数名错误。修正后 36/36；不是把首轮计为通过。[原日志](evidence/retime-edits-20261018-v57/targeted-first.log)、[原 JSON](evidence/retime-edits-20261018-v57/targeted-first.json)、[修正结果](evidence/retime-edits-20261018-v57/targeted-second.json)。
2. 真实第二轮 RT05 在 1.6–1.8 秒的 float PCM 最大差 **0.1399361491**。完整总线被按曲线段拆窗，且等速小段反复重启 tempo 上下文。产品修复保留整条总线和准确跳点，并合并相邻等速段；同一普通源曲线参考在最终 RT05 误差 **0**，阈值没有扩大。另加 4 项真实时钟性质测试。原输出、参考、调用、源码摘要及旧 renderer/time_mapping 字节保留在失败归档。
3. RT06 与普通恒速文件头部参考有 **0.0879335701** 的 PCM 差异。探针先证明新作者子序列的完整 PCM 与旧输出最大差 0；差异来自已经声明的尾部选择规则。独立 FFmpeg atempo 原始输出 24,475 个采样帧，实际保留末 24,000 个，与完整总线结果差 0。普通文件头部参考仍作为未接受参考公开，不声称两条路径相同。[原参考差异](../assets/retime-release-20261019-v57/RT06-legacy-head-comparison.json)、[末端选样](../assets/retime-release-20261019-v57/RT06-native-tempo.json)、[作者 PCM 探针](evidence/retime-edits-20261019-v57/author-probe.json)。自然瞬态、相位、任意声音与听感继续开放。
4. 第一/第三/第五轮分别发现空视频声音参考、样例关键帧缺 interpolation、输出窗样例起点未重置造成重叠；均为夹具错误，原失败保留。初版字幕使用错误的 font_size 字段，静帧显示过小；发行样例改为受支持的 fontsize，再实际重跑全 9 组。
5. 首次原生安装的负例断言，误用了 render 之前的项目字节作为比较基准；render 会持久化记录。负例实际退出 2。修正为操作前即时字节比较，另起全新安装目录重跑，旧失败证据不删除。
6. 未指定 HTML 工具链的嵌套专项为 73 方法、1 跳过，不能按无跳过验收；完整终态使用已固定的本地 HTML 与 Rubber Band 工具链另计。[原记录](evidence/retime-edits-20261019-v57/nested-integration.json)。
7. 发布检查首次退出 2：原 DejaVu 许可尾空格、原生安装回执 CRLF 和 unittest 子测试进度末空格被通用空白检查标记。沿用本仓库先前证据规则，为 V57 捕获目录指定 `-text -whitespace`，保留原字节与 SHA；产品 Python 仍使用 LF。没有清洗许可或原日志，也没有重写历史失败。[原始检查记录](evidence/retime-edits-20261019-v57/staged-whitespace-first.json)。

## 实现与使用约束

```json
{"action":"retime","clip_ids":["b"],"transform":{"speed":2},"sync_content":"ripple","options":{"linked":true}}
```

```powershell
python -B -X utf8 -m ai_ad_editor timeline edit --project ./work/demo --input ./retime.json --dry-run
python -B -X utf8 -m ai_ad_editor timeline edit --project ./work/demo --input ./retime.json
```

compose 使用 `{"op":"retime_clip","clip_id":"b","transform":{"speed":2}}`，可以同时包含其它原子编辑。曲线和定格示例见各 RT 请求 JSON。磁吸多选按原时钟从后向前处理；关联局部素材使用同一宿主的变速积分，保留前/中/后作者窗。显式 opt-out 的同步轨道保留绝对位置；标记、根总线自动化不猜测重定时，缩短越界则拒绝。

可直接导入[RT04 可编辑工程包](../assets/retime-release-20261019-v57/RT04.aevpkg.zip)并本地重新渲染；它含原媒体/字体、权利证据、原作者子序列及本次变速图：

```powershell
python -B -X utf8 -m ai_ad_editor convert import --input ./RT04.aevpkg.zip --output ./work/retime-restored
python -B -X utf8 -m ai_ad_editor render --project ./work/retime-restored --output ./work/retime-restored/renders/replay.mkv --container mkv --audio-codec pcm_f32le --pixel-format yuv444p --crf 0 --publish
```

离线程序包是 CPython 3.13 x64 原生 Windows 目标，使用七个随包固定 wheel；已有本地 Python 与 FFmpeg 才能启动。安装器接受显式 `--bundle`、新 `--target` 和 `--manifest-sha256`，不使用虚拟环境或下载依赖；准确摘要与本轮实际命令见[安装回执](../assets/retime-release-20261019-v57/install-receipt.json)及[51 次隔离命令记录](evidence/retime-native-release-20261019-v57/calls.json)。

静态外部 blend 留在外层；动态外部 blend-opacity、直接真实转场端点和跟踪引用拒绝自动包装。片段总预算为 20,000，沿用输出窗/深度/工作栅格限制。根轨道处理与命名路由保持在片段变速之后，不能靠拆非线性检测器轨道解决碰撞。R3 文件型外部引擎不直接消费内存总线；不把默认 FFmpeg 路径通过写成 R3 通过。

本次只静态查看接触表及实际编码抽帧，**未连续播放或人工听审**。未验收 HDR/长片/任意自然素材、动画外部混合、所有手势、全量素材/模板库、另一台机器、完整剪映功能及质量等价。64 直接输出窗和图深度预算仍需按实际输入满足，单测数量不能替代效果验收。

RT06 核对的是透明度动画在当前不透明底图上的 RGB 合成；本轮没有新增透明交付 Alpha 误差统计。VP9 Alpha 的既有 V52 受控结果保留为历史证据，不算作本轮重跑或任意 Alpha 内容验收。
