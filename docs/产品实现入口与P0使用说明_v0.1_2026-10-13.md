## 1. 已实现的 P0

当前代码已经提供一个可复现的最小闭环：创建 Agent Project、导入本地素材并探测流信息、登记 Rights Ledger、应用时间线变更集、结构/时间/引用/权利校验、生成本地 MP4、写渲染清单和操作记录，以及检查本机依赖。Rights Ledger 0.2.0 支持不可变修订、状态转换、撤下/争议/过期阻断、渠道字段、恢复时的新证据、审计事件、模板/父资产依赖、历史影响和 `rights decide` 的非破坏性 replace/delete 决策、审批/撤销链与替代资产依赖门禁；已批准处置会阻断后续发布，确定性 `manifest_sha256` 发布清单保留决策证据。渲染器已支持常用淡入淡出、相邻片段的 crossfade/wipe/slide 以及本机 FFmpeg xfade 转场目录、灰度/色调/模糊/锐化/亮度对比度/饱和度/伽马/色温/色彩平衡/曝光/色阶/曲线/降噪/时域混合/镜头校正/框线/去闪烁/边缘/去色带/防抖/直方图均衡/渐变平滑/海报化/噪声/反色/色键、rectangle/circle/ellipse/path/polygon 遮罩、基本形状与固定点数 polygon 的 mask.* 关键帧、静态 line/cubic path segments 采样、invert 反转和静态/动态 alpha-only feather 羽化（polygon 动态 feather 使用固定边缘的内侧距离近似）、multiply/screen 等混合及 blend.opacity 关键帧、像素/归一化 crop 及 fit/fill/stretch 模式、`crop.x/y/width/height` 位置与尺寸关键帧（通过固定画布逆向采样保持输出尺寸）、静态与线性/cubic Bezier 关键帧缩放/旋转/透明度/位置、倒放、反向速度曲线段反射、任意片段内时间点定格、全局与局部区间调节层、项目内 LUT3D、WebM `yuva420p` 透明画布输出、独立 `subtitle` 文字轨道与 text generator、片段 transform/keyframes/mask/blend 按 `track.order` 与视频轨道共同合成、纯文字黑/透明基础画布、本地透明层旋转、内联字幕与 fade/slide/typewriter/pop/bounce 文字动画、drawtext 行距/描边/阴影/对齐/字形整形/边界修正、本地字体 advance width 和按字体优先换行、源文本逐字时间匹配、速度、音量关键帧、`audio.pan`/`pan` 声像关键帧、保留立体声通道的数值声像、降噪、压缩、均衡、高低通、对白增强、变调、混响、响度归一化和旁白闪避。项目还支持手动快照、时间线写入前快照、快照恢复、已知旧项目的 `project migrate`（写入前快照、候选校验和迁移报告）、丢失资产按哈希重链接和唯一文件名近似重链接；质量检查覆盖画布、流、时长、音画时长差、可选黑帧、响度和目标 LUFS，并可通过 `quality scopes` 生成本地 waveform/vectorscope/histogram 色彩审查图和哈希报告。`policy audit` 在项目发布前扫描 JSON/JSONL 中的远程协议、URL、云存储和服务商标记；媒体导入与格式转换在写入前复用同一门禁，确保离线项目不携带远程引用。另提供本地 FFmpeg 镜头/静音/节拍锚点理解、离线字幕格式解析、代理/缩略图/波形准备、本地启发式高光候选、FFmpeg 内置 flite 的 ASCII/英文离线 TTS、模板变量快照、批量隔离渲染、本地资产库索引和 Agent Project/OTIO/Kdenlive XML 的受限互操作入口。素材库索引当前为 `0.3.0`：它保存确定性 token、同 stem 字幕侧车文本、媒体时长/尺寸/音频流 facets，支持 stat 签名增量刷新和可选 FFmpeg `ahash-v1` 画面候选，并提供本地词法查询、SHA-256 精确重复组和 `library similar` 人工复核候选；其 `vector_index=false`，不冒充 VLM 内容理解。效果目录通过 `effects list/inspect` 公开 41 项本地滤镜及参数限制，供 Agent 在生成时间线前做能力规划。

最近补齐的输出/全局调色边界：`settings.adjustments` 在视频轨道合成、转场、遮罩和混合之后按顺序执行序列级效果栈，并复用已验证的效果参数关键帧；省略区间时覆盖全序列，提供 `start_tick`/`duration_tick` 时按序列时钟执行局部区间层；项目内 `.cube/.3dl/.csp/.dat` LUT 资源通过 `lut3d` 走本地 FFmpeg，并在校验阶段执行路径、扩展名、存在性和登记 SHA-256 门禁；`lut register/list/inspect` 提供项目级清单与 Rights Ledger 追踪；连续片段可以显式使用 `auto_handle` 转场并保持原时间线长度。输出支持 yuv420p/yuv422p/yuv444p 及 10-bit 变体，`settings.color` 的 primaries/transfer/matrix/range 显式传递给 FFmpeg。LUT 强度、预览缓存、HDR 代理和跨设备色彩一致性仍保留为后续验收项。

```text
project init → media ingest → timeline compose → validate → rights check → render → quality check
```

所有命令输出 JSON envelope；`--dry-run` 可用于写操作计划；项目文件、Rights Ledger、校验报告、操作记录和渲染 manifest 使用临时文件加原子替换。渲染输出只允许位于项目目录内。

根目录 `ai-ad-editor.ps1` 会把 `TEMP`、`TMP`、Python 字节码缓存和本地模型/库缓存指向 `product/.runtime/`；CLI `doctor` 会返回实际运行缓存路径。模型只允许从显式本地目录加载，绝不自动联网下载。

`--progress jsonl` 会把结构化进度事件写到 stderr，保持 stdout 的 JSON envelope 可供 Agent 直接解析；渲染事件由 FFmpeg 本地 progress 文件驱动，覆盖开始、运行进度、产物写入、完成、失败和取消；`operation inspect` 可读取操作记录。项目绑定写命令已经支持 `--idempotency-key` 的结果重放和冲突拒绝，并在完整读改写期间持有项目级原生文件锁；锁冲突返回 `PROJECT_WRITE_LOCKED`、退出码 6 和 `retryable=true`。`render --cancel-file` 可以在启动前或运行中终止本地子进程、清理临时产物并记录取消状态。失败/取消的 render 会保存项目指纹、素材哈希、渲染计划和输出规格，`render --resume <operation_id>` 仅在依赖未变化时重建渲染，并在输入变化时结构化拒绝。`queue enqueue/list/inspect/run/cancel` 将多版本输出持久化到项目 `operations/render-queue.json`，复用同一渲染器，支持显式失败重试、顺序执行和运行中取消；`queue cancel` 在渲染器持锁期间仍通过原子 `.cancel` 标记递交请求，`queue list/inspect` 显示 `cancel_requested`，由运行器确认最终状态；完整状态机见[本地渲染队列契约](./specs/本地渲染队列与任务状态契约_v0.1_2026-10-14.md)和[项目写锁与取消通道契约](./specs/本地项目写锁与取消通道契约_v0.1_2026-10-14.md)。

|---|---|

| `migration.py` | 纯函数旧项目补全、资产指纹门禁、schema 迁移报告和迁移链 |

| `render.py` | 用受控参数数组构建 FFmpeg filter graph，执行本地轨道/序列级效果、动画、音频链和色彩/像素格式输出，并原子发布 manifest |

| `transcribe.py` | 读取已存在的 Transformers 模型执行离线 ASR；可解析时间戳并写入项目内 SRT，不自动下载模型 |

`timeline compose` 的变更集还支持 `update_clip`、`remove_clip`、`split_clip`、`ripple_insert`、`ripple_delete`、`slip_clip`、`slide_clip`、`set_clip_speed`、`set_clip_speed_curve`、`reverse_clip`、`freeze_frame`、`add_sequence`、`append_sequence_clip`、`apply_motion_preset`、`add_track`、`update_track`、`remove_track`、`add_marker`、`remove_marker` 和 `set_sequence_duration`；内置 `zoom_in`、`zoom_out`、`pan_left/right/up/down`、`ken_burns`、`rotate_in/out`、`fade_in/out` 和 `shake` 预设。写入前会再次执行机器 schema 与项目语义校验，避免把无法渲染的时间线保存为成功状态。`settings.adjustments` 支持全序列栈，也支持用 `start_tick`/`duration_tick` 声明局部区间层；渲染器在轨道合成后对区间做 trim、效果、concat，音频保持不变。嵌套序列会在渲染时展开，静态 transform/effects/blend 会下推到子片段，单级和多级父级的动态缩放/旋转/位置/透明度会按最终序列时钟映射到子片段，嵌套 `speed_curve` 会用本地解析积分把子序列源边界映射到最终时钟，静态子片段 reverse 会保持时序，父子 mask 会顺序合成 alpha；任意时间点 freeze_frame 在已完成时间映射的视频流上分支并回接，默认同时在同一局部时间点插入等长静音，`audio_mode=continue` 才在尾部补齐；叶片内部变速仍按区间平均速度，嵌套父级 reverse 会反转 Bezier 控制点，非线性 speed_curve 下叶片 keyframes 的分段时钟映射和不同坐标空间的多重 mask 仍会产生近似边界。

Agent 规划效果时先执行 `python -m ai_ad_editor effects list`；`--query color` 可按类别筛选，`effects inspect --name curves` 会返回可接受的点字符串和范围。新增原生滤镜默认是静态执行，若变更集带有不支持的效果参数关键帧，渲染 manifest 必须保留 `RENDER_FEATURE_APPROXIMATE`，不能静默宣称剪映级逐帧效果。

`media track` 使用本地模板匹配，从视频抽取采样帧并输出 `frames[]`、置信度和 `transform.position.x/y` 关键帧；传入 `--clip-id` 会先创建 `before-track-apply` 快照，再把关键帧写回片段。它适合可解释的 Agent 粗跟踪，遮挡、尺度变化、镜头切换和动态形状仍需后续模型级跟踪器或人工复核。

项目绑定的写命令可以带 `--idempotency-key`。相同项目、相同命令、相同请求内容会重放原始 JSON 结果；同一幂等键对应不同请求会返回 `IDEMPOTENCY_CONFLICT`，记录保存在项目的 `operations/idempotency/`。

渲染完成后可以运行 `python -m ai_ad_editor quality check --project <项目目录> --input <项目内 MP4> --require-audio`；加上 `--max-av-sync-ms` 检查视频/音频流的时长差，加上 `--expensive` 执行黑帧和 `ebur128` 响度扫描，配合 `--target-lufs`、`--lufs-tolerance` 和 `--fail-on-black` 可把渠道阈值变成失败门禁，报告写入 `validation/`。这些检查和 golden 哈希漂移门禁已具备代码和回归证据，但固定版权素材集、视觉字幕验收和跨设备阈值仍未关闭。

交换格式可以通过 `convert export --target-format otio` 或 `--target-format kdenlive-xml` 输出；两者都会生成转换报告，无法直接表达的效果会标记为 `Approximate`，导入时由报告决定是否接受降级。
- 本地 `lavfi` 颜色+正弦波素材完成导入、Rights Ledger 核验、时间线编排、验证和 1080×1920 MP4 渲染。
- 本地 FFmpeg flite 完成 ASCII/英文 TTS WAV 生成、项目内路径门禁、操作记录和非 ASCII 输入结构化拒绝；多语言模型 TTS 仍按 P1 处理。
- `doctor` 已确认原生 Windows、Python 3.13、FFmpeg/FFprobe 8.1；只读取 Docker/WSL PATH，不启动它们。

## 5. 尚未达到剪映等效的部分

P0 只证明稳定的 Agent 项目/渲染底座，不代表已经达到剪映完整功能。离线 ASR 的 CLI 适配器已经存在，但必须提供真实本地模型快照才能做转写验收；本地 FFmpeg flite 已提供 ASCII/英文 TTS 基线，但多语言/情绪/可控语速 TTS 仍需模型适配器；稳健模型级对象跟踪、可变点数路径动画、复合转场、完整多总线音频混音、完整 OTIO/Kdenlive/外部项目转换、GPU 调度、语义素材推荐、素材/模板目录、固定版权素材集的完整 golden 视觉证据和 130 项能力矩阵仍需按 P1/P2 逐项实现与验收。当前已提供本地模板跟踪、固定点数动态 path/polygon 遮罩与内侧边缘距离近似 feather、静态 line/cubic path segments 采样、rectangle/circle/ellipse 动态 feather、`crop.x/y/width/height` 动态裁切窗口的 CPU `geq` 固定画布逆向采样、速度曲线、单级和多级父级的动态缩放/旋转/位置/透明度映射、嵌套序列展开、嵌套 `speed_curve` 的本地解析积分边界映射、静态 reverse 时序保持、父子 mask 顺序 alpha 合成、独立文字轨道透明层旋转、fade/dissolve alpha 与 slide/wipe 空间转场和优先使用本地字体 advance width 的逐字字幕高亮，但这些能力分别有漂移、点数固定、曲线段逐点动画仍不支持、动态裁切在跨素材尺寸上的 golden 仍待补、叶片内部变速按区间平均速度、音频按短段 atempo 近似、非线性 speed_curve 下叶片 reverse 关键帧的分段近似、mask 坐标空间、独立文字复杂 transition 句柄/复杂模板和跨字体/渲染器文字度量边界；typewriter/pop/bounce 已有本地近似渲染，片段内嵌字幕 rotate 仍保持近似，独立文字轨道 rotate 已执行实际透明层旋转；质量检查的音画时长差、黑帧和 LUFS 以及本地 golden 哈希漂移门禁具备实现，但正式版权素材集、字幕视觉和跨设备阈值仍未关闭。当前渲染器会对不在本地安全映射白名单的效果和复杂转场发出 `Unsupported` 警告，不能静默声称等效；基础关键帧 cubic Bezier 在提供合法控制点时已可由 FFmpeg 表达式执行。
