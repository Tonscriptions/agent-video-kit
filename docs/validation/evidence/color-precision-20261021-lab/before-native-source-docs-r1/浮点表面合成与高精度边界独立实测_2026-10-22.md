# 浮点表面合成与高精度边界独立实测

这是尚未接入编辑器的独立实验。当前主线为 V90；V91 音频时钟的第一轮 2145 完整回归因 4 个队列问题失败，已另行修复，当前 2148 完整门禁由原任务执行。本实验复制的是 V91 修复前的 267 产品输入，287 个基础文件逐一相等；不宣称该父版已通过或已发布。

本实验增加浮点合成与几何两份模块及两份测试，当前 271 冻结输入、165 包内资源；22 个新增测试方法。最早269输入/12方法的结果作为历史纪元保留，两份合成源码与测试保持字节相同，后来只新增几何模块与测试。与音频队列修复后的父候选还差两个队列文件，接入前必须明确迁移并重新验证。[基础复制清单](evidence/color-precision-20261021-lab/foundation-r1.json)、[合成源码快照](evidence/color-precision-20261021-lab/before-float-geometry-r1/manifest.json)、[完整实验约束](../specs/浮点表面合成与高精度边界_实验_v0.1_2026-10-22.md)。

仅原生 Windows、既有 Python/NumPy/Pillow/FFmpeg 8.1；未用 Docker、WSL、容器、虚拟环境或在线模型，没有打开交互浏览器标签页。所有原片由本项目生成，可按 CC0-1.0 公开；无外部图片、字体或模型。
