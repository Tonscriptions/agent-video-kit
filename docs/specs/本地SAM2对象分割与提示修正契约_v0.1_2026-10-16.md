# 本地 SAM2 对象分割与提示修正契约

|---|---|

| 状态 | 有效 |

| 范围 | 原生 Windows、本地 safetensors、显式 CPU/CUDA、多对象提示与透明视频 |

## 1. 产品目标

实现差异 #55/#94 所需的通用对象选择与视频分割能力。差异 #56 的物体移除、局部修复和生成填充仍未实现；本模块只提供其可复用的选区基础。Agent 可以用正负点、框、多对象联合、后续帧修正和显式镜头切换重置选择人物及商品。分割概率不是物理透明度或发丝真值，不能把 SAM2 分割当作 RVM 前景颜色重建或完整剪映抠像质量验收。

使用[官方 SAM2 视频接口](https://huggingface.co/docs/transformers/en/model_doc/sam2_video)的流式会话；只加载已有本地模型，不安装依赖、不解析在线模型 ID、不下载权重、不使用远程自定义代码。Python 中须已有 Torch、Transformers、numpy、Pillow。CPU/CUDA 在登记时明确选择，固定 FP32，不自动切换设备。

## 2. 登记与命令

新增视觉 engine `transformers-sam2-video-local-v1`、协议 `agent-video-sam2-segmentation-v1`。`media adapter register` 要求本地模型目录、原生 Python `.exe`、证据文件及 `--device cpu|cuda`（默认 cpu，设备写入登记）。完整 safetensors、配置、Python、证据和执行实现进入哈希清单，运行前后核验；模型与 Python 不随项目包分发。

`media matting --asset-id <视频> --adapter-id <SAM2> --derived-asset-id <新ID> --prompts <本地JSON>` 输出项目内 QTRLE/ARGB MOV，复用已验收的有界管道、全帧 RGBA 解码哈希、源音频时钟、取消/超时、Windows Job 和事务/权利依赖。`--object-id <整数>` 可重复，默认合并全部对象。`--mask-mode binary|probability` 默认 binary；`--logit-threshold` 默认 0。概率模式为 sigmoid(logit-threshold)，必须披露其分割概率性质。原始 RGB 保持 straight，所得 alpha 与已有源 alpha 相乘。

可选 `--apply --track-id <视频轨道> --audio-track-id <音轨>` 与 RVM 相同。源范围、旋转/SAR、缩小、CFR、片尾补帧与预算遵循[RVM 透明素材契约](./本地RVM人物视频抠像与透明素材契约_v0.1_2026-10-16.md)。RVM 不接受 SAM2 提示参数。

## 3. 提示格式与时钟

```json
{
  "version": "1.0.0",
  "coordinate_space": "normalized-output",
  "frames": [
    {"frame": 0, "objects": [
      {"object_id": 1, "box": [0.0, 0.0, 0.8, 0.999], "points": [{"x": 0.43, "y": 0.32, "label": 1}, {"x": 0.20, "y": 0.58, "label": 1}]},
      {"object_id": 2, "box": [0.55, 0.60, 0.95, 0.98]}
    ]},
    {"frame": 12, "objects": [
      {"object_id": 2, "points": [{"x": 0.70, "y": 0.80, "label": 1}]}
    ]},
    {"frame": 24, "reset": true, "objects": [
      {"object_id": 1, "box": [0.0, 0.0, 0.8, 0.999], "points": [{"x": 0.43, "y": 0.32, "label": 1}, {"x": 0.20, "y": 0.58, "label": 1}]},
      {"object_id": 2, "box": [0.55, 0.60, 0.95, 0.98]}
    ]}
  ]
}
```

`frame` 是经过范围裁切、显示方向/SAR 归一化及 CFR 后的零基输出帧号；坐标是该输出画面的归一化坐标，范围 0..1。框为 x1/y1/x2/y2，必须有正面积。点 label 只允许 1（保留）或 0（排除）；每个对象须有框或至少一个正点。首条事件必须在第 0 帧，帧号严格递增、无重复。对象 ID 为正整数，事件内不得重复。后续修正替换该对象在该帧的提示；不会回改已经输出的帧。提示范围须人工/上层 Agent 复核：单面部点可能只选脸，即使相同多点在不同重置帧也可能缩小范围，可加入对象框并重新检查。

显式 `reset` 清除前一镜头全部会话状态；重置事件必须为所有此前已激活对象重新提供提示。新对象可以在后续帧加入；未出现前不参与联合结果。重置不等于自动识别镜头切换。输入及规范化提示摘要进入报告，不允许静默忽略未知字段、越界坐标、未声明对象或无效帧。

## 4. 工程与质量门禁

流式执行每次读取一帧，不预载整个视频；保留模型所需的条件状态与最近非条件记忆，清理过期图像和历史索引。状态张量预算为 512 MiB，超出结构化失败；它不代表模型、CUDA 缓存或整个进程内存。提示文件最多 128 KiB、256 个事件、8 个对象、每对象每次 32 个点。过多条件状态可触发预算，需显式分镜/重置。

worker 必须返回请求/模型/源/提示摘要、设备、版本、逐帧处理计数、alpha 统计、状态预算与修正/重置计数。管道拒绝格式错误、帧缺失、非有限输出、哈希不符和设备回退。源素材及模型共同约束派生资产发布；模型卡声明许可证不自动使任何源素材获得商业授权。

验收必须包含协议与真实 FFmpeg 回归、真实本地模型、多对象/商品、修正/重置、透明往返、权利阻断与目视结果。自然运动、遮挡恢复、边缘/发丝和广泛广告素材的质量保持待验收，不能仅以测试数量关闭差异。

## 5. 本轮验收与边界

278/278 完整回归和 21 项专项通过；真实 CPU/CUDA、多对象/选择、修正/重置、自然运动及概率透明交付见[实测](../validation/SAM2本地对象分割与提示修正实测_2026-10-16.md)和[机器证据](../validation/evidence/sam2-smoke-20261016.json)。接口契约有效不等于广泛画质通过：领口/手部漏抠、重置选区变化、概率残影、发丝/遮挡/真值和商业许可仍待验收。

Python 网络 guard 与 local_files_only/trust_remote_code=False 约束本轮原生加载；它们不是操作系统网络隔离。

后续新增[蒙版逐帧核验与检查点契约](./本地蒙版逐帧核验与检查点契约_v0.1_2026-10-16.md)，用于核对实际编码结果。正提示点不保证对应二值像素必定选中；须区分目标对象和保留对象，再用明确 selected/clear 断言及完整范围目检复核。[后续自然实测](../validation/本地蒙版范围与正负检查点实测_2026-10-16.md)中女孩前臂误选被修正，但男孩手腕仍漏选，两份核验报告都保持失败；稀疏点通过数不替代完整分割质量。
