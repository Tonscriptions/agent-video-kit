# 离线 CTC 字词强制对齐实测

状态：离线 CLI、真实中英文推理、编码时钟和本机隔离安装已核验；**英文词块定位精度门槛未通过**，完整回归 **1135/1135，1592.399 秒**，0 跳过，170 文件前后冻结。

对应[先行契约](../specs/离线CTC字词强制对齐契约_v0.1_2026-10-18.md)及[模型/语音/发行依赖来源](../third-party/CTC模型与英文演示语音来源_2026-10-18.md)。V49 增加独立的标准 Wav2Vec2 CTC 强制对齐，消费明确原文，而非识别后重写。OpenFilm 分句、已有 Whisper、显式描线各自保留；本轮不把 OpenFilm 的固定歌词时刻解释为通用声学模型。

**预声明最大边界误差 2/30 秒，即 66.6667 毫秒；英文实测最大 258.1875 毫秒，失败。** 作者用阈值修剪并摆放的词块仅是受控参考，不是逐音素真值。实际 CTC 发射峰形成较窄的字符/词区间，多个开始偏晚、结束偏早；没有扩大区间、移动真值或放宽门槛以通过。高亮时钟正确与声学准确是两个结论。

## 实际硬件、冻结与失败

五个开发 worker 共八次前向，安装版另一个 worker/一次前向，不能与协议 mock 或 CLI 数混计。实际 NVIDIA RTX 3060；Python 3.13.14、NumPy 2.4.6、Torch 2.13.0+cu130、Transformers 5.14.1。英文 worker 用时短 86.054 秒、长 10.567 秒、SRT 11.295 秒；中文短 58.938 秒、长 18.805 秒。冷启动和机器并行负载不同，不是稳定性能承诺。英文最高已记录 CUDA 分配 866,922,496 字节，中文 1,960,642,048 字节；这不是全进程内存或其他素材上限。全部实际 worker 网络审计无请求，未安装或下载依赖。

早期实测与最终发行之间，只修改四个发行相关冻结文件：`product/pyproject.toml`、`product/offline/build.py`、`product/offline/install.py`、`product/tests/test_offline_install.py`；对齐、渲染及其余 166 文件字节相同。最终安装版再执行了真正模型和音画比较；不把早期 170 文件整个冻结集合冒充最终集合。

保留的失败包括：官方源/范围 DNS 与中断、英文旧配置缺内置处理器类型、中文运行副本证明尚未落盘时启动被拒绝、繁体 OOV、英文边界门槛、初始重复音轨、错误 16 kHz 预期、首次时钟审计的 `sha256:` 前缀比较错误，以及缺 Pillow 的隔离安装。分别见原取得/实测目录、[初始双音轨 MKV](../assets/ctc-alignment-20261018/initial-double-audio.mkv)、[首次时钟审计失败](evidence/ctc-media-clock-20261018/failure.json)；没有删除失败或改写为通过。

CTC 允许把错稿强制安放；后验置信不是准确率。模型字符峰时间、高亮正常和工程事务成功均不等于音节起止正确。**英文受控定位门槛未通过；中文缺独立精标；歌词/歌声、多人重叠、口音噪声广泛语料、完整声音效果、长片/HDR、内容库与完整剪映功能/效果等价仍未验收。** 后续应先在保留原门槛的独立语料上评估边界估计/声学适配，不能自动给成功对齐结果盖质量通过章。

[最终来源/发行/媒体/文档审计](evidence/ctc-release-audit-20261018.json)核对上述计数、全部公开文件 SHA 及四个发行文件差异；不把核验记录视为声学质量通过。

最终发行审计首次也曾把原始十六进制摘要与带 `sha256:` 前缀摘要直接比较而误报；实际十六进制值一致，统一摘要表示后通过。执行时脚本和失败记录保存在 `evidence/ctc-release-audit-attempt1-20261018/`，未修改产品或媒体来消除这次审计错误。
