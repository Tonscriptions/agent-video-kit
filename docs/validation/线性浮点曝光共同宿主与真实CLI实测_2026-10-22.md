# 线性浮点曝光共同宿主与真实CLI实测

本次限定交付为现有显式Float32时间线上的静态曝光。新增`float_exposure.py`与14项曝光测试；修改共同宿主、能力发现和既有预览的未支持效果夹具。父候选300输入，本候选302输入，5个产品路径有差异；父版本完整回归和实际发布须独立确认，不能据已有源码/安装测试推断全套产品通过。

曝光量范围−3..3 EV，黑位−1..1。实现使用NumPy分块浮点运算；不复制FFmpeg实现代码或在运行时请求网络。参数语义与边界参照[FFmpeg官方实现说明](https://ffmpeg.org/doxygen/trunk/vf__exposure_8c_source.html)，并以本机FFmpeg 8.1真实Float32调用独立交叉核验。系数和每步运算按声明的binary32边界处理，允许约定的数值误差，不宣称跨编译器逐位相同。

首轮原始7组公式观察没有覆盖分母符号；后续12组交叉测试检出2处符号不符，原失败未改写。修正的是产品系数计算，没有降低断言容差或删去失败用例。相关74项通过是一次实际执行，不把首轮14项、74项、安装目标274项或全套目标2369项累计成不同功能数量。
