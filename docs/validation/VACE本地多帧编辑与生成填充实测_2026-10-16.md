本轮为 `media inpaint` 增加显式提示词控制的联合视频窗口。测试通过、真实模型能运行、功能成片成功与达到剪映画质分别验收。冻结源码后的完整回归 338/338 通过，32 帧 SAM2→VACE→成片正式链路成功，但自然镜头抽样画质未通过，部分帧明显差于匹配输入的 LaMa 对照。8 帧、30 步受控正式链路也成功，但仍有暗矩形补丁；功能成片成功不能替代画质验收。完整日志摘要、源码、模型清单和正式结果见[本轮机器证据](./evidence/vace-smoke-20261016.json)。

## 3. Windows 共享 I/O 故障与修复

此前自然视频流程在 SAM2 写入进度 JSON 时失败：父进程打开进度文件，`os.replace` 报 `WinError 5`，没有进入 VACE 推理。增加删除共享后，原生最小实验仍复现普通替换失败。

修复使用允许删除共享的只读快照，并在普通替换冲突时调用原生 `FileRenameInfoEx` 的 POSIX 替换语义；持有的旧句柄继续读取完整旧内容，新打开路径读取完整新内容。模型校验的拒绝删除读锁继续阻止覆盖；短暂占用有界重试，持续占用保留原目标、报错并清理暂存文件。

| 验证 | 当前结果 |
|---|---|
| 原生最小实验 | `ReplaceFileW` 和 `FileRenameInfoEx` 对共享 7 的读取成功，对共享 1 的读取拒绝 |
| 原子 I/O＋摘要读锁 | 12/12，4.452 秒；包含跨进程旧快照、20 次连续发布及模型锁拒绝覆盖 |
| VACE＋上述原生专项 | 35/35，50.917 秒；包含 23 项 VACE、7 项摘要读锁、5 项原子 I/O |
| 自然视频重跑 | SAM2、VACE、音频/入轨、MP4、quality/validate/policy 全部成功；无进度替换冲突 |
| 完整回归 | 冻结源码后 338/338，1583.083 秒；包装任务 1586.828 秒，源码前后摘要一致；与权重校验并行执行，耗时不是独立性能基准 |

历史 323 项只证明当时源码；后续 326 项运行因源码中途改动失效，333 项运行中断，34 项专项出现 1 项错误。这些历史不覆盖当前修复版本。

## 5. 匹配 LaMa 对照与自然画质结论

另以相同源文件、完全相同的解码 SAM2 蒙版、grow 4、最大模型边 256、context 64、threshold 0.5、feather 0 运行 LaMa。32 帧、CUDA、完整交付 57.402 秒；蒙版外 RGB/全部 alpha、原声、成片、项目、策略和预期权利阻断通过。两模型架构和窗口不同，此对照只用于定位样例缺口，不构成等架构或广泛性能/质量排名。

独立解码全部 32 帧，再抽样 0/4/8/12/13/16/17/21/25/26/29/30/31 帧，覆盖两段窗口重叠及最后短窗口。源、蒙版、LaMa、VACE 四列联系表保存在本地未提交媒体目录，其哈希、帧号、独立像素核验与目视记录嵌入[机器证据](./evidence/vace-smoke-20261016.json)。

| 检查 | 结果 |
|---|---|
| VACE 早段 | 移除男孩的位置出现浅色异形物、绿色/紫色块 |
| VACE 中段/首个重叠附近 | 蓝灰色块、椭圆及形体残留，床单与墙面纹理不连续 |
| VACE 后段/末窗口 | 腿部/床边生成彩色块及人形残影，部分帧明显差于 LaMa |
| LaMa 对照 | 大部分目标被移除，彩色幻觉较少；床单仍有涂抹、软补丁及人物交叠/腿部残留 |
| 自然画质 | **未通过**；不能声称 VACE 改善了 LaMa 或达到剪映效果 |
| 时序范围 | 已记录相邻帧选区 RGB 差异诊断；没有自然背景真值，也未做连续播放复核，不能把差异均值当时序质量得分 |

## 6. 受控样例与后续校准

相同 8 帧渐变真值、grow 0 的 **30 步正式 CLI 已成功**，两窗口 0–4/3–7、重叠 2、seed 0/1。蒙版外 RGB 改变 0、全部 alpha 一致；1 帧空选区旁路，512 个软 alpha 像素保留。正式登记、29 项完整性、原声/入轨、MOV/MP4、quality/validate/policy 与预期权利 exit 7 通过。

| 指标 | 30 步正式结果 | 验收边界 |
|---|---|---|
| 选区真值 | masked PSNR 7.737→25.171 dB，提升 17.434 dB；相邻误差变化 MAE 2.531 | 仅本简单合成渐变背景，不是广泛质量或时序得分 |
| 抽样目视 | 0/3/4/7 帧；空帧正常，彩色遮挡物被替换，但有明显较暗矩形补丁 | 生成区域未重建正确渐变，受控视觉质量也未通过；未做连续播放 |
| 完整流程 | 1771.617 秒；管道 985.144 秒、worker 978.803 秒；源码前后不变 | 含登记/全文件读取/加载/交付，非独占基准 |
| 模型阶段 | 加载 510.662 秒，其中文本阶段 298.118 秒；窗口 10.742/5.982 秒；正/负 21/14 tokens | 无提示词截断/扩写；阶段时间不能重复相加 |
| 数组/显存 | 自有数组上界 11,403,264 bytes；Torch 峰值已分配约 6.75 GiB | 数组不含模型/激活；显存不是总进程/设备占用 |

此前 5 步加载/API 的 27.046 dB 保留为历史，不能代替完整 CLI，也不支持“步数增加就必然改善画质”的结论。两次正式 VACE 运行分别覆盖自然与受控两个场景，匹配 LaMa 对照单独计数。

2026-10-16 核对上游：VACE 主仓库列出 1.3B 参考尺寸约 81×480×832；原版推理脚本默认 50 步、shift 16、81 帧，而本次使用的官方 Diffusers scheduler 配置是 flow_shift 3.0，与本地固定配置一致。不能据原版数值不同就判定本地 scheduler 配置错误。来源：[模型尺寸](https://github.com/ali-vilab/VACE)、[原版推理参数](https://github.com/ali-vilab/VACE/blob/main/vace/vace_wan_inference.py)、[Diffusers scheduler](https://huggingface.co/Wan-AI/Wan2.1-VACE-1.3B-diffusers/blob/main/scheduler/scheduler_config.json)。这些上游页面可更新，本轮模型本身固定 revision 如第 1 节。

当前 17 帧、最大模型边 256 的局部 ROI 明显小于参考配置，生产路径只缩小而不放大 ROI。分辨率/上下文、窗口时长、30/50 步和 scheduler 配置是待分离验证的假设，尚未证明哪项是伪影根因。后续同输入/seed 逐项校准，明确报告资源和失败；开发侧直接调用诊断不能冒充正式 CLI 验收。

## 7. 未关闭的验收项

自然视频纹理/残影/重叠窗口、持续播放、提示词编辑范围、长输入和跨设备资源仍未通过。完整模型/源素材许可和成片用途独立核验。姿态、美颜、全视频生成、复杂广告模板及其他剪映差异继续按[能力矩阵](./能力覆盖与验收矩阵_v0.1_2026-10-13.md)推进，#56 保持 `degraded`，不缩减完整功能与效果对标目标。
