## 1. 每个源帧覆盖一个时间区间

源按登记帧率 F 建立 CFR 时钟；第 k 帧表示 `[k/F, (k+1)/F)`。裁切 `[source_in, source_out)` 保留与该范围相交的帧，包括两端部分相交的帧。源帧区间为：

```
first = floor(source_in_tick / ticks_per_second * F)
end_exclusive = ceil(source_out_tick / ticks_per_second * F)
```

这两个边界使用有理数计算，交给原生 `trim=start_pts:end_pts`，不先转换成浮点秒再让 1/F 的粗时间基准舍入。短于一帧但非空的源范围仍保留它覆盖的源帧。该规则针对已经显式归一化的 CFR 显示时钟，不声称保留原始 VFR 呈现时间戳。

帧率探测无效时沿用既有输出帧率回退，并在清单和 `NESTED_SOURCE_CFR_NORMALIZED` 中保留实际采用值。归一化不新增模型推理、外部服务或隐式下载。

## 2. 首帧、内部帧和 EOF 分别映射

普通方向的首帧锚定实际 source_in；倒放首帧锚定实际 source_out。内部正放继续使用源 PTS；内部倒放用所选源区间的右边界减去 `N/F`，避免把被裁掉的半帧再次计入偏移。

原生 setpts 在所有帧之后还会求值 EOF。恰好读完所选源帧数量时，该结束事件映射到正放的 source_out 或倒放的 source_in，再经过原有完整祖先解析时钟组合。不能把“最后一个完整帧位置”当作真实裁切终点，否则低速尾部会提前失去画面。

如果实际输入提前结束、没有读满预期数量，不把它伪装成已到作者边界，不新增 tpad 或向后克隆修复缺失输入。帧率归一化本身仍可能按既有 CFR 采样规则重复输入帧；这与将缺失素材延长到任意作者终点是不同的行为。

## 3. 最终输出是公共网格上的半开区间

对显示帧率 R、展开片段作者范围 `[start, start+duration)`，可见样点索引为：

```
first_output = ceil(timeline_start_tick / ticks_per_second * R)
end_output_exclusive = ceil((timeline_start_tick + duration_tick) / ticks_per_second * R)
```

解析 PTS 后的 fps 继续使用公共网格，不重设分段局部相位。其后用上述整数区间裁切，不重置 PTS。即使 AVTB 表达式舍入到了前一帧，也不得在作者起点前显示；最后一帧不得泄露到片段后的真实时间线留白。区间内没有任何输出样点时，该视频分支应为空，主时间线继续产生背景。

不得通过延长项目时长、删除末尾留白、放宽发布门禁或掩盖黑帧来证明覆盖正确。测试应同时检查作者范围内的可见性、源帧身份及前后范围外的不可见性。

## 4. 清单与作者数据

沿用既有 timeline compose/render 接口及作者 Schema，无新增顶层 CLI 参数。`inputs[].nested_time_mapping` 继续保留 version、maps、source_display_fps、video_pts 和 keyframes，并新增 `frame_sampling`：

| 字段 | 含义 |
|---|---|
| protocol | `covering-source-cfr-half-open-v1` |
| source_frame_start / source_frame_end_exclusive | 实际计划选择的源 CFR 整数帧范围 |
| expected_source_frames | 预期原生输入帧数，不等于已经独立观测的帧数 |
| output_frame_start / output_frame_end_exclusive | 最终公共帧网格上的作者可见范围 |
| first_source_seconds / eof_source_seconds | 首帧和结束事件采用的源端点 |
| eof_event | `authored-boundary-after-expected-source-frame-count` |
| output_interval | `authored-half-open-on-global-cfr-grid` |

这些字段描述计划，必须另外用原生编码帧验证。作者 assets/settings/sequences 规范摘要及 Rights Ledger 原字节在渲染前后保持一致；正常 outputs/provenance 登记不算作者时间线变化。

## 5. 验收与保留边界

专项含正放/倒放、Bezier/线性速度、起点差一个 tick、极短源范围、显式尾部留白、两个部分裁切的倒放祖先、非零叶片源偏移、30000/1001 源及输出帧率，并保留对齐边界和无输出样点的控制。可见性必须逐输出样点完全一致；源帧身份沿用受控门槛≤1 个登记源帧，不将编译清单当作最终像素真值。

公开实测须保留 V24 原失败的输入与固定旧版真实输出、修复后实际 MP4、对照 GIF、源/字体许可、命令、probe、逐帧数据和 SHA-256。动画/高亮、音轨前后保留、作者时钟及当前完整回归分别计数。

任意非整帧项目时长仍受已有发布时长门禁约束；本契约不放宽其容差。一般 VFR、嵌套定格、完整群组/父枢轴、复杂转场、HDR/线性光、大项目性能及完整剪映功能/效果等价继续未验收。
