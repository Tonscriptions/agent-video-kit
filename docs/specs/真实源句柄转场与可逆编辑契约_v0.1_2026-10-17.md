V35 契约。借鉴 OpenFilm O03 的添加/调长/移除和关联音轨工作流；使用本项目整数 tick 原生声明，不复制其提前移动入片、缩短工程和换轨的排布。原 clip、字幕、关键帧、素材范围、轨道顺序和序列时长保持作者数据；渲染副本才扩展源句柄。不是新的 AI 特效模型或剪映全量转场库。

## 1. CLI 与声明

`timeline transition --project <root> --input <request.json> [--sequence-id <id>] [--expected-project-sha256 <dry-run摘要>] --dry-run`。去掉 dry-run 保存；支持已有幂等、锁、快照、事务回滚。compose 的 `{ "op": "source_transition", "transition": <request> }` 可加入同一事务。

```json
{"action":"add","id":"tr_ab","from_clip_id":"a","to_clip_id":"b","duration_tick":90000,"type":"dissolve","audio":"linked"}
```

`resize` 必须提供 id、duration_tick，可更新 type；`remove` 只提供 id。未知字段拒绝。audio 默认为 linked，可显式 none；linked 要求每个相关音轨能唯一配到同一剪口，否则整组拒绝。参与音画轨道任一 locked 时不可添加、调长或移除。其他字幕/音乐不移动，不启动波纹编辑。

`sequence.source_transitions` 是有界（≤256）数组，每项严格六字段：id、type、duration_tick、from_clip_id、to_clip_id、audio_pairs；后者为显式同轨音频引用对。添加时推导并冻结配对；以后重新关联不隐式修改已保存转场。删除最后一个转场移除该数组字段。实际引用、锁、时钟、源边界由语义校验器检查，不能绕过 JSON Schema fallback。

## 2. 时钟与句柄

同视频轨 A 的尾与 B 的头必须精确连续。D 为整数显示帧数且小于两侧原片段时长。前窗取 floor(D帧数/2)，后窗取剩余帧；所有作者边界、窗和源扩展均须能用整数 ticks 精确表达，不静默舍入。奇数帧的额外一帧放在剪口之后。窗口必须在序列内；同轨相邻转场窗口可接触、不可相交。

A 读取额外后窗，B 读取额外前窗，恒速按精确 Fraction 映射；倒放反向扩展源区间。登记的源时长不足、源范围/速度不一致或非整数源 tick 时明确拒绝。无末帧复制、自动缩短转场或新增静音兜底。已有其他音频滤镜/编码路径的尾部策略仍单独存在，不因此取得听感验收。

关键帧、效果参数、蒙版和字幕使用原作者时钟；超出作者区间的关键帧端值保持。作者音量/声像及淡化保持原时钟，再乘独立的线性交叉淡化包络；不会覆盖作者 fade_in/out。音轨总线仍在各片段处理后求和。转场声明不新增素材权利或跳过发布门禁。

## 3. 接受范围与拒绝范围

首版支持本地视频 + 明确音轨上的视频/音频媒体、恒定速度、倒放、连续剪口、同轨多剪口链和关联音频。类型：dissolve、crossfade、dip_black、dip_white，以及 wipe/slide 的 left/right/up/down。黑白场使用固定 gbrap 上的自定义 xfade 双线性包络：前窗从 A 淡到不透明黑/白，原剪口达到该颜色，后窗由黑/白淡入 B；奇数帧使用各自半窗时长。不会直接把 FFmpeg 内置 fadewhite/black 的不同曲线称为剪口黑白场。无 HTML 页面/浏览器。

首版明确拒绝图片/生成器、嵌套容器、将转场序列作为嵌套源、速度曲线/定格、跟踪绑定、单片段 blend 及 blend.opacity、参与片段已有旧 transition_in/out。不同来源帧率/VFR、HDR/线性光、透明边缘、全部类型自然画质和大工程性能须另行验收，不用少量帧/PCM 或回归数声称剪映等价。

外部 OTIO/Kdenlive/明文草稿对该声明报告 Unsupported；strict 导出拒绝。原生 agent-json/package 保留。引用片段被其他编辑删除/移位导致剪口失效时，保存前校验拒绝；可先在 compose 移除转场再修改片段。不把转场悄悄烘焙或丢弃。

## 4. 核验要求

真实源编号/时间变化画面、独立手工取源窗口和渐变数学参考；剪口前后、总帧数、不受影响区间、双剪口链、倒放与恒速；音频独立 PCM 包络求和。移除应恢复原作者轨道/clip 数据和相同渲染结果，重复幂等/摘要冲突/锁/句柄短缺/事务故障需保留失败证据。原上游研究测试不计为本产品通过数。公开原片、输出、GIF、SHA 和机器证据统一放 docs/，无权发布的媒体留本地。
