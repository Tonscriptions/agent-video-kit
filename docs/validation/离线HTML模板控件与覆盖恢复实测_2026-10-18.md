新增 `motion html-controls` 在指定 CFR 帧的两个新上下文实际绘制，返回根 CSS 变量及原单位、文字和单图片控件；`motion html-render --overrides` 逐帧覆盖并保存新版本。`--from-asset-id` 继承原配方，`null` 单项恢复页面自身内容。图片只接受已登记本地资产，哈希与权利依赖同步进入新输出，原源码包不改变。

```json
{
  "variables": {"--brand": "#38bdf8", "--title-size": "30px"},
  "texts": [{"at": "#title", "value": "VIDEO 2"}],
  "images": [{"at": "#product", "kind": "img", "asset_id": "product-new"}]
}
```

`n` 为 1 起始，可只改重复 selector 的一个元素。文字以文本写入，保留换行和内联子元素；不解释 HTML。未知字段、未声明变量、失配/无效 selector、错误图片种类和复杂无直接文字目标均拒绝。控件为采样时刻的 DOM/CSS 清单，不能代表整个动画或自动发现 Canvas 中的字与图。

开发失败按实际保留：第一次来源提取误把多份嵌套 LICENSE 当成唯一文件，随后固定根 LICENSE；dev1 测试夹具误用 `media ingest --path` 导致 7 个初始化错误；dev2 检查失败时 Windows 临时日志句柄未释放，覆盖原拒绝代码；dev3 的 17 项执行通过，但期间补充了测试文件，冻结检查失败，**不算通过**；dev4 的 56 项通过；首组公开实测完成图片和迁移重建后在第 25 次策略审计失败，原因是 `page.evaluate:` 调用栈前缀被当作 URI scheme。修复为带文本前缀的诊断，不放宽策略规则，保留[原失败与调用](evidence/html-template-initial-20261018/terminal.json)。最终批次另行核验，不与历史通过数相加。

原始原创输入、实际三列成片与 GIF 随下方最终批次发布；素材全部为程序生成的产品图、HTML/CSS 及既有原创 AgentGrid 字形。没有新增模型调用。静帧目检、连续播放和听审分别记录；自然广告美学、缺字/越界自动诊断、任意页面/媒体/WebGL、长片资源、HDR、干净机器发行和完整剪映等价继续未验收。FGT 仍是 V44 研究候选，来源链和自然修复质量没有因本次模板功能改变。

## 使用

```powershell
ai-ad-editor motion html-controls --project E:\work\ad --source-asset-id title --frame-index 0
ai-ad-editor motion html-render --project E:\work\ad --source-asset-id title --asset-id title_v2 --overrides E:\work\changes.json --dry-run
ai-ad-editor motion html-render --project E:\work\ad --from-asset-id title_v2 --asset-id title_v3 --overrides E:\work\reset.json
```

执行前登记已有本地 Node/Playwright/Chromium；`dry-run` 只规划，不能检查 CSS selector 是否在实际 DOM 存在。正式输出使用新 ID，源包和旧输出不覆盖；成功后检查报告的实际目标、精确时钟、全帧顺序与浏览器关闭/原生 Job 回收。CSS 根变量只覆盖声明值，保留单位；字体族可以识别，但新增字体文件须另建已登记资源的源码版本，系统字体/缺字与排版效果未验收。
