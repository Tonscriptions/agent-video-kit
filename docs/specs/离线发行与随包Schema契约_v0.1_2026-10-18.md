# 离线发行与随包 Schema 契约 v0.1

状态：V47 开发前声明；所列本机范围已按[本轮实测](../validation/离线发行与随包Schema实测_2026-10-18.md)核验，其他机器/全部平台仍未接受。最终完整剪映功能/效果目标不变；本轮关闭实际发行时合同文件和日期格式检查缺失的问题。

1. Agent Project Schema 按原字节随 wheel 分发，只读取包内固定资源，核对预声明 SHA-256；文档中的权威副本、包内副本与固定摘要必须一致。缺失、篡改或解析失败返回错误，不搜索父目录或退回成功。
2. 使用明确声明的本地 jsonschema/referencing 执行器和随包日期格式检查；缺少执行器不得以 builtin 语义检查冒充成功。保留既有语义问题诊断。当前 Schema 只有 date-time 格式，新增格式没有实现时拒绝；不使用格式检查器的可选导入结果猜测覆盖情况。
3. 日期检查器采用固定 MIT `rfc3339-validator` 0.1.4 的 Python 3 适配，另以完整匹配拒绝尾部换行，允许规范中的小写 t/z；支持合法闰日，不支持闰秒，不能宣称全部 RFC3339 日期均可表达。仅允许 Schema 内部 fragment 引用；注册表不读取远端或本地外部引用。固定 `$schema`/`$id` 是命名元数据，不发出请求。资源读取与诊断不依赖源码仓库、当前目录或在线服务。
4. 提供 `schema show/export`：展示可机读合同和实际摘要，按原字节导出新本地文件，不覆盖已有目标。dry-run 无落盘；doctor 报告随包资源及执行器状态，缺失时失败。
5. 构建原生 Windows CPython 3.13 x64 离线发行包：当前产品 wheel、固定版本依赖 wheel、原始许可、清单/摘要和标准库安装脚本。构建仅消费已有本地 wheel；取得公开依赖是独立的显式开发步骤，不纳入产品默认执行。
6. 安装必须使用 `--no-index --no-deps --require-hashes`，检查 Python/ABI、清单、路径/库存/摘要和 wheel 元数据；只在全新本地目录原子发布，拒绝现有目标，不写全局 site-packages。失败/取消/超时移除所属临时安装目录，目标工程与其他安装不受影响。运行时使用显式已有原生 Python/FFmpeg，不调度 Docker/WSL、虚拟机或虚拟环境。
7. 生成的启动入口隔离用户 site/PYTHONPATH，所有核心依赖从安装目录加载；运行缓存在该目录下或显式 E 盘路径，不能回流到 C 盘全局缓存。媒体、模型、Node/Chromium 工具链另行显式登记，不由安装器下载。
8. 验证包括原 V46 源码错误日期被接受及独立 wheel 降级的真实负例；修复后的正常/错误日期、缺失执行器/资源/摘要、外部引用、不同 cwd、原字节导出和目标保护；真实离线安装、断网/可选重库阻断、独立依赖来源、实际剪辑/渲染与工程包往返、安装篡改/已有目标/取消回滚。

本地路径约束包括文件探测之前拒绝 UNC、设备路径、URI 与映射网络盘；覆盖 bundle、安装目标、取消标记和构建输入/输出。原入口的阻断探测复现及修正测试单独保留，不执行真实 SMB/DNS。

后续修改合同须同步 `docs/specs/agent-project.schema.json`、`product/src/ai_ad_editor/agent-project.schema.json` 与 `schema_contract.py` 的固定摘要；随包字节和当前执行覆盖都要实际核验。发行包的 ABI/依赖版本必须另建明确锁定清单，不能把本轮 `cp313-win_amd64` 成功外推到其他 Python/平台。

机器安装验证不等于另一台干净机器或全部操作系统兼容性，文件摘要不等于作者签名。公开演示复用既有有来源的原创输入并保留视频/时钟/音频探测；静帧目检、连续播放和听审分别记录。自然 AI 质量、完整剪映等价、长片/HDR/跨设备和内容库仍独立验收。

## V49 字体依赖补充

首次隔离安装实际执行字体导入时，发现历史六轮包缺少 Pillow；开发机用户 site 的现成依赖曾掩盖该问题。失败记录保留在[CTC 安装实测](../validation/离线CTC字词强制对齐实测_2026-10-18.md)。新增 `font-text-v1` 明确要求七个 wheel：产品、jsonschema、attrs、jsonschema-specifications、referencing、rpds-py 和 Pillow。Pillow 固定 12.1.0 / `cp313-cp313-win_amd64`，取得、大小、SHA 和原始许可证单独存证。构建器仅消费本地 wheel，不联网。

历史清单省略 profile 时按 `core-v1` 六轮清单验证，不能把声明 Pillow 的新产品放入旧清单；未知 profile、缺第七轮、名称或摘要不符均拒绝。安装后在 `-I -S` 新进程中检查实际 `PIL` 导入路径及版本属于目标目录，再执行真实字体导入和渲染。Python/FFmpeg、Torch/Transformers 与模型仍为明确外部本地输入，不声称基础七轮包包含全部 AI 工具链。
