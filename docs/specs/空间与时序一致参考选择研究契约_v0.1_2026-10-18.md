# 空间与时序一致参考选择研究契约 v0.1

状态：研究已完成，v3 未通过预定质量门槛；未进入正式修复接口，未通过剪映效果验收。实际数据见[实测报告](../validation/空间与时序一致参考选择实测_2026-10-18.md)。

本增量针对差异 #56。现有双模型参考按每个像素独立选择供体，可能出现空间接缝和帧间变化；隐藏表面运动、选区完整性和自然画质仍未解决。产品仍使用既有 LaMa/VACE 显式适配器，本研究不能修改默认修复行为或将不通过的质量结论改记为通过。

研究只使用明确存在的原生 Windows Python、OpenCV/NumPy 与本地数组；不下载模型或包，不启动浏览器、服务商、Docker/WSL 或其他虚拟化。Python 网络 guard 在原生库导入前安装，不等同于操作系统防火墙。

供体仍须完全来自不透明且未被选中/排除的观测像素；双线性四角足迹、路径置信度、共同可见背景支持和不同帧数量逐项检查。多个运动模型指向同一帧时只能计一个独立供体。新一致性项只能改变已准入供体的选择，不能引入上一帧修复 RGB 作为新供体或扩大修改范围。所有 alpha 与选区外 RGBA 精确保留。

所有候选使用固定 4 轮红黑标签更新，空间代价系数 0.08，时间代价系数 0.06；它们是有界启发式，不声称全局最优、正确隐藏几何或自然闪烁验收。v1 以羽化后的上一帧输出作代价先验；v2/v3 改为记录实际采样供体颜色，先验始终不能作为新观测或增加供体票数。活动矩形保留原全画布棋盘奇偶；其等价性由直接检查覆盖。首候选、修订候选的源码及失败结果均须保留。

v3 在可见且两端有效的相机/稠密运动残差上拟合至多两个局部运动组：最少 128 个样本，8 次中位数更新，每组至少 `max(64, 样本数/20 向下取整)`，中心距离不足 0.75 px 时退回单组；双组赋值要求最近中心距离不超过 1.5 px、两距离差至少 0.25 px。不确定像素弃权，不把组号当对象、语义表面或跨帧身份。隐藏区推断的光流只能归组，不能用于拟合中心。

空间项不跨不同运动组传播。候选供体改变还须通过同组的可见观测拒绝检查：65×65 窗口内至少 64 个改变的有效可见预测，RGB MAE 至少下降 0.1，MSE 不超过参考的 0.99 倍。该检查与候选共享可见上下文，不是独立统计交叉验证，也不能约束不可见区域的误差；源码中的 `crossvalidation` 名称不应被解释为质量保证。

预先定义的研究质量门槛为：每个已评分区域的 MSE 与同画布相邻重建误差变化 MAE 均不高于同输入、同运行时的既有双模型参考；不能放宽阈值、合并不同表面掩盖退化或用供体覆盖率代替质量。后一个统计没有运动补偿，仍需另外核验运动补偿误差、自然连续播放及语义/纹理。真值先于人工遮挡生成，仅进入评分器，从不传入修复器。

沿用平移纹理、双表面、同一自然画面的人工遮挡和自然移除四组历史输入；v1 重跑旧算法形成配对基线，并记录与历史 NPZ 是否相同。v3 可复用该配对基线，但必须核对输入四数组、运行时与旧算法源码摘要。修订候选另用固定 seed 20261018/20261019/20261020 的静止纹理、双运动/切镜、非刚性/曝光变化三组验证；生成器在修订候选测量前冻结。没有独立第三方盲测或新自然素材，不能据此宣称通用改善。静止正控制相等是控制通过，不宣称改善。

研究仍限 2–65 帧、每帧至多 1,048,576 像素。v1 自有数组估算为 `WH × (224N + 2048)` 字节；v3 增加运动组及观测检查缓冲后改为 `WH × (256N + 2048)`，实际调用采用 1536 MiB 上限；不含输入、OpenCV 内部和全进程 RAM。逐帧与标签更新检查取消回调，数组/参数在原生运动估计前校验。长窗口、模型登记、权利依赖、音频保留、工程事务和产品 CLI 尚未由本研究验收。

`scripts/run_coherent_reference_fixture.py` 仅为研究 NPZ 的独立 CLI，读取 `source/forbidden/selected/fallback`，不读取真值。禁止 UNC/远程 URI、pickle 和超预算数组；只允许在本项目 `.runtime` 的全新目录写结果。取消和超时在检查点执行，不能硬中断一次正在进行的原生库调用。不能以它替换正式 `media inpaint`、登记模型或自动开放发布。

交付须包含固定源码摘要、真实单元检查日志、逐组 NPZ/指标/失败、实际原图/成片/GIF及独立复核。公开媒体仅使用本项目原创合成内容；未核验发布权利的自然素材留在 E 盘本地，只公布记录路径和摘要。产品源码维持 V41 的 137 文件冻结基线；不把研究方法数与既有 975 项产品回归相加。
