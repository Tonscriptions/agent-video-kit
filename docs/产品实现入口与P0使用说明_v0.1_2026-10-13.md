`rights decide` 的非破坏性 replace/delete 决策、审批/撤销链与替代资产依赖门禁；已批准处置会阻断后续发布，确定性 `manifest_sha256` 发布清单保留决策证据。渲染器已支持常用淡入淡出、相邻片段的 crossfade/wipe/slide 以及本机 FFmpeg xfade [本地视频防抖与稳定化派生素材契约](./specs/本地视频防抖与稳定化派生素材契约_v0.1_2026-10-15.md)。

最近补齐的输出/全局调色边界：`settings.adjustments` 在视频轨道合成、转场、遮罩和混合之后按顺序执行序列级效果栈，并复用已验证的效果参数关键帧；省略区间时覆盖全序列，提供 `start_tick`/`duration_tick` 时按序列时钟执行局部区间层；项目内 `.cube/.3dl/.csp/.dat` LUT 资源通过 `lut3d` 走本地 FFmpeg，并在校验阶段执行路径、扩展名、存在性和登记 SHA-256 门禁；`lut register/list/inspect` 提供项目级清单与 Rights Ledger 追踪；连续片段可以显式使用 `auto_handle` 转场并保持原时间线长度。输出支持 yuv420p/yuv422p/yuv444p 及 10-bit 变体，`settings.color` 的 primaries/transfer/matrix/range 显式传递给 FFmpeg。LUT 预览缓存、动态或非 `.cube` 强度、HDR 代理和跨设备色彩一致性仍保留为后续验收项。

```text
project init → media ingest → timeline compose → validate → rights check → render → quality check
```

所有命令输出 JSON envelope；`--dry-run` 可用于写操作计划；项目文件、Rights Ledger、校验报告、操作记录和渲染 manifest 使用临时文件加原子替换。渲染输出只允许位于项目目录内。

根目录 `ai-ad-editor.ps1` 会把 `TEMP`、`TMP`、Python 字节码缓存和本地模型/库缓存指向 `product/.runtime/`；CLI `doctor` 会返回实际运行缓存路径。模型只允许从显式本地目录加载，绝不自动联网下载。

`--progress jsonl` 会把结构化进度事件写到 stderr，保持 stdout 的 JSON envelope 可供 Agent 直接解析；渲染事件由 FFmpeg 本地 progress 文件驱动，覆盖开始、运行进度、产物写入、完成、失败和取消；`operation inspect` 可读取操作记录。项目绑定写命令已经支持 `--idempotency-key` 的结果重放和冲突拒绝，并在完整读改写期间持有项目级原生文件锁；锁冲突返回 `PROJECT_WRITE_LOCKED`、退出码 6 和 `retryable=true`。`render --cancel-file` 可以在启动前或运行中终止本地子进程、清理临时产物并记录取消状态。失败/取消的 render 会保存项目指纹、素材哈希、渲染计划和输出规格，`render --resume <operation_id>` 仅在依赖未变化时重建渲染，并在输入变化时结构化拒绝。`queue enqueue/list/inspect/run/cancel` 将多版本输出持久化到项目 `operations/render-queue.json`，复用同一渲染器，支持显式失败重试、默认顺序执行或 `--workers N --continue-on-error` 有界并发和运行中取消；`queue cancel` 在渲染器持锁期间仍通过原子 `.cancel` 标记递交请求，`queue list/inspect` 显示 `cancel_requested`，由运行器确认最终状态；完整状态机见[本地渲染队列契约](./specs/本地渲染队列与任务状态契约_v0.1_2026-10-14.md)和[项目写锁与取消通道契约](./specs/本地项目写锁与取消通道契约_v0.1_2026-10-14.md)。

## 3. 代码边界

| 模块 | 责任 |
|---|---|
| `project.py` | 项目目录、初始结构、原子保存、原生 Windows 项目写锁、序列/轨道查找、历史快照和恢复 |
| `migration.py` | 纯函数旧项目补全、资产指纹门禁、schema 迁移报告和迁移链 |
| `media.py` | 本地媒体/字幕分类、FFprobe 探测、代理、缩略图、波形、素材哈希、两遍 `vidstab` 防抖和丢失素材重链接 |
| `tracking.py` | 使用本地 FFmpeg 帧抽取、Pillow/numpy 模板匹配，或通过哈希门禁的 argv-only JSON 视觉 runner 生成置信度和位置关键帧；不调用在线视觉服务 |
| `model_registry.py` | 登记/验证音频与视觉本地模型适配器的路径、内容哈希、执行器、许可证和 Rights Ledger 记录 |
| `runtime.py` | 将 TEMP/TMP、Python、Transformers、Torch 和 pip 缓存固定到 E 盘 `product/.runtime/`，并强制离线模型策略 |
| `captions.py` | SRT/VTT/ASS/SSA/TTML 解析、时间范围校验和 SRT 规范化 |
| `local_tts.py` / `soulx_worker.py` | 显式本地 SoulX/声线登记、完整性验证、隔离原生推理和 24 kHz → 指定母带；无网络或自动下载 |
| `speech.py` | 通过本地 FFmpeg flite 生成 ASCII/英文 WAV；拒绝非 ASCII 文本，不自动下载模型或调用网络 |
| `effects.py` | 维护 45 项本地 FFmpeg 效果的规范 ID、别名、参数范围、后端和关键帧限制；供 `effects list/inspect` 查询 |
| `render_queue.py` | 项目内 JSON 渲染队列、作业状态、取消标记、失败重试和顺序/有界并发执行编排；项目写锁与 CLI 取消通道在 `project.py`/`cli.py` 协作；不启动服务或网络调度 |

## 2026-10-16 LaMa 区域修复增量

`media inpaint` 使用已登记的本地 TorchScript LaMa 和项目蒙版资产生成派生视频。Agent 可先用 SAM2 输出对象选区，再修复原视频中对应的区域；纯黑白蒙版用 `luma`，透明对象视频用 `alpha`。模型和蒙版必须已存在本地，输入不能依赖运行时下载。

```powershell
python -X utf8 -m ai_ad_editor media adapter register --project ./work/demo --adapter-id lama_local --engine torchscript-lama-local-v1 --model-path E:/models/big-lama.pt --executable D:/runtime/python.exe --evidence E:/models/lama-evidence.json --device cuda --dry-run
python -X utf8 -m ai_ad_editor media inpaint --project ./work/demo --asset-id source_video --mask-asset-id selected_alpha --mask-channel alpha --adapter-id lama_local --derived-asset-id repaired_video --mask-grow 4 --apply --track-id track_video_1 --audio-track-id track_audio_1 --dry-run
```

示例路径、资产和轨道 ID 须替换为实际本地项目值；先正式登记模型，再检查修复计划，最后去掉修复命令的 `--dry-run` 执行。动态蒙版的 `--mask-start-seconds` 指向蒙版自己的起点，须覆盖全部输出帧；默认拒绝尺寸不匹配，可显式选择 `--mask-resize nearest` 接受有限比例缩放。源、蒙版及模型权利形成派生闭包；修复结果通过功能测试也不能跳过发布许可。
