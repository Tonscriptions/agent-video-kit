## 已发生的缺口与下一轮验收

V66 的两个失败分别绑定原生 worker PID `24208` 和 `34396`；Windows 事件报告相同的 `torch_cpu.dll / 0xc0000005 / 0x8e4a279`。当前 CLI 只返回 `MATTING_PIPELINE_FAILED`，cause 包含 FFmpeg Broken pipe 和截断的加载输出，尚没有结构化 native worker PID/exit/stage。这是本次[原始 CLI 响应](validation/evidence/video-outpainting-20261019-v66/vace-harmonic-r3/outpaint.stdout.log)与[Windows 事件](validation/evidence/video-outpainting-20261019-v66/vace-harmonic-r3/windows-native-crash-events.json)之间可直接核对的差距。

现有 [`matte_native`](../product/src/ai_ad_editor/local_matting.py) 在错误摘要中已对 response 尾部限定 2,500 字节、对 decoder/worker/encoder 三份 stderr 各限定 1,500 字节；这部分有界读取不需重新从上游移植。仍缺的是临时区清理前的独立附件、进程归因和可复查 manifest。worker 的 stdout 是 RGBA 二进制管道，不能作为普通日志自动收集；未来诊断只保存其字节计数/摘要等白名单元数据。
