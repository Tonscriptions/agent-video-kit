V37 将已编辑的片段和引用子序列保存为不可覆盖的本地版本，再以可继续编辑的嵌套组插入另一工程。资源、作者时钟和权利历史随组保存；同名资产与关联 ID 使用新实例命名空间。此次接受受控本地子集，完整剪映等价仍未验收。

## 1. 实际输入与比较方法

原片复用 V35 自制 CC0 计帧器、移动块和双声道合成音，逐文件核对原公开摘要；视频 240×136、10 fps、80 帧/8 秒，WAV 为 48 kHz 双声道。新增字幕、暖色 `.cube` 及原创网格 TTF 字形也按 CC0 提供。字体由已有 FontTools 生成，不发布 Windows 商业字体文件；FontTools 只属于夹具生成工具，产品没有新增运行依赖。

源序列包含未选前景、两段有真实源句柄转场的音画、文件字幕、固定字体/LUT、不同画布的子序列及音频轨道处理。目标先有一秒前缀，同名 `video_a` 故意绑定另一份视频。摄取、转场、片段组保存/查询/检查、dry-run/正式插入、严格验证、策略审计和发布渲染均实际调用 CLI；作者工程及独立参考工程由夹具明确写入 JSON，不声称这些夹具全部来自 compose 操作。

参照从原作者工程直接按已声明的选择集筛选，手工建立原始作者时钟容器，用固定 V36 渲染；不读取新模块的选择结果或 ID 映射来构造参考图。对照可以检查片段组闭包、文件、时钟与合并是否改变画面/声音，**不是一套独立渲染算法，也不是自然广告质量或剪映画质等价证明**。

## 3. 专项回归与失败

29 个新增方法覆盖干跑零写入、版本不可覆盖与离线搬迁、同名不同字节、重复实例、标记/文字与 ID 分离、嵌套/关联/转场/跟踪闭包、字体/LUT/字幕真实搬迁、资源破坏与越界、过期摘要、上下文/画布、目标锁/碰撞、幂等、权利修订/处置/模型父依赖、本地证据文件、原生锁、预算、部分闪避总线拒绝、晚期元数据失败回滚和磁盘复制失败；还包括中断暂存清单不可见与真实 Windows 目录联接越界拒绝。新方法属于完整套件子集，不与完整通过数相加。

[开发原日志/三个原始烟测与实际误期望成片](evidence/fragments-development-20261018/verification.json)全部保留。开发原失败：首轮 22 项有两处渲染输出相对路径和一处测试取值顺序错误，修正后 22 项仅参考夹具遗漏序列 name；第二次修正后扩展至 27 项全部通过。首次完整 runner/公开脚本误用 `-I`，屏蔽已有用户目录 Pillow/NumPy，造成测试模块无法导入/字体导入失败；改为原生依赖可见的 runner 后从头重跑。产品源码没有为这些测试环境错误增加依赖或改变编辑行为。

首次 N05 夹具把 `restricted` 且仍明确允许 `commercial_ad` 的记录误认为必须阻断，实际渲染成功。这不是库提升权利状态；原门禁允许该用途。正式反例改为明确 `blocked`。自由文本 restrictions 仅保留声明，不自动变成机器政策；该能力边界也写入契约。原误期望、实际输出和日志分别保存，不覆盖为成功。

随后一次 N05 实际已经以退出码 7 拒绝，脚本误期待顶层 `RIGHTS_BLOCKED`；现有发布渲染先做严格工程验证，返回 `PROJECT_INVALID`，原因包含 `RIGHTS_STATUS_BLOCKED`。修正断言后重新执行整套烟测，没有修改产品错误码或放宽门禁。

最终代码复审补充两项边界反例：未原子发布的 `.fragment-*` 清单干扰查询，以及版本目录联接指向库外时未先检查边界。两个方法在修复前均失败；现在查询忽略暂存版本，库版本路径先检查解析后的归属。第一次专项筛选误把 `-k` 当正则，实际执行 0 项，保留该日志且不计为验证。先前 27 项专项和成功烟测属于开发证据；原计划 812 项的那轮完整回归实际只运行 785 项，出现 1 项失败及 3 项跳过，并因追加测试及源码修复失去前后字节冻结资格。另查出 runner 没有向子进程传入产品 PYTHONPATH，也未显式传入已有 Rubber Band 原生工具，导致网络禁用子进程导入失败与音频类跳过；诊断后中断下一次配置仍不完整的运行。修正 runner，记录本地可执行文件/DLL/许可摘要并补齐环境，不修改产品或测试断言。最终 29 项专项、814 项完整回归和全部公开烟测、发行检查均重新从头执行，不沿用旧通过记录。

## 4. 复现与使用

从 E 盘仓库根目录执行，输出目录必须尚不存在；全部使用现有原生本地依赖：

```powershell
$nativeRubberBand = 'product/.runtime/rubberband-offline-probe-20261017/native/rubberband-4.0.0-gpl-executable-windows/rubberband.exe'
C:\Python313\python.exe -B -X utf8 scripts/run_frozen_regression.py --output product/.runtime/<新完整回归>.json --rubberband $nativeRubberBand
C:\Python313\python.exe -B -X utf8 scripts/run_frozen_regression.py --pattern test_fragments.py --output product/.runtime/<新专项>.json
C:\Python313\python.exe -B -X utf8 scripts/smoke_fragments.py --output docs/assets/<新公开样例> --work product/.runtime/<新烟测>
C:\Python313\python.exe -B -X utf8 scripts/audit_fragment_media.py --public docs/assets/<新公开样例> --output docs/validation/evidence/<新媒体审计>.json
```

`--rubberband` 必须指向已在本地准备好的原生可执行文件，同目录保留 `COPYING.txt` 与 `sndfile.dll`；runner 记录三者摘要，不下载或安装工具。缺少该工具时对应音频类会显式跳过，不能据此宣称本次完整的零跳过结果。runner 同时为测试子进程设置本地产品 `PYTHONPATH`；使用本机已有可选依赖，不代表干净机器发行验收。

发布样例库位于 [library](../assets/fragments-20261018/library)。查询 `cta`，版本 1 是全组、2 是自动补全后的部分选择、3 是子级。`fragment inspect` 验证完整资源摘要；`list` 只查询元数据，不意味着资源已验证。保存和插入请求格式见契约。

不接受的范围包括跨时基/FPS/色彩/音频上下文转换、全局调节层和外部音频可执行文件搬运、展开入多个目标轨、部分闪避总线、自动传播后续来源撤回、未知动态依赖和完整开放内容库。普通异常回滚元数据并删除本次复制资源；进程被杀仍可能留下未引用文件。AAC 预览声音不作为无损 PCM 依据；连续播放、听审、自然素材、HDR/VFR、长片 RSS、干净机器发行和完整剪映等价仍未验。
