## 1. 目标

`convert export --target-format package` 生成一个可以在另一台受支持本机上恢复的 `.aevpkg.zip`。项目包必须包含可编辑工程、Rights Ledger 和项目引用的本地素材，使 Agent 可以把一次广告工程作为单个可校验交付物保存、复制和重新导入。

项目包是本项目的开放交换格式，不是剪映私有草稿格式，也不依赖剪映客户端、账号、在线模板或云端资源。剪映或其他外部工程仍需先经过显式转换器，转换器必须生成 Exact/Mapped/Approximate/Unsupported/Failed 报告。

## 2. CLI

```powershell
python -X utf8 -m ai_ad_editor convert export `
  --project .\work\demo `
  --output .\exports\demo.aevpkg.zip `
  --target-format package

python -X utf8 -m ai_ad_editor convert import `
  --input .\exports\demo.aevpkg.zip `
  --output .\work\demo-imported
```

导出不会打包渲染成片、缓存、队列状态、操作日志或历史快照；这些文件是机器本地副作用。导入后 Agent 可以重新校验、渲染和生成新的运行记录。

## 3. ZIP 结构

```text
package-manifest.json
project.json
rights-ledger.json
project.lock.json                # 源项目存在时包含
assets/<asset-id>_<safe-name>    # project.json 中引用的每个本地资产
fonts/**                         # 项目内字体支持文件（若存在）
templates/**                     # 项目内模板支持文件（若存在）
validation/**                    # 项目报告/转换证据（若存在）
conversion-report.json
```

`package-manifest.json` 的 `files` 数组为每个文件保存相对路径、字节数和 SHA-256。导出时每个项目资产 URI 被重写为 `assets/` 下的包内相对路径，源机器的绝对路径不会成为恢复依赖。缺失的引用资产会阻止导出，不会生成不完整的“可移植包”。

## 4. 导入安全门禁

导入器在写入目标目录前检查：

1. manifest 的 `package_format`、`package_version`、必需文件和每个文件的路径、大小、SHA-256；
2. 成员路径不能是绝对路径、不能包含 `.`/`..` 穿越段、不能包含 NUL，不能是符号链接；
3. ZIP 中不能出现 manifest 未登记的额外文件；
4. `project.json` 必须是受支持的 Agent Project schema 版本，`rights-ledger.json` 必须存在；
5. 任何检查失败都返回结构化 `ARGUMENT_INVALID`，目标目录不留下 `project.json`，也不执行网络访问或模型下载。

导入器不会执行包内脚本、插件、可执行文件或远程 URL。所有资产仍需在发布前通过 `policy audit`、项目校验和 Rights Ledger 门禁。

## 5. 权利与发布边界

项目包携带 Rights Ledger 原记录和哈希，但“包内存在”不等于“允许商业发布”。导入后的记录继续保留原来的 `verification_status`、许可证、证据和限制；`render --publish` 或 `rights export` 仍按目标渠道重新执行发布检查。

包内的 `validation/` 仅是审计证据，不能覆盖项目 schema、素材哈希或 Rights Ledger。导入生成新的 `conversion_*.json`，记录包格式、哈希检查和目标项目路径。

## 6. 当前状态与后续边界

本版本已经覆盖：

- Agent Project JSON、Rights Ledger、项目锁和项目内支持文件的本地打包；
- 引用资产的可移植 URI 重写；
- ZIP 路径穿越、符号链接、未登记文件和哈希篡改拒绝；
- 导入/导出转换报告和空目标目录门禁。

本版本没有声称外部剪辑器工程无损兼容。OTIO、MLT 和剪映草稿仍由各自 adapter 进行能力映射；效果、复杂字幕、跟踪、生成式结果和在线模板必须按转换报告标记近似、固化或不支持。未来若增加剪映草稿读取，只能处理用户明确提供且有权访问的本地文件，不调用剪映运行时或任何线上接口。


## 2026-10-15 模型登记元数据增量

项目包额外保留存在的 `models/audio-adapters.json` 与 `models/visual-adapters.json`，逐文件进入 SHA-256 manifest。只包含登记元数据；外部模型权重、原生 Python 和代码环境不会自动打包或重新绑定。在其他设备推理前必须复核本地路径、依赖与哈希；已经生成的关键帧仍可编辑，片段模型权利依赖不能丢失。
