## 1. 修复的问题与验收范围

旧实现只把嵌套速度曲线用于区间边界，区间内叶片仍按平均速率播放；关键帧端点虽移动，段内插值会重新线性化。裁切叶片自己的速度曲线、多个 reverse 组合及非整帧分段相位也会引入错位。

现由内向外组合每层源时钟，保留叶片原曲线定义域；视频按解析 PTS 和公共输出帧网格采样，关键帧在原作者局部时钟内求值。音频仍用 atempo 短窗，累计边界来自同一复合时钟并统一取整为 48 kHz 样本。没有新增 CLI 参数。

这轮只接受受控 CFR 时钟、相应关键帧几何和脉冲包络。自然模型画质、完整群组语义和全部剪映能力仍未验收。

## 4. 正式 CLI 与交付检查

生成批次实际执行 **23 次 CLI，全部 exit 0**：项目初始化 1、素材摄取 2、五次时间线 compose、五次严格校验和十次旧/新发布渲染。另对五份新成片执行 **5 次** `quality check --require-audio --expensive --fail-on-black --max-true-peak-dbfs -1`，全部通过；这 5 次另计，没有混入 23 次生成调用或测试数量。

## 5. 冻结回归、失败与重跑记录

最终完整回归 **435/435，776.365 秒**；88 份 product/src 和 product/tests 源文件在执行前后摘要一致。[13 项专项](../../product/tests/test_nested_time_mapping.py)为完整回归子集，单独执行 13/13、16.027 秒；固定旧版执行同 13 项有 13 项语义断言失败、15.081 秒。这些计数不相加；435 是完整套件结果，前轮 422 保留为历史。

专项覆盖父曲线正/倒放、双层曲线、内层倒放/双倒放、原叶片曲线裁切、不同输出 fps、多段 hold/linear 与反向分段、叶片/父级/蒙版本地关键帧、脉冲包络。source≤1 帧和几何≤3 px 的原门槛均未放宽。

初始新增夹具遗漏 interpolation 字段，先修正夹具再做权威前后对照；增加多段样例时曾有 2 项失败，定位为每段 `fps start_time` 重建相位，修复为公共帧网格后通过。没有把这些开发中间结果冒充最终成功。

另一次完整运行因核验夹具误要求整个 project.json 不变而被明确终止：已确认本机运行进程及命令行后只停止对应测试进程树，并非超时。该断言错误拒绝正常的输出/provenance 登记；最终断言改为上述作者字段及台账。相同错误曾使首轮公开生成中止，旧结果保留在忽略目录。相关原始失败/中断日志及说明进入[独立证据](./evidence/nested-time-20261016.json)，不计作最终产品失败或完整通过。

## 6. 原生 Windows 复现

在仓库根目录，使用本地已具备 NumPy、Pillow 的 Python，确保 FFmpeg/FFprobe 在 PATH。字体和许可证必须显式提供；输出及工作目录必须是新目录，脚本不会覆盖已有批次，也不下载依赖。旧版基线提交须已在本地 Git 可读。

```powershell
& $nativePython -I -B -X utf8 .\scripts\smoke_nested_time_mapping.py `
  --output-dir .\docs\assets\nested-time-repro `
  --work-dir .\product\.runtime\nested-time-repro `
  --font-file $localDejaVuSans --font-license-file $localDejaVuLicense
```

`$nativePython`、`$localDejaVuSans`、`$localDejaVuLicense` 应指向现有原生运行时和字体文件；本批使用本机 ComfyUI 随附的独立 Python 执行脚本，没有启动 ComfyUI 服务。脚本与当前源码摘要、旧版归档全部源文件摘要及实际 argv 已记录；跨 FFmpeg 构建仍需重新核验，不能承诺编码字节一致。

## 7. 未关闭的边界

1. 源先按登记 fps 规范为 CFR；任意 VFR 原始呈现时间戳尚未接受。
2. 速度曲线 ease/Bezier 仍按源坐标线性速度段处理，保留 warning；原最小源速度归一化 0.01 没有在本轮取消。
3. atempo 短窗仍可能有相位接缝或音色变化；极端窗口超过 16384 或不足一个 48 kHz 样本时显式拒绝。
4. 容器/叶片定格、字幕 cue/逐字时间/内置动画的联合时钟未验收，不能套用本轮通过结论。
5. 父级枢轴、mask 坐标空间、混合/音频总线、真正的复合群组渲染、深层/长曲线及 4K 性能继续待补。
6. 原 RVM/SAM2 漏抠、LaMa/VACE 自然修复缺陷、开放内容库规模、发行和完整剪映功能/效果仍未通过，0 新模型实测推理不改变这些状态。
