# 命名音频总线、发送/返回与侧链契约 v0.1

V55 开发与验收基线。使用 Windows 原生 Python/FFmpeg，48 kHz 双声道浮点，禁止运行时联网。本文先于实现与验收数据编写；完成情况以同轮实测记录为准。

## 作者字段与事务

可选 `sequence.audio_routing`；缺省或 null 保留旧树状混音。通过 `timeline compose` 的 `add_sequence.audio_routing` 或 `update_sequence.patch.audio_routing` 原子写入。所有引用局限于该作者序列；无隐式跨序列总线。总线 ID 与轨道 ID 使用不同命名空间，`master` 保留给最终出口。

```json
{
  "version": 1,
  "tracks": [
    {"track_id": "track_audio_1", "output": "dialogue", "sends": [
      {"bus_id": "room", "tap": "pre_fader", "gain": 0.2}
    ], "keyframes": [
      {"property": "audio.volume", "keyframes": [
        {"at_tick": 0, "value": 0.5, "interpolation": "linear"},
        {"at_tick": 90000, "value": 1.0}
      ]}
    ]}
  ],
  "buses": [
    {"id": "dialogue", "audio": {"compressor": {"threshold": 0.2, "ratio": 3}}, "output": "master"},
    {"id": "room", "audio": {"reverb": {"in_gain": 0.8, "out_gain": 0.9, "delays": "60", "decays": "0.25"}}, "output": "master"},
    {"id": "music", "audio": {"volume": 0.6}, "sidechain": {
      "bus_id": "dialogue", "tap": "post_fader", "compressor": {"threshold": 0.1, "ratio": 8}
    }, "output": "master"}
  ],
  "master": {"audio": {"volume": 0.8}}
}
```

`version` 必须为整数 1；tracks/buses 缺省空数组。未列出的 video/audio 轨道仍输出 master。每个显式轨道行必须唯一，引用现有 video/audio 轨道。`output` 缺省 master，可指定命名 bus，或 null 关闭该节点的直达输出；null 不关闭发送和检测支路。`sends` 缺省空数组，每项 bus_id 必填，gain 缺省 1、范围 0..4，tap 缺省 post_fader。同一目标允许多条发送，按实数相加，不自动去重。

轨道音色/基础音量/声像/静音沿用 `track.audio`；轨道行只增加路由、自动化和可选侧链。bus/master 的 `audio` 接受 volume、数字 pan、mute/muted、bus solo、denoise/noise_reduction、compressor、equalizer/eq、highpass/lowpass、dialogue_enhance/voice_enhance、pitch_semitones、reverb、loudnorm、fade_in/fade_out；拒绝未知字段和类型错误。master 不接受 solo。数字范围沿现有处理器，浮点必须有限。bus/master 的淡入淡出以整个序列 0..duration 为包络；轨道淡入淡出继续给出原有不支持警告。

每个 keyframes 属性轨只允许 audio.volume（0..4）或 audio.pan（-1..1），同属性不得重复。发送的 keyframes 是 gain 点数组。点采用整数作者序列 tick，必须严格递增、位于 0..duration；支持 linear/hold/ease_in/ease_out/ease_in_out 和 2/4 控制值的 Bezier。Bezier 控制值均在 0..1，使用现有 33 点查找插值；不是无限精度曲线。区间外保持端点，逐 48 kHz 样本计算，不重置到每个叶片。无点时使用静态值。

侧链必须且只能指定 bus_id 或 track_id，tap 同发送；compressor 可缺省，参数使用本机 FFmpeg sidechaincompress：threshold/ratio/attack/release/makeup/knee/level_in/level_sc/mix/mode/link/detection 的有界值。检测源不自动混入可听信号。静音检测源输出零检测信号；没有素材的轨道也是全长零。先完成源节点处理，再交给目标检测器。

## 执行顺序与边界

开启命名路由后，每个轨道/总线：

1. 输入在作者序列时钟求和，`amix normalize=0`，不因输入数量或静音衰减。
2. 可选命名侧链压缩；随后依次执行降噪、内部 compressor、EQ、高低通、人声增强、移调、混响、响度处理。顺序固定，不宣称任意插件机架。
3. 强制回到 48 kHz 双声道浮点，补齐/裁切至作者序列样本长度。mute/muted 将该节点所有发送与检测输出静音。
4. 这里是 **pre_fader**：已完成音色效果，尚未施加本节点音量/声像/淡变。
5. 音量/声像自动化和淡变；这里是 **post_fader**，直达 output 使用此点。所有分支显式 asplit，避免重复消费 FFmpeg pad。
6. master 完成相同处理，最终不自动限制器；输出编码器的溢出/压限与格式是另一个交付问题。

这是显式启用后的处理顺序；旧链的音量在效果前。开启路由会有意改变压缩等非线性处理与音量的相对顺序，迁移时必须听审。

bus `audio.solo` 按图隔离：保留通往所选 bus 的输入边及从所选 bus 流出的后续边；屏蔽同一轨道绕过所选 bus 的 dry 直达和无关汇入。多 bus solo 取这些通路的并集。检测信号始终来自未应用 bus-solo 屏蔽的完整处理图，避免 solo 改变侧链压缩。必要时构造独立检测上下文，清单记录双图代价。原有序列局部 track.audio.solo 先执行，仍保留其旧语义；mute 优先于 solo。

任何直达/发送/检测形成的循环（即使静态 gain=0）都拒绝；不支持延迟反馈。校验在作者项目提交之前完成。缺失引用、未知字段、非法自动化、锁定/过期事务沿已有门禁拒绝，原项目不留半写。

命名路由子序列必须先合成完整音频，再由父容器处理 source trim、反向、恒速/曲速、定格及输出窗口；不能把非线性 bus 效果分摊到叶片。多个实例各自拥有信号状态和命名空间；不产生作者伪资产或有损中间文件。完整子总线变速沿现有 inline/atempo 边界；文件专用 Rubber Band R3 不伪装为可消费内部 pad。

保存片段组时，如果选择所在序列开启命名路由，自动扩展为该序列全部片段，并报告增加的 ID，保留完整 bus、检测、时间上下文。跨项目插入重映射 track_id，bus 名称局限于各自子序列、保持原名。包导入/导出必须保留原字段。自动碰撞换轨克隆该轨道的路由行和作者时钟自动化；原有不能拆分的轨道音色/闪避限制继续拒绝，也不能把片段放入另一条命名检测轨道，不静默改变效果拓扑。

硬上限：每序列 video/audio 轨道与 bus 及 master 合计 128 节点，含检测的 512 边，单属性 64 点、总计 1024 自动化点；生成的路由滤镜文本不超过 4 MiB。双图上下文按实际两套节点/边计入 256/1024 执行上限。该估算不等于总 RSS 或整工程并发预算。

## 验收基线

线性路由、发送前后、静音/solo、多级 bus、增益/声像/发送自动化用原始 PCM 与独立逐样本数学参考比较，48 kHz 输出样本数必须精确；浮点最大绝对误差阈值 2e-6。效果/侧链用独立拼接的同版 FFmpeg 参考核验接线与次数，明确不属于独立 DSP 算法实现验证。嵌套反向/裁切/曲速/定格/窗口分别检查完整处理次序与时钟；音色算法、自然声审听和完整剪映等效不由这些夹具通过推定。

原输入 WAV、真实输出、波形/路由演示、复现脚本、图/采样元数据与 SHA-256 同步 README；保留所有真实失败与修复后重测。完整回归和原生离线安装另计。未实现空间声、任意音色参数自动化、插件宿主、反馈网络及专业响度交付，仍属于后续需求。
