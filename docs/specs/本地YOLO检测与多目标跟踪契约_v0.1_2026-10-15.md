## 输入与登记

使用现有 `media adapter register/list/inspect`。`--model-path` 必须是显式本地、非空、自包含 `.onnx` 文件；`--executable` 必须是现有原生 Windows Python `.exe`，环境已包含 numpy、Pillow、onnx、onnxruntime。不得安装依赖、下载权重、启动服务或虚拟化环境。登记必须提供现有本地 `--evidence` 文件；模型、Python、证据、内置 worker 和关联算法均记录 SHA-256，登记参数也纳入摘要。

专用参数为 `--threads`（1–32，默认 4）、`--confidence`（新轨迹置信度，默认 0.35）、`--low-confidence`（关联用检测下限，默认 0.10）、`--match-iou`（默认 0.10）、`--max-gap-seconds`（默认 0.8）和可重复 `--class-id`（COCO 0–79，默认 0/person）。参数、路径和完整性不合格时拒绝执行。默认权利为 unverified/internal；模型元数据中的许可证名称不能替代完整证据。

登记及 inspect 检查本地文件、参数和摘要，不启动 Python/ONNX 推理。自包含图、标准算子域、COCO-80 类名、输入输出结构和已安装依赖在专用 worker 推理前核验；inspect 的 `ok` 不能视为模型可执行或质量已验收。

## 执行与时间

由已登记 Python 以 `-I -B -X utf8` 启动内置 worker，使用 v2 多目标协议。原生 ONNX Runtime 显式使用 CPUExecutionProvider，不启用 CUDA 或在线回退。只接受 RGB float32 `[1,3,640,640]` 输入和端到端 `[1,N,6]` 输出（xyxy、confidence、COCO class）。拒绝外部 ONNX 数据和非标准域算子；640 正方形 letterbox 的偏移按实际取整尺寸反算。坐标为原始未旋转栅格的归一化中心与宽高。

视频由本地 FFmpeg 解码；按照 `step_frames / avg_frame_rate` 重采样，帧时码为请求起点加采样序号乘间隔。此时钟是 FFmpeg 重采样时钟，不声称逐原始 VFR 帧精确对齐。非零旋转/起始 PTS、非方形像素、未知时长/帧率和超出解码预算的输入拒绝。最多 4000 个采样、64 个累计对象、50,000 个观测；超过 `max_samples` 时拒绝完整范围，调用者应明确缩短范围或加大 step，采样间隔不能超过 max-gap。不静默截断或伪造剩余轨迹。FFmpeg 子进程及临时目录在成功、失败和超时后清理，解码器置于原生 Windows kill-on-close Job Object，不使用虚拟化。

ROI 表示持续检测区域，按检测中心过滤；全画幅使用 `--roi 0,0,1,1`。`--all-objects` 生成检查报告；应用、绑定和重构图要求显式 `--object-id`。对象 ID 在同一模型、输入、参数和 CPU 环境下按检测排序确定分配。

## 关联、输出与权利

采用常速度预测、同类别 IoU/中心距离门限、Hungarian 全局分配和高/低置信度两轮关联。新对象只由高置信度检测建立；短缺失期允许关联恢复，超过 max-gap 后建立新 ID。此算法没有外观 ReID、姿态或分割，不宣称跨镜头、长期遮挡和同类交叉身份可靠。报告只输出实际检测帧，缺失区间不伪造检测；编辑器在观测点之间插值，必须保留复核警告。

worker 阻断 Python 网络调用，校验请求、模型/源码/证据/输入摘要并回传；父进程再次验证协议、摘要、采样时码、唯一 ID、有限坐标、边界与置信度。网络审计钩子不等同操作系统网络沙箱。没有检测时返回结构化错误，不回退模板或虚构固定框。

正式应用把模型权利 ID 写入片段 `rights_dependencies`，权利闭包、发布清单和缺记录检查必须消费此字段；快照/恢复包含视觉模型 registry。分析报告不修改片段或把所有已登记模型变成发布依赖。报告目标已存在时拒绝覆盖，失败不得改写已有报告、项目或台账。

正式应用要求使用已摄取源素材的 `--asset-id`。兼容文字绑定以完整请求时长映射目标片段，避免把末次观测点拉伸到片尾。显式提供 source-track-id/source-clip-id 可启用[持久画布绑定](./本地跟踪绑定坐标空间与渲染重算契约_v0.1_2026-10-15.md)，在裁切、源变换、镜像、时钟和输出画幅变化后重算，已完成受控组合样例；嵌套父层、VFR、mask/自然遮挡和完整效果坐标仍需专项验收。密集轨迹的长滤镜图执行见[Windows 命令长度契约](./本地长滤镜图与Windows命令长度契约_v0.1_2026-10-15.md)。模型 registry 侧车会随快照、元数据事务及项目包保留，权重和 Python 不自动打包或重新绑定。

## 验收

必须同时具备：登记/篡改/网络拒绝/失败回滚测试；letterbox、双目标运动、低置信度关联、缺失恢复与确定性测试；实际 ONNX + 本地人物图片生成受控运动视频的检测、轨迹、文字绑定、重构图和 FFmpeg 渲染。受控样例不替代真实广告、自然遮挡和同类交叉的广泛质量验收。实测结果另存 validation，保留输入和模型哈希，模型与媒体不上传。
