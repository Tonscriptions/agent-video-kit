## 组件字段

| 编号 | 约束 | 后续验收 |
|---|---|---|
| CP-01 | 暴露字段定义和逐片段取值分离；限定 text/image/boolean/var，唯一稳定 ID 与可读名称分离 | 重命名不丢值；同名/重复目标显式处理；缓存和包重放稳定 |
| CP-02 | Agent 使用 JSON Schema 发现字段类型、默认值、范围/单位、目标和可选值；不依靠 GUI 选择 | CLI 列表与实际可写字段一致；未知/重复/超预算输入返回结构化错误 |
| CP-03 | 沿用现有最多 128 项、64 KiB 覆盖预算，selector 最长 512、n 为 1..1024，CSS 变量名沿用既有正则 | 上游允许 `--` 和 `n=1e20` 的输入在宿主明确拒绝；已有合法项目行为不变 |
| CP-04 | 图片值只能引用已登记、在本地资源闭包内的资产 ID；不把字符串直接变成任意 URL | 远程路径、目录逃逸、缺失/变更摘要和权利不满足时拒绝；合法源图包重放一致 |
| CP-05 | boolean 表示组件可见性；明确 true/false/default，默认恢复须恢复原页面的可见状态 | 原来隐藏/显示的对象、空字符串文字、逐项与全量重置、混合已有覆盖分别验证 |
| CP-06 | 保留原 HTML、原作者时间线和非目标覆盖；变更经现有锁与事务提交 | 失败不留下半写工程；包/片段库/队列可编辑重放；CLI 原生像素与实际安装分别核验 |

原 `propsOf` 会丢弃无效字段；本项目的写入命令须返回明确错误，不能把静默丢弃当作成功。不得为移植方便开放任意 style 写入、改变现有 HTML 沙箱或绕过本地运行政策。新增 schema 字段和显隐执行策略须先定版，再实现和全量回归。

## 时间线预览与持久缓存

| 编号 | 约束 | 后续验收 |
|---|---|---|
| PV-01 | 以现有完整时间线图语义生成指定帧或半开区间；不以输入素材抽帧或先完整编码再剪切代替 | 画面/透明/音频与独立完整时间线参考一致，覆盖非零起点、NTSC、关键帧、嵌套、速度与转场 |
| PV-02 | 区分请求时间、实际帧序号/PTS、区间端点和音频样本区间；使用有理数作者时钟 | 首尾部分帧、末帧、无音轨、48000 Hz PCM、动画时间与完整参考独立比对 |
| PV-03 | 缓存 key 绑定规范化作者工程、有效输出设置、所需资产与字体/LUT/运行时/模型等资源的真实字节摘要 | 同大小+同 mtime 的内容替换必须失效；不同速度/帧率/画布/版本不能串用；记录可审查依赖清单 |
| PV-04 | 不降低现有 SHA 完整性门槛；缓存命中仍核对收据、资源闭包和结果摘要 | 损坏输出、伪造收据、源图变化、已删除资源、DLL/脚本变更明确拒绝或重建；不能仅用文件名命中 |
| PV-05 | 复用现有工程锁、进程管理、取消 marker 和原子写入；独立新临时目录，完成验证后才发布 | 取消/失败/进程中断不覆盖成功结果；重复请求和并发请求有确定归属与恢复路径 |
| PV-06 | 显式区分 authored/output/cache；预览衍生物不改工程、权利、模型运行事实或最终发布 gate | 缓存复制不新增一次模型执行；manifest 保留源和派生关系；最终交付仍做正式 render 与发布核验 |
| PV-07 | 配额、条目大小、临时空间和清理均有界；禁止跟随逃逸链接删除外部路径 | 清理只操作项目缓存内经解析确认的路径；保护运行中条目；满盘/损坏/缺失的失败可审查 |
| PV-08 | 冷启动、缓存命中、纯滤镜吞吐、完整编码和交互播放分别测量 | 报告输入/设置/并发/总耗时；不由缓存命中或 HSL 滤镜速度宣称实时播放达标 |

上游 `projectPrint` 使用路径、大小与取整 mtime；R12 已实际观察到内容变化但 key 相同。该规则禁止原样进入本项目。图片缓存与音频缓存共用内容身份与取消/配额设施；新增音频代理不能把上游的四位小数速度量化默认为作者精度。

## 发布门槛

组件参数和预览分别形成可审查的 CLI 契约、真实 CLI 结果和离线安装证据后，才更新产品能力声明。必要的像素、透明、PCM、PTS、包重放、故障与完整回归完成前，不能把本设计改写成“已实现”。所有复制的源码保留 MIT 许可与固定提交；相关 `$video-cut-` Skill 在真实命令可用后同步更新。
