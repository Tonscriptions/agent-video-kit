# 作者时钟浮点帧宿主与缓存源边界

本候选延续完整产品目标，连接原始帧时钟、Float32 表面与作者工程。它是后续流式渲染的库层，不代表默认 `render`、`preview`、音频或缓存链路已完成精度迁移。尚不支持的作者操作明确报错；完整剪映对标、全部效果和自然素材质量验收继续保留。

父候选为 V92 的 282 份冻结产品输入，创建实验目录时其完整回归仍运行，尚未发布；不得将复制证明写成发布证明。新增 3 个模块与 3 个测试文件后冻结为 288 份。来源、8 份夹具和 9 份离线依赖见 [创建收据](../validation/evidence/float-timeline-20261022-lab/foundation-r1.json)。

| 编号 | 契约 | 实现及边界 |
|---|---|---|
| FTH-01 | 工程入口 | `FloatTimeline` 消费已校验的 Agent Project IR，深复制作者数据；输入源必须匹配登记资产 SHA 与同一个显式 `ColorSignal`。库本身不代替完整工程、版权或发布门禁 |
| FTH-02 | 原始时钟 | `TimedSurfaceSource` 保存 signed int64 PTS、duration、明确有理数 time base 与容器起点。正放取左闭右开区间，倒放取对应右端的左极限；不以平均 FPS 推测源帧位置或末帧 EOF |
| FTH-03 | 可变帧率 | 已知相邻 PTS 之间保持前一帧。最终可用帧使用其原生 duration 限定已知覆盖；duration 为零时拒绝推测后续范围。部分帧包的覆盖末端不等于整条原片 EOF，未导出的帧不能恢复 |
| FTH-04 | 静态图片 | 显式 `still=True`，单表面按作者片段持续；不将图片单包 duration 当成片段终点。图片与视频资产种类必须一致 |
| FTH-05 | 作者时钟 | 输出帧时刻和常速源映射使用 `Fraction`；支持正速、倒放、冻结、presentation window。冻结源时钟时作者动画仍继续；工程源范围和关键帧不重写 |
| FTH-06 | 曲线时钟 | 复用既有 `compile_curve`、`make_map` 与 `unmap_time`，保留归一化曲线和已有误差证书；内部仍为 Float64，不宣称非线性映射是精确有理数求解 |
| FTH-07 | 嵌套与层次 | 子序列先在自己的透明画布合成，父变换与透明度作用于完整子结果。连续作者时间及正/倒放的左右极限跨层传递；hold 动画的左极限使用 Float64 相邻值，不宣称大整数动画 tick 无舍入 |
| FTH-08 | 几何和动画 | 复用 `keyframe_value` 的 6 种插值，以及 Float32 表面的预乘双线性逆仿射采样。支持缩放、旋转、位置、锚点和透明度；整像素中心规则明确，未增加高阶缩小抗混叠 |
| FTH-09 | 蒙版 | 支持源坐标归一化矩形、圆、椭圆、反选及相应全局 clip 关键帧。蒙版只改 alpha。羽化、路径、蒙版本地关键帧等尚未接入，明确拒绝 |
| FTH-10 | CPU 合成 | `composite_rgba` 实现 32 种既定混合，Float32 输入/输出、Float64 分块计算、独立 alpha。复用经过核验的信号、几何与模式别名；不逐帧启动 FFmpeg 合成 |
| FTH-11 | 色值范围 | normal 保留有限负值与大于 1 的 RGB；其余显示混合只在真实重叠且 alpha 非零的区域要求 RGB 位于 0..1。隐藏 RGB 不影响可见颜色；alpha 为零的输出 RGB 归零 |
| FTH-12 | 背景 | 项目十六进制 RGB/RGBA 背景默认按显式 bt709/sRGB 解码后转换到工作信号；透明度不进入传递函数。子序列保持透明，不继承根背景 |
| FTH-13 | 帧包缓存源 | `BundleSurfaceSource` 校验三文件帧包、配方 SHA、登记原片 SHA 与信号。只接受未预先应用几何的源，避免作者变换重复。部分包返回原始帧号，不将其改成从零编号 |
| FTH-14 | 资源生命周期 | 帧包像素与时钟只读 mmap，取帧返回独立数组；open 和正常 close 重核字节，取帧前后检查文件属性。退出时关闭全部自有映射；异常退出优先保留原异常。两次字节核验之间不承诺抵御能伪造文件属性的并发写入 |
| FTH-15 | 容器起点 | 有原始解复用起点时显式覆盖必须相同；未知时要求调用方明确提供并记录假设，不按帧率或首个视频 PTS 猜测容器零点 |
| FTH-16 | 取消与预算 | 继承几何/合成的分块取消；同帧最多 128 个展开片段、展开最多 4096 片段、最多 16 层、单个 RGBA 表面不超过 256 MiB。现有 768 MiB 数值核估算不等于进程 RSS，也不是所有嵌套临时表面的全局内存上界 |
| FTH-17 | 明确未接入 | 效果、转场、crop、生成器、字幕、跟踪绑定、源转场计划、其他轨道类型与未知关键帧属性明确拒绝；音频轨道跳过并标明未渲染。没有静默回落至旧 8 位路径 |
| FTH-18 | 后续必做 | 连接统一精度策略、常规流式视频编码、既有原生音频时钟、render/preview/cache、取消/队列/清单/版权门禁；再接入全部操作、字幕、跟踪、羽化、ICC/PQ/HLG 和 HDR。当前中间帧包的 2 GiB 上限不能成为最终长片渲染架构 |
| FTH-19 | 发布后复现 | 媒体脚本支持显式 `--source-root`，发布仓库默认使用本仓库已有的 V92 原片/帧包；不要求作者实验目录存在。不自动下载或安装依赖；同一安装的独立便携重放需匹配全部 Float32 像素字节 |

本次 CPU 合成和作者宿主的代码为本项目实现，数学核验沿用既有 W3C/信号契约；没有复制 OpenFilm 的 GUI 或云 provider。OpenFilm 既有字幕、HTML、模板字段、缓存、诊断等适配继续复用，不能据此将本轮独立数值核心视为已完成全功能渲染。

验收见 [实际测试与原片](../validation/作者时钟浮点帧宿主与真实媒体独立实测_2026-10-22.md)。
