# 多机位仿射时钟与漂移校准（实验 v0.1，2026-10-21）

状态：独立开发，尚未通过功能验证、完整回归、生产接入或发布。源基线为 V89 候选的 260 个固定输入；生产发布必须另绑定实际 V89 完整 2043 方法通过和已推送的提交。不得改动正在运行的 V88/V89 输入及脚本。

现有同步只有 `source_seconds = reference_seconds + offset`，不能修正两台设备录制时钟的速率差。新增本地 `affine` 模型：`source_seconds = offset_seconds + source_per_reference * reference_seconds`。正漂移表示相同事件在源机位出现得越来越晚；生成片段的变速等于 `source_per_reference`，源入/出点同时使用该映射。参考主音轨仍须显式指定，不能自动替换为机位音轨。

| 编号 | 要求与验收 |
|---|---|
| AC-01 | 固定偏移为默认路径，旧命令和三种源覆盖策略语义保持；仿射必须显式选择。无隐式降级为固定偏移。 |
| AC-02 | 从同一已归一化原生音频特征估计多个分布时间窗；使用完整窗口 Pearson 匹配、亚采样峰值、鲁棒拟合及再次对齐。完整保留每个锚点、峰值/次峰、残差、接受/拒绝与拟合范围。 |
| AC-03 | 参数有限且有界：最多 600 秒既有分析前缀、3–31 个窗口、窗口 4–60 秒、最大漂移不超过 20,000 ppm；有效时间跨度至少两个窗口。输入为空、平坦、极短、无足够独立重叠或窗口数不足时明确拒绝。 |
| AC-04 | 默认最大漂移 5,000 ppm。采样/拟合量化、统计范围、实际锚点跨度与漂移不确定性须报告；不能将一个全局互相关峰当作漂移证据。 |
| AC-05 | 低相关、重复模式歧义、超漂移范围和不符合单一仿射时钟的残差不能成为可应用的成功校准。保留失败证据，不以不可信速率生成片段。 |
| AC-06 | 模型同时给出正向源时钟与逆向参考时钟；两个方向的单位与正负号明确。报告旧 `relative_delay_seconds` 只代表参考零点的偏移。 |
| AC-07 | `build_switch_segments` 对源首/末原生帧覆盖求逆，正确处理 `reject/trim/stretch`。trim 保留校准后的事件位置/速率及空缺；stretch 继续明确警告改变同步，不伪装成时钟校准。 |
| AC-08 | 源入/出点和输出时长必须一致，正/负漂移均生成对应速度。校准导致的 speed<1 不得误报为源不足；原生缺口、非零原点、显式时间线起点和部分选区共同核验。 |
| AC-09 | 校准报告有明确有效参考范围。作者请求超出被观察的范围时默认拒绝；仅显式允许外推时带警告和外推区间。未知/无效模型、非有限数、bool、无效 rate、内容摘要变动、不匹配参考 ID、空或非规范 SHA、矛盾的 ppm/旧零点偏移/逆变换和超出源/参考媒体的观察范围拒绝。摘要检查用于内容一致性，不是可信签名或对恶意重签元数据的认证。 |
| AC-10 | CLI 支持显式模型、窗口、锚点、漂移上限与外推选择；共享既有项目路径、权利、快照、事务、重放、dry-run 零写入和覆盖拒绝。 |
| AC-11 | 纯函数对已知偏移/正负漂移/无漂移、噪声/增益、局部坏窗、重复与非线性时钟分别验证。独立期望来自预先给定的源时钟，不能以被测拟合输出作为真值。 |
| AC-12 | 原生实测至少包含分钟级、小漂移与较大漂移，及固定偏移对照；比较起/中/末时间锚点和逐帧源采样。覆盖范围、帧率、PTS、无损画面/PCM与有损输出分开记录。 |
| AC-13 | 原输入和实际 MP4/GIF、确定性生成脚本、SHA、权利与失败证据保存至 docs；GIF 不证明声音或连续播放质量。自然多机位、声学差异和人工听审仍需要独立验收。 |
| AC-14 | 用八轮离线媒体包重新安装并执行真实 CLI，核对新增资源、模块来源与 NumPy 原生运算；不复制宿主依赖，不联网下载或启动虚拟化。 |
| AC-15 | 专项通过后才能准备完整回归，完整套件必须绑定实际已发布 V89/2043。产品/测试/脚本/夹具/九个固定依赖前后冻结，最后更新 README 编号表、全部 17 Skill 审计、暂存字节审计与普通推送。 |

本次使用现有前缀分析预算；超过 600 秒的全片分布抽样、非线性/分段时钟、丢采样与时间戳跳变需后续扩展，不能以本实验宣称已支持。自然录音广泛成功率、HDR、长片吞吐/RSS、连续播放、听审和全部剪映功能效果都不是现有证据已经证明的能力。完整产品目标保持不变。
