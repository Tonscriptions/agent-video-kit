本适配器把公开可读的本地剪映式草稿 JSON 转换为 Agent Project，并反向生成同一文件轮廓的明文 JSON。当前只实现文件字段映射，未验证任何商业版本的打开、保存、导出和视觉等效。版本号用于结构标识，不构成商业版本兼容性承诺。

公开字段研究来源可追溯到[上游快照清单](../../research/agent-video-kernels/sources/GuanYixuan__pyJianYingDraft/source-snapshot.json)，固定提交为 `6bb2d06a713f7b58e1375269daec835a03882086`。生产实现不导入上游 GUI 控制、私有资源下载或解密逻辑。源码许可证不自动授权草稿内媒体、字体、音乐或特效。

## 1. CLI 与产物

在项目根目录使用 PowerShell：

```powershell
.\ai-ad-editor.ps1 convert import --input E:\media\draft_info.json --output .\workspace\draft-imported
.\ai-ad-editor.ps1 convert import --input E:\media\draft_info.json --output .\workspace\strict-import --strict
.\ai-ad-editor.ps1 convert export --project .\workspace\draft-imported --output .\exports\draft_info.json --target-format jianying-draft-json
```

导入通过 `materials` 对象、`tracks` 数组和 `canvas_config` 对象识别明文草稿。路径相对草稿文件所在目录解析，输出目录必须不存在或为空。目标项目包含复制后的本地媒体/字体、未核验权利台账、`validation/draft-conversion-report.json` 和脱敏后的 `validation/source-draft.json`。

导出生成目标 JSON、`<目标>.conversion-report.json` 和 `<目标>.source-agent.json`。旁车保存源 Agent Project 的未映射参数；报告保存源哈希、适配器版本、状态计数和能力条目。媒体/字体使用哈希已核验的本地绝对路径，不自动复制到导出文件旁；跨机器交付使用[本地项目包](./本地项目包与交换清单契约_v0.1_2026-10-15.md)。

`--strict` 当前只适用于此草稿适配器。遇到 `Approximate/Baked/Unsupported/Failed`，发布目标前返回 `CONVERSION_STRICT_REJECTED`；错误 envelope 的 `cause` 包含状态计数和损失条目。拒绝时不创建新项目、不覆盖已有导出文件。文字排版始终保留近似项，因此含文字的草稿不能通过当前严格模式。

## 2. 字段映射

| 编号 | 能力 | 导入与导出行为 | 边界 |
|---|---|---|---|
| D01 | 时基 | 微秒与 90,000 tick/s 用有理数换算，FPS 保留为有理数 | 导入最多半 tick 舍入；输出舍入到微秒 |
| D02 | 画布与时长 | 宽高、FPS、时长及前导/片段间/尾部空隙 | 最大 8192；复杂画布背景未完成视觉验收 |
| D03 | 轨道与层级 | 视频、音频、文字、本地图片/视频贴纸映射；mute/render_index 保留 | 单轨不同层级使用首片段并报告近似；其余类型报告不支持 |
| D04 | 本地素材 | 复制、探测、去重、SHA-256 登记；导出检查引用与哈希 | 缺失或只有资源 ID 生成 Failed，不下载 |
| D05 | 片段时钟 | 源/目标起点、时长、固定速度、倒放 | 范围与 speed 冲突以范围比率为准并报告近似；曲线速度不等效 |
| D06 | 变换 | 中心原点/Y 向上转为左上原点归一化坐标；旋转、等比缩放、alpha、翻转 | 非等比缩放用 X 并报告近似；导出非中心锚点报告不支持 |
| D07 | 裁切 | 轴对齐四角与静态像素/归一化矩形双向映射 | 透视、动态裁切、fill/stretch 等效未实现；越界钳制有近似报告 |
| D08 | 关键帧 | 位置 X/Y、角度、等比缩放、透明度、音量，按片段时钟映射 | 线性可映射；Bezier/缓动近似；hold 回退线性并报告；未知属性保留 |
| D09 | 文字 | 独立文字片段、文本、RGB/alpha、基础对齐、字号百分比 | 度量、换行、富文本、字距、描边、阴影、竖排、动画未完成商业视觉验收；外部字幕资产、视频内嵌字幕和文字画布裁切导出报告不支持 |
| D10 | 字体 | 显式本地 TTF/OTF/TTC 复制/登记，导出检查哈希 | 缺失、资源 ID、局部字体仅报告，不下载、不自动授权 |
| D11 | 视频原声 | 导入展开为关联显式音轨，未修改的关联音轨导出合回视频 | 单独调音量/静音后保留独立音轨、视频原声归零；无非零音量的原声不增加混音输入 |
| D12 | 音频 | 片段音量、线性音量关键帧、淡入淡出、全局视频静音 | 额外处理/轨道控制报告不支持；独立音轨引用视频容器报告外部兼容性近似 |
| D13 | 隐藏片段 | 导入跳过渲染，保留时间空隙和源记录 | 不作为可见片段执行 |
| D14 | 私有资源 | Unsupported/Failed 条目与脱敏源参数 | 私有特效、转场、滤镜、遮罩、动画、云资源不执行、不下载 |
| D15 | 复合工程 | 导出首序列；其他序列、嵌套、标记及未映射参数保存在旁车并报告 | 不承诺多序列、复合片段或全部剪映功能无损互转 |

未识别商业版本可在 best-effort 按可识别字段解析，但增加 `draft-version/Approximate`，严格模式拒绝。加密、二进制、非法 UTF-8/JSON 直接拒绝，不解密。

## 3. 事务、权利与本地策略

导入先检查全部媒体路径和可识别字体路径，再在目标父目录的临时目录构建候选。映射和严格门禁通过后校验项目，保存项目、台账、报告、脱敏源，最后移动为目标目录。失败不发布候选；best-effort 中素材缺失可保留部分项目，但报告为 `partial`，CLI `ok=false`、退出码 2。

导出写入前检查源项目、引用素材、哈希和损失门禁。输出或旁车不得覆盖项目主文件、台账或已登记资产。三个文件分别原子保存，目标 JSON 最后发布；它们不是跨文件事务，磁盘错误后可能需要清理已写旁车。

HTTP、对象存储、UNC、远程 file 主机在复制和外部进程前拒绝。源记录中的网络端点替换为 `redacted_reference_sha256`，包括文字材料中的嵌套 JSON 字符串；源文件本身不修改。`sha256:<64 hex>` 是内容身份元数据，允许出现在台账和报告中；其他网络门禁仍生效。

导入权利默认为 `LicenseRef-UNVERIFIED`、`verification_status=unverified`、仅允许 internal。转换和预览不提升许可证状态，发布须经过 Rights Ledger 门禁。

## 4. 渲染与回归证据

最终音频总线在 48 kHz 重采样后按序列时长补齐并裁到确定样本数，保留最后一段音频之后的静音，默认 80 ms 音画时长差门槛不变。字体过滤器优先用项目相对路径及正斜线，避免 Windows 中文绝对目录的 FreeType/Fontconfig 失败；FFmpeg 的 cwd 为项目根目录。

`product/tests/test_draft_adapter.py` 包含 11 项回归：

1. 源/目标时钟、2 倍速、中文文字、坐标、关键帧、原声、音频淡入淡出及实际输出。
2. 基础草稿严格双向往返，实际输出 RGB 帧、音频 RMS 一致。
3. 私有效果可见损失、严格拒绝、端点脱敏、本地策略审计。
4. HTTP、S3、UNC、远程 file 主机在复制前拒绝。
5. 重复 ID、负时间、错误结构、越界范围、非有限 FPS 拒绝。
6. 缺失素材保留部分项目，返回失败状态。
7. 素材哈希变化拒绝导出。
8. 严格拒绝时保留已有输出；外部字幕资产、视频内嵌字幕和透明画布生成可见损失报告。
9. 裁切、RGB/alpha、对齐、字号、本地字体往返及实际渲染。
10. 单独修改原声音量、轨道静音、全局视频静音后的实际音频往返。
11. 非明文输入与覆盖源项目的请求拒绝。

这些测试使用本地合成媒体及本机字体，不等于真实广告 golden、商业字体排版一致性或剪映运行时验收。完整结果见[回归验证记录](../validation/回归验证记录_2026-10-13.md)，整体状态见[构建进度总表](../构建进度总表_2026-10-15.md)。
