# 离线逐笔描线动效契约 v0.1

目的：把 OpenFilm 示例中的两个纯 Canvas2D 函数拆成 Agent 可调用的独立描线源；复用现有 HTML 离线编码、透明叠加、工程包和片段组，不引入 three.js、GUI、CDN、在线生成或模型下载。本契约先于产品实现编写。

## 输入与命令

`motion stroke-source --project <工程> --input <本地 JSON> --asset-id <新 ID>` 生成可编辑 HTML 源资产；支持现有 `--dry-run`、幂等和工程事务。随后用 `motion html-render --source-asset-id <ID> --asset-id <新编码 ID>` 编码，按现有选项入轨、取消或超时。

输入顶层字段严格限定为 `version`（`agent-stroke-motion-v1`）、`width`、`height`、`fps`（整数 num/den）、`duration_tick`、`stroke_width`、`color`（`#RRGGBB`）、`characters`。字符项严格为 `text`（一个 Unicode 码点）、`start_tick`、`end_tick`、`strokes`；每条笔画为至少两个 `[x,y]` 绝对画布坐标。时间基继承工程，字符按输入顺序且时间不得重叠；允许间隙及无笔画空格。至少一个可见字符，不自动生成缺少的字形或时间。全部坐标、时间和长度须有限；描线宽度至少 0.25、至多 64 px，完整线帽边界必须在画布内。

上限：清单 2 MiB、256 码点、2048 笔画、32768 点、点数乘编码帧数 800 万；沿用 HTML 的 4096 边长、1800 帧、20 亿像素工作量和输出预算。超限拒绝，不截断。以上是显式数据/工作量预算，不是总 RAM 或截止时间保证。

## 字节复用与执行

从固定 `openfilm/examples@2e8f47866bc2d32305cd5d97adcffd7480df2297` 的 `one-prompt/src/px/stroke.js` 提取原字节 `drawStrokeText` 与 `writtenLength` 两个 export；保留 OpenFilm MIT 和原 pdoom-video MIT。新增 Python 负责严格输入验证、线长/字符范围计算和确定性打包，不采用上游 SVG 字体解析、隐式缺字跳过、光学字距或字体网络加载。

源码包保存原输入字节、校验后的几何数据、两个原函数、许可和页面。页面每帧清空并仅按传入时间绘制，使用显式 Canvas2D；颜色可通过唯一 `ink_color` 参数修改，拒绝非十六进制颜色。JSON 文本作为独立资源加载，不拼接到可执行脚本或可见 DOM。支持正向、反向与随机求帧；现有 worker 在两份新上下文乱序重绘全部帧。所有页面和子进程归现有 Windows Job 回收。

源资产整体默认未核验、仅内部使用；MIT 代码不自动授予用户笔画、字形设计或内容商用权。修改输入需生成新的源 ID；打包往返保留源码和来源。正式输出继续依赖源资产权利闭包。

## 验收与边界

先用独立线段截断参考检查长度、插值、字符间隙、重复时间调用和回退求帧；非法结构、非有限值、越界、配额、ID 冲突、事务回滚和幂等须有负例。实际原生 worker 编码原创向量字样，提供原 JSON、透明输出、叠加 MP4、GIF、帧/PTS/摘要及页面回收证据；独立几何参考与实际解码按预声明抗锯齿容差比较：离线段中心和边缘 2 px 以内不做硬阈值，其余前景/背景覆盖一致率至少 99.9%。工程包往返重建 RGBA 必须逐字节一致。

这提供的是**显式笔画的逐笔绘制**，不代表自动汉字笔顺、通用排版/复杂塑形、歌词强制对齐、自动语音识别或完整剪映特效。Canvas 文字不属于已有 DOM 文字门禁的语义覆盖。未经实测不得宣称自然广告审美、连续播放/听审或跨机器一致性通过。
