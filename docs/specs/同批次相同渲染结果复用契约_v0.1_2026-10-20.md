# 同批次相同渲染结果复用契约 v0.1

状态：V70 同批次复用契约、真实 CPU 视频、原生安装与完整回归限定通过；性能及完整剪映等价未验收。

## 目标与来源

参考 OpenFilm 固定 `71922644da5d6b67db2cc796d4e057f98999944f` 的
`studio/server/exports.mjs:startAll()` 和 `cloneOf()`：同次请求内，相同有效规格的成功产物可复制给另一输出名。
借用批次规划规则与夹具，沿用现有 Python 项目、本地队列、JSON 协议和 FFmpeg。
不引入 Studio、React、HTTP 服务、桌面 Agent、剪映导出、在线 provider、npx、浏览器或虚拟化。
原固定源码及 MIT 随既有来源归档保留，不把旧采用重复算作成本节省。

## 第一版范围

- 显式 `queue run --reuse-identical`；默认关闭，旧执行路径保留。
- 仅同一命令调用、同一项目、串行 worker；并发请求与复用同时指定时在启动前拒绝。
- 未找到可复用的成功前序产物，执行普通渲染。失败/取消的前序作业不作来源。
- 输出名、作业 ID/label、已完成输出清单和队列写入的更新时间不是内容差异。
- 有效画布、帧率/时基、序列/轨道、字幕、关键帧、遮罩、音频、编码器、质量、色彩、采样与硬件配置均影响签名。
- 不跨规格、容器、源字节或发行实现匹配；不使用持久缓存或跨命令的旧成功作业。
- 首版只接纳能列全实际本地依赖的确定性配置；未声明字体、动态 HTML/外部运行器等不能可靠列全的依赖拒绝复用，不能静默忽略。
- 首版拒绝逐作业硬件探测、外部音频伸缩、外部字幕/字体回退、外部跟踪报告绑定、未固定种子的颗粒及多文件播放列表。已编码成本地普通媒体的模型/HTML 产物按实际视频字节处理，复制不会运行其来源配方。

## 内容快照

使用深层规范 JSON：字典排序、数组顺序保留、禁止非有限数，不能把仅顶层 keys 的 replacer 用作深层白名单。
比较归一化后的真实渲染设置，省略值与显式相同默认值应一致。自定义文件名不进入内容签名。

项目作者数据保留，只有已证明不参与画面/声音的 outputs、provenance.change_log、project.updated_at 从签名副本去除。
不得改写实际项目，也不得借此排除权利数据；每个目标仍独立执行当前权利/项目验证。
当前权利账本、所有实际媒体/蒙版/字体/LUT 本地文件、原生工具、运行实现都须绑定 SHA-256。
源文件大小和 mtime 不是内容真值；同大小并恢复 mtime 的内容修改必须失效。
缺失文件、未知依赖或执行中变化应明确失败，不能沿用声明的旧 SHA。

项目内全部资产均保守纳入，未使用资产变更也可能造成一次额外编码；不宣称最小依赖图。
显式字体使用实际文件，产品包顶层 Python/MJS/JSON/notice、原生 Python/FFmpeg/FFprobe、相关目录 DLL 与 Pillow 实现文件纳入运行摘要；不声称枚举全部 Windows 系统组件。
每次首次编码前绑定已有派生缓存，编码后检查原文件未变；来源 manifest 保存编码后实际缓存摘要，复制前后再次核对这些文件。
新产生的其它缓存不凭名称替换原绑定，损坏缓存拒绝复制；渲染本身的画面质量仍须独立审查。

## 产物复制与事务

成功来源必须有实际非空成片及原 manifest，绑定其 SHA、operation ID、依赖快照和结构质量结果。
只登记已经提交成功的来源。目标先排除路径冲突、已有文件和源/目标同一路径。
逐块复制到本次独立临时文件；仅轮询本次目标取消标记，不取消来源或其它作业。
校验复制字节 SHA、输入/工具/实现前后快照和结构质量；原子发布到项目内新路径。
取消、磁盘失败、源损坏/变化、manifest 不一致均不发布半成品，不改前序成片。

复制产物的新 manifest/operation 具有新的 ID、当前输出路径/指纹与显式 reuse 来源。
原命令、编码器/设备观测、耗时与质量证据保留来源属性；不能伪装本次又执行 FFmpeg 编码或模型。
每个目标独立登记输出、进度、警告、权利检查和持久队列状态；沿用项目写锁与取消短通道。
不建立可变硬链接，不读任意旧队列路径，不扫描其它项目或后台进程。

## 验证与发布

1. 同项目/有效规格、不同名命中；省略/显式相同默认值命中；嵌套设置差异、数组顺序、不同帧率/编码/Alpha 不合并。
2. 媒体/字体/LUT、代码/工具、权利变化失效；同大小/还原 mtime 的内容变化必须失效。
3. 来源不存在、坏 manifest/成片、目标已存在或同名、复制取消/失败、复制中源变化不能留下半成品。
4. 真实 CLI：至少两个同规格目标、一种不同规格、一个失败/取消来源；证明实际执行/复制次数，逐帧/PTS/PCM/字节核验。
5. 默认路径相同配置沿用旧输出；开发/原生安装单独运行；GUI/模型/浏览器调用数不能由复制伪造。
6. README 编号表、原始输入、实际输出与 JSON 收据同步；先报告实际命中与开销，再评估性能，不预先宣称提速百分比。
7. 所有门禁通过后再合入 main、普通推送；以已发布 V69 为基线，冻结本轮 214 个产品输入后验收。
