# 浮点表面合成与高精度边界：独立实验约束

本实验面向功能差异 #112（10-bit 交付）和 #114（色彩管理/HDR）。当前实现独立 Float32 合成、几何、原生 RGB/灰度与明确 YCbCr 读取核心，尚未接入编辑器时间线、CLI、预览、缓存或离线发行。完整剪映等价目标保留；本规格不把输入输出格式名称当成精度证明。

| 编号 | 约束与验收条件 | 当前状态 |
|---|---|---|
| FPC-01 | 原始 10/16-bit 数据须先逐码值核验，保留原片、原生生成/解码命令及 SHA；修复前后复用同一原片 | 两组原创无损原片已核验 |
| FPC-02 | 公共表面为 planar `gbrapf32le`，RGB 为 straight alpha 表示；调用方提供统一色域、传递函数、尺寸、CFR 时间格和完整覆盖 | 独立核心已实现；宿主接入待做 |
| FPC-03 | Source-over 按 Porter-Duff 运算：`Ao=As+Ab*(1-As)`，`Co=(Cs*As+Cb*Ab*(1-As))/Ao`；总 alpha 为零时规范化 RGB 为零 | 实际 FFmpeg 与独立 NumPy 参考通过 |
| FPC-04 | 不透明度与蒙版只改变覆盖率，不先把 straight RGB 再乘一次 alpha；动画表达式使用表面实际 PTS | 独立核心已核验 |
| FPC-05 | 混合模式须考虑透明背景：先求 `Cs'=(1-Ab)*Cs+Ab*B(Cb,Cs)`，再执行 source-over；禁止假定所有背景不透明 | 28 个可分离模式、4 个非分离模式已核验 |
| FPC-06 | hue/saturation/color/luminosity 按明确的 SetSat/SetLum/ClipColor 规则，独立参考不得只复制滤镜表达式 | 排序颜色参考与实际 geq 输出核验通过 |
| FPC-07 | `and/or/xor` 自身定义为 16-bit 码格运算，必须在发现信息中声明；不能称这些模式为连续浮点函数 | 元数据与测试已声明 |
| FPC-08 | 公共边界 straight、内部预乘须显式标记。FFmpeg 自动插入 alpha 转换会影响数值，须检查实际图协商 | 8.1 实测修复后 40 次核心执行无自动转换 |
| FPC-09 | 8-bit overlay/alphaextract/alphamerge、16-bit rotate/xfade 等滤镜不得混入“全浮点”声明；每个操作按实际版本逐一验证 | 13 项滤镜探针留证；完整操作清单尚未接入 |
| FPC-10 | 解码到浮点、增删 alpha、输出量化都属于精度边界；独立数值核心通过不能覆盖这些边界 | 已发现默认 swscale 16-bit 转换损失；zscale RGB 边界另验 |
| FPC-11 | 当前无 alpha RGB 原片：原生 zscale 转 RGB float，精确复制已知不透明 alpha 平面；输出按平面复制取 RGB 后 zscale 量化。不得推断任意透明源已覆盖 | 历史两组不透明媒体已验证；新增原生 RGB/灰度 alpha 和 YUV/alpha 数值适配，产品接入仍待做 |
| FPC-12 | 输入标签、表达式和操作预算须在执行前验证；禁止把表达式扩展成任意 FFmpeg 输入、文件或网络请求 | 标签、模式、注入、256 操作预算专项通过 |
| FPC-13 | 图最多 1 MiB、256 次操作、表达式最多 32 KiB。宿主仍须提供帧、像素、内存、磁盘、取消和错误恢复预算 | 图/几何/像素预算及原生源取消、提前退出已实现；编辑器宿主生命周期待接入 |
| FPC-14 | 所有输入与测试脚本纪元须保存；旧失败不覆盖。测试、媒体、完整回归、安装验证分别计数 | 原失败、执行脚本、SHA 与源码冻结记录均保留 |
| FPC-15 | 默认渲染器、预览、嵌套、转场、字幕、特效、运动重采样须接入相同精度策略；不支持操作必须明确报告真实量化边界 | 尚未接入；不得称整个编辑器已具备此能力 |
| FPC-16 | 色域/传递函数/矩阵/范围元数据、线性光合成、PQ/HLG、HDR10 元数据、色调映射、示波器与显示参考须分别验证 | 未实现/未验收 |
| FPC-17 | 数值测试可以包含负 RGB 和大于 1 的通道，证明核心没有直接截断；不能由此宣称 HDR 画质合格 | 数值通过；HDR 验收为 false |
| FPC-18 | 发布前必须绑定实际发布父版，执行完整回归、实际原视频/GIF、独立安装、17 Skills 与 README 同步以及普通推送 | 当前独立实验尚未进入发布门禁 |
| FPC-19 | 仿射几何的 RGB/alpha 重采样须在预乘域完成；透明区 RGB 不得污染边缘；点与双线性采样分别有明确像素中心和边界语义 | 独立 NumPy 分块核心与实际20帧动画已验证，未接入宿主 |
| FPC-20 | 输入/输出≤16777216像素、单维≤16384、分块≤262144像素，工作区估算≤768MiB；取消须分块轮询，输入不能隐式整帧复制或改写 | 当前预算、取消、C连续Float32输入及有限值门禁已实现；估算不是RSS或4K60性能保证 |
| FPC-21 | 含alpha输入的RGB解码不能隐式合成黑色后再丢弃alpha；RGB与alpha须分别保留精度和表示 | 实测zscale直接丢alpha会预乘RGB；16-bit原生alpha及明确先去alpha再转RGB的探针已通过，原生 RGB 同格式解码后自行归一化，alpha 独立；编辑器接入待做 |

| FPC-22 | 原生RGB/灰度8–16位整数及Float16/32按原格式解码；分量顺序、端序、MSB填充、alpha表示必须明确，禁止默认swscale归一化 | 原生RGBA16及65536码、格式族、所有权/预算/取消专项通过；不是所有FFmpeg像素格式覆盖 |
| FPC-23 | 原生视频读取须保留源帧PTS/时长、原始时间基；登记SHA、工具与实现字节在交付末帧前重新核验；前缀不能称整源已解码 | 4帧RGB VFR、2帧YUV VFR及20帧实际媒体通过；未自动旋转或CFR重建 |
| FPC-24 | YCbCr需显式矩阵、full/limited和六种色度位置；直接以浮点解算RGB，alpha独立全范围，色度边界复制且双线性；保留超黑/超白 | BT.709、BT.601系及BT.2020 NCL，planar420/422/444、NV12/NV21、P010/12/16数值专项通过 |
| FPC-25 | YCbCr转RGB不等于传递函数/色域转换；源与宿主仍须明确共同工作空间；逐行采样须由调用方声明，不能把未探测字段当成已验收 | 当前仅源RGB数值，scan为调用方声明，隔行、BT.2020 CL、PQ/HLG及显示参考仍待适配 |
| FPC-26 | “无损codec”原片必须逐码验证；仅强制输出色彩标签可能先触发自动YUV→RGB→YUV | 实际失败r7与两轮探针保留；完整输入标签对照65536级及全原码相同 |
| FPC-27 | 读管道4×64KiB stdout、2×64KiB stderr，取消轮询、超时和所属进程/线程清理；单帧工作区预算不代表整体峰值RSS | 实际取消、提前退出和完整读取验证；未验收长片、4K60或进程RSS |
| FPC-28 | 原生读取→仿射→合成→16位无损输出须真实生成样例，再验证浏览MP4/GIF；这仍不能替代编辑器时间线/安装/完整门禁 | 20帧真实媒体、26检查及实际抽帧目检通过；仍未接入编辑器 |

算法参考：[W3C Compositing and Blending Level 1，2024-03-21 固定版本](https://www.w3.org/TR/2024/CRD-compositing-1-20240321/)。FFmpeg 行为以本机 8.1 可执行文件 SHA、实际 stderr 与逐像素输出为准，不推广到所有版本。

当前结果、原输入、原输出和失败见[独立实测](../validation/浮点表面合成与高精度边界独立实测_2026-10-22.md)。这里只约束下一步实现边界，不将未执行内容记作通过。

YCbCr来源：[ITU-R BT.709-6](https://www.itu.int/dms_pubrec/itu-r/rec/bt/r-rec-bt.709-6-201506-i!!pdf-e.pdf)、[BT.601-7](https://www.itu.int/dms_pubrec/itu-r/rec/bt/r-rec-bt.601-7-201103-i!!pdf-e.pdf)、[BT.2087的BT.2020 NCL系数](https://www.itu.int/dms_pubrec/itu-r/rec/bt/R-REC-BT.2087-0-201510-I!!PDF-E.pdf)；位置枚举见[FFmpeg pixfmt.h](https://ffmpeg.org/doxygen/7.1/pixfmt_8h.html)。色度边界/双线性是本适配器声明的重建策略，不代表所有codec或隔行格式的规范重建器。
