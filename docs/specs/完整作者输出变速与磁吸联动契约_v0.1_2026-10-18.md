# 完整作者输出变速与磁吸联动契约

2026-10-18，V57，先于实现与实测声明。目标为 Agent 可执行的完整画面、字幕和声音同步变速；继续使用原生 Windows/Python/FFmpeg，无在线处理、容器或虚拟环境。完整剪映功能和效果仍是总目标，本轮不缩小总目标。

| 编号 | 约束 |
|---|---|
| RT01 | `timeline edit` 新增 `action: retime`，接受非空、无重复 `clip_ids`、`transform`、`options`、`sync_content`。compose 的 `retime_clip` 接受相同编辑请求并加入原子批次。它相对当前可见完整输出变速；既有 set_clip_speed/set_clip_speed_curve/freeze_frame 仍修改原作者参数，不把两种时钟含义混淆。 |
| RT02 | transform 包含 speed、speed_curve、reverse、freeze 中至少一项。speed 为不低于 0.01 的有限正数；reverse 为严格布尔值。speed_curve 使用原有源域 hold/linear/easing/Bezier 及 1024 段有界编译器，源域为本次选中片段的旧可见长度；低于原生 0.01 下界拒绝，不静默抬升。freeze 在变速/反向之后，at_tick 是新内容输出时钟，duration_tick 正整数，audio_mode 为 silence/continue。 |
| RT03 | 单次可选择多个主轨片段；linked=true 时扩展同组主轨。按从后向前处理各宿主，避免先修改较早位置使请求时钟漂移。主轨时长变化后自动闭隙/推后全部后续主片段；普通非磁吸主轨同样作显式波纹操作。副轨独立选择允许变速，但不能与主轨混合选择；副轨不隐式波纹主轨。 |
| RT04 | 每个宿主先完成原可见作者图，包括原输出窗、速度曲线、倒放、定格、动画、字幕、片段声音及完整嵌套总线，然后才接受本次 transform。持久化为普通可编辑子序列及父容器；不烘焙中间媒体，不更换原素材/字体/模型/权利依赖，不伪造内存资产 URI。原外层片段 ID 保留，子层 ID 全项目避碰。 |
| RT05 | 原片段的 blend 是与外部底图交互的边界，不能烘入透明子画布。静态字段保留在外部容器；原空间变换/蒙版/字幕/其它动画属于被变速的完整原内容。V57 的动态混合包装拒绝是历史边界；V74 通过[独立混合作者时钟](外部混合动画与完整输出变速契约_v0.1_2026-10-20.md)补充支持，保留原曲线与有界相对映射，alpha 只乘一次。连续参数和隔离祖先已栅格化帧序的区别仍按新契约限定。 |
| RT06 | 与宿主显式关联、且与宿主区间相交的副片段同步接受同一个完整输出 transform；linkage=true 时完全位于宿主内的 rider 同样处理。部分覆盖的关联素材按宿主原时钟分成 before/body/after，body 使用完整宿主变速图后的输出窗；不能把部分素材自身长度重新归一化为另一条速度曲线。原成员区间不丢失、不重叠；反向会同时反转 body 的位置和内容。 |
| RT07 | sync_content 缺省 ripple：其它同步轨道保留自身播放速度，按主轨增长在旧尾插入空档，按缩短在新尾到旧尾删除同段内容，后续同步轨道随动；不把背景音乐默认拉成另一速度。显式 retime 时，未锁定且 sync_lock=true 的相交同步副片段也按 RT06 变速。sync=false 或 sync_lock=false 保留原位，显式关联和 rider 规则另计。 |
| RT08 | 变速曲线片段位置使用与生产渲染器相同的有界源积分，反向使用反射时钟，最终落点量化到整数 tick；相邻分段共享同一边界。定格会扩展包含保持帧的片段覆盖区；silence 和 continue 的音频行为保留现有定格契约。零 tick 结果明确拒绝；显示帧量化与声音算法近似继续报告。 |
| RT09 | 受影响锁定成员原子拒绝；跟踪源/目标、直接真实源转场端点和旧跨片段转场需先解除或对完整上级组变速，不静默丢引用。碰撞使用现有等效轨道规则，禁止为解决碰撞拆分非线性音频总线或命名检测器。原根轨道效果与命名路由留在各根轨道，位于片段变速之后。 |
| RT10 | 原序列标记、命名总线自动化及独立同步 opt-out 轨道维持绝对时钟；序列缩短后越界作者点仍拒绝，不能裁掉点来使校验变绿。原序列显式空白尾长度随主轨净变化保留，实际副轨更长时按最大结束时钟保留。 |
| RT11 | 请求严格拒绝未知字段及 bool/float 冒充整数 tick。规划不解码、不调用模型；输入及预计输出片段预算为 20,000，新建子序列/输出窗沿用实际渲染图深度/工作栅格/64 直接实例配额，不降低画质或悄悄跳过素材。 |
| RT12 | dry-run、基准摘要、快照、幂等、整批 compose、撤销、工程包、片段组及离线发行继续适用。计划必须包含每个宿主的旧新长度、后续位移、原区间/输出区间、变速成员、原 ID 到子序列/子片段映射、新轨道及拒绝/近似边界。 |
| RT13 | 必须实测主轨恒速/曲线/反向/定格、多宿主、不同长度和局部覆盖的关联声音/字幕、连续 BGM 的 ripple/retime 两策略、嵌套效果完整作者图、原输出窗、幂等/摘要/事务失败、工程包及原生安装后复现。原输入、真实 MP4/GIF、逐帧身份和采样证据公开，保留失败。 |
| RT14 | 独立原帧/原 PCM 时钟与同版完整作者图参照分别记录；同版 DSP 参照只证明变速接线和时钟，不证明自然听感。视频、透明度、字幕、音频长度、有限性、实际编码 PTS、静帧、连续播放、听审、自然质量、长片/HDR及完整剪映等价分别验收。 |

2026-10-19 实测修正：完整内存音频总线不在 hold 曲线跳点拆成不同作者窗口；嵌套音频积分保留每层曲线跳点，并合并相邻等速区间，使原生 tempo 上下文覆盖完整宿主。连续曲线仍使用有界分段近似，不声明连续相位或自然听感。原生总线路径使用既有实际变速尾部对齐规则；普通恒速文件路径的头部截取不能直接作为相同 PCM 参考。两者真实差异、原失败与独立尾部选样见[实测](../validation/完整作者输出变速与磁吸联动实测_2026-10-19.md)。
