本契约描述独立实验目录中的实现，尚未合入 main。基于持久帧索引实验的 254 项产品输入，新增一个独立时钟测试文件；当前产品输入共 255 项。V82、帧索引实验及 main 的产品字节不因本实验改变。

| 编号 | 约束 | 范围与边界 |
|---|---|---|
| NC-01 | 原生源显示区间 | 对含 `_nested_time_maps` 的已登记本地视频叶片，保留解码帧原始 PTS 与 duration；不先按登记平均帧率做 CFR 归一化。 |
| NC-02 | 作者时间映射 | 将原生源时刻输入现有解析嵌套时间映射，最后按全局输出 CFR 网格采样；沿用作者起点、显式 duration 及原有曲线积分语义。 |
| NC-03 | 小数源边界 | 选取覆盖请求源入点的帧；源出点为半开区间。正放在原生起始帧和真实 EOF 处使用显式时钟事件，内部原生 PTS 不变。 |
| NC-04 | 倒放区间 | 以原生显示区间的末端为倒放边界，保留各区间时长；再还原为原源时刻进入嵌套映射。父子倒放按方向组合处理。 |
| NC-05 | 真实 EOF | 不把音轨尾部当作视频帧，不补造结束后的静帧；实际 EOF 与作者裁切共同限制可见区间。 |
| NC-06 | 封装时钟 | 从 ffprobe 已登记 time_base 及 format start_time 归一化源原点；登记与实际时间基不同、未知末帧 duration 等输入明确拒绝。 |
| NC-07 | 共享派生数据 | 复用帧索引上下文与原生无损分块倒放助手；继续遵守缓存字节绑定、取消、发布前重验、内存估算与磁盘预约限制。 |
| NC-08 | 资源边界 | 保留原实现的 100 万帧、表达式大小、分块数量、共享缓冲预算和磁盘上限；并未验收长片吞吐、总 RSS 或并发资源预算。 |
| NC-09 | 合成表面边界 | 转场、路由等触发的中间合成表面沿用其既有子级 CFR 契约。原生视频叶片的区间修复不等同于任意嵌套合成的 VFR 完整验收。 |
| NC-10 | 效果验收 | 只对记录中的原创几何素材、逐帧参考和现有邻近回归作限定结论；自然视频、HDR、音频质量、所有曲线/效果组合及剪映等价另行验收。 |
