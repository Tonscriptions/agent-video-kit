# OpenFilm 当前复用决策

结论：**适合拆模块，继续使用现有 Agent Project + Python/FFmpeg 主链。** 最有价值的分句、关联规则、片段组、帧时钟和 HTML 参数规则已有受控接入；再次搬一套相同主链不会降低成本。新的投入优先放在缺少的创作流程、互操作和明确的质量边界。
