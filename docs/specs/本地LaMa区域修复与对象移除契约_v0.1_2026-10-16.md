# 本地 LaMa 区域修复与对象移除契约

| 项目 | 内容 |
|---|---|
| 文档编号 | SPEC-LAMA-INPAINTING-001 |
| 状态 | 有效 |
| 日期 | 2026-10-16，Asia/Taipei |
| 范围 | 原生 Windows、本地 TorchScript、CPU/CUDA、视频区域修复与对象移除 |

## 1. 目标与边界

推进差异 #56 的对象移除、局部修复，并复用 #55/#94 的 SAM2 分割结果。输入原视频与本地蒙版资产，使用 LaMa 对选定区域补全，保留蒙版外 RGB 和原始 alpha；输出无损 MOV、音频及可应用时间线的派生资产。

本引擎逐帧执行图像修复，不能将它描述成跨帧联合视频修复、真实背景恢复、提示词生成填充或完整剪映等价。时序一致性、遮挡、复杂纹理和商业广告质量须另行取得证据；完整目标不缩减为本轮功能。

## 2. 登记与命令

视觉 engine `torchscript-lama-local-v1`，协议 `agent-video-lama-inpainting-v1`。登记要求已有本地 LaMa TorchScript `.pt`、原生 Python `.exe`、本地证据与 `--device cpu|cuda`（默认 cpu）。固定 FP32；Torch/numpy/Pillow 必须已安装。模型、Python、证据和执行实现进入摘要清单，不调用下载器、HTTP 服务、IOPaint GUI 或容器。

`media inpaint --project <项目> --asset-id <源视频> --mask-asset-id <蒙版图像或视频> --adapter-id <LaMa> --derived-asset-id <新ID>` 默认读取蒙版 alpha，适配 SAM2 QTRLE/ARGB 输出；`--mask-channel luma` 读取黑白蒙版亮度。阈值默认 0.5，白/高 alpha 为修复区域；`--mask-grow` 扩大区域，`--mask-feather` 在区域内部柔化混合。空蒙版帧原样通过。

源范围、帧率、画幅、帧数、音频、超时和取消复用 RGBA 管道。蒙版帧从其显示起点加 `--mask-start-seconds`（默认 0）取样，必须覆盖本次输出时长；静态图明确循环。源与蒙版都执行显示方向/SAR/CFR 归一化。默认拒绝几何不匹配，显式 `--mask-resize nearest` 才允许相同比例缩放；不猜测裁切、变速、透视或绑定关系。执行前核对 dry-run 时钟。

每帧只对蒙版包围框及 `--context-pixels` 上下文推理，最大模型长边由 `--model-max-edge` 限制；模型输入补齐到 8 的倍数。超大区域会显式缩放并报告，输出画幅不因此改变。保留源 alpha，最终只在扩大的修复区域混合，区域外 RGB 必须逐字节一致。

## 3. 执行与完整性

FFmpeg 将源 RGBA 与归一化蒙版 RGBA 横向堆叠后流式传入隔离 worker，布局为每行 source RGBA + mask RGBA，不缓存整段视频。worker 核验源/蒙版/模型/请求摘要、设备与参数，输出逐帧 RGBA、修复/空蒙版计数、实际模型区域预算、区域外不变和 alpha 摘要。输出完整解码后的 RGBA 必须与 worker 摘要一致。

父进程使用 Windows Job 管理解码、推理和编码进程，取消/超时停止全部子进程；输出拒绝覆盖，失败清理媒体并由项目事务恢复元数据。源视频、蒙版及其依赖、LaMa 模型共同约束发布；模型代码许可证不自动授权权重或素材。

## 4. 验收

必须有提示蒙版和静态/动态蒙版、alpha/luma、阈值/扩大/羽化、空帧、几何/时钟/路径/哈希拒绝、真实 FFmpeg、权利依赖、幂等/快照/项目包、失败回滚与进程清理测试。真实模型须验证 CPU/CUDA、受控真值及 SAM2→修复→成片，目视和时序缺口单列，不能用 mock 或无损编码摘要证明画质等价。

## 5. 参数、蒙版和资源语义

| 参数 | 默认与范围 | 语义 |
|---|---|---|
| `--mask-channel` | `alpha`；可选 `luma` | alpha 字节或 RGB 的 Rec.709 亮度加权；值大于 `255 × threshold` 才选中 |
| `--mask-threshold` | 0.5；0..1 | 严格大于；1 会形成空选区，不把黑色背景当作修复区域 |
| `--mask-grow` | 4；整数 0..64 | 在输出像素空间用边长 `2×grow+1` 的方形最大值扩大区域 |
| `--mask-feather` | 0；0..32 像素 | 高斯模糊只在扩大后的区域内部参与混合；外部 RGB 保持原值 |
| `--context-pixels` | 64；整数 0..1024 | 扩大的蒙版包围框四周增加上下文，裁到输出画幅 |
| `--model-max-edge` | 1024；整数 64..2048 | 只缩小模型 ROI；RGB 双线性、蒙版最近邻，随后向右/下按边缘补齐到 8 倍数且每边至少 64；补齐后最长边最多向上取整 7 像素 |
| `--mask-start-seconds` | 0；非负有限数 | 视频蒙版自己的显示起点偏移，不自动加源视频的 `--start-seconds`；静态图只能为 0 |
| `--mask-resize` | `reject`；可选 `nearest` | 默认显示尺寸相同；显式缩放要求宽高比误差不超过 2%，用于像素舍入，不支持推断裁切/透视 |
| `--max-frames` | 18000 | 复用共享 RGBA 管道的显式帧数预算；不把长视频整体存入内存 |

蒙版先按显示方向/SAR 归一化，再缩放和按输出 CFR 取样。视频蒙版必须覆盖取样起点加实际输出时长，不对缺失区间填充尾帧；FFmpeg 实际解码帧数不足会使管道失败。静态蒙版明确循环。源尾部不足一帧的延长仍遵守共享管道的 CFR 报告。

每帧先判断空蒙版，再在限定 ROI 上运行 LaMa。下采样使非空蒙版完全消失时明确拒绝，要求增大模型长边或减少上下文；不交付一次没有选区的模型调用。报告包含实际 ROI、缩放帧数、模型调用/空帧数、修复像素和裁剪到 0..1 的模型值数量。ROI 样本最多保留前 16 帧。

512 MiB 是已拥有帧数组及模型输入/输出数组的保守预算，**不包含权重、Torch 临时张量、进程总 RAM/VRAM**；CUDA 另记实际峰值分配。没有跨帧状态、设备回退或跨设备字节一致承诺。源须为 SDR；HDR 必须先显式 tone map。蒙版外保持的是归一化源画面的 RGBA，编码/缩放前后的原始文件字节没有相等承诺。

## 6. 应用、权利、恢复与输出

正式执行使用 `before-media-inpaint` 快照，输出项目内尚不存在的 `.mov`；视频应用要求 `--apply --track-id`，原声应用另需 `--audio-track-id`。不指定 audio 轨道时原声只保留在派生 MOV 内。目标范围已有片段时拒绝，只有显式 `--replace-track` 才清空指定轨道。范围、帧率、超时、取消、幂等和项目写锁沿用共享管道。

JSON envelope 的命令为 `media.inpaint`，报告结果位于 `data.inpainting`，同时保留资产、源/蒙版 ID、生成的视频/音频片段、快照和项目校验。派生资产依赖源和蒙版资产；Rights Ledger 同时依赖源、蒙版及 LaMa 模型；SAM2 蒙版继续传递它自己的源和模型权利闭包。登记 `models/visual-adapters.json` 可随快照/项目包携带，但外部权重和 Python 不随包分发。

共享管道错误保留 `MATTING_*`，LaMa 模型/蒙版专属检查使用 `INPAINT_*`；agent 应同时读取错误 `cause` 和失败报告。Python socket/DNS/HTTP 审计 guard 在 Torch 导入前安装，但它不是系统防火墙。运行期不安装包、不下载媒体或模型、不启动 IOPaint、HTTP、剪映、Docker/WSL。

实测、像素检查和未通过的自然场景质量项见[验证记录](../validation/LaMa本地区域修复与物体移除实测_2026-10-16.md)。

## 7. 显式区域色差融合与惰性加载

默认 `--repair-blend direct` 保留原始模型输出/ROI 缩放和合成语义；显式 `harmonic` 保留模型浮点 RGB 缩回 ROI，随后执行[共享调和颜色修正](./本地修复区域色差融合契约_v0.1_2026-10-16.md)，再进入原有选区/羽化和一次量化。可选求解步数与容差进入请求摘要、幂等和完整性绑定；非收敛、超预算、全画布无边界选区及畸形报告失败，不能回退 direct 后继续发布。

LaMa 权重改为首次有效推理时加载；空选区与无效选区预算先检查。全空管道仍导入原生 Torch/检查 CUDA 和权重摘要，但不加载 TorchScript 权重。已拥有帧/ROI 浮点数组与求解数组合并计入 512 MiB，模型/Torch/总进程和显存另计；报告增加 `base_state_peak_bytes` 与 `blend`。本轮 adapter 绑定 10 项文件（新增共享融合内核），旧摘要须重新登记，不能手改绕过。实测与质量边界见[本轮记录](../validation/本地区域色差融合实测_2026-10-16.md)。
