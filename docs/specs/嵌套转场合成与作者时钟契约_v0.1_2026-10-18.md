本轮扩展真实源句柄转场在嵌套中的执行：在子序列原作者时钟上完成转场与画面合成，再将完整透明画面送入父级裁切、倒放、恒速/非线性速度曲线及投影。音频保持原始源叶片和原总线，不把有声中间成片当作新的音频源。整个渲染使用一个 FFmpeg 图，不生成/注册中间视频资产。

这补齐 V35 对“含转场的子序列被父级引用”的拒绝。转场两端本身仍要求直接本地视频；本轮不接受两个容器之间直接建立源句柄转场，也不放宽转场叶片的速度曲线、定格、跟踪绑定、blend 等既有限制。完整剪映等价仍需其余需求逐项验证。

## 1. 作者工程及 CLI

工程 Schema 不新增公开字段。声明仍在 `sequence.source_transitions`，`timeline transition --sequence-id <child>` 提供 add/resize/remove；父级按既有 `sequence_id` 引用子序列。dry-run、可选原始工程 SHA、幂等、项目写锁、快照和元数据事务沿用既有实现。

```json
{
  "action": "add",
  "id": "tr_ab",
  "from_clip_id": "video_a_clip",
  "to_clip_id": "video_b_clip",
  "type": "dissolve",
  "duration_tick": 90000,
  "audio": "linked"
}
```

```powershell
ai-ad-editor timeline transition --project <工程> --sequence-id child --input <请求.json> --dry-run
ai-ad-editor timeline transition --project <工程> --sequence-id child --input <请求.json> --expected-project-sha256 <计划摘要>
ai-ad-editor render --project <工程> --dry-run
ai-ad-editor render --project <工程> --output <工程内成片>
```

后续主工程渲染自动包含子级转场；`render --sequence-id child` 仍导出该序列自身的画布/时长。添加、调整或移除子级转场不得改变父级引用、原作者片段范围、剪口和序列总长。正式 render 仍会按原机制写入时间戳/渲染记录，不承诺 project.json 的整文件字节不变。

## 2. 视频与空间处理顺序

| 编号 | 顺序/不变量 | 含义 |
|---|---|---|
| N01 | 子序列真实源句柄与作者动画 | 子级直接片段先按原声明编译，不把父级取窗重新当作新的转场开始 |
| N02 | 子级原生画布透明合成 | 维持子级层级、效果、字幕与 Alpha；投影前不铺成不透明黑底 |
| N03 | 父级取源窗口和时间映射 | 支持窗口在转场中途开始；恒速、倒放、速度曲线作用于已合成画面，而非仅移动转场端点 |
| N04 | 父级空间和动画 | 采用既有容器 crop/fit/锚点、变换、透明度、效果、蒙版与 fade 顺序；父动画仍按父作者时钟 |
| N05 | 多级祖先与重复引用 | 每层时间/画布继续组合；同一子级可独立取窗和多次使用；滤镜输出先 split，不把一个输出 pad 多次消费 |
| N06 | 普通子序列兼容 | 无转场后代的分支保留原展开路径；本轮控制样例与固定 V35 比较原始 RGB/PCM |

只在需要时创建渲染副本中的 `_inline_video_asset_id` 和合成资产，最终不会写进作者工程、素材台账或便携包。它们没有外部 URI，不能成为需要下载或登记版权的新媒体文件。FFmpeg pad 重命名只处理真正的标签，保留单引号内文本与转义括号。内部序列 ID 避让作者 ID，避免合法祖先名如 `child__surface` 被误报循环。

子级关闭选中根专有的项目全局 adjustments，避免在子、父重复套用；原子级各轨/片段效果照常执行。当前项目共享 FPS/色域/SAR，内部仍是编码 RGB/8-bit 合成，不扩展为线性光/HDR 或独立子 FPS 的验收。

恒速同样使用精确组合时钟与高精度 PTS，避免直接除以源 `1/fps` 粗时基，使二倍速相邻两帧时间戳相撞、固定提前一个源帧。验收源帧必须有足够可区分的帧码；不能让相邻灰阶变化小于像素舍入容差而掩盖相位错误。

## 3. 音频与时钟

子级音频不经过视频表面：原源文件裁切、伸缩、声像、片段/轨道处理、旁白闪避、序列求和和父容器总线仍由现有音频树执行。已有本地 R3 注册继续接收原始、摘要校验的源路径，不会读取合成资产的虚构路径。

真实源句柄的淡入/淡出与交叉包络使用**原子序列连续作者时间**。父级倒放时，第一份反向源采样取自半开源选区右侧的最后一个样本；包络在该输出样本的连续显示时刻求值。因此该模式不承诺与“先把整段子级 PCM 混好，再整文件按采样倒序”逐样本相同；两种包络求值相差一个采样时刻的情况须分别表述。

分段 concat 输出为微秒时基，areverse 后其时间戳未必描述连续采样位置。进入包络/音量自动化前使用 `asetpts=N/SR/TB` 重建局部采样时钟，避免表达式 `t` 随片段复位或变成错误尺度。再按父级映射反求子作者时间；作者 clip 的动画/淡入淡出仍扣除原作者起点，源 head 延伸不造成二次移位。

atempo 的分段/上下文近似、R3 局部时序、相位、瞬态、极短窗音高和听感限制继续保留。采样数/有限性、受控 DC 或独立混音通过不能代替自然声音的质量验收。

## 4. 元数据、警告与预算

| 节点/字段 | 记录内容 |
|---|---|
| `sequence-inline-surface` | 子序列 ID、内部 asset ID、原生画布、实际输入偏移/数量、子图 metadata 与 warnings、处理顺序和中间文件数 |
| `video_clock` | `child-authored-composite-before-ancestor-time-map` |
| `audio_path` | `original-source-leaves-and-authored-buses` |
| 视频输入 `inline_sequence_id` | 区分真正的源文件和内联子级画面；其物理输入号为 null |
| 根 warnings 的 `inline_sequence_path` | 子图警告向顶层传播，逐层保留路径；Agent 不必只钻入内部 manifest 才能发现近似 |
| `sequence-inline-budget` | 所有已构建子表面的估计工作量、递归子投影和根投影的合计、显式配额及 `intermediate_files=0` |

预算复用 `settings.sequence_sampling.max_working_bytes` / `--sequence-memory-mib`。每份原生表面计 `width * height * 16` 工作字节，另加各层既有投影估计；重复引用共用一份子表面图，父投影各自计算，非同时段的父实例也保守计入。超额返回 `SEQUENCE_INLINE_BUDGET_EXCEEDED`，在正式 FFmpeg 作业前拒绝。原单层投影先超额时仍返回其原错误。

这属于表面/投影的**准入估算**，不计算完整解码/编码缓存、时序滤镜缓冲、线程、并发作业、浏览器或进程 RSS；不可将该数作为峰值内存上限证明。切勿仅为让验证通过而静默提高配额。

## 5. 仍拒绝或未验收的情况

| 范围 | 当前处理 |
|---|---|
| 转场两端是嵌套容器 | 保留 `SOURCE_TRANSITION_CLIP_UNSUPPORTED` |
| 转场直接叶片的曲线/定格/跟踪/blend 或旧转场字段 | 保留既有显式错误；本轮仅允许祖先恒速/倒放/曲线作用于完整子画面 |
| 含转场分支的任一祖先 freeze | V36 首版以 `SOURCE_TRANSITION_SCOPE_UNSUPPORTED` 拒绝；V51 当前允许在完整子画面/子总线上暂停，见 [复合定格契约](复合片段定格与完整音画时钟契约_v0.1_2026-10-18.md)。转场直接端点本身的 freeze/curve/container 限制仍保留 |
| 循环或不存在的子引用 | 保留 `SEQUENCE_CYCLE` / `SEQUENCE_REFERENCE_MISSING` |
| 子级近似/字体/字幕/effect 警告 | 继续在顶层输出并附路径，不因内联隐藏 |
| 自然广告、方向转场窗内独立美术参考 | 受控组合取帧通过与独立方向算法验收分计 |
| VFR/HDR/独立 FPS、长片 RSS/吞吐 | 未验收 |
| 闭源服务、剪映应用、浏览器、Docker/WSL | 不使用，不新增运行依赖 |

本契约须与本轮原片/GIF、失败记录、完整冻结回归及发行证据共同评估，不能单靠图结构或窄测试宣布完整剪映等价。
