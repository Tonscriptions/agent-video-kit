## 1. README 的固定维护规则

根目录 [README](../../README.md) 的 V01–V30 记录实际执行的功能、结果、证据与边界。后续每次功能新增、核验或真实样例实测必须同步维护相关行，新增功能则追加稳定编号。实际功能执行、历史回归、模型实测与研究检查分别标注日期和范围；失败与未通过质量项保留。

可视结果优先提交可公开的原输入和短 MP4/GIF。音频功能同时提供可听音频或有音频的视频，注明机器检查与听审状态。素材、输出、播放时钟、生成器、版本和 SHA-256 要可追溯；研究动画必须标注未集成边界。相关规则已写入 [AGENTS](../../AGENTS.md)、[文档中心](../README.md)及 [P0 fixture 规则](fixtures/p0/README.md)。
