## 1. 本轮实现

[camera_motion.py](../../research/temporal-background/camera_motion.py) 从已观测背景提取角点、双向 LK 跟踪及 RANSAC 相似变换，拒绝弱空间支持和超出运动范围的拟合。选区/排除区/非不透明 RGB 在跟踪前抹除；固定几何只是刚性背景候选，不能当作被遮挡运动的真值。

[reference_core.py](../../research/temporal-background/reference_core.py) 同时传播相机模型和前序 DIS 补全模型。每个供体的两条映射在共同可见背景上比较 65×65 邻域 RGB 误差；共同支持不足时，不把两组不相交观测强行排序。单路径须有至少 64 个上下文观测、平均误差不超过 12，双线性足迹和路径全部有效。一个供体帧最多进入一次参考池，再要求至少 3 个不同帧颜色一致；平移样例显式要求 2 帧。成本同时考虑观测误差、时间距离和颜色偏差，小分量拒绝，只在选区内羽化。

这些是拒绝启发式，不证明隐藏几何正确。上下文可能横跨不同表面，重复纹理、光照、视差、长期遮挡仍可能误导；参考逐像素选择也没有变成全局时序优化。贡献掩码表示可用率，非恢复正确率。

## 2. 检查与代码完整性

[研究检查](../../research/temporal-background/test_reference_core.py)新增 12 项，与前序 10 项合并实际执行 **22/22**。覆盖独立含外点相似变换、退化几何、已观测纹理真值、双表面选择、共同可见支持、禁止双线性角点、不同供体帧计数、无观测/透明供体、切镜、选区 RGB 扰动不变、预算/参数前置及取消。两组变异分别放宽足迹阈值和把一个供体重复入池，针对性断言均按预期失败，非产品回归失败。

7 份研究 Python 在最终执行前后摘要一致，包含原有 3 份未改动源码及新增 4 份。生产/测试/烟测 **89 份 Python 与已通过 363/363 的产品版本相同**；本轮没有重跑完整产品回归，也不把研究 22 项加成产品 385 项。4 个输入、4 个 NPZ 和 5 张联系表逐项摘要核验；独立从 NPZ 重算全部 MSE/PSNR，并全帧比较蒙版外 RGBA/全部 alpha。见[机器证据](./evidence/temporal-reference-selection-20261016.json)及[最近产品验证](./evidence/repair-blend-smoke-20261016.json)。

## 3. 受控真值对照

所有 PSNR 单位为 dB，仅在同一选区内评分。真实画面使用前序同一 32 帧源、前景排除、人工遮挡和 Telea 半径 5；对照 NPZ 的源/真值/蒙版/fallback 全部逐数组相同。两组合成输入先生成真值再覆盖前景，评分真值不进入修复器。平移 seed 42；新增双表面 seed 615，上表面每帧平移 2 px，下表面反向平移并发生正弦形变。

| 样例 | fallback | 前序 DIS 参考 | 本轮双模型参考 | 本轮贡献/选区像素 |
|---|---|---|---|---|
| 独立平移纹理 | 20.800 | 30.878 | 31.124 | 9,072/9,072 |
| 双表面：刚性 | 23.077 | 34.782 | 34.829 | 9,590/9,600 |
| 双表面：形变 | 23.363 | 32.392 | 32.303 | 9,182/9,216 |
| 双表面合计 | 23.215 | 33.448 | 33.410 | 18,772/18,816 |
| 真实画面人工遮挡：墙面 | 25.613 | 30.109 | 32.459 | 70,657/70,720 |
| 同源人工遮挡：床单 | 23.448 | 24.803 | 25.357 | 27,462/29,256 |
| 墙面＋床单合计 | 24.861 | 27.804 | 29.017 | 98,119/99,976 |

真实墙面和床单较前序改善，但新增双表面合计由 33.448 降至 33.410 dB，形变表面也略退化，**不能宣称全面优于前序方法或直接替换默认内核**。同一真实源的墙面/床单不算两个独立广告场景，人工色块真值不是自然人物移除真值。

独立时序诊断另按已知合成表面运动重采样相邻帧的重建误差；真实画面只算同画布相邻误差变化。两者详见机器证据，不是自然闪烁或持续播放验收。

## 4. 自然镜头仍未通过

沿用 32 帧 512×288@8、目标 grow 4、双人供体排除 grow 8、已有 LaMa harmonic fallback，不新增任何学习模型运行。151,301 个选区像素中 60,256 个有供体贡献，约 39.8252%；前序为 34.7618%。覆盖增加不能证明额外像素正确。

抽看 13 帧：部分墙纸和床面出现更清楚的观测纹理，但腿状残留、床单涂抹、局部接缝仍在；部分残留位于选区之外，按保留契约没有修改。**自然人物移除画质未通过，研究不接入生产**。没有自然背景真值，不报告自然 PSNR；没有连续播放、长窗口、跨设备或广泛广告验收。

## 5. 资源、运行与复现

| 项目 | 实测与边界 |
|---|---|
| 原生环境 | 既有 Windows Python/OpenCV 5.0.0/NumPy 2.4.6/FFmpeg，CPU 4 线程 |
| 运行耗时 | 本轮完整诊断 183.785 秒，含 22 检查、两组前序合成对照及四组新方法任务；不是 P50/P95 |
| 自有数组预算 | WH×(192N+1536)，32×512×288 为 1080 MiB；默认预算 1536 MiB，最大 2048 MiB；不含输入、OpenCV 内部、总进程 RAM |
| 进程观测 | Python 峰值工作集 830.277 MiB、Windows PeakPagefileUsage 1197.055 MiB；后者为进程提交内存指标，不是实际磁盘交换量；均不含测试/FFmpeg 子进程 |
| 本地策略 | 主进程及研究测试在原生库导入前安装 Python 网络 guard，阻断事件 0；无安装、模型下载、新模型运行、Docker/WSL 或浏览器；guard 不等于系统防火墙 |
| 交付范围 | NPZ/抽帧/JSON 诊断；未做本轮编码、音频、媒体入轨、项目恢复、Rights Ledger 或正式 CLI 接入 |

输入清单与前序四字段相同：`source`、`target_mask`、`exclusion_mask`、`fallback`，均是已有本地视频。源/蒙版/fallback 帧数、尺寸、帧率必须一致；研究最多 65 帧、每帧 1,048,576 像素，预算不足提前拒绝。真实 holdout profile 限 512×288，不是任意画幅的通用产品命令。

```powershell
& '<已有原生Python.exe>' -I -B -X utf8 research/temporal-background/run_reference_probe.py `
  --input-manifest '<四字段本地清单.json>' `
  --output-root '<尚不存在的本地目录>' `
  --array-budget-mib 1536
```

可重复 `--scene-cut-frame N` 表示输出零基帧 N 之前切镜。可选 `--compare-evidence` 指向前序本地 JSON；其绑定的旧 NPZ 必须仍存在且哈希匹配，四输入/切点配置必须相同，比较前逐数组核对源、真值、选区和 fallback。脚本[入口](../../research/temporal-background/run_reference_probe.py)不安装依赖或下载模型；外部 Python 须已有 NumPy/OpenCV/Pillow。

## 6. 后续门槛与来源

本轮证据支持继续使用候选运动模型和可见背景评分，尚不足以正式替换修复内核。下一步先补选区完整性与遮挡边界、空间/时间一致的参考选择及跨场景验证，再做有界长窗口、产品登记/权利/音频/成片接入；保留 #56 degraded 和全部剪映功能/效果、内容库、许可、性能及发行要求。
