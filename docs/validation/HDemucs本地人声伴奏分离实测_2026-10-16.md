## 1. 输入、模型与复现

本次输入为本地 12.68 秒中文语音，叠加确定性、等 RMS 的和弦/低音/打击乐合成伴奏。采样率为 44,100 Hz，双声道，共 559,188 个采样点。合成随机种子 771，原始语音和混音哈希保存在[机器证据](./evidence/hdemucs-smoke-20261016.json)。此夹具可计算已知人声参考指标，但不等同自然歌曲或真实广告混音素材集。

验证权重为官方 TorchAudio HDEMUCS_HIGH_MUSDB checkpoint，文件 334,697,255 bytes，SHA-256 为 `85ce4420e0852344b816487b4c4bb821bd406376b93bf684b2b76aa56404c46a`。开发验证期间曾显式从官方来源获取该文件并保存来源/摘要证据；这不属于产品运行时下载。CLI 和 smoke 脚本均只接受现有本地路径，权重、Python、缓存和媒体未提交版本库。权重和源语音许可仍为 unverified。

运行环境为原生 Windows，本地模型 Python 3.13.14、numpy 2.4.6、Torch 2.13.0+cu130、TorchAudio 2.11.0+cu130。CUDA 为本机 RTX 3060。精确模块路径、设备和版本见机器记录；本记录不保证其他 Torch/TorchAudio 组合兼容。

从仓库根目录执行以下脚本，所有参数须指向已存在的本地输入，输出目录须为新目录：

```powershell
python -B -X utf8 scripts/smoke_audio_separation.py `
  --source E:\fixtures\speech.wav `
  --model E:\models\hdemucs_high_musdbhq_only.pt `
  --python E:\python\python.exe --evidence E:\models\evidence.json `
  --output-root .\workspace\separation-smoke-new --devices cpu cuda
```

脚本固定 4 秒分段、25% 重叠、4 个 CPU 线程。每个设备各 4 段推理；运行时没有模型下载、云 API、剪映程序、Docker、WSL 或浏览器进程。

## 3. 回归和边界

新增 22 项测试位于 `product/tests/test_local_separation.py`。数学测试使用已知增益回调验证接缝/DC/首尾/反相/静音/非有限值；协议测试使用小型 mock worker，实际执行 FFmpeg 解码与 WAV 编码，验证采样、哈希、model 权利依赖、失败清理、幂等和恢复。这些测试不替代本节真实 checkpoint 推理。既有 extract/mid-side 测试新增了实际 policy.audit 断言。

本次完整回归结果和运行时检查由[本轮机器证据](./evidence/hdemucs-smoke-20261016.json)及[回归总记录](./回归验证记录_2026-10-13.md)给出。接口与预算见[HDemucs 契约](../specs/本地HDemucs人声伴奏分离契约_v0.1_2026-10-16.md)。

未完成项包括人工试听、自然歌曲/广告语料、多人对白与噪声、人声泄漏/音乐残留的广泛评估、长音频吞吐、跨设备资源上限和模型/声源许可复核。当前只提供人声及残差伴奏，不导出独立四源；完整剪映音频对标仍未验收。
