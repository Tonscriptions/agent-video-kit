## 3. 实际本地 Whisper 输入

[实测元数据](evidence/subtitle-segments-asr-20261017.json)记录一次实际 CPU/4 线程 Whisper small 推理，而非复制历史识别结果；录音是已有的 12.68 秒中文参考，与 V15 同语料，不增加独立说话人覆盖。原生 Python 3.13.14、Torch 2.13.0+cu130、Transformers 5.14.1；权重与执行器按已登记 SHA 核对，worker 禁网，未记录网络尝试。

这次识别产生 5 条原句，CER 为 **0.02**（50 个参考字符，1 个繁简字替换）；随后用 8-cell/500-ms 规则生成 9 条显示字幕，未重新识别、未改变识别文字。时间来源均为 `estimated-from-line`，不宣称逐字对齐。模型 worker 112.25 秒包含载入、核验与推理，当时并行回归仍在运行，不能当性能 SLA。

入轨后渲染 101 个新视频帧，原始 ASR 控制也为 101 帧；新旧解码音频均为 609,280 个立体声采样帧，PCM 完全一致。视频为 640×360、8 fps、12.625 秒；源音频 12.68 秒，容器音频约 12.6933 秒。该观察不关闭通用非整帧尾部/音画时钟需求。源录音、模型和字体的公开权利未核验，字幕派生链保留权利依赖，`rights check` 与 publish render 均按预期阻断。音视频留在忽略的本地 `workspace/subtitle-segments-asr-20261017/`，不进入 Git 或公开演示目录。

## 5. 复现

在项目根目录运行原生 Windows 命令。先提供已有、许可清楚的本地 Node ≥22.2、FFmpeg、字体与需要时的 Whisper 模型，不自动下载依赖。示例路径需替换为实际本地目录；所有输出使用新的项目内路径。

```powershell
$env:PYTHONPATH = 'E:\dev\sandbox\AI广告剪辑\product\src'
python -B -X utf8 -m ai_ad_editor subtitle segment --project <项目> --input <本地字幕或ASR报告> --output assets/segments-new.json --dry-run
python -B -X utf8 -m ai_ad_editor subtitle segment --project <项目> --input <本地字幕或ASR报告> --output assets/segments-new.json --apply --track-id <字幕轨> --font-asset-id <本地字体资产>
python -B -X utf8 scripts/compare_openfilm_subtitles.py --source <固定上游树> --output <新的对照目录>
python -B -X utf8 scripts/smoke_subtitle_segments.py --output <新的公开目录> --work <新的工作目录> --font <Kosugi字体> --font-license <其许可文件> --latin-font <DejaVu字体> --latin-license <其许可文件>
python -B -X utf8 scripts/audit_subtitle_segments.py --folder <上述公开目录> --report <新的审计JSON>
```

[公开媒体脚本](../../scripts/smoke_subtitle_segments.py)、[固定上游对照](../../scripts/compare_openfilm_subtitles.py)、[媒体独立审计](../../scripts/audit_subtitle_segments.py)、[实际 ASR 脚本](../../scripts/smoke_subtitle_segments_asr.py)均为可审阅源码。整库回归需额外显式设置已有的 `AI_AD_EDITOR_TEST_RUBBERBAND`，否则音频两组测试按设计跳过。

## 6. 尚未验收

只完成三帧静态目检和自动核验，**没有连续播放或听审**；[目检记录](evidence/subtitle-segments-static-review-20261017.json)绑定这三张图的 SHA。公开片的人工文字/标记与真实 ASR 证据分开，参考片复用相同渲染器。没有扩大自然广告语料、翻译模型、逐字/说话人强制对齐、任意语言与字体、复杂塑形/RTL、字幕样式迁移或通用语义剪辑的覆盖。

ASS/SSA/TTML 输入在本命令中转成纯文字和时钟，原样式/动效不保留；Node 的 Intl/ICU 版本会影响部分中文切词边界。30 秒超时和 128 MiB V8 旧生代堆上限不等于进程总 RSS 保证。离线 wheel 不捆绑 Node、FFmpeg、模型或 Python 依赖；项目 JSON Schema 目前未随 wheel 分发，离开仓库时使用已声明的内置语义校验回退，非干净机器发行验收。上述缺口与完整剪映功能、素材/模板库、开放 AI 质量仍按主路线维护。
