## 1. 边界原则

系统的核心对象是 Agent Project JSON、变更集、操作状态和证据包。Concat、FFmpeg、Shotcut、Kdenlive、Whisper 或任何 AI 模型都属于适配器或执行后端，不得成为上层需求的隐式数据模型。

产品运行时不要求 GUI。GUI 可以作为未来人工审阅器，但 GUI 不能拥有只有它才知道的项目状态，也不能成为 CLI 渲染的启动前提。

## 2. 模块与依赖方向

```text
Agent / Skill / 外部编排器
            │ JSON 请求、变更集、事件
            ▼
CLI 与操作服务 ──────────────── 权限、幂等、任务状态、日志
            │
            ▼
广告编排层 ── edit plan、模板变量、候选片段、版本变体
            │
            ▼
项目领域层 ── schema、时间线、关键帧、字幕、音频、迁移
       ┌────┼───────────┐
       ▼    ▼           ▼
媒体后端  互操作适配器  资产/权利库
FFmpeg/  OTIO/MLT/     素材、模板、
Concat   外部项目       Rights Ledger
       └────┼───────────┘
            ▼
验证层：结构、媒体、转换、权利、发布门禁
```

依赖只能从上层调用下层契约；下层不能读取 Agent 会话、GUI 状态或隐式全局项目。验证层可以读取所有产物，但不能修改原始项目来“修复”结果。

## 3. 模块契约

| 模块 | 接收 | 产出 | 不得承担 |
|---|---|---|---|
| CLI/操作服务 | JSON 请求、项目路径、幂等键、队列作业 | envelope、进度事件、操作记录、项目内队列状态 | 业务逻辑复制、GUI 操作、分布式调度 |
| 项目领域层 | Agent Project JSON、变更集 | 校验后的项目、迁移结果、差异 | 直接执行 shell 或网络下载 |
| 广告编排层 | brief、脚本、素材候选、模板 | edit plan、变量绑定、版本计划 | 绕过项目 schema 直接拼 FFmpeg 字符串 |
| 媒体后端 | 已校验的渲染计划、输入哈希 | 中间文件、最终媒体、渲染日志 | 修改项目语义、判断许可证 |
| 互操作适配器 | 外部项目、版本、策略 | 本地项目、转换报告、原始扩展 | 静默丢失、解密或绕过访问限制 |
| 资产/权利库 | 资产元数据、证据、模板清单 | 索引、Rights Ledger、发布资格 | 仅凭文件扩展名推断许可 |
| AI 适配器 | 固定媒体哈希、模型配置 | 转写、标签、候选、遮罩、模型 provenance | 将不可复现结果写成确定事实 |
| 验证层 | 项目、媒体、报告、权利快照 | 错误、警告、门禁结果、报告 | 隐式修改输入或跳过失败 |

## 4. 进程与文件边界

- CLI 负责启动和编排子进程；媒体后端以受控参数数组启动，禁止把未校验用户输入拼为 shell 命令。
- 每个操作拥有独立临时目录、日志、状态和产物清单；并发任务不得共享可写缓存，除非缓存按内容哈希隔离。
- 项目目录的规范文件、锁文件、Rights Ledger 快照和操作记录必须可备份；缓存和代理可以重建。合作 CLI 对项目读改写使用 `operations/project-write.lock`，并用 `operations/project-transaction.json` 对项目/Rights/操作元数据执行可恢复事务；大体积 `assets/`、`renders/`、`cache/` 不复制到事务备份，恢复时只报告媒体副作用。状态机见[跨文件项目事务恢复契约](../specs/跨文件项目事务恢复契约_v0.1_2026-10-15.md)。
- 网络请求默认关闭。下载模型、素材或外部项目时，必须在操作记录中保存 URL、证书/响应摘要、哈希和许可证证据。
- 路径必须经过 allowlist、项目根目录约束和符号链接策略检查；失败返回结构化错误。

## 5. 同步与异步

短操作（schema 校验、项目摘要、Rights Ledger 查询）可以同步返回。分析、代理生成、渲染、转换和模型推理必须使用操作状态机：`queued → running → succeeded/partial/failed/cancelled`。项目内 `queue run` 默认以同一状态语义顺序执行多个 render 作业；显式 `--workers N --continue-on-error` 时仅并发 FFmpeg/质量检查阶段，队列状态保存在 `operations/render-queue.json`，项目元数据和状态提交仍由主线程串行化，受控 worker 不等于分布式调度。

操作状态机的唯一事实来源是操作记录。进度事件是可丢弃的观察流，重连后必须能通过 `operation inspect` 恢复当前状态和产物。队列运行持有项目写锁时，`queue cancel` 走独立的原子取消标记通道并异步确认终态。

## 6. Concat/FFmpeg 后端接口

后端必须实现统一能力接口，而不是把上游命令直接暴露给 Agent。当前本地 CLI 通过 `capabilities` 暴露能力清单；后端接口仍按以下语义组织：

- `probe(asset) → ProbeResult`
- `render(plan, inputs, output_spec) → RenderResult`
- `preview(plan, range) → PreviewArtifact`
- `capabilities() → CapabilityManifest`
- `doctor() → DependencyReport`

`CapabilityManifest` 要列出版本、支持的容器/编码、关键帧属性、效果包、音频处理、GPU/CPU 路径和已知限制。上层根据能力清单决定是否允许 Exact、Mapped、Approximate 或 Baked；不能只看后端名称。

## 7. 扩展与插件

插件以 manifest 声明 `id`、版本、许可证、输入输出 schema、依赖、平台、网络权限和能力。插件加载前必须验证来源、哈希和许可证；插件运行时不能默认获得项目目录之外的写权限。

插件输出必须可被 Agent Project JSON 或 provenance 引用。只输出不可追踪的图片或视频而没有参数、输入哈希和版本的插件，不得进入可复现发布路径。

## 8. 失败归属

| 失败 | 归属模块 | 最低处理 |
|---|---|---|
| JSON/schema/时间越界 | 项目领域层 | 返回路径、期望值和修复提示 |
| 素材缺失/哈希变化 | 资产层/CLI | 阻断渲染，列出资产 ID |
| 编解码/滤镜失败 | 媒体后端 | 保留工具日志和可重试属性 |
| 外部字段无法映射 | 互操作层 | 写转换报告，不得静默跳过 |
| 许可证/归属/撤下 | 权利层 | 退出码 7，阻断发布 |
| 模型超时/输出异常 | AI 适配器 | 标记中间结果无效，允许替换模型 |
| 黑帧/响度/同步不合格 | 验证层 | 不发布，关联输出和检查项 |

## 9. 边界验收

架构评审通过前，至少要有一个 CLI 操作证明：同一个 Agent Project JSON 可以在不启动 GUI 的情况下，经过项目校验、媒体后端渲染、质量验证和 Rights Ledger 检查；替换媒体后端时，上层项目和报告格式不变。
