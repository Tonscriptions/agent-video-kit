# 离线 CTC 字词强制对齐契约 v0.1

本契约先于产品实现：在现有 Whisper 转写以外，增加真实 CTC 声学模型对给定文本的强制对齐，输出原文码点区间、字符/词时间和可入轨字幕。不得用均分文字或现有分句估时冒充对齐。

## 接口与时钟

沿用 `asr adapter register`，显式新增 `--engine transformers-wav2vec2-ctc-local-v1`；原 Whisper 默认值、旧登记与转写行为保持兼容。仅接受本地标准 Wav2Vec2 CTC safetensors、完整配置/词表、原生 Python、明确 CPU/CUDA 和独立权利证据；禁止运行时安装、下载、自定义模型代码或设备降级。

`subtitle align --project <目录> --asset-id <本地音视频资产> --transcript <UTF-8 文件> --adapter-id <登记 ID> --output <新 JSON>`，支持 dry-run、幂等、超时/取消及现有事务。文本文件允许纯文本或 SRT：纯文本可跨窗口对齐完整录音，SRT 的明确时间窗口逐段对齐；不把句时码当作字时码。输出保存原文、码点区间、规范化 token、字符和词时间、源/文本/模型/实现摘要与推理报告。可 `--apply --track-id <字幕轨> --font-asset-id <字体>`，生成已有逐词高亮格式；字符级和空格分词由明确粒度选项区分。

FFmpeg 解码为 16 kHz 单声道；只计实际样本时钟。推理窗口在模型卷积总 stride 网格上切分，显式重叠/裁去上下文后拼接输出格；禁止按 `音频时长/输出帧数` 拉伸时间。模型输出格以感受野中心的相邻中点为内部边界，仅保留与实际音频相交的格，首末边界延伸至录音边界；末窗按需要明确填零，不生成零时长尾格。SRT 每段网格锚定其明确起始样本。结果按工程整数 tick 量化；未覆盖尾部或不可达路径失败，不静默截断输入。

## 文本与算法

执行带 blank 的完整重复 token CTC Viterbi：允许停留/前进一状态，只在非 blank 且与前两状态不同的 token 允许跨两状态，保留回溯并检查最终可达性。朴素穷举独立小矩阵检验最优路径，不只重复实现公式。

原文保持不变；拉丁字母可按明确 `upper`/`lower` 规范映射到词表，中文直接匹配。明确忽略标点/空白并在报告中保留原文位置与原因；缺少的字母/汉字、未知多码点 token、空白独占、无有效 token、重复字符需要的帧不足均拒绝。不自动繁简转换、翻译、删词或调用识别器重写用户文本。词时间由其对齐字符合并，标点附着不能制造新声学时间。

模型后验/路径得分只作定位和复核提示，不解释为校准过的正确率；错稿仍可能被强制安置。保持 `ALIGNMENT_REVIEW_REQUIRED`，单独标注低后验字符，不能据低分随意删除原文或宣布结果准确。

## 资源、完整性与提交

先行上限：音频 1,800 秒、文本 16,384 码点、CTC token 8,192；单推理窗口最多 30 秒，重叠至少一个感受野。输出声学数组不超过 512 MiB、DP 回溯不超过 64,000,000 状态格；超过预算明确失败，可使用原文 SRT 段落降低每次 DP 规模，不能缩短已声明音频或文字。以上不是进程总 RAM/显存保证；OOM 明确失败，不切 CPU 或删减文本。

执行前冻结源、文本、登记组件及实现摘要；原生读锁覆盖长推理与资产提交。worker 使用既有断网审计及 E 盘缓存，输出须绑定请求摘要并在主进程再次验证时钟、区间、原文引用和完整性。JSON/SRT/项目/台账/轨道写入应原子提交，既有文件不覆盖，失败/取消保留诊断而不留下已登记半成品。派生字幕依赖音视频、原文和模型权利；默认不提升许可状态。

## 验收

应包含独立穷举 CTC 路径、重复字符、空白、标点、未知字符、跨窗口网格、长于 30 秒、SRT 多段、预算拒绝、篡改、取消、失败回滚和字幕高亮入轨验证。必须真实运行中英文模型；公开原创合成语音及其明确词块窗口作为受控定位参考。词块边界不等于语音学精标：2 帧误差目标按 30 fps 预声明，若未通过保留失败，不降低阈值以过关。未确认权利的自然中文只公开测量记录，不上传语音。

完整回归、wheel/原生离线发行、Skills 和 README 证据同步更新。强制对齐不等于说话人分离、歌词/歌声泛化、多语言自然质量或完整剪映等价；以上仍须单独验收。
