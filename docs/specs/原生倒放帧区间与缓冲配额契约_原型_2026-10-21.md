本目录是原生 Windows 实验源码副本，尚未合并 main。已有主线的普通倒放功能不等于本契约已发布，也不等于与剪映全部功能或自然素材质量等价。本原型不使用 Docker、WSL、虚拟机、虚拟环境、网络推理或新下载依赖。

## 功能边界

| 编号 | 项目 | 约束 |
|---|---|---|
| RV-01 | 目标 | 普通视频叶片段的原生 VFR 显示区间倒序，保留各帧实际持续时间、非整帧源裁切和全局输出采样相位。 |
| RV-02 | 源索引 | 流式读取原生 ffprobe 的 `best_effort_timestamp`、`duration`、time base、尺寸和容器 start time。不得以平均帧率重建 VFR。 |
| RV-03 | 区间 | 源帧显示区间为相邻原生 PTS 构成的半开区间；最后一帧使用原生 duration。先与请求源区间相交，再将区间镜像。倒放起点使用源出点之前的帧。 |
| RV-04 | 时间原点 | ffmpeg 默认输入会减去容器起始时间在流 time base 上的整数重标结果；原型按 nearest/ties-away-from-zero 映射，不能无条件减去视频首帧 PTS。 |
| RV-05 | 时钟 | 沿用有理数工作 time base，原生 PTS、作者 tick 和 CFR 输出网格可精确表达；不可表示时结构化失败。非线性反函数仍有既有浮点求值和曲线编译边界。 |
| RV-06 | 变速 | 倒序帧的 PTS 必须由原始显示区间计算；不能只调用 `reverse` 后沿用原顺序时长。常速和已支持的速度曲线作用于这条倒序源时钟。 |
| RV-07 | 序列裁切 | 在叶片段原作者时钟上选择可见源区间。叶片段本身倒放时，从 `source_out_tick` 向前选；之后再与父级方向异或。不得从源入点选择另一区间。 |
| RV-08 | 真正短源 | 实际视频末尾短于有效素材/请求区间时，倒放产生对应前导空白，不能以最后一张画面补满。公开输入仍须通过素材长度和项目校验。 |
| RV-09 | 输出 | 只在全局 CFR 半开网格取样。MP4/GIF 是观看副本；数值参考使用 FFV1/BGRA NUT、实际源 PTS 和独立区间公式。 |

源区间 `[a,b)` 中一张帧的可见区间为 `[l,r)` 时，其倒序区间为 `[b-r,b-l)`。以输出时刻反查原源帧时，在恰好落在源边界的时刻取该边界之前的帧。非整帧的部分首尾时长也必须保留。

## 有界资源与失败

| 编号 | 项目 | 约束 |
|---|---|---|
| RB-01 | 索引存储 | 两个 int64 数组，最多 1,000,000 帧；行长最多 4096 字节，stderr 保留最多 64 KiB，原生探测默认超时 300 秒。 |
| RB-02 | 输入检查 | 缺失有效 PTS、非严格递增 PTS、未知末帧 duration、无交集、尺寸无效、登记 time base 不一致和区间不可表示均拒绝。 |
| RB-03 | PTS 表达式 | 按帧号 N 进行平衡二分查找，表达式最多 64 MiB；显式表达 EOF。深度上界与索引/表达式 SHA 写入实际渲染清单。 |
| RB-04 | 共享倒放缓冲 | 仍使用原生 FFmpeg 对所选片段整段缓冲。按每帧宽×高×16 字节保守估算解码栅格，共享上限 256 MiB；所有可达实例累计，包括时间不重叠的片段和子图。 |
| RB-05 | 配额范围 | 配额仅覆盖所选原生倒放帧栅格；不等于进程 RSS 上限，不包含解码/编码队列、对齐、索引、表达式和其他滤镜。大幅面或长片可能被明确拒绝。 |
| RB-06 | 超限 | 在执行编码图之前返回 `REVERSE_VIDEO_BUFFER_BUDGET_EXCEEDED`，包含当前实例/共享估算、预算和范围。不能静默降低画质、抽帧或切换在线服务。 |
| RB-07 | 探测取消 | 模块级探测支持显式取消标记，并只回收自己创建的原生进程；尚未验收整个渲染规划阶段的端到端取消传播。 |

## 尚未接受的组合

原型专项不能接受一般 VFR 嵌套倒放、倒放音频与新视频时钟的逐采样联合等价、完整速度曲线音质、HDR/线性光/自然素材质量、长片缓存与交互延迟、跨平台或全部剪映效果。73 项既有嵌套回归只证明已测组合未出现失败，不能替代这些新边界的验收。

长片开发路径是可重放的分块倒放缓存、持久化有界帧索引、失效与取消、磁盘准入和逐块资源核验；当前 256 MiB 拒绝边界是临时实现约束。完成这些工程后仍需长片、多解码器、非零音视频起点及真实素材单独验收。

核验记录见[原型实测](../validation/原生VFR倒放帧区间原型实测_2026-10-21.md)。主线 V81 的完整回归与本原型分开记录；本原型通过若干专项不能将 V81 尚在运行的完整回归标为通过。
