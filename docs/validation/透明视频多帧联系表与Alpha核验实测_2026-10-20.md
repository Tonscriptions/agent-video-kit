## 已保留的失败

- [focus-r1](evidence/contact-sheet-20261020-v71/focus-r1.json)：19 项中 1 项失败。ffconcat 测试夹具使用了安全模式拒绝的绝对路径，实际在 probe 阶段失败；改为相对有效引用后可检出 concat 并在容器门禁拒绝。执行过的 [原测试](evidence/contact-sheet-20261020-v71/focus-r1-executed-test.py) 与 [当时实现](evidence/contact-sheet-20261020-v71/focus-r1-executed-contact-sheet.py) 原字节保留。
- [focus-r2](evidence/contact-sheet-20261020-v71/focus-r2.json)：19/19、82.847 秒、0 跳过，是增加原生探测取消与自动 PTS 候选前的历史版本，不能替代当前 25 项收据；[当时实现](evidence/contact-sheet-20261020-v71/focus-r2-executed-contact-sheet.py) 保留。
- [clock-r1](evidence/contact-sheet-20261020-v71/clock-r1/verification.json)：开发时发现正起点素材采用绝对 seek 组合导致时钟偏移；原诊断 stderr 保留。当前改为容器相对 seek，分别核验原始 PTS、1200 秒偏移与非零起点。不将失败原型算作功能通过。

## 完整回归失败与原生进程修复

[full-r1](evidence/contact-sheet-20261020-v71/full-r1.json) 实际运行 1589 项、4657.831 秒、0 跳过，51 失败和 20 错误，216 个源码输入前后相同；没有被改写为通过。[逐项归因](evidence/contact-sheet-20261020-v71/full-r1-fixture-diagnosis-r2.json) 分为 70 处历史夹具缺失和 1 处 Windows Job 加入失败。首次诊断只识别到五个媒体/字体文件，随后补入旧版源码 ZIP/JSON 和 Space Grotesk 字体，共 [8 个明确 Git blob](evidence/contact-sheet-20261020-v71/fixture-manifest-r1.json)。材料从本地已提交对象展开，未下载。

旧实现先运行进程再加入 Job，存在提前退出窗口。[受控原生对照](evidence/contact-sheet-20261020-v71/job-race-r3/verification.json) 让旧进程先自然退出，再真实调用 AssignProcessToJobObject，重现拒绝；新实现使用 Win32 挂起创建、加入 Job 后恢复唯一主线程，成功完成。[4 项原生测试](evidence/contact-sheet-20261020-v71/job-start-r2.json) 覆盖执行前停留、20 个快速子进程、加入故障关闭和真实后代回收。本次控制证明了该竞态及修复；旧完整日志未保存原始 Win32 错误码，不能据此断言所有 Job 加入失败都有同一原因。

[focus-r4](evidence/contact-sheet-20261020-v71/focus-r4.json) 的 25 项中有 1 个超时测试失败：原测试假定 0.1 秒内一定已启动进程，但启动前期限到达也是合法行为。现在确认真实阻塞子进程启动后，再由测试注入期限，检查实际回收；[focus-r5](evidence/contact-sheet-20261020-v71/focus-r5.json) 为当前结果。生产期限没有放宽。原测试字节保留。

[第一次旧/新控制](evidence/contact-sheet-20261020-v71/job-race-r1/verification.json) 通过；[第二次](evidence/contact-sheet-20261020-v71/job-race-r2/verification.json) 在负载下未能于固定 150ms 等到旧进程退出，因此控制本身失败。当前控制明确等待旧进程实际自然退出，故障与内核调用均真实，注入的调度窗口另行标注，不宣称为自然故障率。

当前原生/安装/联系表目检重新执行，源码输入为 **217**；旧 216 输入的收据与 33 个旧公开文件保留为历史，不与当前 33 文件/6 次探测相加为功能通过数。当前全量回归为 [full-r2](evidence/contact-sheet-20261020-v71/full-r2.json)，运行期间不计通过。

## 质量与实施边界

该能力降低 Agent 检查 Alpha、布局和锚点的工具开发成本，不提供美颜、人体塑形、重打光或新抠像模型。
8-bit 预览、抽样图像和包时间索引不能替代 HDR/源精度、长片性能、连续播放、自然素材质量或音频听审。
旋转元数据由 FFmpeg 处理，但本轮没有单独验收所有旋转案例；不声称全容器兼容。
每步文件大小检查不是整个进程的内存/磁盘硬预算；60 秒探测/索引与解码 timeout 分别计时。
成功也不会自动设置质量为 accepted，不更改时间线创作内容，不自动通过广告发布门禁。
未使用 Docker/WSL/虚拟化，未启动 GUI/浏览器，未执行模型前向或在线媒体请求；共享 GPU 没有新增推理负载。
