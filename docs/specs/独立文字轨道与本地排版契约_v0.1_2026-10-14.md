## 1. 项目与编辑入口

`kind=subtitle` 轨道是独立合成层，按 `order` 与视频轨道共同排序。内联文字片段使用 `generator: {"type": "text"}` 和 `subtitle.text/style`，不需要占位视频资产；此生成器与 `asset_id`、`sequence_id` 互斥。当前 v0.1 渲染器已经实现独立文字片段的时间窗、字体排版、逐字时间匹配、位置/缩放/旋转/透明度关键帧、遮罩、混合、fade/dissolve 透明层转场和 slide/wipe 空间转场，以及透明层 `rotate` 动画，文字层可以与画面合成；当序列没有视频片段时，渲染器使用黑色或透明基础画布输出纯文字序列。通用片段字段仍可由 schema 保存；独立文字片段的复杂 transition 句柄和复杂排版仍需单独验收。

```json
{"operations": [
  {"op": "add_track", "track_id": "titles", "kind": "subtitle", "order": 10},
  {"op": "append_clip", "id": "headline", "track_id": "titles",
   "generator": {"type": "text"},
   "timeline_start_tick": 45000, "source_in_tick": 0, "source_out_tick": 90000,
   "subtitle": {"text": "本地广告标题", "style": {"fontsize": 48, "box": false,
     "x": "(w-text_w)/2", "y": "(h-text_h)/2"},
     "animation": {"type": "rotate", "from_degrees": -90, "to_degrees": 0, "duration": 0.5}}
  }
]}
```

已登记的 SRT/VTT/ASS/SSA 资产可直接放入字幕轨道，使用本地 libass 绘制；外部文件的样式和 cue 源时间按文件处理，内联文字动效不能隐式替换其样式。`style.font_asset_id` 可引用已登记的 `kind=font` 资产；显式 `fontfile` 必须是已存在的本地文件，禁止远程路径或下载字体。引用字体和字幕文件必须纳入渲染输入指纹，字体资产继续经过 Rights Ledger。

## 2. 合成与旋转

当前实现把独立文字先画到本地透明帧，再以透明层叠加到同序列画面；`rotate` 动画执行实际像素旋转，不得以淡入冒充。角度按源局部时钟从 `from_degrees`（默认 -90）到 `to_degrees`（默认 0）线性变化，`duration` 为正数，`delay` 为有限非负数。片段整体 `transform`、片段关键帧、mask 和 blend 现在也作用于独立文字透明层；fade/dissolve 在 alpha 层执行，slide 通过 overlay 位置表达式移动透明层，wipe 通过 alpha 逐帧裁切。复杂 transition 句柄仍保留近似边界，不能把当前能力扩大解释为完整文字模板系统。

生成文字默认在画布中心排版，旋转动效的透明层只包含文字，不能旋转底层视频。内联文字仍默认位于画面下方；固定画布边缘会裁去超出画布的文字。任意字形中心旋转、文字路径、复杂文字模板和立体文字仍需独立验收，不能据此宣布复杂文字编辑完全对标。

## 3. 换行与逐字时间

`max_width/wrap_width` 优先使用当前本地字体的实际 advance width 换行，保留显式换行和原文索引；没有可用字体度量时回退平均字宽并写入近似警告。字形组合、ZWJ 组合和变体选择符不得拆开。不同字体/FreeType 构建、复杂双向文字与标点禁则仍需视觉校准。

逐字高亮按 `word_timing` 的文本在原文中顺序定位，允许显式 `start_char` 消除重复词歧义。词跨越换行时拆为对应行的绘制范围；定位使用整行前缀度量，不能将当前词的 `text_w` 当作整句宽度。打字机动画沿同一排版结果定位，换行符不绘制成可见字符。整句、逐字高亮、打字机与背景应共享坐标和字形基线。无法匹配的时间词必须拒绝或明确报告，禁止悄悄把词画在行外。

## 4. 失败与证据

未知生成器、多个源引用、无文字内容、错误轨道、缺失字体、非法旋转角度/延时/时间词索引必须在保存前结构化拒绝，项目原文件保持不变。当前自动验收包含实际 FFmpeg 输出、时间窗、字幕轨道层级、文字与画面合成、纯文字画布、透明层旋转滤镜、换行后的源文本匹配和字体指纹；旋转前后字形包围框、复杂文字模板和跨设备视觉 golden 仍需要补充样例，不能用图结构检查代替视觉证据。agent-json 应保留生成器；OTIO/Kdenlive 未映射的文字不能标记为 Exact。
