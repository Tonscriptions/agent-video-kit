## 1. 锁定原则

本次拉取的开源仓库保存为 `sources/upstream/` 的浅克隆快照，并在机器清单中记录远端、提交、分支、许可证文件和拉取时间。它们是研究资料或未来可替换适配器的候选，不能被视为已经集成到产品运行时。

产品运行时当前只使用本项目 `product/` 下的 Python CLI 和 PATH 中的原生 `ffmpeg.exe`/`ffprobe.exe`。运行时不会导入 Concat、Shotcut、Kdenlive、Jianying、video-recap-skills 的代码，也不会请求 MiMo、Fish Audio、HeyGen 或其他在线/闭源服务。

## 3. 依赖门禁

- 改变仓库提交、许可证、编译参数或 FFmpeg 发行版后，必须更新机器清单和发布门禁证据。
- 上游适配器如果需要 GUI、MCP HTTP、模型下载或第三方 API，只能作为显式可选实验，不得进入默认离线路径。
- 不调度 Docker、WSL、容器或虚拟机。`doctor` 只读取 PATH 中是否存在相关可执行文件，不启动它们。
- 任何素材、模板、字体、模型和生成结果仍需独立登记 Rights Ledger；代码仓库开源不等于媒体可商用。

2026-10-13 已确认：原生 Python 3.13、FFmpeg 8.1、FFprobe 8.1 可用；Cargo 未出现在 PATH，因此没有把 Concat Rust 构建当作 P0 运行时。P0 运行验证使用本地 FFmpeg `lavfi` 合成媒体，未下载外部媒体或调用网络服务。
