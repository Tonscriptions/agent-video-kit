# OpenFilm 当前复用建议与导出恢复增量

**可以复用。对本项目最有价值的是 HTML 动效协议、字幕与模板规则，以及批量渲染的生命周期管理。已有能力继续沿用当前适配；新增优先候选是有限重试、代理转码去重和浏览器回收。OpenFilm 本身不能补齐离线 AI 算法或完成剪映全功能等价。**

本页为 R17，承接 [R16 源码与成本评估](OpenFilm_0.2.5可拆模块与复用成本评估_2026-10-22.md)。本轮固定检查新源码并执行隔离观察，没有新增产品功能、安装上游完整依赖或交付新成片。以下工量是规划估计，不能当作已节省的人时。

## 3. 新增重试能做什么、还不能证明什么

| 编号 | 实际观察 | 接入时的约束 |
|---|---|---|
| OF17-B01 | `Target closed` 首次失败后第二次成功；`ERR_NO_BUFFER_SPACE` 同样重试一次 | 单任务最多重试一次，持久失败必须终结；真实资源不足仍需降低并发，重试不是内存预算 |
| OF17-B02 | 浏览器持续失败共执行两次；缺文件、脚本错误、循环提示、未知编码器、非 Error 抛出均只执行一次 | 作者/参数错误不套瞬时故障重试；上游按错误文本分类，本项目需结合结构化错误码和阶段 |
| OF17-B03 | 首次调用中发送取消，单次/池两条路径均失败终结且未重试 | 维持宿主取消令牌、进程所有权、临时文件隔离，避免重试写入已取消的输出 |
| OF17-B04 | 原始 worker 运行了，实际 `render()` 被替换为假模块 | 尚未证明新浏览器启动、旧浏览器关闭、半成品清理、帧/PCM 一致性或系统资源恢复；不能宣称真实崩溃恢复通过 |
| OF17-B05 | 新增上游真实浏览器终止测试依赖 `pgrep`，声明 Windows 跳过条件 | 本轮没有执行该测试，既不记通过，也不把“未执行”登记为一次实际跳过。Windows 需基于自有进程句柄另做故障注入 |
| OF17-B06 | 本机 Node 22.14 原测试缺少 `import.meta.main`，真实失败 **1 项** | 官方 Node 22 文档注明该属性从 **22.18.0** 加入；`--import` 本身可用，不代表新属性存在。未来宿主明确 Node 版本门槛，不能据此说打包 Electron 有故障 |

Node 属性来源：[固定 v22.18.0 官方文档](https://raw.githubusercontent.com/nodejs/node/v22.18.0/doc/api/esm.md#importmetamain)。没有为本轮安装新 Node 或调用真实第三方 Agent。CommonJS 两次对照仅证明对应原生入口与环境行为。

R16 的池无全局容量、代理 key 只绑定路径/大小/mtime、NLE 最近帧率与极短片段等观察仍有效：相应函数本轮逐字节未变。它们属于[历史已执行观察](OpenFilm_0.2.5可拆模块与复用成本评估_2026-10-22.md#3-本次发现的适配边界)，本轮没有再制造真实错代理或验证目标 NLE。

## 4. 建议排期与接入工量

以下以一名熟悉当前 Python/Node/FFmpeg 工程的开发者估算，包含限定异常、取消、离线安装与证据。**这是完成适配的成本，不是已节省成本。**

| 优先级 | 限定交付 | 生产化工量预估 | 采用条件 |
|---|---|---|---|
| P0 | 将错误分类、有限重试与取消夹具接入既有 HTML 作业生命周期 | **1–3 人日** | 先完成真实 Windows 故障、清理与原片/输出一致性验证 |
| P1 | 单批次浏览器池，补宿主全局并发与资源约束 | **3–6 人日** | 确有批量 HTML 启动成本；与 P0 共享生命周期，不能直接累计为净节省 |
| P1 | 同源代理转码去重，使用已有内容 SHA、任务与缓存系统 | **3–5 人日** | 保留原片精度，取消一个消费者不误伤其余消费者；与池共享测试和所有权工程 |
| 条件项 | 一种基础开放 NLE 交换适配 | **8–15 人日** | 先指定真实开源目标；验证剪切、源范围、音频、字幕、静态布局和损失报告 |
| 条件项 | 自有 Agent 宿主的入口/图片预算等小模块 | **2–4 人日** | 已有可控消息与进程管线；完整宿主另计，当前 CLI 不默认建设 |

现有 HTML、字幕、模板字段、诊断与编码探测不重新排一次移植。对目前“原片浮点内核统一到正式 render/preview”的开发主线，OpenFilm 没有新增可替代的浮点锐化、HDR、抠像或光流内核；上述工程按真实瓶颈接入。

自然素材 AI 效果、完整滤镜/转场、长片性能、HDR、离线模型质量、素材/模板库，以及剪映全功能和观感等价仍需独立实现与验收。本轮没有实际工时对照，不能给出整个项目降本百分比。
