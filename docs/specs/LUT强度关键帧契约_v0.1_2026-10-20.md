# LUT 强度关键帧契约 v0.1

V73 在 V58 的完整作者时钟、CFR 采样和根图共享预算之上增加 `lut3d.intensity`，别名 `lut/cube/look`。本契约先于实现落盘；验收结果另存，不能用计划代替通过记录。

| 编号 | 约束与验收 |
|---|---|
| LA01 | 强度关键帧为有限数值 0..1；沿用 hold、linear、ease_in、ease_out、ease_in_out、Bezier。未知通道、重复通道、越界值和非法时序须结构化拒绝，不能静默采用静态值。路径、LUT ID、插值枚举保持静态。 |
| LA02 | 以完整作者 tick 求值，正确映射片段显示窗口、祖先裁切/变速/倒放和嵌套；区间调节层沿用其区间局部时钟。不能以可见区间重置已有作者动画。 |
| LA03 | 动态强度采用本地 FFmpeg `lut3d` 的完整变换结果与未调色 RGB 像素混合，A=w×LUT(RGB)+(1−w)×RGB；alpha 逐字节保持。当前路径明确为 8-bit 编码 RGB 混合，不宣称线性光、HDR 或剪映专有调色算法等价。 |
| LA04 | 复用本机 FFmpeg 可读的 `.cube/.3dl/.csp/.dat` 与现有登记、哈希、版权和项目内路径限制；资源格式无效由原生执行失败显式暴露。不得下载素材或调用在线模型。 |
| LA05 | 数值命令发给每个实例独有的 blend RGB opacity 通道；启动前核验本机 T 标志。命令缓存内容寻址，损坏显式拒绝；根递归图共享 2,000,000 状态采样、200,000 命令、16 MiB 文本和 1,024 实例配额。导出清单必须绑定 LUT 原字节和混合语义。 |
| LA06 | 视频/图片、文字层、嵌套片段与调节层均通过统一滤镜编译器执行；串联多个相同 LUT 不得串台。包迁移、剪辑片段复用、队列摘要与重放保留可编辑关键帧，缓存不是作者资产。 |
| LA07 | 先用原始像素和原生 FFmpeg 复现旧静态半强度中性 CUBE 的红蓝索引问题。修复 CUBE 的 red-fastest 采样顺序，并版本化派生缓存键；旧错误缓存不得继续命中。静态 0/1 行为保留，静态部分强度的网格混合与动态像素混合对域外/非线性及舍入的区别如实记录。 |
| LA08 | 有意义的原生测试覆盖独立像素期望、alpha、所有插值、NTSC 帧率、时钟及上述上下文；本轮实际生成原视频/MP4/GIF，记录输入、命令、帧率/帧数/时长、SHA-256 与失败样例。核验离线安装入口和完整原生回归，冻结源码与八份外部夹具，禁止跳过测试。 |
| LA09 | 验收后更新 README 编号表、能力矩阵、路线/技能与离线资料，通过 staged 字节核验后普通提交/推送 main。本轮只补齐这项差异，不提升未测试的 AI 质量、HDR 或整体剪映等价状态。 |

静态 CUBE 派生缓存将逐字节复核，损坏保留并报错。LA03 的动态混合精度和 FFmpeg 格式支持必须由实际执行证据限定，不能从扩展名推断全格式兼容。
