# 本地蒙版逐帧核验与检查点契约

| 项目 | 内容 |
|---|---|
| 文档编号 | SPEC-MASK-REVIEW-001 |
| 状态 | 有效 |
| 日期 | 2026-10-16，Asia/Taipei |
| 范围 | `quality mask`；本地已登记图像/视频，原生 FFmpeg 和 Python 标准库 |

`quality mask --project <项目> --asset-id <蒙版资产> --channel alpha|luma` 核对实际编码蒙版。它输出每帧选区面积、半开包围框、相邻帧 IoU、面积变化及可选明确检查点；不推断对象身份，不将面积/IoU 或检查点通过描述为完整分割质量。

`--threshold` 为 0..254 整数，默认 127，严格大于阈值才选中。alpha 要求源流具有 alpha；VP8/VP9 透明素材显式选择本地 libvpx 解码器。luma 使用 FFmpeg 的 8-bit gray 转换。输出按显示方向/SAR 归一化、nearest 缩放；`--max-edge` 默认 1280、0 保留显示尺寸，取整后每边最小 2 像素，实际尺寸以计划为准。帧时钟为显式 `--fps` 或源平均帧率，CFR 与片尾至多一帧补齐必须披露；静态图像只核对一帧，不接受 `--fps`。

默认 `--max-frames 4096`，最多 10000；`--budget-mib 256` 限制解码灰度临时文件，范围 1..1024 MiB，执行前根据输出像素与帧数拒绝超预算。报告逐帧增长有帧数上限；Python 按帧扫描，不要求 NumPy，不加载模型，不下载内容，不访问网络。FFmpeg 180 秒超时后清理临时目录，不留下可误当作成功的最终报告。

可选 `--expectations <本地JSON>`：最多 128 KiB、256 组事件、每帧最多 32 个点；帧从 0 开始、严格递增，点在输出画布的归一化 0..1 内。格式如下：

```json
{
  "version": "1.0.0",
  "coordinate_space": "normalized-output",
  "frames": [
    {"frame": 0, "points": [
      {"x": 0.3, "y": 0.8, "expected": "selected", "radius_pixels": 1, "minimum_fraction": 1.0},
      {"x": 0.7, "y": 0.5, "expected": "clear", "radius_pixels": 0, "minimum_fraction": 1.0}
    ]}
  ]
}
```

`radius_pixels` 默认 0、范围 0..64，使用裁到画布内的方形邻域。中心像素为 `min(size-1, floor(normalized*size))`。`minimum_fraction` 默认 1，须有限且在 (0,1]；对 selected/clear 分别计算邻域选中/未选中比例，低于指定比例则失败。未知字段、非有限数、bool 冒充数字、越界帧和非法枚举必须拒绝。检查点是用户/Agent 提供的断言，其自身正确性仍需复核，不能代替完整真值标注。

空选区、画布边缘接触、相邻面积超过 3 倍或不足 1/3 只生成审查提示，不自动认定错误。`--scene-cut-frame` 可重复，必须唯一且在 1..frames-1；切点处不比较前一帧。IoU 是未运动补偿的像素交并比，双空或切点返回 null。

`--dry-run` 只做来源/哈希/参数/预算和期望预检，不解码、不落盘。正式执行在前后核对源资产与期望 JSON 哈希，报告进入项目 `validation/`；`--report` 只能指定该目录内 `.json`，不能覆盖源或期望文件。检查点失败仍保存报告，并返回失败 envelope/退出码 2；结构错误、资产缺失或哈希变化为结构化错误，不把失败包装成通过。未提供检查点时 `expectations_checked=false`，结构成功不代表语义成功。

报告包含源 SHA-256、期望摘要、阈值/时钟/尺寸/预算、FFmpeg 版本、逐帧数据、失败点、审查警告及 `semantic_quality_accepted=false`。只读取既有资产，不改时间线、权利台账或素材；权利及发布门禁继续独立适用。

实现及验收见[蒙版范围与正负检查点实测](../validation/本地蒙版范围与正负检查点实测_2026-10-16.md)：16 项专项纳入完整 379 项回归；公开 32 帧合成漏选/完整蒙版，真实 SAM2 提示修正仍失败的样例同样保留。契约有效仅表示入口、参数和失败行为已验证，不关闭 #55/#56 的自然质量缺口。
