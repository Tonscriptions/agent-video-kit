# OpenFilm 复用复核与开发成本更新

**结论：现有“按模块拆取”的方案仍适用，优先复用字幕、编辑规则、片段组、HTML 动效及创作流程。** OpenFilm 已提供 Agent CLI 和可编辑 HTML 场景，能减少这些外围模块的开发量；其在线生成服务路由没有提供本项目所需的本地 AI 特效模型内核。继续保留 Agent Project＋Python/FFmpeg 主链，可以沿用已完成的离线、作者时钟、权利、工程包和发行约束。

```powershell
C:/Python313/python.exe -B -X utf8 scripts/audit_openfilm_refresh.py --fixed sources/upstream/openfilm-recheck-20261018-r54/repo.zip --archive sources/upstream/<新来源目录>/repo.zip --output docs/validation/evidence/<新查询目录> --work product/.runtime/<新解包目录>
C:/Python313/python.exe -B -X utf8 scripts/audit_openfilm_r05.py --refresh docs/validation/evidence/openfilm-refresh-20261019-r05/verification.json --output docs/validation/evidence/<新原生检查目录>
```

第二步读取本次固定来源和现有 `D:/Program Files/nodejs/node.exe`，执行八个经过审读的原测试文件；不会调用真实桌面窗口。固定源码及版本依据：[仓库](https://github.com/openfilm/openfilm)、[许可证](https://github.com/openfilm/openfilm/blob/7a64d1feacdb59fb631694af7501a4ca570254ca/LICENSE)、[本轮完整证据](validation/evidence/openfilm-reuse-final-20261019-r05/verification.json)。
