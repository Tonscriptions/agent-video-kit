# 离线 HTML 模板控件与覆盖恢复契约 v0.1

状态：V45 已实现的受控范围；以下约束于开发前声明，[测试和成片终态证据](../validation/离线HTML模板控件与覆盖恢复实测_2026-10-18.md)另行记录。本轮采用 OpenFilm 固定提交 `eefd6a8d379289102141359a4718dbab12170526` 的 MIT 纯函数与 DOM 覆盖/恢复规则，继续使用现有 Agent Project、离线 HTML host、原生 Windows Job 和 FFmpeg，不引入 Studio、Electron、在线供应商或安装入口。

1. `motion html-controls` 在指定 CFR 帧、两个新浏览器上下文中实际绘制，返回 `:root` CSS 自定义属性、文本和单图片的控件清单及采样摘要；不编码、不登记资产、不修改工程或权利台账。`--dry-run` 不启动浏览器。采样相同不是整段绘制、字体字形或美学验收。
2. `motion html-render --overrides <local.json>` 接受 `variables` 对象、`texts` 和 `images` 数组。CSS 变量值为显式字符串，保留 px/%/em 等单位；文字不作 HTML 解释；图片必须引用已登记、本地、哈希一致的图片资产。不给任意样式、远程 URL、字体下载或浏览器执行片段提供覆盖入口。
3. 文本项为 `{at, n?, value}`；图片项为 `{at, n?, kind: "img"|"bg", asset_id}`。`n` 为 1 起始，省略代表该 selector 的所有匹配，匹配数和请求大小受限。未知字段、重复目标、无效或失配 selector、无直接文字的复杂文字目标、图片类型不匹配、未声明变量必须报错，不静默忽略。
4. 从已有输出 `--from-asset-id` 重建时默认继承完整覆盖。新文件仅更新指定项；变量/文字/图片值 `null` 表示移除此项，恢复页面自身逐帧内容；空字符串是实际文字。覆盖在页面 `frame(t,params)` 后应用，每帧前先恢复上次改动，不积累旧值或污染页面动画。
5. 修改保存到新输出的 `html_motion.template_overrides`，原始源码包、原输出保持不变。图片保留 `asset_id` 引用、独立 SHA 和权利依赖，支持工程包与片段组的既有 ID 重映射。权利默认未核验；模板 MIT 不提升图片/字体/派生内容的发布资格。
6. 运行继续禁止网络、页面媒体/iframe/WebGL；资源总数、字节、帧数、像素工作量、超时、取消及事务沿用 HTML 契约。实际执行后必须关闭所有 page/context/browser 并回收原生 Job；失败不登记新资产、编码成片或工程变更。
7. 预声明核验：真实 DOM 变量类型/单位；动画每帧覆盖与恢复；两张原创图片的独立像素参考；原源码与覆盖输出差异；全帧乱序重绘、精确 PTS、透明 alpha；继承/移除、实际工程包和片段组重建；缺失目标/网络变量/错图片类型/资源变更失败及事务/浏览器回收。发布原创输入、实际 MP4/GIF 和 SHA，人工静帧、连续播放、听审分别记录。

策略审计按实际字段语义区分 DOM 数据与资源地址：仅在明确 `agent-local-html-motion-v1` 的配方/报告结构中，将 `p:first-child` 选择器和 `CTA: BUY` 文字中的未知 scheme 识别为 CSS/文字；普通 uri/模型/媒体字段仍严格拒绝未知 scheme。真实 `://` 地址、已知远程 scheme 和供应商标记即使出现在这些模板数据里仍会拒绝，不改变运行时断网守卫。

这不是完整 OpenFilm 页面编辑器或 HTML 时间线，不自动提供语义理解、缺字检测、布局美学、视频换源、关键帧编辑或剪映等价。FGT 继续保留 V44 研究状态，其上游权利链和自然画质未验收，不因本轮模板接入改变。
