## 2. 正式 CLI 实际执行

生成入口为 [build_readme_gallery.py](../../scripts/build_readme_gallery.py)。原生 Windows 运行；不下载素材或模型，不启动 Docker/WSL、浏览器或额外服务。图形和测试音由本地脚本生成；最终编辑与合成通过独立 Python 子进程调用产品正式 CLI `main`，没有绕过产品渲染器制作成片。

## 5. 原生 Windows 复现

使用已安装 NumPy/Pillow 的原生 Python 和本地 FFmpeg/FFprobe，不自动安装依赖。在仓库根目录执行；`--work-dir` 必须是没有旧项目的新目录，生成器不会删除或重置现有项目。

```powershell
# 生成正式产品 CLI 演示；输出与临时项目均留在忽略目录。
python -B -X utf8 scripts/build_readme_gallery.py `
  --output-dir product/.runtime/gallery-reproduction/output `
  --work-dir product/.runtime/gallery-reproduction/work

# 同时从种子重算两组研究样例，额外需要本地 OpenCV。
python -B -X utf8 scripts/build_readme_gallery.py `
  --output-dir product/.runtime/gallery-research-reproduction/output `
  --work-dir product/.runtime/gallery-research-reproduction/work `
  --rebuild-synthetic-research

# 直接使用仓库附带的项目包；输出目录须不存在。
.\ai-ad-editor.ps1 convert import `
  --input docs/assets/readme-20261016/cli-showcase.aevpkg.zip `
  --output product/.runtime/gallery-package-reproduction
.\ai-ad-editor.ps1 validate --project product/.runtime/gallery-package-reproduction --strict-rights
.\ai-ad-editor.ps1 render --project product/.runtime/gallery-package-reproduction `
  --publish --profile custom --width 640 --height 360 --output renders/replay.mp4
```

本轮实际使用现有原生 ComfyUI 附带 Python（只作为本地解释器，不启动 ComfyUI 服务），`--research-root workspace/repair-observed-plate-reference-final-20261016` 复用已冻结数组。跨 OpenCV/FFmpeg/字体版本不保证二进制逐字节一致。生成器为避免误借旧成绩会检查本记录绑定的生产源码基线；原始摘要不同且仅为 CRLF/LF 差异时，允许与固定已验证提交按换行归一化核对，实际代码变化仍拒绝。该分支已用内存替换模拟验证，不修改生产文件；本机最终执行仍匹配原始 89 份摘要。未来产品变更后需先完成适当验证，再显式更新证据绑定。

[.gitattributes](../../.gitattributes) 禁止 Git 对公开演示文件、生成器和独立核验记录做文本换行转换，保证这些文件的原始 SHA-256 不因 Windows checkout 改变。此规则与源代码比较边界一并修正后，在新目录重跑最终 14 次 CLI 流程，并重新生成公开媒体与摘要；最终证据只绑定这次发布样例，不将草稿/复跑累计为新增产品测试。

本轮 [文档与媒体审计](evidence/docs-audit-readme-gallery-20261016.json) 核对 Markdown 本地目标、元数据状态、文件摘要和演示媒体清单；不访问外链、不检查网页锚点，不代表画质或许可的外部法律确认。
