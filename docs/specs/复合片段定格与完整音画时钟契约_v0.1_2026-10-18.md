## 1. 作者输入与执行顺序

不新增公开 Schema 字段或私有项目格式。沿用 `sequence_id`、`source_in_tick/source_out_tick`、`speed/speed_curve`、`reverse` 和 `freeze: {at_tick, duration_tick, audio_mode}`。`duration_tick` 包含插入的定格时间；`at_tick` 是取源、变速和倒放之后、插入暂停之前的片段局部输出时间。已有 compose、窗口拆分、工程包和片段库须保留这些作者字段。

执行顺序固定为：子序列在自己的原生透明画布完成全部图层、字幕、子动画、转场及子级音频总线；对整份子输出执行作者取窗、变速、倒放及定格；再应用容器自身 crop/TRS/anchor/opacity/effect/mask/fade 和父音频总线。父容器动画继续使用其所在序列的作者时钟，不随自身 freeze 暂停。更外层的时间映射作用于这份完整结果。同一子序列不同 freeze 实例互不覆盖。

作者工程和资源台账不保存内部序列/资产。规划和渲染不得为这一步生成、登记或下载中间成片；全部在单一 FFmpeg 图中处理。子级不重复执行仅属于选中根的全局 adjustments。循环引用、缺源、原有非法冻结范围仍显式拒绝。

## 2. 显示帧和声音

视频沿用已有直接片段的显示帧语义：内部插入点在显示帧格点向上取整，重复插入点之前的帧；起点使用第一帧，末端使用最后一帧。插入帧数为 `max(1, round(duration_seconds * fps))`。不整帧定格时长保留 `FREEZE_FRAME_QUANTIZED`，不能声称具有任意亚帧的相同画面语义；作者时长与全局半开输出区间保持不变。

`audio_mode=silence` 在完整已处理子总线上按 48 kHz 采样位置插入等长静音，之后恢复其余声音。`continue` 保持既有直接片段语义：原声音继续，尾部补静音至总长；不是循环最后一个采样，也不是在选区外读取额外源声音。父容器的音量包络在其完整输出时钟上执行一次；子级音量/效果在暂停前已处理，不在各叶片上重新求值。

默认 FFmpeg atempo 的局部相位、音高、极短窗、自然听感仍单独验收；离线文件型 R3 对已经合成的内联音频仍不能冒用原始文件路径，要求该路径时保留显式拒绝，不静默切换引擎。选中子序列自身输出不继承引用者的 freeze。

## 3. 预声明核验

| 编号 | 场景 | 必须观察的结果 |
|---|---|---|
| NF01 | 普通复合片段中部、起点、末端定格 | 所有编码帧对应独立固定帧码；暂停帧及恢复帧无重复偏移 |
| NF02 | 原生子画布、透明图层及独立父级变换 | 暂停已合成图层；保留 alpha 和父坐标，不能用黑底或逐叶片暂停替代 |
| NF03 | 子字幕和子级动画；父级动画 | 子图随整帧暂停；父动画继续；完整像素/明确 ROI 与独立作者参考核对 |
| NF04 | 已有真实源句柄转场中途定格 | 冻结转场中间混合画面，恢复原进度；端点本身 freeze/curve/container 的原拒绝仍保留 |
| NF05 | 取窗、倒放、恒速、速度曲线和更外层重映射 | 先完成子画面，再执行映射；帧选择与独立解析时钟核对；不只检查帧数 |
| NF06 | 多级定格及重复引用 | 每实例独立处理，多个 FFmpeg pad 不重复消费、不读取其他图的输出 |
| NF07 | 完整子总线、silence/continue、父音量包络 | 恒速一倍情形核对全部立体声采样，最大绝对差 ≤2e-6；变速另报时长/有限性和内容边界 |
| NF08 | 输出窗口落在暂停中间及恢复以后 | 与完整作者结果的对应输出选区一致，原作者字段保留 |
| NF09 | 预算、循环/缺源、被拒引擎、无冻结控制 | 在执行前明确失败；无冻结分支与固定 V50 基线逐字节控制，不偷换总目标 |
| NF10 | 发行、原生独立安装和工程包 | 随包源代码一致；独立 CLI 实际渲染重建；内部 ID 不写回工程、台账或导出项目 |

恒速解析像素参考最大 RGB 误差 ≤3（8-bit 编解码舍入），帧身份必须零错配；alpha 使用公开输入逐像素核对。曲线引用独立积分/逆解，不以同一产品的第二次渲染证明算法正确。作者复杂字幕可采用固定子级成片作暂停参考，但必须标为同渲染器参考，只验暂停/恢复及父时钟，不冒充独立字形算法。全部编码 PTS、视频帧数、音频采样数和 SHA 必须记录。

## 4. 元数据和验收边界

manifest 记录 `sequence-inline-surface`、`purpose=nested-sequence-freeze`、原容器/子序列、原时钟参数、完整子级和定格子图、实际输入、全部警告及 `intermediate_files=0`。工作栅格估算累计子图、定格表面与父投影，超额在 FFmpeg 前拒绝；该估算不证明 loop/reverse 缓冲或全部进程 RSS 的上限。

本增量不关闭 VFR/HDR/独立子 FPS、自然广告美学、长片资源、自然音高/相位/听感、AI 修复/对齐及完整剪映等价。原失败证据和未运行项须保留；最终状态由当轮实际执行决定。

## 5. 执行后状态补充

预声明门槛未调整。无损内核图的逐像素 alpha 精确；正式 VP9/WebM 输出仍有 128→129、最大 1 的误差，零误差交付门槛失败。无损 FFV1 图探针不是新增 CLI 编码支持，曲线音频的长度/有限性也不是内容质量通过。完整数字、原片、失败及独立安装见 [V51 实测](../validation/复合片段定格与完整音画时钟实测_2026-10-18.md)。

额外门禁诊断发现：10 fps /4.01 秒根项目的 MKV 为 41 帧、192,480 立体声采样帧；同项目 MP4 因视频/音频尾部时长差 90 ms 超过既有 80 ms 门禁拒绝发布。任意低帧率非整帧交付仍未验收，不能用主样例与根半开区间测试替代这项门禁一致性。
