目标是补全当前只保留源开头缺口的实现：在源音频中途存在时间戳缺口或单调PTS下的区间重叠时，剪切、倒放、变速、嵌套、R3输入和多机位分析必须消费同一个作者源时钟。不能靠启用软async伸缩或忽略重叠来规避。

以当前V90候选的263产品输入为独立开发基线；其2084完整回归与发布尚在原任务中推进。本实验的后续完整门禁必须绑定实际发布V90，不能以候选拷贝或专项通过代替父版发布。

| 编号 | 必须实现与验收的约束 |
|---|---|
| ANC-01 | 以实际解码帧的PTS、nb_samples、原生采样率、声道和流time_base建立索引；保留相对容器原点，不能用容器duration推定内部连续 |
| ANC-02 | 以原生采样格表示分段。源内部正缺口补零；实际解码顺序中后来的帧覆盖同一源区间较早样本。正缺口、重叠、交替出现均须真实原生样例，不把重叠简单拒绝当成功能完成 |
| ANC-03 | 在PTS量化的半tick容限内保持连续样本，不因粗容器时基把正常1024样本包反复剪短或补零；精确原生采样时基下的真实单采样跳变需要独立核验 |
| ANC-04 | 已有源首缺口、非零容器原点、负PTS、解码器实际skip/discard和EOF必须与内部区间共用索引。压缩源以实际解码PCM和有效帧索引为数值参考，不与编码前PCM作无损相等声明 |
| ANC-05 | 连续源保持原通路和float上采样精度；禁止中间s16再量化。软async漂移补偿仍关闭；设备仿射校准与单个源内的硬缺口整理是不同层次 |
| ANC-06 | scalar选择、reverse、identity/非恒速曲线、nested、R3和多机位特征提取必须一致使用归一后的源时钟；需要保持可编辑原始资产引用、源范围和显式主音轨 |
| ANC-07 | 只在需要时生成派生原生float PCM；索引与缓存绑定源SHA、规范参数、FFmpeg/ffprobe版本或SHA、分段时钟、采样格式、协议版本和全部派生文件SHA。不得只信size/mtime |

## ANC16 队列复用中的合法空派生文件

连续源索引固定文件集保留0字节替代`audio.pcm`，表示继续使用原素材，不是缺失波形。队列复用必须把该文件的0长度和空内容SHA纳入派生清单及复制前后核验；不得跳过它、伪造波形或关闭依赖核验。原始素材、运行时和成功成片仍须非空。合法空派生变为非空、非空派生截断为空、文件缺失均拒绝复用。

首次2145完整回归有4个队列失败，修复后的31专项已通过；当前新增64方法，完整2148及92项隔离安装待实际终态，不能使用旧2145或旧61结果代替。历史音频媒体只比当前少这2个队列文件变更，其余265输入相同；新安装会重做媒体并核对原无损RGBA/PCM结果。详见[失败与修复](../validation/源音频硬缺口与重叠缓存独立实验_2026-10-21.md)。
