# 本地运行策略与远程引用审计契约 v0.1

| 字段 | 内容 |
|---|---|
| 文档编号 | SPEC-LOCAL-POLICY-001 |
| 状态 | 有效 |
| 版本 | 0.1.0 |
| 日期 | 2026-10-14 |
| 适用范围 | `ai-ad-editor` 运行时、项目产物和生产 Skill |
| 后端 | 原生 Windows、本机 Python、本机 FFmpeg；网络关闭 |

## 1. 目标

产品运行时必须能够在断网环境完成项目创建、素材处理、时间线编排、渲染和质量检查。远程媒体、远程模型、闭源服务地址和在线下载入口不得进入可执行项目产物，也不得被转换器、Skill 或本地模型适配器静默调用。

研究文档可以保留公开仓库和许可证引用，供审计使用；这些 URL 不属于运行时输入。生产 Skill 只允许描述本地 CLI、本地文件、本地模型目录和本机可执行文件。

## 2. 允许和拒绝的引用

允许：

- 项目内相对路径、绝对本地路径；
- `local://` 和 `file://` 元数据引用；
- 已存在且由调用方显式提供的本地模型、字体、LUT、媒体和工具路径。

拒绝：

- `http(s)://`、`ftp(s)://`、`s3://`、`gs://`、`rtmp(s)://`、`rtsp://`、`ws(s)://`；
- HeyGen、OpenAI、ElevenLabs、Fish Audio、Gemini、Kling、fal.ai 等在线或闭源提供方标识；
- YouTube/Vimeo 下载、在线素材目录、远程 webhook、云渲染和在线 npm/包安装作为运行前提。

## 3. CLI

```powershell
python -X utf8 -m ai_ad_editor policy audit --project .\work\demo
python -X utf8 -m ai_ad_editor doctor --project .\work\demo
```

`policy audit` 只读取项目下的 JSON/JSONL，不访问发现到的地址；报告会给出扫描文件数、失败字段和远程引用的 SHA-256 摘要，不把完整敏感值写入日志。发现违规时返回 `POLICY_REMOTE_REFERENCE`，退出码为 2。

`media ingest` 的 `--source-url`、`--license-url` 和 `--evidence` 只接受本地路径或 `local/file` URI。OTIO/MLT 导入只接受本地媒体引用；远程 `target_url` 在转换前拒绝。

## 4. 失败和审计证据

| 错误码 | 触发条件 | 结果 |
|---|---|---|
| `ARGUMENT_INVALID` | 单个命令参数包含远程 URI 或闭源提供方标识 | 不启动 FFmpeg、不写项目 |
| `POLICY_REMOTE_REFERENCE` | 项目 JSON/JSONL 产物包含远程/提供方引用 | 审计失败，报告保留字段路径和摘要 |
| `POLICY_SCAN_PARSE_FAILED` | 项目产物不是可解析 JSON/JSONL | 审计失败，保留文件路径和解析错误 |

审计是确定性字符串和 URI 检查，不声称能够证明任意本地二进制或模型内部没有网络行为。发布前仍需对工具版本、许可证和 Windows 防火墙策略进行独立复核。

## 5. 能力边界

本契约解决的是“运行时不主动联网、项目不接受远程引用”的底座约束，不把本地模型的质量等同于云端模型，也不把公开仓库链接视为已安装程序。所有本地模型必须由调用方预先放置、登记版本/哈希和许可证，系统不会自动下载权重。
