本轮新增人物视频抠像，关联差异 #55/#94/#115：`rvm-onnx-cpu-matting-v1` 已完成本地真模型、透明 MOV、两背景合成及透明 WebM 的功能闭环。24 项专项覆盖循环状态、音频/显示归一化、哈希、取消/恢复/权利；[实测与质量缺口](./RVM本地人物抠像与透明成片实测_2026-10-16.md)明确记录首帧和手持物丢失，广泛广告质量仍为 `degraded`，不能将这些差异标为全面关闭。

最新 #56 增量为 LaMa 逐帧区域修复与 VACE 实验性提示词/联合窗口生成填充。VACE 本地 CUDA、32 帧/3 窗口/30 步、音频/入轨/MP4、29 项完整性和像素保留已有[正式实测](./VACE本地多帧编辑与生成填充实测_2026-10-16.md)，前序正式基线完整回归 338/338；本轮显式 shift/1/2/4 倍输入增量专项 41/41、完整回归 344/344 通过，新正式受控链路成功，87 份源码前后不变，详见[本轮证据](./evidence/vace-profiles-20261016.json)。五组同源参数校准全部完成，暗补丁未消除，默认值不变；色差融合当时为未接入的 NumPy 原型，现已显式接入，见下段。但自然镜头有明显色块、形体残影和纹理不连续，部分抽样帧差于匹配输入的 LaMa；受控 30 步仍有暗矩形补丁。LaMa 仍有涂抹与交叠残留。#56 保持 `degraded`，不能整体转为 `verified`，也不表示通用视频生成/编辑或剪映效果已完成。

本轮 #56 增加共享 harmonic 区域修正、选区预算/收敛及父进程核对、失败回滚和 LaMa 惰性加载；宿主规划保持标准库。完整 363/363（含 73 项融合子集），89 份源码前后不变；LaMa 受控/自然/全空及 VACE 受控完成最终原生交付，独立像素/音频核对通过。LaMa 自然仍有腿状残留与纹理涂抹，#56 保持 `degraded`，见[实测](./本地区域色差融合实测_2026-10-16.md)及[机器证据](./evidence/repair-blend-smoke-20261016.json)。

## 1. 状态枚举

| 状态 | 含义 |
|---|---|
| `proposed` | 产品目标或研究建议，尚未形成契约 |
| `contracted` | 已写入 schema/CLI/模块契约，但没有实现证据 |
| `implemented` | 代码路径存在，尚未完成完整回归 |
| `verified` | 固定版本、固定样例和质量门禁已通过 |
| `degraded` | 只能近似、固化或部分支持，差异已记录 |
| `blocked` | 依赖、许可证、平台或安全门禁阻断 |
| `unsupported` | 当前路线明确不支持，必须有替代或拒绝策略 |

## 3. 单项验收字段

后续应将此矩阵扩展为 CSV/数据库，至少包含：

`capability_id`、`matrix_row`、`requirement_id`、`priority`、`status`、`owner_module`、`backend`、`schema_path`、`cli_command`、`fixture_id`、`expected_quality`、`license_gate`、`evidence_path`、`last_verified_at`、`known_limits`。

例如“位置/缩放/旋转关键帧”应登记为：P0、项目 schema 的 `keyframes[]`、`timeline compose`、fixture `P0-003`、状态初始为 `contracted`，只有渲染样例通过后才改为 `verified`。

## 4. 状态推进规则

1. 新能力先进入 `proposed`，写清用户价值、输入输出、风险和许可证。
2. schema、CLI 或模块契约完成后进入 `contracted`。
3. 有代码和单元/契约测试后进入 `implemented`，但此状态不等于视觉质量通过。
4. 固定版本、固定样例、媒体质量和权利门禁全部通过后进入 `verified`。
5. 近似、固化、外部模型或版本限制必须进入 `degraded`，并关联转换报告。
6. 许可证、平台、性能或安全阻断进入 `blocked`；明确不做的能力进入 `unsupported`。

## 5. 发布门禁

发布候选必须生成覆盖摘要：P0 `verified` 数量、P0 `implemented` 但未验证数量、P1/P2 未完成数量、`degraded/blocked/unsupported` 清单，以及每项的替代方案和风险。没有摘要就不能把“达到剪映水准”写成总体结论。
