本轮候选将显式 `settings.pixel_pipeline.engine="float32-native-v1"` 工程的 `preview frame` 和 `preview range` 接入同一原片窗口、FloatTimeline 及作者音频图。原项目、素材引用、源区间、关键帧、混合和嵌套时钟保持可编辑。默认后端迁移及全剪映功能等价继续属于完整产品目标。

## 1. 选择与共同执行路径

| 编号 | 要求 | 实现边界 |
|---|---|---|
| FP-01 | 显式浮点工程必须使用原生浮点预览，不可静默进入旧视频滤镜图 | 复用标准 `FloatRenderContext`、`NativeSurfaceSource`、`FloatTimeline`；原生源 SHA、信号、YCbCr 采样、几何与算子限制一致 |
| FP-02 | 先建立完整作者帧宿主，再抽取 `[start_frame,end_frame)` 作者帧号 | 不将源缩略图、局部序列重置或重新起算的关键帧充作时间线预览；嵌套倒放及原生 VFR 保留原展示区间 |
| FP-03 | 区间参考保存直通 Float32 视频和 Float32 PCM | `master.nut`：straight `gbrapf32le`，明确 BT.709 基色、linear 相对传递；音频为既有作者音频引擎生成的 48 kHz 双声道 `pcm_f32le` |
| FP-04 | 帧预览有明确的整数交付边界 | `frame.png` 为真实 RGBA16 PNG；在作者明确的输出传递函数之后执行 nearest-even 16 位量化，alpha 独立保留 16 位 |
| FP-05 | 缩放发生在线性光完整合成之后 | 在共同线性工作域对预乘 RGB/alpha 双线性重采样，再返回 straight 表面。像素中心映射为 `source=(target+0.5)*ratio-0.5`；不宣称大比例缩小的面积抗锯齿 |
| FP-06 | MP4 是另行生成的观看副本 | 从线性 Float32 参考在黑色背景上线性合成，显式转换至 BT.709 OETF / YCbCr / limited / left chroma，H.264 + AAC；不将其作为 alpha、Float32、PCM 精度或 HDR 的参考 |
| FP-07 | 音频区间与视频结束独立 | 样本端点为作者显示帧时间向上取整至 48 kHz，并在作者结束样本处截断。视频的最后一个完整 CFR 帧可晚于音频结束；不得用共同 `-t` 静默裁掉尾部 |
| FP-08 | 作者、源及运行时内容决定缓存身份 | 保存完整作者设置/信号、请求、素材和权利账、实际本地代码、FFmpeg/FFprobe、NumPy Python/原生模块/DLL 内容 SHA。恢复原 mtime 和大小不构成相同内容 |
| FP-09 | 命中缓存只复核身份与产物 | 命中不新建帧宿主、不解码、不编译音频图、不运行编码器或模型。仍需读 SHA；缓存及可编辑收据不是外部签名 |
| FP-10 | 失败和取消完整清理自有执行资源 | 字节队列最多 4×64 KiB；所属线程、子进程、provider 在缓存发布前结束。失效产物拒绝，用户显式 prune 后重建；既有导出目录不覆盖 |
| FP-11 | 空间准入按实际参考精度估算 | 区间视频 16 字节/像素，PNG 至少 8 字节/像素，另计音频、派生交付及暂存。最多 3,600 帧、256 缓存条目；这是磁盘准入，不是进程总 RSS 上限 |
| FP-12 | dry-run 不开原生 provider 或写缓存 | 校验参数及显式信号、计算身份并检查现有缓存；不宣称已完成像素解码或渲染质量验收 |

## 2. 预览参考与正式交付

区间参考固定为 BT.709 linear Float32，便于检查尚未整数化的合成结果。它可以保留由变换、混合和透明度产生的小于一个 RGB16 码阶的变化。`range_policy` 仍须明确为 `reject` 或 `clip`；格式能装载负值和超一值不等于本轮接纳 HDR 或放宽作者交付约束。

PNG 使用作者输出信号，区间参考使用线性信号，MP4 使用 BT.709 OETF。三个文件承担不同的检查用途，收据必须分别记录信号、精度和转换，不可仅复制色彩标签。像素比较必须选择相同信号域并按明确的最终量化边界转换。

复用既有作者音频图，继续支持已接入的反转、冻结、路由和本地伸缩。独立检查每个 PCM 样本、视频帧和重置后的展示时间戳；AAC 编码不构成样本精确参考。

## 3. 需要继续完成的产品范围

默认后端尚未迁移；标准浮点宿主尚未接入的滤镜、转场、字幕、裁剪、跟踪、羽化及全局调整继续明确拒绝。后续必须移植并验证这些功能，不能以拒绝行为代替最终完整实现。

源 SAR、旋转/显示矩阵、隔行、ICC、PQ/HLG/HDR、长片、长 GOP 随机访问、并发总 RSS 和自然素材质量仍需单独实现与验收。原片导入的既有大小/时长限制不因预览接入而解除。

本轮验收应包含独立灰阶、全部 alpha16、亚 RGB16 变化、VFR/嵌套时钟、线性预乘缩放、作者 PCM 端点、缓存内容变更与损坏、真实取消/编码失败、安装版执行及真实 CLI 样例。测试数按源码、安装版和完整回归分开记录。
