# 本地分割蒙版轨迹与锚定契约

| 项目 | 内容 |
|---|---|
| 文档编号 | SPEC-MASK-TRACK-001 |
| 状态 | 有效 |
| 日期 | 2026-10-16，Asia/Taipei |
| 范围 | `media track`、`media track-bind`、`media reframe` 的显式已登记蒙版输入 |

三个命令增加 `--mask-asset-id`，与模板 ROI、模型适配器和对象 ID 选择互斥。此时源必须为已登记视频，蒙版必须为已登记视频；蒙版中全部选中像素的半开包围框构成一个已由调用者选定的目标，不自动拆分对象或修复漏抠。默认以 alpha 严格大于 127 选中，黑白视频须显式 `--mask-channel luma`。

`--mask-source-start-seconds` 默认 0，定义蒙版首帧对应的源显示原点时间。源范围由既有 start/end 决定，reframe 默认取片段源裁切。范围必须被源和蒙版时长覆盖；显示方向/SAR 归一化后的纵横比须匹配（至多取整产生的一像素误差），不同画面裁切不能通过缩放静默对齐。蒙版来源/源身份的对应关系仍由调用者复核。

复用[编码蒙版核验](./本地蒙版逐帧核验与检查点契约_v0.1_2026-10-16.md)：`--mask-max-edge 1280`、`--mask-max-frames 4096`、`--mask-budget-mib 256` 和可选 `--mask-expectations`。存储预算不代表总 RAM/VRAM。显式 `--mask-scene-cut-frame` 标出零基蒙版输出帧；一个跟踪范围不能跨切点，须分段执行。dry-run 只预检，不解码或写入报告。

逐帧框中心/宽高归一化到源显示坐标。`confidence=1` 只表示存在非空选区，**不是模型置信度或分割准确率**。范围内任何空选区默认失败，避免将消失或完全遮挡的目标伪造成连续轨迹。边界不落在采样时刻时线性插值框；片尾至多一帧保持最后观测，二者均须记录。`--step-frames` 和 `--max-samples` 确定性稀疏采样，保留两端；不以重复末帧拉伸运动时间。

存在失败检查点或空选区时，保留实际蒙版核验与失败跟踪报告，返回退出码 2，不改项目/权利台账。报告限制在项目 `validation/` 内 JSON，不得覆盖期望文件。源/蒙版摘要在执行前后核对；没有回退到模板、其他模型或线上服务。

失败诊断具有 `report_version` 和 `status=failed`；正常异常回滚后保留当前 `AppError.path` 明确引用的版本化失败 JSON，无关或成功报告不享有此保留语义，详见[事务契约](./跨文件项目事务恢复契约_v0.1_2026-10-15.md)。解码失败或执行期间输入变化仍报实际错误，不伪造轨迹。

成功报告可生成位置关键帧；绑定可复用既有源片段的裁切/变换/画布重算，重构图复用既有 crop 计划。应用前快照与事务保持有效。源和蒙版权利依赖都写入目标片段，蒙版继承的模型/素材权利继续闭包检查；项目包和后续渲染不得绕过权利门禁。

现有画布编译器仍使用源登记的编码栅格；固有 90°/270° 旋转或非方形 SAR 导致显示尺寸变化时，源片段画布绑定与重构图应用明确拒绝，须先烘焙显示几何。普通源片段的裁切、图层旋转、缩放、镜像等继续由既有编译器处理。报告模式可核对显示归一化坐标，不能由此声称完整固有几何已支持。

必须验证真实编码蒙版、逐帧框与时码、范围偏移/插值/抽样、空选区/切点/期望失败、哈希/路径/预算、标签与竖屏实际渲染、源变换重算、权利阻断及项目包保留。自然模型选区误差仍会影响轨迹；此增量不关闭自然分割、姿态锚定、遮挡身份恢复或完整剪映效果验收。

已执行的受控全帧渲染、透明标签补边修复、自然选区/标签像素失败及完整回归终态见[实测](../validation/本地蒙版驱动锚定与重构图实测_2026-10-16.md)。契约有效不表示自然分割或完整剪映等价已验收。
