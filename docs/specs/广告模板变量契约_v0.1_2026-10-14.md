# 广告模板变量契约 v0.1

## 目的

模板是 Agent 批量生产广告变体的输入契约。模板只引用项目内已经登记的素材、字体和本地操作；变量解析不访问网络、不调用剪映运行时，也不执行任意表达式。

## 变量声明

`variables` 是声明数组，每项至少包含 `name`。名称必须匹配 `[A-Za-z0-9_.:-]+`，同一模板不能重复声明。支持的 `type` 如下：

| 类型 | 约束 |
| --- | --- |
| `any` | 保留 JSON 值类型，默认类型，适合兼容旧模板 |
| `string` | 字符串，可选 `min_length` / `max_length` |
| `number` | 数字（不含布尔值），可选 `min` / `max` |
| `integer` | 整数（不含布尔值），可选 `min` / `max` |
| `boolean` | JSON 布尔值 |
| `asset` | 非空素材 ID 字符串；项目应用阶段仍必须检查资产存在和权利 |
| `color` | `#RRGGBB`、`#RRGGBBAA`、`rgb/rgba(...)` 或命名颜色 |
| `enum` | 字符串且必须出现在 `values`、`choices` 或 `enum` 数组中 |

`required: true` 且没有 `default` 时必须由调用方提供。默认值会复制到解析结果，不会修改调用方传入的变量对象。变量类型错误、枚举值不存在、范围越界和重复声明都在实例化阶段返回结构化参数错误。

## 占位符

- 单独的 `{{name}}` 保留变量原始 JSON 类型，因此数字、布尔值和对象可以用于操作字段。
- 字符串中的 `{{name}}` 会执行文本替换，例如 `"{{headline}} · {{aspect}}"`。
- 对象、数组等复合值不能嵌入字符串；必须使用单独占位符。
- 未提供的占位符会使实例化失败，避免静默生成带有未替换标记的成片。

## 快照与可复现

实例化结果带有 `template_snapshot`，记录模板 ID、版本和解析后的变量（包括默认值）。批量变体还会把快照写入每个变体项目的操作报告，便于 Agent 重放、审计和定位某个广告版本使用的输入。

## 与权利和本地策略的关系

变量解析本身不授予素材权利。应用模板后，项目验证仍需检查素材是否存在；发布或批量发布必须通过 Rights Ledger、目标渠道和本地运行策略门禁。模板中的 URL、云端 provider、远程媒体或隐式下载引用会被策略审计拒绝。

## 当前边界

本版本完成类型/范围/枚举校验、内嵌替换和无副作用默认值解析。模板操作仍沿用现有 Agent Project 变更集边界；复杂模板槽位图、条件分支、表达式计算和跨项目资产复制需要后续版本以显式操作契约补齐。
