## 1. 结果与实际缺陷

完整 **506/506，947.834 秒**；96 份 Python 产品源码/测试和 1 份 Schema（共 97 份）执行前后原始字节摘要一致；15 项新增专项为完整套件子集，固定旧版同测 15 方法失败（含 subTest 共 18 条失败记录）。九组实际成片，123 次正式 CLI（其中 39 次渲染、9 次质量、9 次本地策略）；独立复核 632 个新版主帧、1480 个空白/覆盖率对照帧，旧版 632 帧另计。最大 RGB 误差由旧版 9.93–54.91 降至 2.22–3.61（阈值 6）；源帧误差为 0，同组各变体解码 PCM 摘要一致。0 新模型推理。受控 8-bit 编码 RGB 下的字面/框/阴影/描边颜色、透明度及已测淡入/图层 opacity 子项通过；动态尺寸内嵌颜色显式近似，ASS、逐词+动画、随机/有状态位置组合、通用 CJK/RTL、超低 alpha 高精度、HDR/线性光、定格/VFR/群组、4K 性能和完整剪映等价未验收。

固定旧版本为 `da87598184b61310a7958a3d17fee4b210545f15`，直接由本地 Git 原始 blob 归档后运行，未用新代码模拟旧版。探索性原生/编译探针显示：透明底上 `white@0.5` 的 alpha 原为 63/255、RGB 约 126–127，颜色和覆盖率已被反复相乘。新路径在不透明黑底单独提取每个组件的不透明白色覆盖率，用 FFmpeg 实际解析的直通 RGB 和 alpha 重建，再按框、阴影、描边、字面的顺序 source-over；`@0.5` 实际为 127/255，`@0x80` 为 128/255。专项直接检查原始 RGBA，实测再核验实际编码 RGB。

## 3. 独立数值复核和可见预览

生成器从实际不透明控制和空白底片恢复逐像素覆盖率，计算作者颜色和 alpha 的 source-over 参考。独立审计不导入产品或生成器，以 RGB 三通道最小二乘恢复覆盖率、闭式透射率乘积计算重叠，以独立 4096 区间八点 Gauss 积分复核嵌套时钟；生成器使用逐通道比率均值及递推，故两次误差数值略有差异。嵌套时钟最大差 5.54255364937e-08 秒，阈值 2e-6。旧版每组均明显越过 RGB 门槛，新版九组通过。空白/覆盖率控制仍复用产品原生布局，不构成对所有字体塑形本身的独立真值。

## 5. 复现、权利与原始字节

使用原生 Windows Python、FFmpeg 8.1，生成器另需已有本地 NumPy/Pillow/fontTools；不调用 GUI、Docker、WSL、虚拟化、服务或下载。公开原视频/脉冲为前轮 CC0 自制夹具的原字节副本，生成器与源脚本摘要、每个输入/输出、帧率/时长/帧数、全部调用/操作及编码参数在证据中。字体从已有本地 DejaVuSans.ttf 提供，[字体许可证](../assets/text-paint-20261016/font-license.txt)原样保留，不分发字体二进制，也不把字体重新标为 CC0。见[来源](../assets/text-paint-20261016/fixture-provenance.json)。

```powershell
# 使用已经存在、具备 NumPy/Pillow/fontTools 的原生 Python；输出目录必须不存在。
& $nativePython -I -B -X utf8 scripts/smoke_text_paint.py `
  --output docs/assets/text-paint-reproduction `
  --work product/.runtime/text-paint-reproduction `
  --font $localDejaVuSans --font-license $localDejaVuLicense
```

[公开生成器](../../scripts/smoke_text_paint.py)只做编排、控制生成、解码与数值比较；旧/新正式输出均经过对应真实 CLI。最终源码/测试/Schema、旧版 Git blob、生成器/时钟参考、颜色探针执行器、全部 86 份公开文件和原始日志均有 SHA-256。每次正式渲染前后作者 assets/settings/sequences 和原始 Rights Ledger 摘要一致；正常输出登记另计。文档及 14 个本地技能审计见[文档审计](./evidence/docs-audit-text-paint-20261016.json)与[技能审计](./evidence/skills-audit-text-paint-20261016.json)。

## 6. 保留缺口

受控 8-bit 编码 RGB 下的字面/框/阴影/描边颜色、透明度及已测淡入/图层 opacity 子项通过；动态尺寸内嵌颜色显式近似，ASS、逐词+动画、随机/有状态位置组合、通用 CJK/RTL、超低 alpha 高精度、HDR/线性光、定格/VFR/群组、4K 性能和完整剪映等价未验收。一般单行位置的随机/有状态表达式没有在本轮组合中验收；逐词/多行仍执行既有位置拒绝规则。组件掩码独立求值，不把受控位置样例推广到所有表达式。现有复杂文字/文件动画警告继续保留。八位整数量化、颜色探针本机构建绑定、半透明组件先合并再乘图层 opacity 的语义均公开；本轮未测长片吞吐、峰值内存或所有缩放/混合组合。
