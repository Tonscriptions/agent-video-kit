# 字词边界模型对照核验契约 v0.1

目的：解决 V49 将稀疏 CTC token 发射峰直接作为词起止所暴露的偏差。原[CTC 门槛与失败](../validation/离线CTC字词强制对齐实测_2026-10-18.md)保持不变，不能通过固定加减时长、均匀分字、移动参考、删除难词或提高误差容忍度过关。

1. 先按实际词/字符定位训练方式、许可、原生 Windows 可运行性和已有资源选择候选。Qwen3-ForcedAligner-0.6B 的模型卡声明 Apache-2.0，须固定模型 LFS、源码提交和原许可后审读/运行；不调用其云接口、URL 音频、Web UI、vLLM、Docker 或安装脚本。代码 MIT 不替代 Charsiu 权重目前缺失的独立许可；Where Words Begin and End 发布模型的 CC BY-NC 不作为本项目默认可商用内核。
2. 现有 Whisper-small 的显式原文 teacher-forced cross-attention/DTW 可作独立候选；必须消费用户原文并保留可逆 token→码点范围，不以自动转写或改稿代替强制对齐。模型输入不得读取人工参考起止。
3. 保持原六词音频、原稿和作者放置参考逐字节不变；首要门槛仍为所有词起止最大绝对误差 ≤2/30 秒。任何失败如实保留，不以模型已成功返回或平均误差掩盖最大值。
4. 在取得新候选结果前另生成固定留出：使用 FFmpeg Flite 的另一声音 `rms`，词表 `LOCAL VIDEO EDITOR KEEPS EVERY ORIGINAL WORD`，间隔依次 0.2/0.35/0.25/0.4/0.3/0.15/0.45 秒，初始静音 0.3 秒，仍以绝对有符号 PCM ≥32 修剪。留出最大边界误差门槛相同，逐词报告；它仍是合成词块参考，不是自然连续语音逐音素真值。
5. 本机中文 S4 原稿用于实际原文覆盖、繁简行为、有限/有序/在源范围内的边界和资源证据。不公开原声；没有独立精标时不得宣称中文精度通过。唱歌、多人重叠、噪声口音和广泛自然精度保持开放。
6. 取得与解包是独立开发步骤，原文件/原失败/原摘要保存在 E。运行必须显式本地模型、safetensors、已有原生 Python，安装网络守卫、离线环境并记录实际模块路径；没有模型/设备不得偷偷下载、换模型、换设备或调用线上服务。
7. 真实前向、模型进程、CLI、研究检查与产品回归分别计数。研究候选通过前不注册为正式能力；若接入产品，须补来源/实现读锁、请求与样本约束、OOV/文字映射、预算、取消超时、事务/权利、安装包、完整回归和 README 原片/GIF 的实际证明。

本契约不把单个合成样本门槛改称剪映全功能等价。是否采用由本机实际边界、不可丢失的原文映射、运行资源和许可共同决定；作者宣称的外部 benchmark 指标只作为候选选择依据。
