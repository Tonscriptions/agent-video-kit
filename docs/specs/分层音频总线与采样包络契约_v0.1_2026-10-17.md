## 1. 总线层次与处理次序

子序列的音频不再绕过父容器直接送到根混音器。保留既有源裁切、倒放和速度映射，先处理各片段自己的音量、效果、声像与包络；在该片段所属序列内建立音频总线：

1. 确定该序列自己的音轨 mute / solo，排除不可听分支。
2. 完成片段的源时钟处理、音频处理与采样点放置。
3. 在当前序列内，为显式请求闪避的 music/bgm/background 输入提供 voice/dialogue/narration/speech 检测信号。
4. 同一轨道的子输入先求和，再统一执行该轨道的静态音频处理。
5. 把当前序列的轨道总线求和。
6. 子序列容器的 volume、效果、pan 和 fade 作用于这幅音频结果一次。
7. 裁切到容器的采样窗口，再送入父序列对应轨道。

整个过程使用同一张本地 FFmpeg 滤镜图，不生成容器中间音频文件。压缩器、降噪、均衡和响度等非线性/有状态处理不能通过把同一设置分摊给叶片模拟。轨道处理同样在其片段合并后执行。

根序列及所有子总线使用浮点加法，`amix normalize=0`。输入数量、额外静音输入或片段结束不会自动改变其他轨道增益。两路同相、同幅信号会相加；反相会按真实采样抵消。总线可超过单位峰值，浮点输出保留它；整数编码可能削波，须独立检查质量并显式配置压缩/响度处理，不自动加限制器。

这会改变旧版按输入数量自动归一化的多轨成片音量。旧工程作者字段不重写，历史成片及其证据保持原字节。单一输入的恒等控制需独立重验，不能用结构兼容承诺所有旧多轨成片声压相同。

## 2. 采样时钟与自动化

内部布局使用 48 kHz。片段或容器的全局半开区间 `[start_tick,end_tick)` 对应：

```text
first_sample = ceil(start_tick × 48000 / ticks_per_second)
end_sample   = ceil(end_tick × 48000 / ticks_per_second)
```

使用有理数计算，不先四舍五入到整数毫秒。一个 90 kHz tick 的延迟对应本例中的第 1 个输出采样；不会提前到第 0 个采样。容器的滤镜尾音在 end_sample 截止，外部空档保持静音。根输出采样数继续按已声明序列时长的 48 kHz 最近整数约定补齐/裁切；任意非整帧发布时长仍受已有发布门禁约束。

动态 volume 和数字 pan 在 `aeval` 中逐采样求值，避免增益依赖解码音频帧的批次大小。容器的自动化属于**容器所在序列的作者时钟**；容器自己的 reverse/speed 只改变其内部内容，不反转自身的包络。外层倒放、裁切或非线性变速会反向映射内层容器的作者时间，再求内层原关键帧和 fade。祖先 trim 后包络不从零重启。

volume / audio.volume 的值范围为 0..4。pan 使用既有 −1..1 立体声 balance：向右时衰减左声道，向左时衰减右声道，保留左右源独立内容；它不是单声道等功率声像或空间音频。原有受控 raw FFmpeg pan 表达式入口保留。

片段 freeze 的音量关键帧沿用既有冻结时钟；片段 fade 仍按实际输出局部时长执行。嵌套 freeze 的联合音画语义不由本轮接受。

## 3. 控制范围与路由

音频静音不会隐藏视频。`clip.audio.mute/muted` 关闭该音频片段或子序列音频；视频轨道的 `audio.mute/muted` 只关闭经它引用的序列音频。`track.muted` 继续表示整条轨道不参与渲染。

solo 按每个作者序列分别计算，只选择该序列内的 audio 类型轨道。子序列内的 solo 不会静音父级或其他子序列的音轨。根 audio 轨道的 solo 不隐式选择视频轨道上的容器；这种视频容器的音频由其显式 audio 设置控制。

闪避在当前序列内处理，不穿透已合并的子容器。父级需要把整个容器作为 music 或 voice 时，显式给容器 audio.role。多个声音输入各自拆分出检测分支，再合成检测总线；多个待闪避输入各拿独立检测输出，避免复用已消费的滤镜 label。只处理明确请求闪避的音乐输入。检测信号取片段/子容器处理后的输入，位于当前轨道静态处理之前；阈值是现有本地固定策略，不是广播级自动混音。

## 4. 本地处理参数与校验

片段、轨道和容器共用既有本地处理器：volume、denoise/noise_reduction、compressor、equalizer/eq、highpass、lowpass、dialogue_enhance/voice_enhance、pitch_semitones、reverb、loudnorm、pan。处理顺序按此列表执行，随后是显式 fade 包络。当前效果参数为静态值；音量/数字声像可用现有片段关键帧逐采样自动化。

轨道没有片段作者包络，`track.audio.fade_in/out` 明确输出未支持告警；请把 fade 写在片段或容器上。轨道静态效果位于轨道求和之后。未知/未定义的音频路由字段不能作为已支持 send/return 的证据。

关键数字必须有限且在本地滤镜支持范围内；拒绝 bool 充当音量，拒绝负音量/负 fade、越界压缩器和不匹配的回声抽头。回声 delays/decays 为以 `|` 分隔的非负数字，数量相同且不超过 32。非法参数在时间线变更时拒绝并保持项目与 Rights Ledger 原字节，不等到渲染进程失败再回滚。

## 5. 可审计结构与核验

manifest 的 `audio-track-bus` 保存所属序列容器、轨道、输入数、静态处理与禁用归一化的混音方式；`sequence-audio-bus` 保存父容器、源序列、采样窗口、作者时钟、处理次序和 `intermediate_files=0`。`sequence-audio-root` 保存根输出采样数、浮点求和与 `automatic_limiter=false`；叶片音频输入记录全局开始采样和长度。该结构只证明实际编译路线，不能取代声音核验。

回归入口为 [test_audio_buses.py](../../product/tests/test_audio_buses.py)，包含受控求和、静音、solo、深层增益、外层裁切/倒放/非线性时钟、后置压缩/均衡、回声窗口、采样对齐、多检测支路和失败回滚。公开复现入口为 [smoke_audio_buses.py](../../scripts/smoke_audio_buses.py)。无损 float MKV 的全部采样点是精度检查信号；另行转出的 AAC MP4 只是有损试听/观看文件。GIF/波形预览无声，不能代替听审。

参考对线性求和、增益和时钟使用独立 NumPy/数学公式；对压缩器/均衡，用先独立求和的 PCM 送进原生 FFmpeg。后者验证效果处理位置，未独立验证 FFmpeg 算法或主观效果。所有原输入、旧失败、新结果、参考、来源/许可和哈希分别保留。

## 6. 持续开放的完整产品要求

当前没有任意命名的 send/return、外部侧链图、反馈路由、空间/环绕声、响度目标自动投放、通用效果参数自动化、嵌套定格、VFR 联合时钟、长片资源预算或主观混音验收。

此前 R3 极短音高、apart 反相混合和听感失败保持开放。V29 当轮诊断中，已有 windowed atempo 对非线性恒定 DC 输入出现幅度变化/局部静音；“相同变速信号上的包络正确”不关闭该声音内容失败。真实音乐、语音、瞬态、相位、连续播放及完整剪映功能/效果等价必须继续取得相应证据。

## 7. Agent 组合示例

下面沿用正式 B02/B08 的操作形状，假设已有 `child` 子序列、`seq_main` 和 `track_video_1`，目标区间没有未经允许的重叠。把现有 2 秒子序列作为一个容器，先将子输入求和，再乘 0.5 并压缩：

```json
{
  "operations": [
    {
      "op": "append_sequence_clip",
      "sequence_id": "seq_main",
      "track_id": "track_video_1",
      "id": "ad_group",
      "nested_sequence_id": "child",
      "source_in_tick": 0,
      "source_out_tick": 180000,
      "duration_tick": 180000,
      "timeline_start_tick": 0,
      "audio": {
        "volume": 0.5,
        "compressor": {"threshold": 0.1, "ratio": 4, "attack": 1, "release": 50}
      }
    }
  ]
}
```

此例使用 90 kHz 工程时基。保存为项目内变更文件后，通过现有 `timeline compose --project <工程路径> --input <变更文件>` 应用；`render --dry-run` 检查总线节点，再执行真实渲染和独立质量/权利门禁。需要包络时，把现有 `audio.volume` 关键帧写在这个容器片段上，不复制到每个子片段；需要静音时设置该容器 `audio.muted=true`，内部画面继续参与合成。

正式核验：[12 组原声/成片与逐采样实测](../validation/分层音频总线与真实采样实测_2026-10-17.md)；V29 当轮 DC 诊断与音高/相位和听感失败按第 6 节保留，DC 的后续受控重验见下文 V30。

V30 后续对 V29 同字节 DC 输入做[分段上下文与完整尾部重验](../validation/分段音频上下文与完整尾部实测_2026-10-17.md)：内部零帧 82→0，六组受控 DC 完整有效区间通过。前述 V29 失败记录保留为历史，不据此关闭极短音高/apart 相位、自然声音或听感。
