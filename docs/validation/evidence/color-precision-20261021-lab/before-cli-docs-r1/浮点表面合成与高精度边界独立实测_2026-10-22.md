# 浮点表面合成与高精度边界独立实测

本实验建立时主线为V90；V91音频时钟首轮2145完整回归因4个队列问题失败，另行修复后的2148门禁由原发布任务执行，状态以主线README真实收据为准。本实验复制的是V91队列修复前的267产品输入，287个基础文件逐一相等；接入前仍须迁移两个队列文件。不把未通过的父候选称为已发布。

当前六份浮点/原生读取模块和五份测试，278冻结输入、169包内资源；59方法/77.798s/0失败/0错误/0跳过，记录58次原生执行（列表不包含读取器内部的所有ffprobe/摘要检查）。旧12/22/34/44方法的纪元和失败r7分别保留，没有合并计数。[当前纪元及字节桥接](evidence/color-precision-20261021-lab/current-epoch-r2.json)、[11份精确实验源码快照](evidence/color-precision-20261021-lab/implementation-r2/manifest.json)、[完整实验约束](../specs/浮点表面合成与高精度边界_实验_v0.1_2026-10-22.md)。

仅原生 Windows、既有 Python/NumPy/Pillow/FFmpeg 8.1；未用 Docker、WSL、容器、虚拟环境或在线模型，没有打开交互浏览器标签页。所有原片由本项目生成，可按 CC0-1.0 公开；无外部图片、字体或模型。
