# HTML 文字布局与字体覆盖实测

V46，2026-10-18。范围及预算于实现前声明在[核验契约](../specs/HTML文字布局与字体覆盖核验契约_v0.1_2026-10-18.md)。完整回归、公开样例、离线 wheel 和技能检查均取得下方终态证据，功能与质量边界分别保留。

新增 `motion html-quality` 按全部 CFR 帧实际绘制，并在独立上下文反向重绘，比较帧与布局诊断；报告文字行矩形、画面/容器的部分或完全裁切、实际平台字体与源字体的 Unicode→glyph 映射。源码或 `--from-asset-id` 已保存配方均可检查。`html-render --layout-check strict` 在编码前检查，严格模式随新配方继承，每次重建重新核验；布局预检与编码共用命令期限。

采用 OpenFilm 固定 `eefd6a8d379289102141359a4718dbab12170526` 的 MIT `cutText` 原函数，带来源头共 2262 字节、原函数 38 行，见[提取与字节证据](evidence/openfilm-layout-adoption-20261018/verification.json)。原函数用于同帧对照，产品的完全出框、独立轴裁切、body overflow 传播、字体解析、CLI 和门禁为本项目扩展；没有引入上游网络 host、Studio 或供应商。

本轮发现 V45 原创 AgentGrid 字体缺少 `O` 映射。V45 先前只验收像素/配方一致性，未验收字形；旧素材与证据保持不变。本轮保留缺字负例，另建添加原创 `O` 字形的版本。系统 fallback 的实际字体只记录元数据/摘要，其 PNG 留在本地 ignored runtime，不发布这类像素。公开出框、裁切及修复演示使用新增完整原创字体。

开发记录：第一次字体测试误以为原字体含 `O`，11 项中 1 失败；第一次 12 个浏览器场景因测试夹具把字体放入代码 files 而未登记资源全部在初始化阶段失败，未运行新浏览器质量 worker。修正夹具与预期后，12 字体检查、12 实际浏览器质量检查及后续 69 HTML 组合检查分别通过；这些是不同冻结版本的历史子集，不能与之后全量相加。加入 body 和解析总预算后，13 字体与 70 HTML 组合检查通过。首轮公开实测在第 18 次 CLI 后发现严格失败的报告被回滚清除，原调用/媒体摘要见[失败记录](evidence/html-quality-initial-20261018/terminal.json)；新增 report_version 并把预览放入 cache，随后重新核验报告与 PNG 实际存在。

标准库解析覆盖 SFNT/WOFF1 的 Unicode cmap 0/4/6/10/12/13；WOFF2 或未知字体来源保留未核验状态。glyph 非零只证明映射存在，不证明字形审美、复杂脚本塑形或中文自然排版。旋转/3D、复杂 mask/clip-path、SVG/Canvas 语义文字明确未验收；全帧 DOM 范围不等于图片中全部文字或字形墨迹边界。自然 AI 效果、声音/听审、长片/跨设备资源、干净机器和完整剪映等价继续按原路线推进。

第二轮实测完成 20 次 CLI 后，复现脚本误将工程包导入的必填 `--output` 写为 `--project`，在参数解析阶段退出 2；这是脚本错误，未产生完整通过结果。[原参数/错误/已有调用](evidence/html-quality-argument-failure-20261018/terminal.json)保留，修正后另建新目录完整重跑，没有覆盖失败记录。

## CLI

```powershell
ai-ad-editor motion html-quality --project E:\work\ad --source-asset-id title --dry-run
ai-ad-editor motion html-quality --project E:\work\ad --source-asset-id title
ai-ad-editor motion html-render --project E:\work\ad --source-asset-id title --asset-id title_v2 --layout-check strict
ai-ad-editor motion html-render --project E:\work\ad --from-asset-id title_v2 --asset-id title_v3
```

最后一条继承 strict，重新核验后编码。源码模式未明确配置默认为 off，旧配方亦为 off；显式改为 off 是配置变更，不可把该输出称为严格验收。`html-quality` 失败退出 2，运行/超时错误 6，取消 8；失败报告位于 validation，预览位于 cache/html-quality，最多 8 帧。命令只写诊断，不登记资产；strict 全帧预检和正式渲染共享总期限。实际使用的 WOFF2/未知字体、变体序列、旋转/3D、复杂裁切/滤镜和 Canvas/SVG 文字等返回未核验，严格模式不能绕成通过。
