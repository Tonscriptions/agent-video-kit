## 1. 目标与证据

为修复或生成区域提供显式可选的局部色差融合，缓解模型结果与选区边界之间的低频亮度/颜色偏差。运行位置在模型预测及窗口混合之后、原选区合成与一次量化之前。保持现有默认直接合成，不自动改写用户的编辑意图。

受控渐变样例的已保存输出，原尺寸 masked PSNR 25.171→42.841 dB，4 倍 23.971→36.808 dB；使用相同原始源、选区和既有模型输出，真值仅用于评分，没有进入修正计算。13 帧自然诊断仍有形体残影、生成色块、纹理涂抹，质量未通过。详见[诊断机器证据](../validation/evidence/vace-harmonic-diagnostic-20261016.json)。

本方向采用区域边界约束的梯度域思想；[OpenCV seamless cloning 文档](https://docs.opencv.org/4.13.0/df/da0/group__photo__clone.html)提供相关开源能力参考。本诊断使用独立的离散调和修正与已有本地 SciPy，不声称与 OpenCV 算法或效果相同；产品实现仅使用已有 NumPy，不运行 SciPy/OpenCV、下载或云服务。

## 2. 数值约定

输入为同一源时钟和画布上的原始 RGBA、模型浮点 RGB、扩张后的二值选区。只允许使用原始选区外 RGB 作为边界；在相同预测与选区下，原始待移除区域 RGB 的任意变化不得影响修正输出。原始 alpha 不进入颜色求解并须逐字节保留。

选区内求解逐通道调和修正 c：以四邻接离散 Laplacian 构成系统，边界误差来自原始选区外颜色与从模型选区内沿边界法线线性外推的颜色之差；无可用内侧邻点时使用边界内模型值。最终模型 RGB 为 g+c。画布外邻点不参与；空选区旁路，缺少任何固定外边界的全画布选区须明确拒绝该模式。

使用可报告收敛状态的有界迭代求解。迭代次数、残差、选区像素、峰值数组估算、截断数和耗时须记录；超预算、非有限数值或未收敛必须失败，不以静默近似结果发布。窗口浮点混合先于修正，浮点修正后沿用选区内羽化合成约定，最终只量化一次；蒙版外 RGB 与全部 alpha 保持不变。

NumPy 原型已使用隐式四邻接矩阵及 Jacobi 预条件共轭梯度，不依赖 SciPy；9 项独立测试、29 帧与先前 SciPy 诊断的交叉核对通过，最大量化通道差 1。原型保留 float32 修正直到上层量化，报告求解步数、残差和自有数组保守上界；预算尚未实测进程峰值，不是 RAM/VRAM 保证。代码与验证保存于[独立原型证据](../validation/evidence/vace-numpy-harmonic-prototype-20261016.json)；本轮已以共享数值内核进入产品运行路径，最终真实效果见后续实测。

## 3. 产品接入

已增加显式融合模式及有界迭代配置，进入 canonical inpainting、请求摘要、幂等、worker 报告和父进程验证。LaMa/VACE 共享同一数值内核；实际执行实现进入 adapter 完整性绑定，旧登记须明确重新登记。预算包含求解数组和既有窗口数组，不能把独立 Python/模型/显存混作自有数组限额。

恢复、取消、失败清理、无损 RGBA、原声与显式音轨应用、源/蒙版/模型权利、快照及可移植项目包沿用当前契约。该模式为逐帧空间融合，不提供跨帧运动、遮挡、对象身份或真实背景结构重建保证。

## 4. 验收要求

需要独立解析参考验证：常量/平面偏移修正、已匹配结果的稳定性、模型内部纹理保留、原始选区内 RGB 扰动不变性、空/多连通/触边/全画布选区、alpha 与选区外精确保留。还需验证非收敛、预算、NaN、取消和畸形报告会回滚，dry-run 不执行模型或写项目。

真实 LaMa/VACE 产物应完成 CLI、入轨、音频、成片和权利门禁；受控真值、自然纹理/形体/接缝及连续播放分别验收。简单渐变指标改善不关闭 #56，不授予广泛广告质量或剪映效果对标通过。

## 5. 本轮 CLI 与执行约束

统一使用 `media inpaint --repair-blend direct|harmonic`，默认 `direct`。`--blend-max-iterations` 为 1..10000、默认 2000；`--blend-tolerance` 为有限数值 0..0.01（不含 0）、默认 1e-6。两个求解配置只允许在显式 harmonic 模式使用。canonical inpainting 增加 `blend_mode`、`blend_max_iterations`、`blend_tolerance`，进入请求摘要、幂等、报告及 adapter 实现完整性绑定。

harmonic 对 LaMa 的浮点预测缩回原 ROI 后执行，对 VACE 的浮点窗口结果混合后执行，均在原选区合成前完成；此路径不提前量化。direct 保留现有输出语义。求解只使用选区外原始 RGB 和选区内预测 RGB；既有 feather 的最终合成会保留部分选区内原始 RGB，不把求解不变性扩张为羽化成片不变性。

自有求解数组使用保守上界 `24×width×height + 384×selected_pixels` bytes，排除输入和模型。常驻帧/窗口数组及浮点中间数组另计。dry-run 报告基本估算、非空选区最小/最大增量和可用预算，实际 mask 像素数在逐帧/逐窗口解码后、相应模型调用之前检查；不读取真值，也不为了估算加载模型。全画布选区在模型调用之前拒绝 harmonic，空选区不求解；预算不保证总进程 RAM/VRAM。

worker 汇总融合帧数、最大选区、求解迭代/残差比、数组上界、截断数、修正幅度、耗时与最多 16 帧样本。父进程须核对模式、计数、预算、收敛范围和样本字段，畸形结果不发布。求解检查点持续允许原有超时/取消回收进程，LaMa 改为首次有效推理时才加载权重。旧 adapter 的实现摘要变化须重新登记，不允许直接改写摘要。

宿主侧规划、预算和报告校验仅依赖标准库；NumPy 在数值计算内部导入，保持未安装 NumPy 的宿主仍可规划，而显式外部模型 Python 须已有 NumPy。隔离进程测试须主动阻止 NumPy 导入，以避免开发机已安装依赖掩盖此边界。
