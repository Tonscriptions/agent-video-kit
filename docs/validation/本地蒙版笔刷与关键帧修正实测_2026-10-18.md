# 本地蒙版笔刷与关键帧修正实测

README V43，2026-10-18。新增正式 `media mask-edit`：Agent 可以直接对编码蒙版作笔刷、框、椭圆、多边形修正，保留可编辑计划、线性/保持关键帧与明确切镜重置，并把结果交给既有修复流水线。完整 **1005/1005，1432.864 秒**，零跳过；141 文件前后字节冻结。30 新增专项包含在完整回归中，不相加。

该模块是标准库几何与原生 FFmpeg 编码，不加载分割模型、不自动推断对象、不自动追踪。与 [V42 供体研究失败](./空间与时序一致参考选择实测_2026-10-18.md)分开：没有把失败研究加入修复后端。完整产品目标仍在推进，当前不具备完整剪映等价验收。

实现复用了现有 `mask_review` 显示网格与输入校验、原生进程取消/超时、文件只读锁、项目事务/幂等、Rights Ledger 和工程包；新几何层位于 [mask_edit_geometry.py](../../product/src/ai_ad_editor/mask_edit_geometry.py)，编码与证据收集位于 [mask_edit.py](../../product/src/ai_ad_editor/mask_edit.py)。修复直接接既有 LaMa 入口，避免另建模型协议或媒体资产系统。OpenFilm 已采用的字幕分段、关联编辑、片段组和 HTML 帧时钟继续按[复用落地记录](../OpenFilm_v0.2增量复用与接入建议_2026-10-18.md)管理，这层蒙版几何由本项目实现。

## 自然场景与质量限制

这次只对此前已做 SAM2 修正的蒙版末帧添加三点胶囊笔刷，补到明确的男孩手腕位置。5 个既有检查点不变，末帧新增 261 个 alpha 像素，前 31 帧完全相同；不重新推断人体，也不把保留人物的腿认作残留。自然输入、原蒙版、新蒙版、修复视频与联系图都保留在忽略的本地路径，公开记录只有路径、SHA、计划、标量和模型执行证据。

真实 LaMa 使用原有本地权重、CUDA、`mask-grow=4`、`model-max-edge=256`、`repair-blend=harmonic`。输出在扩张蒙版外保真，音频保留，但静帧仍有背景纹理涂抹。没有新的密集分割真值、干净背景真值或时序盲评，不能根据 5/5 点通过宣称完整移除或剪映画质。#51 显式蒙版编辑可用；#55/#56 的自然抠像/移除质量继续降级。

## 开发失败与已知边界

- 首次 28 项专项有 1 个失败：测试误把项目锁退出码写为 8，实际正确拒绝为现有约定的 6。修正测试，并新增原生有理数边界/复用引擎拒绝后，30 项通过；多次专项不累加。
- 原创真实流水线随后发现 `source_version=derived:local-mask-edit` 被策略扫描识别成 URI，造成策略检查失败。停止当时旧完整回归的明确子进程树后才修改产品；改用无协议前缀的元数据值，增加真实 policy 回归，从头重跑专项/完整，原失败和停止记录保留，不计验收通过。
- 生成器初次使用 `-I` 时未将 scripts 加入导入路径，在创建媒体前退出；已修正。没有安装依赖或用联网重试。
- 第二次完整回归选用了模型专用嵌入式 Python；其 `_pth` 隔离忽略子进程的 PYTHONPATH，既有 Unicode 管道测试无法以 `-m ai_ad_editor` 找到包。原失败/主动停止记录保留，随后使用与 V41 相同的 `C:/Python313` 宿主从头回归；没有修改产品来适应这个测试环境问题。模型推理仍使用显式登记的独立原生 Python。
- 原生 NUT 夹具的 12 帧/12 fps，format.duration 只声明到 0.916667 秒末帧 PTS，不覆盖完整 1 秒帧区间。因此此蒙版输出选精确 track time scale 的 MOV；这不是所有 NUT/VFR 输入时长的全面修复。
- 仅 normalized-output 坐标和明确 CFR。切镜由调用者指定，linear 要求顶点一一对应；没有自动跟踪、曲线 easing、网格变形或语义补全。4×4 为固定采样，椭圆羽化使用近似距离。
- RGB 固定白色、音频不进入蒙版；不能把它当成保留源颜色的人像抠图。预算限制临时 raw 文件、自有像素数组和估算工作量，不限制整体进程 RSS/模型 VRAM。更长自然素材、HDR/VFR、密集边缘、发行和完整剪映等价继续未验。
