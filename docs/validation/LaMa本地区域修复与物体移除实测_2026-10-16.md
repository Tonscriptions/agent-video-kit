本轮完成 `media inpaint` 的本地模型登记、静态/动态 alpha 或亮度蒙版、时钟/几何校验、ROI 推理、蒙版外 RGB/全部 alpha 保留、音频、时间线、取消恢复和源/蒙版/模型权利依赖。真实 CPU/CUDA 及 SAM2→LaMa→成片链路均可执行。**这推进了 #56 的功能实现，但没有关闭自然运动画质、联合时序修复、提示词生成填充或完整剪映等价。**

## 2. 真实模型样例

四次最终运行覆盖三个源场景，CPU/CUDA 使用同一受控源，不能算作两份独立语料。早期两次受控运行是在“缩放后选区完全消失时拒绝”补充之前，作为历史记录保留；最终四次均绑定当前实现。

| 样例 | 帧数 / 画幅 | 设备与模型调用 | LaMa worker 时间 | 结果和边界 |
|---|---|---|---|---|
| 已知渐变背景＋移动彩块 | 8 / 192×128，1 秒 | CPU；7 次推理、1 帧空蒙版 | 约 10.55 秒 | 彩块移除，已知背景可计算重建误差；软源 alpha 精确保留 |
| 同一受控样例 | 同上 | CUDA；7 次推理、1 帧空蒙版 | 约 14.05 秒 | 同样闭环通过；小输入耗时含导入/加载且并行跑回归，不是吞吐基准 |
| 人像中选中头盔 | 6 / 512×512，0.5 秒 | CUDA；先 SAM2 对象 2，再 LaMa 6 次 | 约 16.66 秒 | 头盔移除；衣服/背景补全有生成痕迹，首帧蒙版有小块误选；源是静态人像的受控平移 |
| 卧室双人自然运动 | 32 / 512×288，4 秒 | CUDA；先 SAM2 对象 2，再 LaMa 32 次 | 约 20.22 秒 | 人物可移除，但交叠处有腿部残影和床单纹理涂抹，不能通过广泛广告画质验收 |

SAM2 前置推理另耗约 28.27 / 41.02 秒；表中只计 LaMa worker。最终 CUDA 峰值分配约 223 / 299 / 263 MB；owned-array 预算峰值分别约 1.81 / 13.07 / 7.59 MB，它们不代表总进程内存。没有两小时或大画幅长期基准。

## 3. 独立像素与成片检查

| 检查 | 结果 | 能证明的范围 |
|---|---|---|
| 蒙版外 RGB | 四次最终运行独立解码比较，变化像素均为 0 | 保留未选区域；不证明修复区域真实 |
| 原始 alpha | 输入/输出所有像素一致；受控样例含 128 软 alpha | 没有把不透明度当作修复模型输出 |
| MOV RGBA | worker 字节摘要与完整 QTRLE/ARGB 解码摘要一致 | 无损编码链路 |
| 空蒙版 | 首帧不调用模型、画面精确保留 | 明确旁路行为 |
| 受控重建 | mask grow=4 后区域 PSNR：修复前 9.929 dB；CPU 后 43.668 dB、CUDA 后 43.663 dB | 仅这份简单背景；不外推纹理、人体或真实广告 |
| 连续帧误差变化 | 已知背景的相邻重建误差变化 MAE 约 CPU 0.582 / CUDA 0.581 | 未做运动补偿；不是自然场景时域质量分数 |
| CPU/CUDA 差异 | 全 RGBA 不同，178 个通道值不同，最大差 1；平均绝对通道差约 0.000226 | 不承诺跨设备字节一致；单设备重复的早期/最终样例摘要一致 |
| 音频与应用 | 保留源音轨，显式应用到 audio 轨道；四份 MP4 均有音频 | 蒙版时间不代替音频或源时间 |
| 结构与策略 | 四份 render/quality、validate、policy audit 通过 | 成片结构与本地运行策略 |
| 发布门禁 | 四次 commercial_ad 检查均按预期 exit 7 | 未核验模型/源不因渲染成功而获准发布；SAM2 模型通过蒙版传递依赖 |

目视检查了受控样例 0/4/7 帧、人像 0/3/5 帧和自然样例 0/8/12/16/20/24/28/31 帧。自然样例第 20 帧交叠处有棕色竖条，第 28 帧有腿部残影；床单线条和纹理的补全不能视为真实恢复。抽帧复核不证明连续播放无闪烁，逐帧 LaMa 也没有联合时序约束。

## 5. 复现

以下命令使用已经存在的原生 Python/Torch、LaMa 权重和来源证据；不会下载安装依赖。

```powershell
python -B -X utf8 scripts/create_lama_fixture.py --output-root product/.runtime/fixtures/lama-demo
python -B -X utf8 scripts/smoke_lama_local.py --source product/.runtime/fixtures/lama-demo/source.mov --mask product/.runtime/fixtures/lama-demo/mask.mov --ground-truth product/.runtime/fixtures/lama-demo/ground-truth.npz --model E:/models/big-lama.pt --python E:/python/python.exe --evidence E:/models/lama-evidence.json --device cpu --output-root workspace/lama-demo-cpu
```

生成脚本在本机复现了源 MOV、蒙版 MOV 和 ground-truth NPZ 的相同文件摘要。`smoke_lama_local.py` 另支持显式已有 SAM2 模型、证据、提示和对象 ID，生成有完整权利链的蒙版后再修复。模型、自然媒体和项目输出保留在忽略目录，不随源码提交。
