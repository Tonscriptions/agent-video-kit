## 1. 本轮问题与实现

前序同画布中位数复用造成碎斑和接缝。本轮在 [flow_core.py](../../research/temporal-background/flow_core.py) 实现背景光流、未知区运动补全和已观测参考传播；[run_probe.py](../../research/temporal-background/run_probe.py) 是本地诊断 CLI，[独立检查](../../research/temporal-background/test_flow_core.py)固定了真值、遮挡排除及失败边界。输入是已有原视频、修复蒙版、所有禁用供体前景的联合蒙版、已有 LaMa harmonic 输出；本轮没有再次运行 SAM2、LaMa、VACE 或其他学习模型。

源 RGB 在选区/排除前景内先抹除，灰度 Telea 仅为 DIS 输入提供连续值；双向 DIS 在已观测背景中筛选锚点，以 Navier–Stokes 方法补全未知光流。流场按相邻帧合成，拒绝越界、显式切镜、距可靠背景过远或双向不一致的映射。候选参考的双线性采样足迹必须全部来自未排除且不透明的像素，至少 3 个颜色接近的供体才复用最近参考；小于 64 像素的分量拒绝，并只在选区内羽化。合成平移样例显式使用至少 2 个供体。

双向一致和颜色一致仍可能同时接受错误的隐藏运动；没有深度、物理表面或学习式光流补全。供体贡献比例仅是可用率，不能充当正确率；羽化也会混入已有 fallback，不保证每个贡献像素等于原供体字节。

## 2. 独立检查与完整性

10/10 研究检查通过：解析零运动纹理重建、禁止双线性角点、被排除 RGB 扰动不变、从未可见区拒绝、显式切镜隔离、alpha/不透明供体限制、全前景拒绝、预算前置、非法参数/形状/非有限流场及取消回调。变异检查把足迹准入改为 >0.999，固定角点测试按预期失败；因为单个无效角点可能只有 1/1024 的插值权重，近似 1 的阈值不能证明足迹完全干净。

最终研究的 3 份 Python 代码在执行前后摘要相同；输入 4 文件、输出 NPZ 和联系表已逐项复核。生产/测试/烟测共 89 份 Python 与已通过 363/363 的上一轮源码完全一致；本轮没有重新运行完整产品回归，也不把研究 10 项相加为 373 项产品回归。详见[本轮机器证据](./evidence/temporal-background-flow-20261016.json)和[上一轮产品证据](./evidence/repair-blend-smoke-20261016.json)。

## 3. 可复现真值结果

| 样例 | 真值与基线 | masked PSNR 前→后 | 供体贡献/选区 | 结论 |
|---|---|---|---|---|
| 12 帧平移纹理 | seed 42 的独立纹理先平移，再覆盖移动品红块；灰色 fallback | 20.800→30.878 dB | 9,071/9,072 | 有明显重建改善，边界仍有误差 |
| 32 帧真实墙面 | 原画面先保存为真值，再覆盖人工色块；Telea 半径 5 fallback | 25.613→30.109 dB | 65,030/70,720 | 条纹比逐帧 Telea 连续，仍非精确真值 |
| 同段真实床单 | 同上，在床面另加移动色块；人物排除区不计入选区 | 23.448→24.803 dB | 24,696/29,256 | 改善有限；非刚性表面/遮挡仍未解决 |
| 墙面＋床单合计 | 同一个 32 帧运行的两个区域，非另增语料 | 24.861→27.804 dB | 89,726/99,976 | 仅人工遮挡任务，不是移除真实人物的真值 |

独立人工遮挡真值只在最后评分使用，没有进入光流或参考合成。真实床单来自一段自然视频，墙面和床单是同一个源片段，不能算两个独立广告场景。抽看合成 0/5/11 帧及真实遮挡 0/8/16/24/31 帧，仍见边界、纹理相位或形变差异；没有连续播放验收。

同画布相邻选区交集上的真值误差变化 MAE：墙面 6.009→4.390，床单 12.774→11.208。该统计没有运动补偿，不等于闪烁指标或连续播放验收。

## 4. 自然人物移除

沿用已保存的源、目标与双人排除蒙版、LaMa harmonic 输出，32 帧 512×288@8，不运行任何新模型。151,301 个选区像素中，52,595 个有观测参考贡献，约 34.7618%；该比率不是恢复正确率。

抽看 13 帧：部分被移除人物背后的墙纸线条比 LaMa 模糊区域完整，部分床面也有观测纹理；腿状残留、床单涂抹、碎片式贡献和局部接缝仍在。**自然修复整体画质未通过，不接入生产**。无人物移除背景真值，不给自然移除 PSNR；不能用上一节人工色块任务的分数代替。研究不改变原始蒙版外像素，现有选区之外的残留也不会自动消失。

## 5. 本地复现与下一步

先将以下 JSON 的四个字段填为已有本地视频路径，保存至项目内独立输入清单；源/蒙版/fallback 的帧数、显示尺寸和帧率必须一致，alpha 蒙版采用 >127.5，目标 grow 4、供体排除 grow 8。真实画面 holdout profile 固定为本报告使用的 512×288 样例；其他画幅会拒绝，不推断画布或 VFR 时钟。

```json
{
  "source": "E:/media/source.mov",
  "target_mask": "E:/media/selected_object.mov",
  "exclusion_mask": "E:/media/all_foreground.mov",
  "fallback": "E:/media/existing_repair.mov"
}
```

```powershell
& '<已有原生Python.exe>' -I -B -X utf8 research/temporal-background/run_probe.py `
  --input-manifest '<项目内输入清单.json>' `
  --output-root '<项目内尚不存在的输出目录>' `
  --array-budget-mib 1024
```

原生 Python 须已有 OpenCV/numpy/Pillow；脚本使用项目已有本地 FFmpeg，不安装任何包。`--scene-cut-frame` 可重复，表示输出零基帧之前切镜。研究批次 2..65 帧、每帧至多 1,048,576 像素，按显式预算提前拒绝；长视频窗口/重叠拼接、资源总量、取消文件/超时、模型登记、Rights Ledger、媒体入轨和正式 CLI 均须在产品接入前另行实现并验收。

下一步优先补强隐藏运动/非刚性形变的置信度与时序一致的参考选择，分别验证选区完整性、真实遮挡和未观测区域。当前方法具备运动补偿和真值改善证据，但不足以作为剪映级对象移除内核；差异 #56 及完整功能/效果、开放素材库、性能和发行目标继续有效。
