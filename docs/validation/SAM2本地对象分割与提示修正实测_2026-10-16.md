## 1. 当前可执行能力

`transformers-sam2-video-local-v1` 通过显式登记的原生 Python、本地完整 safetensors 和证据执行。支持正负点、框、最多 8 个对象、选定对象联合、后续帧修正与显式重置；输出无损 QTRLE/ARGB MOV，保留音频、已有 alpha，并可写入视频及显式音频轨道。两背景 MP4 和透明 VP9/Opus WebM 均有实际渲染与独立 alpha 合成对照。

完整产品 **278/278，通过，469.911 秒**；新增 SAM2 专项 **21/21，27.975 秒**，共享 RVM 专项 **24/24，53.664 秒**。专项和完整回归包含协议 mock 与真实 FFmpeg；下面的权重实测另外证明真模型可执行，不把 mock 当作模型画质证据。

## 2. 模型、运行时与来源

- 使用[官方 SAM2.1 Hiera Tiny 模型](https://huggingface.co/facebook/sam2.1-hiera-tiny)，固定 revision `de431c4043854a71d8101e17995dfe596bf101a5`；`model.safetensors` 为 155,908,064 字节，SHA-256 `48c14467e5cf9e51870511feb72c89688e82dd74523142c0538b663e193ac2a7`，与官方文件元数据核对。开发期经 HF mirror 明确下载；产品只接受已存在的本地文件，不提供运行时下载。
- 模型卡声明 Apache-2.0；本轮模型与素材的商业许可核验均为 `unverified`。来源、镜像、版本及摘要保存在机器证据，不将模型卡声明视作商业发布已获授权。
- 现有原生 Python 3.13.14、Torch 2.13.0+cu130、Transformers 5.14.1、numpy 2.4.6，RTX 3060；使用 Transformers 自带的 [Sam2VideoModel/Processor 流式接口](https://huggingface.co/docs/transformers/en/model_doc/sam2_video)。没有安装原始 sam2、Hydra、容器或新运行环境；固定 FP32，设备在登记时选择，无静默回退。
- 人像夹具为既有静态人像加受控平移，3 秒/36 帧、512×512、12 fps；短版取其前 6 帧。它不包含自然人体运动，没有真值 alpha。
- 自然运动夹具来自官方示例引用的 [sam2-fixtures 数据集](https://huggingface.co/datasets/hf-internal-testing/sam2-fixtures)，revision `ee201e1a2ba9f944f26ab4b3219a32cf6dd27252`；原始 bedroom.mp4 为 2,380,401 字节，SHA-256 `1be76d5d19b066e8ad7c565d88a98e11a8f8d456a707508a7aa35390def70e30`。校验来自镜像 LFS pointer，未独立核对主站文件摘要；许可未核验，仅本地开发评估。取 4 秒/32 帧、512×288、8 fps，附加合成音调用于音频管道校验，不评价自然音频。

## 4. 透明、音频与工程门禁

每个完成用例均核验 worker 原始 RGBA 与 QTRLE 解码全帧摘要一致；两背景渲染与独立 straight-alpha 公式比较，透明 WebM 使用 `libvpx-vp9` 显式解码 alpha。各用例的三份 `quality check`、项目校验和本地策略审计通过；输出保留音频，时间线音频通过显式 audio 轨道应用。源与模型共同进入权利依赖，`commercial_ad` 按预期退出 **7**，不是执行故障。

仅头盔概率模式生成 225,886 个软 alpha 像素。早期烟测脚本把“大面积完全不透明像素”当作所有夹具要求，对小对象/概率掩码误报；已改为检查选定对象非空和透明背景，概率模式按参考 alpha 极值与原有误差阈值验证。独立 RGB 合成、无损 RGBA 摘要和产品门禁保留。变更后的脚本已实际重跑该概率用例并重新编译；完整产品源码/测试在全量回归后未修改。

回归覆盖提示规范/范围/对象与预算、状态清理、完整性、设备/协议响应、输出不覆盖、幂等、失败回滚、快照/项目包、取消/超时和进程清理。14 个 Skill 的官方 quick_validate、前缀、正文摘要、相对链接及 Windows 目录联接审计通过。

## 5. 目视结果与未关闭项

| 样例 | 已观察结果 | 判断 |
|---|---|---|
| 单面部正点 | 选择面部及另行框选的头盔，身体未包含 | 提示具有范围歧义，不能视为整人成功 |
| 人物多点 | 主要人物和头盔可保留；领口、拉链、手部有漏抠 | 功能可运行，边缘/内部质量未验收 |
| 相同短片重置 | 即使重复同组正负点，帧 4 重置后可缩小为面部；CPU/CUDA 相同 | 重置会重新解释提示，不保证保持相同对象范围 |
| 人物框＋多点 | CPU 样例重置后保留主要人物和头盔，较多点提示更稳定 | 该例得到改善，不能推广为所有素材保证 |
| 自然运动双人 | 首尾采样分离出两人，中段其中一人被遮挡；轮廓随运动变化 | 联合 mask 不证明对象 ID、遮挡恢复或复杂运动质量 |
| 仅头盔概率输出 | 选中头盔，首帧物体外仍有弱残影 | sigmoid 是分割置信度，不能当作物理 alpha 或发丝重建 |

无独立 alpha/掩码真值、广泛授权广告集、自然镜头切换、两小时输入、更多模型和完整跨设备性能证据。Python socket/DNS/HTTP guard 与本地加载参数被启用，它们不是 OS 防火墙，也不证明任意原生 DLL 不可能联网。没有启动剪映、Docker/WSL、虚拟机或浏览器。

差异 #55/#94 保留质量缺口；#56 的物体移除/局部修复/生成填充仍未实现。接口及坐标见[SAM2 契约](../specs/本地SAM2对象分割与提示修正契约_v0.1_2026-10-16.md)。旧的[在建状态快照](./evidence/build-progress-checked-sam2-20261016.json)属于历史核对，不代表本轮最终结果。
