# 原生帧索引缓存契约（v0.1 限定验收，2026-10-21）

本契约定义普通原生视频倒放的持久源时间索引。依赖 V82 普通原生视频倒放区间时钟与顺序 FFV1 分块；不扩大一般嵌套 VFR、HDR、倒放音频或长片性能的验收范围。

| 编号 | 要求 | 实现与可观察边界 |
|---|---|---|
| NI-01 | 保存完整原生时间 | 保存 ffprobe 解码得到的小端 signed int64 PTS、duration、原生流和格式信息；不把 VFR 先转成 CFR。PTS 严格递增、duration 非负，最多 1,000,000 帧 |
| NI-02 | 可复现缓存键 | 键绑定源路径与 SHA-256、ffprobe、索引模块、原生帧扫描模块及显式解码器。源字节与工程登记不一致时拒绝；代码、路径或原生程序变化产生新键 |
| NI-03 | 只读规划 | `build_filter_graph` 默认不创建索引目录。`render --dry-run` 未命中时仍需扫描源帧以给出正确倒放区间；同一次作者图内复用相同源数组 |
| NI-04 | 实际执行 | `render`、`preview frame/range` 的实际作者图在未命中时扫描并落盘；根图、剪辑窗口和子图共享同一个索引上下文。正向视频不因该功能建立索引 |
| NI-05 | 验证后命中 | 命中检查精确三文件布局、配方、帧数、二进制长度、加载数组 SHA-256、单调性、元数据及源/程序摘要；不再调用全源 `probe_frames` |
| NI-06 | 计数口径 | `source_index_decode_calls` 仅表示全源帧索引扫描次数，首次为 1、持久缓存或图内复用为 0。仍有源和程序 SHA 读取、最终视频解码/编码、缓存媒体验证，可能另有音频解码；不等于整个流程零源读取或零解码 |
| NI-07 | 原子发布 | 实际执行在项目写锁内，在 `renders/.tmp` 写入并 fsync 三个文件，验证源/程序后原子移动目录。取消、源变化、磁盘不足或同键冲突时不覆盖既有缓存 |
| NI-08 | 编码后验证 | 最终成片/预览发布前重新验证持久索引三文件及源/原生程序。篡改或删除索引会阻止发布，不静默重建后继续提交本次输出 |
| NI-09 | 有界磁盘入口 | 每工程最多 256 个索引目录；新建前盘点条目，达到上限先拒绝。空间预约为两组 int64 数组、128 KiB 元数据预算和 64 MiB 余量。每个最大帧数索引的两数组共 16,000,000 字节；不声称这是进程总 RSS |
| NI-10 | 安全自有路径 | 所有派生缓存路径在 resolve 隐藏目录联接前逐段检查。禁止符号链接、Windows 目录联接、越界、未知条目或清理目标内的未知用户文件 |
| NI-11 | 显式盘点与清理 | `cache list/prune --kind native-video-index`；默认 `--kind reverse-video` 保持既有语义。盘点不认证内容完整性。清理只 unlink 固定三个文件并删除空目录，不递归删除 |
| NI-12 | 保留配额与引用 | 支持 `--key`、`--dry-run` 或 `--keep-mib`。工程当前作者引用的路径受保护。按目录 mtime 从旧到新清理；命中不更新 mtime，因此不声称是真实访问 LRU |
| NI-13 | 保留诊断 | 损坏索引默认保留并报结构化错误，显式清理可移除缺件、空目录或坏 JSON；夹带未知文件或联接时拒绝。清理后下一次实际执行可重建数组；新清单完成时间和清单 SHA 可以变化 |
| NI-14 | 分块缓存独立 | 索引与 FFV1 像素缓存分开。删索引不删除源或像素缓存；重建索引数组相同即可继续复用原像素缓存。V82 的 256 MiB 帧栅格估算和 128 GiB 保守磁盘预约仍然适用 |
| NI-15 | 安装与产品边界 | 原生 Windows、现有离线 wheels、`python -I -S` 安装目录核验。不得以几何 8 帧样例或测试数量宣称剪映整体等价、自然质量、HDR、长片延迟/峰值内存或一般嵌套 VFR 已达标 |

```powershell
ai-ad-editor cache list --project P --kind native-video-index
ai-ad-editor cache prune --project P --kind native-video-index --key <64位键> --dry-run
ai-ad-editor cache prune --project P --kind native-video-index --keep-mib 64
```

固定布局：`cache/native-video-index/<key>/pts.i64le`、`durations.i64le`、`index.json`。派生缓存含当前主机路径，迁移工程传作者配方和原始素材，随后在目标路径重新建立缓存。

实际核验和原输入/输出见[实验记录](../validation/原生帧索引缓存与倒放复用实测_2026-10-21.md)。
