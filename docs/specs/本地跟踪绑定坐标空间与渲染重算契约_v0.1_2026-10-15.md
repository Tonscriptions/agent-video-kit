## 1. 两种绑定模式

既有无源片段参数的模式继续生成源归一化坐标关键帧。新模式同时指定 `--asset-id`、`--source-track-id`、`--source-clip-id`，把源视频片段的源时钟和当前几何投影到目标画布；它不运行剪映或网络服务。两种模式不能混用时间对应规则。

```powershell
python -X utf8 -m ai_ad_editor media track-bind `
  --project .\work\demo --asset-id source_video `
  --adapter-id yolo_local --object-id obj_0001 --roi 0,0,1,1 `
  --source-track-id track_video_1 --source-clip-id product_video `
  --target-track-id titles --target-clip-id price_label `
  --offset-y -0.10 --scale-mode roi --rotation-mode source --apply --dry-run
```

先复核 dry-run，再移除 `--dry-run` 执行。两个 source 参数必须成对提供，源为同一序列、匹配 asset_id 的直接视频片段；目标为另一直接视觉片段。`--rotation-mode none|source` 默认 none；source 表示跟随源层相对首个采样的旋转，不估计主体姿态。单独给 rotation-mode=source 会拒绝。

## 2. 持久数据与重算

可选 `clip.tracking_binding` 保存源轨道/片段 ID、asset_id、源 SHA-256、明确源秒范围、1..4000 个实际观测、画布归一化 offset、缩放/旋转模式及目标基准 scale/rotation/opacity/opacity_keyframes。观测中心/宽高为源未旋转栅格归一化坐标，时钟为源秒；不把缺失帧伪造为检测。

应用先创建快照，将预览 `transform.*` 关键帧与绑定一起原子保存。之后编辑源裁切、变换、时钟或输出画幅时，渲染在项目副本上根据当前设置重新编译，既有落盘预览关键帧不会自动变成新的几何真值；不重复执行模型。manifest 的 `kind=tracking-binding` 输入记录画布、源引用、采样/隐藏帧数与警告。项目输出/provenance 仍按通用渲染契约更新。

绑定拥有 position.x/y、opacity，以及启用时的 scale/rotation；这些字段的预览关键帧会在渲染时重算。目标原始透明度关键帧作为 base 保留并与源透明度相乘。通过 `timeline compose` 的 update_clip 把 `tracking_binding` 设置为 null 可解除绑定，保留当前已保存的预览关键帧；若要保留编辑源后的最新几何，应先重新绑定。重新绑定复用原 base，避免缩放/旋转累乘。

## 3. 几何与时间

按源实际尺寸计算：裁切窗口 → fit/fill/stretch 的缩放及居中 → 源层正数整体缩放/锚点/像素空间旋转/位置 → hflip/vflip → 画布归一化 offset。旋转使用宽高对应的像素距离，避免非方形画布上归一化坐标失真。裁切尺寸/位置关键帧支持已有别名与 Bezier；静态裁切使用 exact=1，动态尺寸延用本地采样实现。位置不钳制到画布内；裁切出画、源片段范围外或源轨道 muted 时把绑定透明度置零。

源时钟复用渲染器的 trim、常速、倒放、速度曲线积分/反算；在显示帧网格按实际 CFR 源帧选择观测，再做观测间插值。定格复用同一显示帧计数：重复指定的已显示帧，插入时长四舍五入到显示帧、至少一帧，非整帧请求报告 `FREEZE_FRAME_QUANTIZED`。定格前裁切动画使用内容时钟，片段变换使用时间线时钟。

编译最多 20,000 个显示帧，超限报 `TRACK_BIND_FRAME_BUDGET`，不削减轨迹。关键帧表达式使用平衡分支树，长滤镜图使用已校验 SHA-256 的本地文件；不通过降低采样率规避执行失败。

## 4. 校验、互操作与权利

Schema 与语义校验覆盖字段、有限数值、源引用、哈希、时钟和依赖循环。渲染前重新计算实际源文件哈希，篡改报 `TRACK_BIND_GEOMETRY_INVALID`，不会继续使用过期观测；源删除造成引用失效时，CLI 事务回滚。模型 Rights Ledger 依赖继续保留，不因投影或解除绑定而自动消失。

Agent JSON 与可移植项目包保留完整绑定。导出 OTIO、Kdenlive XML、明文草稿时按当前项目画布先烘焙普通关键帧，明确报告动态关系丢失；草稿记为 Baked，`--strict` 在写目标前拒绝。源 Agent 旁车保留原绑定供审计，不表示外部编辑器能执行该关系。见[转换报告规范](./项目转换报告规范_v0.1_2026-10-13.md)。

## 5. 验收边界

源要求已探测帧率 0..240（不含 0）、方形像素、零旋转/起始 PTS、名义与平均帧率一致。该检查不等同完整 VFR 逐帧 PTS 证明。lenscorrection/perspective/v360/transpose 等缺少逆坐标映射的效果拒绝，镜像使用显式 hflip/vflip。源负缩放拒绝。

目前仍需专项补齐：嵌套父层完整坐标组合、VFR、镜头切换、mask/遮挡可见性、透视/非线性扭曲、外观 ReID、精细文字边缘/预乘 alpha、跨设备质量和高分辨率密集表达式性能。嵌套父变换发出 `TRACK_BIND_NESTED_COORDINATES_APPROXIMATE`；不把可执行渲染视为这些能力已等同剪映。

回归与真实离线模型组合样例见[实测记录](../validation/跟踪坐标绑定与组合渲染实测_2026-10-15.md)，既有接口见[绑定契约](./本地跟踪绑定与对象锚定契约_v0.1_2026-10-15.md)。
