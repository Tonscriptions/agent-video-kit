# 可复用片段组库与跨项目插入契约 v0.1

| 项目 | 内容 |
|---|---|
| 文档编号 | SPEC-FRAGMENT-LIBRARY-0.1 |
| 状态 | 有效 |
| 实测 | [V37 受控验收](../validation/可复用片段组库与跨项目插入实测_2026-10-18.md)；完整剪映等价未验 |

目标是将已经编辑的片段保存为可检索、带资源及权利闭包的本地版本，供 Agent 在另一工程中继续编辑。借鉴 OpenFilm 固定 `eefd6a8d379289102141359a4718dbab12170526` 的 Saved 工作流；整数 tick、嵌套、事务及权利实现属于本项目。不是安装上游 GUI、HTML runtime 或在线 Skill。

## 1. 命令与版本

- `fragment save --project <源工程> --library <本地目录> --input <保存请求.json>`。
- `fragment list --library <目录> [--query <名称/标签>]`。
- `fragment inspect --library <目录> --id <片段组ID> --version <正整数>`，核对全部文件摘要。
- `fragment apply --project <目标工程> --library <目录> --input <插入请求.json>`。
- save/apply 支持 `--dry-run`，不得创建库、资源或工程操作目录；正式工程变更沿用原生锁、快照、事务与幂等键。

保存请求：`id`、`version`、`name`、`tags`、`sequence_id`，可选 `clip_ids`。省略选择时保存指定序列全部片段；显式选择必须非空。自动补全关联组、跟踪绑定源和转场图像/音频端点；所有新增选择出现在计划。递归包含所引用子序列，保留空轨、锁/静音、轨道处理、关键帧、标记和编辑配置。

插入请求：`id`、`version`、`sequence_id`、`track_id`、`at_tick`，可选 `instance_id`。目标须为未锁定视频轨，区间碰撞拒绝，不自动移位其他内容。一个库版本只发布一次；版本目录名由 ID 摘要派生，避免 Windows 保留字符与名称碰撞。库可整目录离线搬迁。

## 2. 作者时钟与可编辑性

插入结果是原生嵌套序列容器，不是预渲染 MP4。保存子序列保持原始作者 tick；入口记录最早起点和最晚终点，容器用 `source_in_tick` 截取该范围，目标起点单独设定。外部字幕 cue、轨道音频自动化及真实源句柄不因归零而重写。子序列的有效画布固定为保存时宽高，目标可采用另一画布并按既有嵌套规则投影。

首版不转换时基、帧率或色彩/音频执行上下文；不兼容时明确拒绝。源或目标的全局 adjustments、外部可执行 audio_stretch 配置拒绝，避免跨工程改变全局处理或隐式搬运程序。选取部分片段且包含依赖完整序列的闪避处理时拒绝，完整序列可保留原音频总线。选择范围之外内容不承诺出现。原有合成、Alpha、画布背景和源句柄能力边界继续适用。

## 3. 文件与依赖闭包

每个版本包含 `fragment.json` 和 `files/`。清单固定格式版本、作者工程/台账摘要、原始及补全选择、序列/资产、完整所需权利修订链、入口区间及每份文件字节数/SHA-256。非空普通资源使用流式复制与摘要，默认总量上限 4 GiB、文件上限 4096；不在内存中装入全部媒体。

收集直接/蒙版/字体等资产、文件字幕、显式字体及 LUT。LUT ID 在保存时解析为固定文件路径并记录适配与权利依赖，插入不会覆盖目标 LUT 注册表。显式文件引用必须找到对应资产或相同摘要的权利记录；不自动生成已验证许可。未登记的文件先登记后保存。

模型生成的成品作为资产复制，模型权利通过 `derived_from`/`rights_dependencies` 保留。库不包含可执行模型适配器，不自动复制或执行权重；内联跟踪观测及其引用可保留。未知运行时 ID 引用、断开的素材/权利依赖、远程资源、文件改变和未实现语义明确报错，不能静默丢失。

所有运行时文件路径改为版本内相对路径；来源路径只作为历史溯源。权利证据中的现存文件尽可能随包复制，缺失的非运行时证据保持原声明并列入警告，不提升权利状态。摘要证明字节完整性，不证明来源真实性或授权。

## 4. 合并、审查与失败

计划给出源版本清单摘要、目标工程摘要、入口区间、补全选择、资源字节、所有新 ID 映射和限制。`--expected-project-sha256`、`--expected-fragment-sha256` 可绑定已审查计划，过期拒绝。正文、标签和任意等于旧 ID 的文字不得被全局字符串替换。

每次实例重新命名资产、序列、轨道、片段、转场、标记、关联组及权利历史 ID，保留权利状态、限制、期限、撤回和处置历史。目标已有同名不同内容不得覆写，原始库不被编辑。库保存持独立原生锁，暂存完整后同卷原子发布；查询跳过尚未发布的 `.fragment-*` 暂存目录，进程中断留下的暂存清单不得成为可见版本。版本路径解析后必须位于本地库内，Windows 目录联接不能将读写导向库外。插入资源使用独占命名空间，验证后修改工程/台账元数据。

异常回滚工程与台账，清除本次普通异常中新复制的资源；进程被杀时沿用元数据崩溃恢复，可能留下未引用资源目录，不能称为磁盘全回滚。历史快照与幂等记录保留。重复幂等键返回原结果，修改请求拒绝；重复无键插入创建独立实例。

商业发布仍运行原 Rights Ledger 门禁；从库导入不等于获得许可，原库也不会自动同步后续源工程撤回。来源权利变更须显式更新/撤回目标副本，不承诺跨库在线传播。门禁执行已有状态、用途、渠道、期限、撤回和处置规则；自由文本 `restrictions` 只保留声明，不自动解释成机器政策。`restricted` 且明确允许商用的记录不因状态名称单独阻断，明确 `blocked` 等状态才按对应规则阻断。

## 5. 验收

核对闭包、同名碰撞、重复实例、ID/文字分离、不可变版本、时钟/画布、权利修订及处置、哈希破坏、过期计划、干跑零写入、锁冲突、暂存版本不可见、目录联接越界和异常回滚。跨工程实际编码对照固定作者工程参照，分开报告逐帧 RGB、原始 PCM、容器探测、GIF 静帧检查及未进行的听审/连续播放；同步 README、能力清单及相关 `$video-cut-` 技能。参照不是独立渲染算法；完整剪映等价不由该模块单项验收推出。
