# 本地视频扩图与原画面保护契约 v0.1

关联功能差异 #56（局部修复/生成填充）、#95（生成背景/扩图）、#36（画布比例）、#115（Alpha/中间格式交付）。目标是在已有本地 LaMa/VACE 管道上提供真正的画外生成，保留输入显示画面的每一个 RGBA 样本；不能把模糊填充、拉伸或裁切称作生成扩图。本文先约束实现，实际通过范围以[独立实测报告](../validation/本地视频扩图与原画面保护实测_2026-10-19.md)为准。

| 编号 | 约束与验收 |
|---|---|
| OUT-01 | 新增 `media outpaint --project --asset-id --adapter-id --derived-asset-id --width --height`。只读取已摄取的本地 video 和已登记 LaMa/VACE；VACE 保留原文 prompt、seed、窗口及采样参数。无运行时下载、HTTP、剪映、GUI、虚拟化或云端回退 |
| OUT-02 | `width/height` 为明确整数输出像素；各边不超过 8192、总像素不超过 16,777,216，仍须满足原模型数组预算。原显示/CFR 归一化画面不得缩小或裁掉。新画幅至少一边严格扩大；`--offset-x/--offset-y` 是输出像素中原画面左上角，省略时分别向下取整居中。必须完整容纳原画面；拒绝负值、越界和原尺寸无操作 |
| OUT-03 | 复用原 `start/end/fps/max-edge/max-frames` 的显式源归一化，再扩展画布；报告分别保存归一化原画面栅格、新栅格、整数放置及源 SAR/旋转。声明保护的是该原始显示/CFR RGBA 缓冲区，不冒充任意编码格式或 HDR 的原生高精度无损 |
| OUT-04 | FFmpeg 在同一个解码流中将原画面放入新画布，外部用 RGB 127、Alpha 255 初始化；由相同帧/PTS 生成几何蒙版：原矩形 Alpha 0，外部 255。不读取隐藏背景真值，不拿拉伸/镜像/模糊当模型结果，不注册伪造的外部蒙版文件 |
| OUT-05 | 合成仅允许修改原矩形外。所有原矩形 RGBA、透明/半透明源像素和输出 PTS 均独立核对。原 Alpha 不重新估计，生成区 Alpha 为 255。固定 mask grow/feather 为 0，防止侵入原画面；模型缩放、边界求解和窗口重叠不得改变这个保护范围 |
| OUT-06 | 计划包含可重算的合成蒙版身份与 SHA-256、源摘要、原/新几何和生成参数；父进程及 worker 验证规范形式。修改放置、画幅、源或身份均须拒绝。沿用原模型实现摘要闭包，新实现要求新 adapter ID，禁止手改历史摘要 |
| OUT-07 | 支持 LaMa 的逐帧补全及 VACE 的联合窗口；两者能力、设备和失败策略分别报告。显式 `repair-blend harmonic` 可以修正生成区边界色差，保持 direct 默认；原有有限迭代、不收敛拒绝和数组预算继续生效。生成区纹理、结构、接缝和时间一致性独立验收 |
| OUT-08 | 正式交付使用 QTRLE/ARGB MOV 与原声 PCM；沿用源显示起点、选区时间、CFR 尾帧和音频偏移。无损编码全 RGBA 摘要必须等于 worker 输出；独立原画面/PTS/完整 PCM 另核对。GIF/有损 MP4 只是预览，不作精确性证据 |
| OUT-09 | `--dry-run` 不解码、不加载模型、不创建输出或登记资产；取消、超时、权重变化、输出冲突、坏响应、资源不足、编码/元数据失败保留原项目和原输出。沿用原生子进程 Job 回收；不停止别的任务，不降低参数来掩盖失败 |
| OUT-10 | 正式执行先快照；输出、可编辑几何/生成计划、报告、源/模型权利闭包、可选视频和音轨应用以原事务提交。源、模型的未核验/撤回/过期状态继续阻断发布。工程包保留计划与源依赖；片段组跨项目复用先验证原配方，再映射源 ID、重算新配方摘要并校验目标项目。外部模型/Python 不随包分发 |
| OUT-11 | 专项验证边界几何、规范身份篡改、明确预算、源/半透明保护、CFR/PTS/音频、dry-run/取消/失败回滚、实际模型消费新栅格、可编辑元数据与工程包。真实模型结果与可控协议测试分别计数，不把 mock 当生成能力 |
| OUT-12 | 用公开授权或原创原片完成开发版与原生离线安装版的真实生成、编码和复核。受控图像需在执行前声明生成区 PSNR ≥30 dB 的单项门槛；失败仍公开，原画面保护通过不能替代画质通过。自然内容另列纹理、对象、边界和时序观察，不把单个样例提升为广泛质量或剪映等价 |
| OUT-13 | 2026-10-20 补充：VACE 两次原生文本加载访问冲突保留原版本与 Windows 事件；按[读取约束](VACE本地权重读取与原生访问冲突约束_v0.1_2026-10-20.md)选择组件调用内 pread，不编辑共享依赖。全部六权重读取证据、相同采样参数的实际前向及新源码冻结重新验收；改后单次通过不表示底层根因永久解决 |

扩图本身不会自动推断主体、不做语义剪辑、不扩写提示词，也不保证真实被遮挡的画外背景。模型结果与保留的原画面必须分别显示，原输入/实际生成/失败/脚本/逐文件 SHA 同步进入 README 的编号核验表。
