## 1. 结果与实际问题

完整 **524/524，1027.580 秒**；98 份 Python 源码/测试加 1 份 Schema（共 99 份）原始字节前后不变；18 项新增专项为完整套件子集，固定旧版同测 18 方法失败、含 subTest 共 28 条失败记录。12 组正式 CLI 实测，160 次调用包含 50 次渲染、12 次质量和 12 次本地策略审计；846 新主帧（其中 52 帧属于未通过交付）与 1818 控制帧分计，794 帧来自 11 组通过交付。文字组合最大 R/G 差为 2，独立前缀/词状态均无不匹配；各组变体解码 PCM 一致。裁切+倒放+Bezier 样例末尾第 50/51 帧背景消失，源帧最大差 5，保留失败成片，整组交付未验收。29.97 fps 仅验明确 90 帧/3.003 秒时间线；任意非整帧时长、动态内嵌、通用塑形/RTL、VFR/定格/HDR、长片性能和完整剪映等价仍未验收。

旧版固定为 `68006af9e7b3ea26efc697ab2871fad7bf22bf94`，由本地 Git 原始 blob 归档真实执行。旧实现的 word_timing 分支提前返回，跳过文字动画；打字机逐字素独立绘制，居中位置、原生字距、多行基线和框会偏离整段文字。新实现先更新动画再选择普通/激活色，打字机以整行前缀交给原生引擎塑形，保持完整段落位置和基线，并逐组件调度运行时文字命令。无新增 GUI、线上调用、模型推理或顶层 CLI 参数。

## 4. 保留的交付失败与门禁

TA11 [实际新版成片](../assets/text-animation-20261017/after-typing-nested-trim.mp4) 的裁切范围 0.2–2.8 秒、输出起点 0.125 秒、祖先 Bezier 倒放。第 50/51 帧背景视频消失；编码源帧码为 0、预期为 5，最大差 5，文字前缀/颜色仍正确。独立审计确认固定旧版同两帧也为 0，这是本轮新发现的既有视频问题。因此该组只能接受文字子项，**整组交付失败**，不能因 R/G 或质量 CLI 退出 0 标通过。源码与其他样例相同，未在此增量修复该视频 EOF 缺口。

预检对同一组执行 `--fail-on-black` 真实返回 `BLACK_INTERVAL_DETECTED`，包含作者明确设置的 0–0.125 秒空档，见[原始日志](./evidence/text-animation-preflight-v2-media-20261017.log)。正式嵌套检查保留黑帧诊断、取消“任意黑帧均失败”选项，并独立核对作者前空档；末尾意外背景缺失仍明确失败，不以有意留白豁免。TA10 无裁切的 Bezier 倒放通过源帧容差≤1。

首轮公开生成在 TA12 的固定旧版 `render --publish` 被 `OUTPUT_DURATION_MISMATCH` 拦截：3 秒并非 30000/1001 的整数帧终点，90 帧编码为 3.003 秒，超过已有 0.0015 秒容差。见[完整原始失败日志](./evidence/text-animation-initial-media-20261017.log)。随后两次夹具尝试分别在初始 compose、控制样式 compose 时被自动重算回 3 秒，再次被拒绝；[第二批日志](./evidence/text-animation-second-media-20261017.log)与[控制预检日志](./evidence/text-animation-preflight-v4-media-20261017.log)保留。最终 TA12 在每次 compose 后明确设定 90 帧/3.003 秒，单组预检通过，再在新目录重跑整批；产品代码与容差未修改，不宣称任意非整帧时长已支持。
