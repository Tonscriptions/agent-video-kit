## 样例与验收边界

使用本机既有 skimage `astronaut.png` 样图；既有 skimage 来源说明将其记为 NASA 公有领域图片。本轮不下载图片、不安装依赖，图片、模型、证据和派生资产保持 unverified/internal，未将来源标签提升为完整发布许可。模型为已有 61,659,689 字节 YOLOv10m ONNX；原始元数据中的许可证标签不替代权重许可核验，也不把 URL 写入生产 registry。

将同一图片的两个实例放入 960×540、8 fps、4 秒受控视频。上方实例每帧向右移动 5 像素，下方每帧向左移动 3 像素；上方在第 12、13、14 帧完全移除。此用例检验检测、运动关联与短缺失恢复，**不等同自然部分遮挡、外观 ReID、同类交叉或真实广告质量验收**。

## 已执行结果

| 检查 | 结果 |
|---|---|
| 采样 | 32 个，间隔 0.125 秒，末次观测 3.875 秒 |
| 目标 | 两个稳定 ID，分别为 29/32 次观测，共 61 次；没有伪造缺失帧 |
| 短缺失 | 上方对象连续缺失 3 帧后关联回原轨迹，最大观测间隔 0.5 秒 |
| 受控水平位移残差 | 相对初次检测框和已知位移计算；两目标最大约 1.01344/0.61344 原始像素；门槛为原宽度 2%，不是自然视频跟踪精度 |
| 同环境重复执行 | 相同输入、模型、CPU 配置再次执行，objects/frames 完全相同 |
| 文字绑定 | 选定上方 ID，实际生成文字位置关键帧；末点 348750 tick，不把末观测拉伸至 360000 tick |
| 实际编码 | 640×360 文字绑定视频和 360×640 重构图视频，均为 4 秒 H.264/AAC |
| 抽帧检查 | 0.5/3.5 秒抽帧：文字随目标移动，竖屏裁切保留上方对象；两种效果在独立项目验证，不代表组合坐标空间通过 |
| 质量、项目、本地策略 | 两个项目均通过；未核验权利按预期阻断发布（exit 7） |
| 无检测拒绝 | 小 ROI 返回 TRACK_OBJECT_NOT_FOUND，不回退模板或固定框 |
| 外部权重拒绝 | 真实 ONNX protobuf 的外部 tensor 引用在 ORT 加载前拒绝；既有项目/台账/registry 保持原样 |

执行器使用原生 Python 3.13.14、numpy 2.4.6、onnx 1.22.0、ONNX Runtime 1.28.0、Pillow 12.3.0，CPUExecutionProvider、4 线程。隔离进程使用 `-I -B -X utf8` 和 Python 网络审计；最终执行器显式关闭 ONNX Runtime telemetry。未启动 Docker/WSL、虚拟机、剪映、Web 服务或浏览器。网络审计不是 OS 网络沙箱。

最终通过项目为 `workspace/vision-smoke-20261015-d`，32 步命令包含预期失败门禁；4 个最终抽帧哈希与已视觉检查图一致。首轮完整检测 worker 为 11.908 秒，包含解释器、依赖、哈希、模型加载和推理，且有其他本地回归同时运行，不作为速度 SLA。新增 24 项回归，完整产品 194/194 通过，307.168 秒；原始日志位于 `product/.runtime/vision-full-regression-20261015.log`。

## 发现并修复的真实问题

初次完整路径的竖屏渲染返回 WinError 206：32 个采样生成 53,397 字节动态裁切图，逻辑命令约 54,197 个 UTF-16 单元。修复为 SHA-256 本地图文件与 `-/filter_complex`，执行参数约 963 单元；原失败任务使用 `render --resume` 完成实际渲染。没有缩减采样、删除关键帧或更改媒体。

同时补齐视觉模型 registry 侧车的快照、恢复、元数据事务与项目包保留；包中保留登记信息，模型/Python 仍为显式外部输入。模型应用把登记摘要及权利 ID 写入片段，由权利闭包消费；缺记录、摘要变化及未核验状态都会阻断发布。文字绑定按完整请求时长计算时钟，修正按末观测拉伸的偏差。
