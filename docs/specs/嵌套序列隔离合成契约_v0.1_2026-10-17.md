## 1. 语义与适用范围

`append_sequence_clip` 引用的子序列是一个隔离合成容器。先在透明画布中按子序列自己的轨道顺序合成全部可见视频、图片和独立文字层，再把这一幅结果作为父时间线的一层。父容器的 opacity、变换、效果和蒙版作用一次，不再分别乘到重叠子片段上。

例如，子序列包含不透明红底和覆盖其上的不透明蓝块。容器 opacity 为 0.5 时，重叠区是半透明蓝块；红底不会通过先后两次 0.5 的逐片段合成漏出。两层容器各设 0.5，则每个最终可见像素的覆盖率为 0.25。

这是现有项目结构的执行语义修正，无新增项目 JSON 字段。原始序列、关键帧、素材、Rights Ledger 保持 authored 数据；内部编译字段不写回项目。内部 `_flatten_sequence_tracks(..., groups=...)` 仍展开时间映射，但另存空间合成节点；不传 `groups` 的旧诊断视图保留兼容行为，不是正式渲染执行路径。

## 2. 画布、顺序与枢轴

本版本每个子序列画布使用项目根 `settings.canvas` 的宽高和显示帧率。暂不提供每个子序列独立分辨率、色彩空间或帧率设置。

组内按子轨道 `order`、片段可见开始时间和稳定层序执行合成。子轨道的高 order 只能在该子序列内提高层级。父时间线只看容器所处轨道，子轨道 order=100 不会越过父时间线 order=1 的前景层。同 order 的复杂重叠编排应显式分配不同 order；不宣称任意相同层序的兼容性。

空间操作次序固定为：

1. 合成子序列内的层与配对轨道转场，得到直通 RGBA 画布。
2. 容器 crop：在这幅合成画布上执行，支持既有 pixels/normalized、fit/fill/stretch 和可表达的动画参数。
3. 容器 TRS：围绕该画布的 anchor 执行 scale、rotation，并将 anchor 放到 position。
4. 容器 transform.opacity。
5. 容器 effects，按已登记本地滤镜及既有参数/近似告警执行。
6. 容器 mask，坐标指向变换后的完整画布。
7. 容器 fade / fade_in / fade_out 的 alpha 包络。
8. 按容器 blend 与其父画布混合。

TRS 在固定画布上逆向采样，像素中心为 `(x+0.5, y+0.5)`，透明区域不扩张画布。超出画布的内容被裁掉，符合合成容器边界。旋转中心不再近似成每个叶片的 anchor。组内有 scale 的媒体和独立文字同样使用固定画布，避免 RGBA overlay 在动态尺寸变化时沿用首帧尺寸。

父 mask 和子 mask 分别在自己的合成阶段执行。它们可同时存在，正式路径不再产生“父子 mask 被分摊到叶片”的近似告警；蒙版边界、羽化、动态路径及未支持参数仍遵循既有蒙版契约和实际告警。

## 3. 透明混合

普通层使用 source-over。隔离组内的 multiply 等已登记混合模式必须处理底层 alpha。不能把透明背景的隐藏黑色直接当成不透明底色，否则 multiply 会错误地抹黑未被底层覆盖的区域。

令 `Cb/Cs` 为直通底层/源 RGB，`Ab/As` 为覆盖率，`B(Cb,Cs)` 为混合函数，执行：

```text
Cs' = (1-Ab)*Cs + Ab*B(Cb,Cs)
Aout = As + Ab*(1-As)
Cout_premultiplied = Cs'*As + Cb*Ab*(1-As)
```

本地滤镜图先按底层 alpha 选择源 RGB 与混合 RGB，再恢复源 alpha，最后执行 source-over。正常根画布保留既有不透明混合路径；透明根输出和隔离子画布保留合成覆盖率。

采样阶段以浮点预乘 RGB 处理透明边缘，随后回到直通 RGBA。组内通常有 8-bit RGBA/编码 RGB 的量化；该实现不等于线性光、HDR、超低 alpha 高精度或宽色域合成已经验收。

## 4. 时间与过渡

所有子画布保留最终时间线显示时钟。素材源帧、trim、倒放、标量/非线性速度曲线沿用解析时间映射。空间分组不引入有损中间视频，也不再次编码子序列。

容器关键帧由其**所属序列**的 authored 时钟求值，再逆向穿过外层容器的时间映射。容器自身 speed/reverse 改变其内部内容，不会反向改变自身所属时间线的 fade/opacity 相位。子片段自身关键帧沿用其 authored 时钟。

子容器可见区间为全局半开区间 `[start,end)`。组内的空档保持透明，结束之后不保留末帧覆盖。分段速度曲线重复访问同一容器时，合并其可见窗口，空间操作只生成一个节点。

边界转换为显示帧时，使用有理数 `ceil(tick × fps.num / (ticks_per_second × fps.den))`，以全局帧编号裁切。不能直接让滤镜把小数秒舍入到最近输入时钟：一 tick 的延迟或最后一个部分帧都必须保留其半开区间语义。

组内轨道转场仍要求既有配对片段及时间句柄；不同容器实例使用独立滤镜 label。容器本身的简单 fade 作用于整个组的 alpha，使用 authored 包络。配对容器 xfade 复用轨道转场路径，不能据此推广为任意组合均已验收。孤立的容器 slide/wipe、无句柄复杂转场、嵌套定格及音画联合时钟继续保留未验收边界。

## 5. Agent 可读证据

`render --dry-run` 的 `plan.inputs` 和正式输出 manifest 的 `inputs` 记录 `kind=sequence-composite`：容器/父容器/源序列 ID、透明画布宽高、可见开始与时长、组内合成层数、空间操作次序、`intermediate_files=0`。

该记录说明实际编译的合成结构，不代表画质验证。正式质量检查、权利发布门禁、策略审计和逐帧像素参考分别提供证据。不要删除告警，也不要用测试通过数量替代效果验收。
