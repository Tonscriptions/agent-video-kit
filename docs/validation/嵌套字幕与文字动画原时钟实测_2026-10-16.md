## 1. 当前结果

完整 **470/470，1150.472 秒**；92 份产品源码/测试及 Schema 前后摘要一致；18 项新增专项为子集，固定旧版同测 18 方法失败（19 个失败记录，含 subTest）。八组主场景 448 新帧的源帧误差为 0，四份校准另计 288 帧、最大差 1；105 次正式 CLI 含 20 次渲染、12 次质量，0 新模型实测推理。逐字状态、打字机和透明度对应通过；旋转只接受 6 个选定姿态。高亮字形定位仍偏移，动态尺寸内嵌透明度、定格、VFR、群组、自然画质及整体剪映等价未验收。

原问题是视频按嵌套曲线变化，而字幕仍读取最终 t。现在恢复原作者时钟，覆盖裁切、原偏移、倒放、两层曲线、显示窗与文件时间基准；另修正 ASS 样式 Format 被误作 Events 字段表、字体选项和 asset_id 合并。

**排版仍失败**：主样例第 58 帧可见白底词与黄色高亮错位。逐字状态只判断激活词，不能接受字形锚定。旧版也有此缺陷，本轮保留原画面，未用修图或删除底字隐藏。动态尺寸内嵌淡入仍明确近似，需独立标题另验；整体剪映对标未完成。

## 3. 独立核对与透明度

生成器在源 x 域做 8192 子区间 Simpson 积分；专项用 16384 参数点梯形积分；交付复核从实际作者操作重建曲线，在 Bezier 参数 u 的 4096 区间使用每区间 8 节点 Gauss 积分。均不导入产品编译器或拿生成的 PTS 当答案。两种交付 oracle 最大差 1.03466933687e-07 秒，门槛 2 μs；这是本批原曲线 oracle 的一致性，不代替产品组合误差界。

逐帧核对黄色词质心、打字机连续字形列、积分亮度、旋转像素协方差与 SRT 显示窗。透明度指标为 `(实际亮度−空白)/(不透明−空白)`，使用真实 CLI 对照，绝对误差门槛 0.065。指标未强行夹到 0..1，底图变暗/编码噪声可使其越界；不能直接当作素材真实 alpha。专项使用覆盖加权矩消除淡入小字的二值骨架偏差，角度门槛仍 2.5°。

原生单帧另核验 1/0.8/0.5/0.2 四档：直接 drawtext 最大 alpha 为 255/163/64/10；归一化后乘透明度为 255/204/127/51，目标误差≤1。8 次直接 FFmpeg 诊断单独计数，不计入 105 次 CLI，不是模型推理。

全部新脉冲包络无不匹配：20 ms RMS 窗、阈值 0.15，排除距源边界不足 0.10 源秒的窗口。12 次 quality 通过尺寸/时长、音频流、黑场和真峰≤−1 dBFS；未要求目标 LUFS，没有听审，不接受相位、音色或口型同步。文件字幕同一图另执行 12 帧 info 诊断，实际 fontselect 为 DejaVu Sans→DejaVuSans，该次直接 FFmpeg 单列计数。
