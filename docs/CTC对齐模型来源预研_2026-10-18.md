# CTC 对齐模型来源预研

这是后续语音/歌词对齐缺口的**元数据预研**，与 V48 显式描线输入分开。没有下载权重、执行新模型、注册适配器或新增强制对齐命令；描线字符时间仍由输入明确给出。OpenFilm 的固定歌曲歌词时刻不能当作通用对齐器。

本轮检查了 `facebook/wav2vec2-base-960h@22aad52d435eb6dbaf354bdad9b0da84ce7d6156` 与 `jonatasgrosman/wav2vec2-large-xlsr-53-chinese-zh-cn@99ccb2737be22b8bb50dcfcc39ad4d567fb90cfd` 两份公开模型元数据，声明许可均为 Apache-2.0。官方源在原生请求中超时，原[失败与生成器](validation/evidence/ctc-model-source-20261018/failure.json)保留；后仅通过显式开发镜像获取[API 原回复、固定提交与候选文件清单](validation/evidence/ctc-model-mirror-source-20261018/inspection.json)。这不改变产品运行时禁止联网和自动下载的约束。

英文候选 `model.safetensors` 声明 377,607,901 字节、SHA-256 `8aa76ab2243c81747a1f832954586bc566090c83a0ac167df6f31f0fa917d74a`；中文候选 `pytorch_model.bin` 声明 1,276,296,151 字节、SHA-256 `de031fd4b29e0c0667e5346450fadfe1326c89936b888b59c4ede608db763ee4`，在官方[英文权重页](https://huggingface.co/facebook/wav2vec2-base-960h/blob/22aad52d435eb6dbaf354bdad9b0da84ce7d6156/model.safetensors)和[中文权重页](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-chinese-zh-cn/blob/main/pytorch_model.bin)核对了声明摘要。**这些是来源声明，不是本地权重下载摘要或推理证据。** 中文文件尚无本轮可用的 safetensors 转换与登记，不允许将其直接当成已接入的产品模型。

后续须单独设计重复 token/blank 的 CTC 动态规划、标点和 OOV 策略、长音频窗口、明确采样/卷积时钟、事务与权利依赖，再用独立时码与真实中英文材料验证。许可声明不能替代训练数据、声音输入和具体发布用途的权利核验。本轮不把该研究纳入 V48 新能力或完整产品测试数量。
