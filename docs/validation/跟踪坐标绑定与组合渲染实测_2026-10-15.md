## 3. 真实模型样例

输入复用本地 `workspace/vision-smoke-20261015-d/reframe` 可移植项目包，人物照片/受控双实例视频、模型及原生执行器摘要沿用[YOLO 实测](./YOLO本地多目标跟踪与重构图实测_2026-10-15.md)。复现入口为 `scripts/smoke_tracking_geometry.py`；样例、权重和媒体均不纳入 Git。

受控项目保留既有动态 crop 键，增加源 scale 0.82→0.95、rotation −8°→12°、anchor (0.4,0.5)、position (0.45,0.52)，用真实 YOLO 绑定独立 TARGET 文字，offset_y=−0.10，并启用 ROI scale/源层相对旋转。第一次输出 360×640；随后 CLI 修改 fit 和 hflip，再覆盖输出为 640×360，保持同一组源观测。

两次滤镜图为 104,589 / 105,175 UTF-8 字节，通过本地文件传入，实际命令为 1,020 / 1,032 UTF-16 单元。图摘要、成片摘要、命令结果和实现文件摘要见机器证据。每个绑定采样 33 点，其中包括一个片尾隐藏端点；隐藏数不能解释成 1 帧真实遮挡。

已目视复核两版 0.5 / 3.5 秒的四张抽帧：文字跟随对应人物区域，源层旋转后标签位置稳定，横屏镜像后标签保持可读。画面为受控定位夹具，包含测试背景和较大留白，不是已验收广告设计，也不是自然遮挡或身份交叉测试。抽帧保存在本地 `workspace/vision-smoke-geometry-20261015-a/`，摘要写入机器证据。

## 4. 修复与保留边界

本轮统一文字/源层固定画布仿射，修复非方形旋转和缩放后的中心漂移；用 CFR 帧循环替代重复计数的定格拼接，修复持帧后续时钟偏移；长关键帧表达式改为平衡分支，避免深层 if 解析限制。

仍未关闭：嵌套父层全坐标组合、完整 VFR PTS、非线性扭曲、mask/遮挡可见性、分割/姿态、外观 ReID、精细字体边缘/预乘 alpha、自然素材广泛质量、高分辨率性能和商业发布许可。完整约束见[坐标空间契约](../specs/本地跟踪绑定坐标空间与渲染重算契约_v0.1_2026-10-15.md)，整体进度见[构建进度总表](../构建进度总表_2026-10-15.md)。
