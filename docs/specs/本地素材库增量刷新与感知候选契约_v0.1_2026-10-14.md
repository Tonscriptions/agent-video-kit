| 字段 | 内容 |
|---|---|
| 文档编号 | SPEC-LIBRARY-REFRESH-001 |
| 状态 | 有效 |
| 版本 | 0.1.0 |
| 日期 | 2026-10-14 |
| 适用范围 | `ai-ad-editor library index/similar` |
| 网络策略 | 禁止联网；感知候选只调用本机 FFmpeg |

## 1. 目标和边界

本契约把素材库从一次性扫描扩展为可审计的增量刷新，并提供一个轻量的画面相似候选层。它服务于 Agent 的素材预选和人工复核，不宣称具备 VLM、OCR、人物/物体识别、embedding 或版权判断能力。

`library index --incremental` 复用未变化文件的既有记录，避免重复执行媒体探测和 SHA-256；`library index --visual-hash` 通过本机 FFmpeg 抽取小型灰度帧并写入平均哈希样本；`library similar` 按哈希汉明距离返回候选组。没有感知哈希时，`library similar` 返回空组和结构化警告，不能把空结果解释为“没有相似素材”。

## 2. 增量刷新契约

```powershell
python -m ai_ad_editor library index --root .\library --output .\work\library.json
python -m ai_ad_editor library index --root .\library --output .\work\library.json --previous .\work\library.json --incremental
```

每条记录保存：

| 字段 | 语义 |
|---|---|
| `index_signature.version` | 当前为 `0.1.0` |
| `index_signature.file.bytes` | 文件大小 |
| `index_signature.file.mtime_ns` | Windows 本地文件的纳秒级修改时间 |
| `index_signature.sidecar` | 视频、音频或图片同 stem 字幕侧车的签名；无侧车为 `null` |

只有相对路径、文件 `bytes`、`mtime_ns`、侧车签名和既有记录结构同时匹配时才复用记录。媒体内容被替换但时间戳和大小被恶意保持不变的极端场景不能由 stat 增量模式发现；需要强校验时应省略 `--incremental` 做完整重建。增量模式不会保留已删除文件，顶层 `index_refresh.removed_count` 会报告本次移除数量。

顶层 `index_refresh` 至少包含：

| 字段 | 语义 |
|---|---|
| `mode` | `full` 或 `incremental` |
| `previous_catalog_id` | 增量输入目录 ID |
| `reused_count` | 复用的记录数 |
| `reindexed_count` | 重新探测、哈希和语义生成的记录数 |
| `removed_count` | 上一目录中本次扫描不到的记录数 |
| `visual_hash_count` | 当前含感知哈希样本的记录数 |

`--previous` 的 `root` 必须与当前 `--root` 解析到同一绝对目录，避免跨素材库误复用。许可证参数在刷新时仍写入当前调用值；增量复用不代表许可证证据继承。

## 3. 感知哈希样本

`--visual-hash` 只处理 `video` 和 `image`。当前算法为 `ahash-v1`：通过本地 FFmpeg 将帧缩放到 `16x16`、转灰度、以全帧均值二值化，得到 256 bit 十六进制哈希。图片取 0 秒；超过 1 秒的视频取 0 秒、中点和结束前 0.1 秒三个样本。样本结构为：

```json
{
  "version": "ahash-v1",
  "size": 16,
  "source": "ffmpeg-local",
  "samples": [{"at_seconds": 0.0, "hash": "..."}]
}
```

FFmpeg 抽帧失败只写入目录 `warnings` 的 `VISUAL_HASH_FAILED`，不会丢弃已经成功探测的媒体记录。感知哈希不是内容语义，也不能作为发布、版权、下架或自动删除依据。

## 4. 相似候选查询

```powershell
python -m ai_ad_editor library similar --catalog .\work\library.json --max-distance 12
```

`max-distance` 是两个 256 bit 哈希的汉明距离上限，默认 `12`，小值更严格。任一采样组合命中阈值时，记录通过确定性并查集合并为候选组。输出包含 `method=ahash-v1`、阈值、最小距离、成员数、记录 ID 和相对路径。候选组可以包含相同开场帧但内容不同的片段，Agent 必须把它当作 review queue，仍需人工或更高等级的本地模型复核。

## 5. 版本和能力声明

本能力将素材目录版本提升为 `0.3.0`，确定性语义索引版本提升为 `0.2.0`。能力清单必须同时声明 `incremental_stat_refresh`、`ffmpeg_average_hash_candidates`、`vector_index=false` 和 stat 信任边界。任何接入 VLM、embedding 或 OCR 的后续实现都必须另起模型适配器契约，记录模型路径、哈希、许可证、版本和推理 provenance，不能覆盖本契约的 `deterministic-local` 语义。
