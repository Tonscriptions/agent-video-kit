# 离线逐笔描线动效实测

状态：V48 所列受控描线能力核验通过。完整 **1107/1107，1677.105 秒**，0 跳过；165 文件前后字节冻结。

本轮落实 OpenFilm 示例评估 EX02 的受控子集：原字节提取两个 Canvas2D 纯函数，新增 `motion stroke-source`，接入已有透明编码、时间线、工程包、台账和本地参数重建。不引入 three.js、GUI、在线服务、模型或字体。[先行契约](../specs/离线逐笔描线动效契约_v0.1_2026-10-18.md)、[代码/两份 MIT 归属](../third-party/OpenFilm示例描线函数复用声明_2026-10-18.md)。

![原背景与实际逐笔描线](../assets/stroke-motion-verified-20261018/comparison.gif)

原视频/输出为 384×216、12 fps、36 帧/3 秒；对照为 768×216。GIF 实际为 **16 帧、2,970 ms**，相同停留帧合并，不能写成 18 帧或精确 3 秒。无原始音频；时间线 MP4 有渲染器的静音流，未听审。已看联系表中 0/18/35 三帧，未连续播放；最后时刻为 35/12 秒，不是终点 3 秒。[媒体 SHA/探测](evidence/stroke-media-final-20261018.json)、[独立静帧目检](evidence/stroke-real-verified-20261018/static-review.json)。

复现脚本为 `scripts/smoke_stroke_motion.py`，须使用已有 NumPy/Pillow 的原生 Python，提供新 public/work/evidence 路径和已有工具链 JSON。产品和安装版不依赖这两个图像审查库。`scripts/audit_stroke_release.py` 在新独立目录解包 wheel 与固定依赖，`scripts/verify_stroke_native_install.py` 另验实际安装器。所有构建与输出均在 E 盘；没有启动 Docker/WSL 或留下浏览器 tab。

## 3. 失败与未验收内容

初次专项有 1 项错误码预期失败：颜色先被通用变量检查拒绝，后将专用颜色验证提前；没有放宽颜色规则，原[失败日志](evidence/stroke-tests-20261018/targeted.log)保留。演示脚本的隔离导入路径/审查 Python 库、非法颜色预期退出码与相对输出路径均曾失败，分别修正调用和路径；未把这些运行追加到 17 次正式入口内。

[第一轮 11 次原始调用](evidence/stroke-real-20261018/cli/011.json)和[第二轮输出路径拒绝](evidence/stroke-real-final-20261018/cli/012.json)及其已编码媒体保留。独立 wheel 首次缺少 jsonschema，校验按预期拒绝成功；后按既有离线发行锁加载五个固定依赖，未重新引入成功降级。[缺依赖原记录](evidence/stroke-wheel-20261018/08.stdout.json)。原生安装器首次错误使用 `-S` 屏蔽了自身必需的 pip，返回 `PIP_REQUIRED`；修正安装调用后，已安装 CLI 继续使用 `-I -S`。[原拒绝与生成器](evidence/stroke-native-install-20261018/install.stdout.json)。GIF 审计最初误把输入列表的 18 张当作编码帧数；实际逐帧读取为 16，保留在[开发失败汇总](evidence/stroke-development-20261018.json)。

本轮没有自动字形生成、通用中文笔顺、语音/歌词强制对齐、复杂字形塑形、自然广告美学、HDR/长片或另一台干净机器验收；Canvas 笔画不是 DOM 文字布局门禁的语义覆盖。既有 FGT 自然修复失败与完整剪映功能/效果差距继续开放。
