# 主轨磁吸模式与跨剪口同步拆分契约

2026-10-18，V56，先于实现与实测声明。目标为无 GUI 的本地主轨编辑语义；原生 Windows/Python/FFmpeg，不调用网络、模型、容器或虚拟环境。完整剪映功能及质量仍是总目标，本契约只定义本轮可核验的编辑行为。

| 编号 | 约束 |
|---|---|
| MM01 | `sequence.editing.magnetic` 为严格布尔值，缺省 false。开启时主轨必须从 0 开始、无间隙无重叠；空主轨合法。主轨仍由 main_track_id 或最小 order 的 video 选择。序列尾部可以有更长的副轨。 |
| MM02 | `timeline edit` 的 `{action:magnet,enabled:true/false}` 保存模式；开启会按既有顺序闭合主轨间隙，返回可审阅计划，禁止隐式裁切原有重叠。关闭只改变模式。已有 sync/linkage/linked 设置保留；未明确设置 sync 时，磁吸模式默认 true，普通模式仍 false。可以通过现有 update_sequence 写入字段，但不满足主轨不变量时必须使用开启动作规划，不能直接写入无效项目。 |
| MM03 | 磁吸模式下主轨 `shift` 按所选块最早起点加 delta_tick 取得目标，吸附到删除选择后剩余主轨的最近原始边界；距离相同时取较早边界。以稳定原顺序插入该边界，随后紧邻排列。负请求拒绝。副轨 shift 保留既有行为。选中非主轨与主轨混合移动拒绝，避免猜测拖拽层级。 |
| MM04 | 磁吸模式主轨 remove 将关联扩展后的主轨区间从后向前 extract，保留 sync_lock/linked/linkage 的既有闭包，自动裁切跨剪口同步内容；副轨 remove 沿用普通模式。主轨普通 lift 或有空洞的 incoming insert 不产生磁吸例外，最终校验拒绝。标记和序列级自动化维持绝对时钟；缩短后的越界点仍拒绝，须显式处理。 |
| MM05 | compose 的主轨 append_clip/append_sequence_clip 使用最近原始剪口的 insert；没有起点则追加到主轨尾。完整来片相对起点为 0，保留作者源范围、曲线/倒放/定格/动画和权利。主轨 remove_clip/slide_clip 转交模式规划器；副轨仍使用原语义。主轨 trim_clip 用原可见窗口内的头尾 extract，关联处理与输出窗口沿用范围契约；不同时接受独立移动落点，移动另作 shift。 |
| MM06 | 模式不是绕过几何校验的开关。其他作者改写若留下主轨间隙/碰撞，事务拒绝；改变速度、曲线或定格并自动重排关联源内容，以及所有剪映手势，仍须后续完整实现与验收。整批 compose、dry-run、摘要锁、快照、幂等和原生包继续适用。最终提交保持模式不变量；关联规划前还会校验中间工程，不能依赖无效的中间布局通过该入口。构建批次可先关闭模式，最后再显式开启。 |
| MM07 | reorder 新增 `sync_span_policy: reject/split`。普通模式缺省 reject，保持 V53；磁吸模式缺省 split。split 仅在 sync 开启时，对跨不同主轨位移或跨主轨间隙的同步副片段自动分段。直接关联到主轨的片段仍以显式关联宿主为准，不改成按覆盖画面切分。sync_lock=false 且没有显式关联的轨道维持原位。 |
| MM08 | 自动分段使用完整作者图之后的 presentation_window，保持原 source_in/out、速度曲线、倒放、定格、音频包络、字幕和嵌套处理。第一个分段保留原片段 ID，其余使用全项目避碰的确定性 ID。原主轨间隙/首镜头前的内容固定在原时钟，尾部按既有规则随末镜头；不丢弃未托管内容，碰撞按既有等效轨道规则解决。 |
| MM09 | 对需要切分的副轨关联组，在同一旧主轨边界共同分区，并为后续区域分配新 link_id；每个原片段的所有非空输出分段完整覆盖原可见半开区间，不重叠、不重算源时钟。未发生切分的关联组保持旧 ID/冲突规则；锁定成员、真实源转场端点、跟踪绑定源/目标及旧式跨片段转场仍明确拒绝自动切分。不得放宽非线性轨道/命名检测源的自动换轨限制。 |
| MM10 | 规划不执行解码或渲染；输入与输出片段总数均最多 20,000，预计超限在扩张前拒绝。切分、分区、原区间、新区间、新轨道、字幕偏移和引用变化必须进入计划。JSON/schema、原生包与片段组保留模式和结果；外部格式继续报告 editing/window/关联损失，不能以旁车等同目标软件执行。 |
| MM11 | 验收必须包含普通模式控制、模式反复开关/落点等距/空主轨/持久化、实际 append/remove/shift/trim、不同偏移的跨剪口音频/字幕/嵌套作者窗、关联分区/避碰 ID/sync opt-out、锁/引用/非线性/资源拒绝、快照/摘要/幂等/包与安装后复现。公开自制原帧/PCM 和真实成片/GIF，不以布局图替代实际输出。 |
| MM12 | 原始帧和原 PCM 的独立重排参考与使用同版渲染器的复杂作者图参考分计。PCM 门槛不放宽既有 2e-6；逐帧/采样长度及源身份必须核对。静帧、连续播放、人工听审、自然广告和长片资源分别记录。所有开发失败、中断和未实现边界保留，不声称完整剪映等价。 |

磁吸序列的局部片段组保存扩展到该序列全部片段，并在 selection 报告扩展项，以保留主轨从零紧邻的不变量；不静默关闭模式或改变作者时钟。跨项目仍重映射 main_track_id 和全部片段/关联引用。

本轮是对 [V53 重排](主轨磁吸重排与关联附着契约_v0.1_2026-10-18.md)、[范围编辑](范围编辑插入覆盖与滚滑剪口契约_v0.1_2026-10-18.md)与[输出窗口](片段输出窗口裁切与波纹编辑契约_v0.1_2026-10-18.md)的扩展。音频路由仍遵守 [V55 固定效果顺序和完整子时钟](命名音频总线发送返回与侧链契约_v0.1_2026-10-18.md)。
